## Finding 1

**Annotate `oos_issue_stdout` path must be explicit in `step5b_annotate_main`.**

The plan calls `file_oos_annotate_main` with `--issue-stdout-file str(oos_issue_stdout)` but never defines `oos_issue_stdout`. Bash binds it at `design-step5b-annotate.sh:91` as `$DESIGN_TMPDIR/oos-issue.stdout.txt`. Without an explicit bind, annotate can fail at runtime or read the wrong file while the failure branch greps `oos-issue.stdout.txt` for `ISSUES_FAILED`.

**Suggested revision:** After the non-empty `DESIGN_TMPDIR` guard, set `oos_issue_stdout = design_tmpdir / "oos-issue.stdout.txt"` and use that path for the in-process annotate call and for the failure-path `ISSUES_FAILED` check.
