## Edge cases

- Preserve fail-open pruning on runtime parse and I/O failures, but keep usage errors as exit 2.
- Preserve aggregate original-file state on dispatch, validation, strip, move, or plan-tag parity failures.
- Keep aggregate candidate outputs rejected when missing, empty, symlinked, or outside `--review-tmpdir`.
- Preserve plan-mode scope-reduction blocks and reject accidental merges into those blocks.
- **Plan-mode prune must not partially commit**: if findings were rewritten on disk but OOS append fails, restore the pre-prune findings snapshot and emit `STATUS=skipped`; never leave nit blocks removed without matching OOS append.
- Keep accepted security OOS local only.
- Keep latent non-accepted findings routed to OOS instead of rejected findings.
- Keep parent-tmpdir artifact copies when `--session-env-path` or `--implement-tmpdir` is present.
- Preserve quiet-mode contract streams. Human diagnostics must not corrupt stdout KV contracts.
- Preserve `LARCH_PLAN_REVIEW_PRUNE_NITS_SH` override semantics via `PLAN_REVIEW_PRUNE_NITS_CLI` array expansion in decoded embedded `plan-review-loop.sh` after the default retarget to `review prune-nit-findings`.
- Remove tracked doc references to retired compose shell paths before or with `migrated-scripts.tsv` append so `make lint-retired-scripts` does not fail on `SECURITY.md` or `docs/run-logs.md`.

## Failure modes

- A subtle TSV formatting change can break downstream logs. Keep headers and row cell order byte-compatible.
- A changed aggregate validator can cause either unsafe merged findings or excessive validation failures. Port the current regexes and reasons exactly before refactoring.
- Deleting retired paths before all references are removed will fail `make lint-retired-scripts` and Makefile harness shards.
- Python temp writes must use same-directory temp files so cross-device renames do not change behavior.
- A partial `_rewrite_prune_asset` miss that swaps only the default path string (without `PLAN_REVIEW_PRUNE_NITS_CLI` array expansion) leaves `/design` plan-review with rc 127, fail-open `prune-nit.env` (`STATUS=skipped`), and silent ballot composition drift before tally.
- A naive plan-mode Python port without two-file rollback can silently drop nit findings from `findings-in-scope.md` when OOS replace fails, producing under-counted ballots without a visible hard error.
