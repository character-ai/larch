## Plan

Port **/implement bootstrap/admission entry machinery** from Bash to Python, preserve live orchestration contracts, cut over every caller, replace retired harnesses with pytest, then delete absorbed Bash scripts and stale Makefile targets.

### Approach

Follow the sh-to-py playbook:

- Port behavior into **importable Python functions** first.
- Register **CLI verbs** in `python/cli.py`.
- Cut over all direct callers before deletion.
- Preserve **exit codes**, **stdout contracts**, **stderr diagnostics**, **env fallback behavior**, and **atomic file rules**.
- Replace Bash harness coverage with pytest.
- Delete absorbed scripts and `.md` siblings only after all callers are cut over and the migrated manifest is updated.

Three new runtime modules:

- **`python/bootstrap.py`**: bootstrap phases, invoke wrapper, routing-envelope write behavior, routing-envelope parser.
- **`python/admission.py`**: admission gate, git preflight, fork env.
- **`python/dirty_tree.py`**: dirty-tree detector, recovery scope check, scope-reduction marker detector.
