## Edge cases

- A fresh `.cap-hit` from the current Cursor tier must still make `_raw_is_scout_json()` return false immediately after the Cursor tier.
- `.cap-hit` cleanup must happen before a tier starts, not after it exits.
- `max_archetypes=0` must keep returning early with an empty manifest.
- Reachable over-cap dynamic-scout coverage should use `max_archetypes > 0`.
- Cursor Step 2 same-path normalization must not truncate the manifest before filtering reserved archetypes.
- The Cursor Step 2 test must use `$TMPDIR/scout-coder-manifest.json`, not a `cursor-step2-out/` path.
- The Cursor Step 2 stub must use `STUB_MANIFEST_PATH`, not `STEP2_MANIFEST_PATH`.
- The Cursor Step 2 stub must export `LIB_CURSOR_AUTH_TEST_UNAME="Linux"` with the Cursor auth-test env.
- The Cursor Step 2 stub must use the Cursor `agent` argv shape, where the wrapped prompt is the final argument.
- The Cursor Step 2 stub must not require Codex-only `--output-last-message`.
- Scope-anchor CR/LF tests must not depend on creating literal CR/LF paths on disk.

## Failure modes

- If `.cap-hit` cleanup runs after a tier, a real current-tier cap hit can be hidden.
- If the cap-hit regression test only pre-seeds `.cap-hit` and Cursor does not recreate it, the test can miss the real Cursor-to-Claude stale-marker bug.
- If a new fallback test uses `max_archetypes=0`, it will not launch Cursor or Claude.
- If the Cursor same-path test writes to a subdirectory, it does not cover Cursor dispatcher behavior.
- If the Cursor same-path test uses `STEP2_MANIFEST_PATH`, it can miss the existing Cursor launcher contract.
- If the Cursor same-path test copies the Codex `--output-last-message` contract, it may not exercise the Cursor launcher path.
- If the Cursor same-path test does not run inside a scratch git repo with Cursor auth-test env, it may fail before scout materialization.
