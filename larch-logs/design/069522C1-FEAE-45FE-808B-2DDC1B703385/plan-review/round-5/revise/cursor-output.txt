## Edge cases

- If only Cursor survives waterfall, map it to Voter 3 by tool name.
- If waterfall exits nonzero, continue with partial KVs.
- If `dispatch-waterfall` is invoked without `--mode description`, `agent_waterfall._parse_args` rejects it; the port must always forward `--mode description`.
- If `dispatch-waterfall` omits `--timeout 1200`, externals inherit the default `1800`s timeout and harness timing assumptions drift.
- If waiter emits `TIMEOUT` rows and exits 0, treat those rows as timeouts.
- If waiter exits nonzero, log a usage/config warning and continue.
- If `LARCH_VOTER_WAIT_TIMEOUT` is unset, use `60`, not `wait_reviewers` default `1860`.
- If Voter 1 returns output before its launcher-owned sentinel appears, do not mark it complete until after the waiter barrier.
- If retry succeeds, preserve first-pass output before replacing the canonical voter output.
- If retry fails, leave the original output and diag in place.
- If a missing binary causes a skipped external, do not count it as degraded.
- If an available voter fails or produces non-substantive output after retry, count the panel as degraded.
- If `render voter` fails or ballot-pointer validation fails, abort before any voter launch (exit `2`).
- If `voting parse-rate-retry` is invoked without `--launch-mode` or other required `VPR_ARGS` fields, retry relaunch fails or diverges from bash behavior.
- If `--round-num` is omitted, default to `1` before validation (match retired bash and happy-path harness).
- If pytest uses bare `tmp_path` / `pytest-*` review tmpdir names without a harness segment, `should_suppress_parse_rate_issue_append()` may return false and NOT_SUBSTANTIVE append-failure calls can mutate a live parent `LARCH_EXECUTION_ISSUES_LOG` or `IMPLEMENT_TMPDIR/execution-issues.md` during `make py-test`; nest env-isolation cases under `test_agent_voters.*` and extend `is_harness_review_path()` accordingly.
- If inherited `/implement` env vars are present during tests, avoid appending fixture diagnostics to the live run log.
- If helper subprocesses emit diagnostic KVs, suppress them so `review-core.sh` capture of dispatcher stdout stays parseable.
- If Voter 1 `append-failure --site` drifts from `agent dispatch-voters voter1` while parse-rate uses `agent dispatch-voters`, execution-issues triage and pytest site assertions break.
- If `agent_voters.py` hardcodes `Path(__file__)` for child CLI paths while `CLAUDE_PLUGIN_ROOT` points at a stub plugin root, harness stub interception fails and late-sentinel / parallel-dispatch regressions exercise the wrong code or flake.

## Failure modes

- **KV drift** can break `review core` and tally parsing. Add exact KV tests.
- **Helper stdout pollution** can strip `VOTER_*` KVs from `review-core-voters.env`. Redirect or capture all non-final child stdout.
- **Waterfall argv omission** can hard-fail external dispatch (`--mode` required) or silently change voter wall-clock (`--timeout` default). Assert full argv in pytest.
- **Incomplete parse-rate argv** can break `NOT_SUBSTANTIVE` retry relaunch because `voting.py` requires `--launch-mode` and per-slot prompt/file args. Assert `VPR_ARGS` parity in pytest.
- **Soft-fail render/validation** can launch voters with empty prompts and corrupt the panel. Keep fail-closed exit `2` before launch.
- **Wait-timeout regression** can turn 60s harness timeouts into ~31 minute stalls. Always pass explicit `--timeout`.
- **Serial dispatch regression** can slow or fail the panel. Keep the #3704 concurrency test.
- **Harness-path guard drift** can let pytest env-isolation regressions append parse-rate diagnostics into real execution logs when parent env vars are inherited. Extend `is_harness_review_path()` for `test_agent_voters.` and assert suppression in both `test_voting.py` and `test_agent_voters.py`.
- **Retired-reference lint failures** can appear after adding `migrated-scripts.tsv` rows. Sweep ballot fixtures, tally comments, docs tables, and structure-test prose before closeout.
- **Review-core command quoting** can break if the default command is stored as one shell word. Use an invocation helper or array, not a string with spaces.
- **Overbroad C1b edits** can scope-creep into #3677. Limit C1b changes to voter-dispatch call sites and stale comments.
- **Mixed site/dispatch-label tokens** can break execution-issues grep triage (`agent dispatch-voters voter1` vs legacy `dispatch-code-voters.sh voter1`). Pin both in code and pytest.
- **Stale shrink-not-backfill docs** in `docs/voting-process.md` or `docs/agents.md` can contradict live `agent dispatch-voters` behavior after cutover.
- **Plugin-root resolution drift** can break harness stub trees and production cache installs: child calls must honor `CLAUDE_PLUGIN_ROOT` with the same fallback as `agents._plugin_root`, and `--plugin-root` passed to parse-rate must use the same resolved path.

  - `python3 -m pytest -q python/test_agent_voters.py`
  - `python3 -m pytest -q python/test_voting.py python/test_review_tally.py python/test_review_pipeline.py`
- Run Makefile targets for the retargeted voter slices:
  - `make test-dispatch-code-voters-happy`
  - `make test-dispatch-code-voters-edge-and-r3-claude`
  - `make test-dispatch-code-voters-retry-claude`
  - `make test-dispatch-code-voters-retry-codex-success`
  - `make test-dispatch-code-voters-retry-cursor`
  - `make test-dispatch-code-voters-retry-codex-fail-and-fallback`
  - `make test-dispatch-code-voters-regressions-r1-r2`
  - `make test-dispatch-code-voters-regressions-r3-codex`
- Run migration lint:
  - `python3 python/cli.py lint retired-scripts`
- Run required gates:
  - `make py-lint`
  - `make py-test`
  - `make lint`
