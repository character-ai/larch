1. **[correctness] scripts/design-log-publish.sh:352-356**  
The proposed render-cache root rejection remains behind `[[ -e "$DESIGN_TMPDIR/render-cache" ]]`. A dangling symlink at that path makes `-e` false, so none of the root `-L`, directory, canonicalization, or tree-wide checks run. That contradicts the proposed real-directory contract and leaves a root symlink edge case publishing as success. Revise the guard to include `|| [[ -L ... ]]` and add a dangling root symlink test.

2. **[security] AGENTS.md:17-19; SECURITY.md:139**  
This is a security-relevant publication hardening change, but the plan does not update `SECURITY.md`. The current security note only calls out `plan-review/` as the stricter subtree. Add render-cache symlink fail-closed behavior there so the public-boundary artifact contract stays current.

3. **[security] scripts/design-log-publish.sh:205-247; scripts/design-log-publish.sh:387-388**  
The proposed per-file check reduces the race but does not close it as claimed. `design_publish_stage_file` still silently returns success for symlink/non-file sources and later uses `cp`, which follows a source that becomes a symlink after its own `-L` check. For render-cache’s hardened path, staging should fail on symlink/non-regular replacement and use a stronger no-follow or post-copy validation strategy, or the plan/docs should avoid claiming the race is closed.
