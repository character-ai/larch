## Edge cases

- Empty-output notification coverage must be **per-file** with anchored `check_context` blocks; do not pin Step 5c prose as a stand-in for Anti-pattern #5.
- Gantt tests should use deterministic widths and seconds.
- Final-report fixtures must seed round meta, timing ledger, and vendor timing locally; without them the integration test can pass vacuously.
- Aggregator tests must preserve original findings on failed validation.
- Pre-commit fast-fail test must use a real failing pre-commit stub and counter stubs; asserting direct-target execution in the same test encodes an impossible path because `_run_relevant_checks_inner` returns before `_direct_targets` when pre-commit fails.
- Relevant-check completeness must assert **full union sets** for overlapping paths (structure tests + anti-polling + generic `python/*.py` py-test where applicable), not only the newly added target.

## Failure modes

- Per-file literal pins may still be brittle if anchors drift; keep anchors on normative section headings (Anti-pattern #5, NEVER #8, shared wait rule paragraphs).
- A final-report integration test can become noisy if it asserts the whole summary. Assert the phase-detail subset only and the negative fallback strings.
- Aggregator tests may duplicate existing issue-specific tests. Prefer small invariant-level tests with names that describe the family.
- Adding anti-polling rows to `_DIRECT_TARGET_RULES` overlaps existing `AGENTS.md` / `skills/*/SKILL.md` rows by design; tests must expect the union, and implementers must not drop existing structure targets when merging patterns.
