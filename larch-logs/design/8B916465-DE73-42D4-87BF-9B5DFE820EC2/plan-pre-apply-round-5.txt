### Shared delivery-channel contract (define once; paste or cross-reference at every emit site)

**Read-to-orchestrator-text rule:**

1. Do **not** use Bash, Python, or any other tool invocation to print the final-summary body for user-visible delivery.
2. After `<task-notification>`, use **`Read`** on the completed background-task output (or the `${FINAL_SUMMARY_PATH:-$DESIGN_TMPDIR/final-summary.md}` fallback when markers are absent/invalid and the file is non-empty).
3. In orchestrator context (not via another tool call), locate the first balanced whole-line `LARCH_FINAL_SUMMARY_BEGIN` / `LARCH_FINAL_SUMMARY_END` marker pair in the Read result and slice the body between them.
4. Write the sliced body **directly as orchestrator chat markdown**.
5. If using the fallback file, still write the **entire** Read result as orchestrator chat text (no marker slice needed when the file is the source of truth).
6. Do **not** pipe, `cat`, `python3 -`, `sed`, or `awk` the body for user-visible delivery.
7. **`Read` brings text into context only**; user-visible delivery is orchestrator chat text, not tool stdout.

**Machine KV lines in the same Read result** (e.g. `REPORT_GATE_SIDECARS_FILE=<path>`): locate the KV line in the Read result in orchestrator context, then **`Read` the referenced sidecar file** and emit **that file's full body** as orchestrator chat text immediately after the final-summary body. Do **not** re-parse or extract marker/KV content via Bash or Python tool calls.

**Mandatory full-body inventory (apply at every emit site):** The verbatim emission must include the **entire** marker-delimited (or fallback-file) body, not a subset. Required sections when present in the rendered block:

- title (`## /design run ...` or `## /implement run ...`)
- mode
- duration
- cost line with per-agent breakdown
- tokens
- all top-level bullets
- **`## Review Phase Detail`** (round acceptance table and per-round ASCII Gantt charts)

Emitting only Duration / Cost / Plan-review / OOS top-level bullets while omitting `## Review Phase Detail` is a **contract violation**, even when the markers contain the appendix. Partial top-level bullets alone do not satisfy "verbatim emit."
