## Feature context

> Brainstorm how to add ability to pause to /design, so it can save its state in issue, retain temp directory, and resume later

This is the GitHub issue #2959 in the larch repo. larch is a Claude Code plugin (skills + scripts) under `/Users/zhupanov/larch8`. The `/design` skill is a multi-step workflow (Steps 0 → 6) that takes a feature issue from clarifying questions through reviewer panels to an approved implementation plan written back into the issue body as a `larch:plan` block.

## Round 1 user-resolved scope (binding constraints — do not contradict)

1. **Cross-session full restore.** All state must live on GitHub (issue body and/or comments) so resume works from any machine even if `$DESIGN_TMPDIR` is gone.
2. **Trigger.** User presses Escape or Ctrl-C at any point and explicitly asks to pause. Not automatic crash-recovery.
3. **Pause granularity.** Anywhere — including mid-sketch and mid-plan-reviewer.
4. **Generalization.** Build a shared helper (under `scripts/`) that `/implement` and `/review` can later adopt; do not implement those adopters here.
5. **In-flight externals.** Abandon — kill the launcher, discard partial output, re-launch fresh on resume.
6. **Resume grammar.** Plain `/design <N>` auto-detects paused state and resumes. No explicit flag.
7. **Cycles.** Unbounded pause → resume → pause → resume.
8. **Concurrent issue-body edits.** Warn but continue; paused-state marker wins.
9. **Rollout.** Always-on once landed; no feature flag.
