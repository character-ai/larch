Exploring codebase files referenced in the plan to validate contracts and integration points.
Review findings on the proposed pause/resume plan:

1. **[architecture]** `skills/design/SKILL.md` Step 0b — Sub-step **0b.6** is placed before clarify (3), already-planned (4), tier gate (5), and `write-run-params.sh` (6), but resume routing only says to skip **0c+**. On `LOAD_OK=true`, those later **0b** substeps can still run and overwrite restored `run-params.json`, re-trigger clarify/already-planned prompts, or reset tier flags.

2. **[correctness]** `scripts/design-pause-load.sh` (proposed) — `git archive --remote origin … | tar -x -C "$DESIGN_TMPDIR"` is not viable on GitHub (no `git-upload-archive`). Resume fetch will fail in normal clones.

3. **[correctness]** `scripts/design-pause-load.sh` (proposed) — Published artifacts live under `larch-logs/design/<RUN_ID>/` ([`docs/run-logs.md`](docs/run-logs.md)), not at `$DESIGN_TMPDIR` top level. Blind `tar -x` into `$DESIGN_TMPDIR` leaves files under a nested prefix instead of restoring `run-params.json`, `.brainstorm-done`, etc.

4. **[integration]** [`scripts/design-log-publish.sh`](scripts/design-log-publish.sh) — Publish copies only maxdepth-1 **files** plus `plan-review/` and `render-cache/` ([`scripts/design-log-publish.md`](scripts/design-log-publish.md)); it does not stage `$DESIGN_TMPDIR/.completed/`. New `.completed/step-*` sentinels (and repeat-pause STEP recompute after resume) will not round-trip, conflicting with “preserved through the log-branch snapshot” and test (f) unbounded cycles.

5. **[architecture]** `scripts/design-pause-load.sh` (proposed) — SKILL.md calls `design-pause-load.sh --issue $ISSUE_NUMBER` only; the script must take `--design-tmpdir` (the fresh dir from Step 0a) and likely `--repo` for forked targets. Without that, load target is undefined.

6. **[integration]** [`skills/pause/SKILL.md`](skills/pause/SKILL.md) — `/larch:pause` sources `current-design-env-$PPID.sh` and requires `ISSUE_NUMBER`, but [`skills/design/SKILL.md`](skills/design/SKILL.md) only **may** re-invoke `write-design-current-env.sh` with `--issue-number` after 0b; Step 0a never writes it. Pause can report “no live session” while `/design` is active.

7. **[integration]** [`scripts/design-log-publish.sh`](scripts/design-log-publish.sh):159-169 — Pause idempotent overwrite covers local `branch -D` only. The existing “branch already checked out in another worktree” guard still fails republish for the same `RUN_ID`, blocking the second pause in a cycle.

8. **[correctness]** [`scripts/design-log-publish.sh`](scripts/design-log-publish.sh):441-443 — Empty `git status --porcelain` returns `PUBLISH_OK=true` without applying `--reason pause` / `.paused=true`. Repeat pause on an unchanged tree can skip manifest pause metadata.

9. **[code-quality]** Plan failure modes reference `PAUSE_OK=false` / `ERROR=…` from `design-pause-save.sh`, but the NEW script spec only documents exit 0 and omits stdout KV lines the orchestrator must parse after `exec`.

10. **[correctness]** `scripts/design-pause-save.sh` (proposed) — “Lexicographically-smallest unfinished step” should be “first registry row in [`step-name-registry.tsv`](skills/design/scripts/step-name-registry.tsv) without `step-<id>` sentinel”; string sort diverges from workflow order for some IDs.

11. **[architecture]** [`skills/design/scripts/step-name-registry.tsv`](skills/design/scripts/step-name-registry.tsv) — Step **0c** exists in SKILL.md but has no registry row; plan leaves add as conditional. Pause STEP breadcrumbs should require the `0c` row.

[OUT_OF_SCOPE] **[security]** `SECURITY.md` — No trust-model note for new `pause-requested-<ISSUE>.flag` files beside `current-design-env-<PID>.sh` (same `~/.cache/larch/sessions/` surface).

[OUT_OF_SCOPE] **[architecture]** [`docs/issue-anchored-plan.md`](docs/issue-anchored-plan.md) — `larch:design-pause` body marker not added to the LIVE wire-format doc (only AGENTS.md catalog).

[OUT_OF_SCOPE] **[integration]** [`scripts/test-design-log-publish.sh`](scripts/test-design-log-publish.sh) / `Makefile` — No plan update to cover `--reason pause` branches (idempotent branch, commit subject, `manifest.paused`).

[OUT_OF_SCOPE] **[integration]** [`scripts/test-design-structure.sh`](scripts/test-design-structure.sh) — No structural pin for the two-line Bash prelude + anti-pattern #7; regression risk across ~30 prelude copies.
