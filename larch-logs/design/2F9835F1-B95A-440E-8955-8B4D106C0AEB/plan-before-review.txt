## Approach

Extend the existing `/analyze-bugs` coordinator rather than creating a second workflow. Pin each sweep to the synced `origin/main` tip. Enumerate first-parent commits after the saved marker, or from the prior 48 hours on first use.

Exclude log-only and release commits before ranking. Rank chronic-zone commits first, then larger diffs. Sweep at most `--sweep-max` commits and report the omitted count. A successful capped sweep advances the marker to the pinned tip, so skipped commits are an explicit budget omission rather than a deferred queue.

Build one bounded evidence bundle per selected commit. Include the capped diff, touched files, chronic-zone tags, and a minimal bounded scan for consumers of changed Python symbols. Dispatch the finder once per bundle, then dispatch a refuter for each bounded finding. Treat malformed, missing, or incomplete agent output as a failed sweep.

Render surviving findings in `Sweep candidates`. Add them to the existing combined follow-up body. Keep the existing approval gate and invoke `/issue` with dedup enabled.

## Edge cases

- A first sweep with no commits in 48 hours completes with zero findings and records the pinned tip.
- A later sweep with only excluded commits also completes and advances the marker.
- A capped sweep reports omitted commits and advances to the pinned tip by design.
- A force-pushed or unrelated saved marker fails rather than silently widening the window.
- Empty finder results are valid only when every selected merge has one well-formed row.
- A finder candidate that the refuter rejects never enters the report or follow-up body.
- An empty refutation queue is a successful zero-candidate result.
- Existing non-sweep runs neither read nor write sweep state.

## Failure modes

- Git enumeration, diff, or consumer scans that cannot produce bounded evidence abort the sweep.
- Malformed agent JSONL, missing merge coverage, or missing refutations abort before report rendering.
- A stale pinned tip or state identity mismatch aborts rather than mixing evidence from different main revisions.
- Report or follow-up-body failure leaves the prior sweep marker intact.
- `/issue` filing failure does not rewrite sweep analysis state because analysis completed before the separately approval-gated mutation.
