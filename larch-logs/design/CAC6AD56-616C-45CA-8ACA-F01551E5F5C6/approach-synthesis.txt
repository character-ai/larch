## Concrete divergence resolution

5. **Critical finding from this very `/design` session**: Cursor and Codex sketch launches in Step 2a.2 **failed with exit 127** because `CLAUDE_PLUGIN_ROOT` was unset in the orchestrator's outer environment, `write-design-current-env.sh` skipped writing it (its line 127 logic requires non-empty caller value), and the awk recovery snippet is gated on `SESSION_ENV_PATH` (always empty in standalone). This is exactly the "removing the awk snippet without first ensuring CLAUDE_PLUGIN_ROOT is reliably available will break standalone /design" risk Codex flagged. The plan must close this gap as part of Step 0.

   **Resolution**: in `Step 0a`, before invoking `session-setup.sh`, the orchestrator must establish `CLAUDE_PLUGIN_ROOT` from a deterministic source. Two viable paths:
   - **(A)** Hard-code the canonical fallback derivation: `CLAUDE_PLUGIN_ROOT="${CLAUDE_PLUGIN_ROOT:-$(dirname "$(dirname "$(readlink -f "${BASH_SOURCE[0]:-$0}")")")}` style — but SKILL.md is read by Claude, not sourced as bash, so this doesn't apply directly.

Add a one-line `export CLAUDE_PLUGIN_ROOT='<literal expanded path>'` to the very top of Step 0a's Bash block (before `session-setup.sh` is called). The `write-design-current-env.sh` invocation then captures this value into source-env.sh, and all subsequent blocks resolve `${CLAUDE_PLUGIN_ROOT}/...` correctly via the single-line prelude.
