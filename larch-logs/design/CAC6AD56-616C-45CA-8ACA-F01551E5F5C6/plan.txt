## Tradeoffs and key decisions

1. **CLAUDE_PLUGIN_ROOT template form**: author SKILL.md with the literal `'${CLAUDE_PLUGIN_ROOT}'` template token on disk. Claude Code's SKILL.md loader expands `${CLAUDE_PLUGIN_ROOT}` to the install-time path when sending the SKILL.md to the orchestrator. **Risk**: if Claude Code stops expanding `${CLAUDE_PLUGIN_ROOT}` inside Bash string literals, the orchestrator would see the literal `${...}` token at runtime, and `${CLAUDE_PLUGIN_ROOT}/scripts/...` paths would fail with exit 127. Mitigation is honest: the static CI assertion (A5 above) verifies the template-token form is on disk and ordered correctly, but cannot exercise the expansion mechanism itself. A runtime smoke is out of scope for this PR; the PR description should note this limitation per FINDING_7's prose-honesty option.

2. **Negative-grep idiom**: the four new structure assertions use `! grep -Eq PATTERN FILE` (negate the exit code). This is the standard shell idiom for "assert absent" and avoids the `grep -Eqc ... must return 0` semantic trap (since `grep -q` exits 1 on zero matches, an implementer following that wording could write a harness that fails exactly when SKILL.md is clean).

3. **Sweep-to-zero is binding**: the per-bullet enumeration in §1 above is informational; the binding rule is `grep -n SESSION_ENV_PATH skills/design/SKILL.md == 0`. SKILL.md currently carries 82 occurrences across many sections (per `wc -l` count); enumerated bullets cannot catch them all without missing some. The implementer must edit any residual occurrence not covered by the bullets — verbosity-control prose, timing-ledger env prefixes, Step 3 tally `printf` heredoc, etc.

4. **`tally-plan-review.md` sibling doc**: `.claude/rules/script-md-siblings.md` requires every `.sh` script to keep its `.md` sibling synchronized in the same PR. The plan now includes this file (was missing in the first plan revision).

5. **`dispatch-plan-voters.sh` `--session-env-path` flag retention**: the dispatcher's argv parser keeps the `--session-env-path` flag because it is used by other callers (`/review`, `/implement`); only `/design`'s use is dropped. This is consistent with the user's Step 1c scope decision (top-level helpers untouched).

6. **Anti-pattern renumbering vs. keep gaps**: renumber to keep the list 1-5 contiguous. Verified: no surviving rule cross-references the deleted #4 or #7 numbers (Anti-pattern #1 references the Step 0 router carve-out, #5 references the dialectic guardrail, #6 references timeout families — none mention #4 or #7).

7. **`/implement` tally-batch flushing removal**: dropping `PREV_IMPLEMENT_TMPDIR` and `POST_PLAN_WORKFLOW_PATH` from `tally-plan-review.sh` means `/implement` cannot drive `/design`'s plan-review tally back into an `/implement` log batch. This was already non-functional (since /design is standalone-only after #2588); the dead code masked it. Removing it makes the contract explicit. PR description should note this for any future nesting redesign.

8. **Aggressive simplification vs. conservative**: aggressive (chosen). Issue acceptance "Bash block prelude shrinks to the single source-line" requires deletion of conditional structure, not just hard-coding to standalone branch.

9. **Helper-script scope**: `scripts/session-setup.sh` and `scripts/test-session-setup-*.sh` are NOT touched. `--caller-env` remains live for `/review` and `/implement`. Scope is `/design` subtree only.

## Edge cases

- **Stale CLAUDE_PLUGIN_ROOT in orchestrator shell**: the new `export CLAUDE_PLUGIN_ROOT='${CLAUDE_PLUGIN_ROOT}'` line in Step 0a unconditionally overwrites any pre-existing value with the install-time path. Safe.
- **Multiple concurrent `/design` sessions (the #2599/2602 PID-key scenario)**: unaffected. The `current-design-env-$PPID.sh` symlink scheme remains; the awk-snippet removal does not touch PID keying.
- **`$DESIGN_TMPDIR` cleanup on failure**: unchanged. Standalone log target preserved across failure paths via existing `cleanup-tmpdir.sh` gating.
- **`tally-plan-review.sh` callers outside SKILL.md**: only SKILL.md Step 3 invokes the tally action. Safe to drop the argv. Test the script after edits.
- **Cross-skill references in `skills/shared/*.md`**: these mention `--caller-env` for `/review` and `/implement` callers, NOT for `/design`. They stay unchanged.
- **Plugin upgrade path**: if a user has an in-progress `$DESIGN_TMPDIR` from the previous plugin version, the awk-snippet was a defensive fallback. The conditional prelude `[ -f ... ] && source ...` is preserved, so a stale tmpdir without the source file degrades silently. New code expects the source-env always exists (Step 0a writes it).

## Failure modes

1. **CLAUDE_PLUGIN_ROOT template expansion does not occur**: the `export CLAUDE_PLUGIN_ROOT='${CLAUDE_PLUGIN_ROOT}'` literal stays in the Bash block, the orchestrator sees the unexpanded `${...}` token, sketch launches fail with exit 127 on `${CLAUDE_PLUGIN_ROOT}/scripts/launch-review.sh`.
   - **Earliest warning**: the next `/design` invocation from a fresh Claude session fails Step 2a sketch launches with exit 127.
   - **Mitigation (honest)**: the new structure assertion A5 verifies the template-token form is on disk and ordered correctly (`export CLAUDE_PLUGIN_ROOT='${CLAUDE_PLUGIN_ROOT}'` appears before `session-setup.sh`). The static CI cannot exercise the runtime template-expansion mechanism; if Claude Code regresses on expansion, the failure surfaces only at runtime. A separate runtime smoke harness is out of scope for this PR. Document the limitation in the PR description.

2. **Hidden SESSION_ENV_PATH reference in a non-obvious file**: the binding subtree sweep rule (`grep -rn SESSION_ENV_PATH skills/design/` == 0) and the new structure-test assertions A3/A4 catch this. If the assertions fail, edit the residual occurrence.
   - **Earliest warning**: `bash scripts/test-design-structure.sh` fails with the new A3/A4 assertion.

3. **`tally-plan-review.sh` consumer in a forgotten code path**: only SKILL.md Step 3 invokes the tally action; no other consumer in the repo (verified by grep). The argv drop is safe.
   - **Earliest warning**: `bash skills/design/scripts/test-tally-plan-review.sh` fails on argv parse.
