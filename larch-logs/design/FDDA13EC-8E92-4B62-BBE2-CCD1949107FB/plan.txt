## Approach

Keep the fix surgical.

- **Option A** absorbs short macOS Keychain write locks inside preflight.
- **Stderr suppression** prevents transient `security` failures from leaking during retry attempts.
- **Test mock determinism** makes retry tests hermetic and prevents accidental fallback to real `security` calls.
- **Option B, scoped** preserves a defense-in-depth live fallback without running the full retry loop after confirmed preflight failure.
- **Option B parity** keeps the one-shot branch aligned with the normal Cursor setup chain.
- **Option B terminal behavior** initializes `AUTH_ATTEMPT` and maps any nonzero one-shot probe result to `CURSOR_PRESENT=false`.
- **Setup test wiring** makes child-process tests deterministic when real libraries are sourced.
- **Option C** prevents transient negative results from poisoning later probes.
- **Codex stamp parity** keeps login and env-key stamp paths under the same negative-TTL policy.
- **Option C tests** set a positive general stamp TTL so negative-TTL behavior is actually exercised.
- **No public quiet mode** avoids adding a shared lib contract for a single caller need.
- **No deferred stderr replay** keeps `check-reviewers.sh` simpler and inside the approved Options A, B, and C scope.
- Docs are updated with the new env, stamp, preflight, fallback, and test-mock contracts.

## Edge cases

- **Production retry stderr:** every `security find-generic-password` attempt remains silent with `>/dev/null 2>&1`.
- **Final actionable stderr:** after all retry attempts fail, direct callers keep the existing final diagnostic behavior.
- **Mock precedence:** non-empty `LIB_CURSOR_AUTH_TEST_SECURITY_RC_SEQ` wins over `LIB_CURSOR_AUTH_TEST_SECURITY_RC`.
- **Single-value mock:** when the sequence is unset or empty, `LIB_CURSOR_AUTH_TEST_SECURITY_RC` applies to every retry attempt.
- **Sequence exhaustion:** repeat the last test sequence value.
- **Production mode:** ignore test mock variables.
- **Preflight succeeds:** use the existing full live retry loop.
- **Preflight fails with exit `2`:** run the normal setup chain, then run only one live probe if setup succeeds.
- **Setup fails:** skip the one-shot probe and report `CURSOR_PRESENT=false`.
- **Private config setup runs:** cleanup always runs afterward.
- **One-shot probe runs:** set `AUTH_ATTEMPT="$MAX_AUTH_RETRIES"` first.
- **One-shot probe returns nonzero:** treat it as terminal failure with no retry.
- **Live fallback succeeds:** write a `true` Cursor stamp.
- **Live fallback fails:** write a `false` Cursor stamp.
- **Raw probe stderr:** do not leak it.
- **`LARCH_PROBE_TTL_SECONDS=0`:** all stamps remain disabled before polarity logic runs.
- **Negative TTL tests:** set `LARCH_PROBE_TTL_SECONDS=3600` so the stamp reaches polarity logic.
- **Codex login stamps:** negative TTL applies when `OPENAI_API_KEY` is unset and login mode is used.
- **Codex env-key stamps:** negative TTL applies if that stamp path is used.
- **Mid-run refresh:** existing refresh paths that bypass stamps still work.
