## Edge cases

- **Legacy writer call:** If `--claude-pid` is omitted, keep current warning behavior and do not create a launcher.
- **Launcher write failure:** If launcher creation fails, `write-design-env` returns nonzero.
- **Executable contract:** The generated launcher must have a valid shebang and executable mode bits.
- **Nested shell hazard:** Do not change the documented `$PPID` semantics.
- **Plugin root propagation:** Export `CLAUDE_PLUGIN_ROOT` in the launcher before exec.
- **Plugin root missing or invalid:** If `--claude-pid` is set, fail closed before writing the launcher.
- **Pause/resume harness:** CI calls that pass `--claude-pid` must also provide a valid `CLAUDE_PLUGIN_ROOT`.
- **Launcher symlink target:** Reject symlinked launcher paths or guarded ancestors before writing.
- **Invalid script name:** The launcher rejects paths and parent traversal before exec.
- **Resume refreshes:** Later `write-design-env` calls may rewrite the same launcher. That is acceptable and idempotent.
- **Per-fence boilerplate regression:** Structure tests reject `--session-env-path` and `--claude-pid` in launcher-routed fences.
- **Reference drift:** Reference prose must not preserve separate prelude instructions next to launcher commands.

## Failure modes

- If #4019 has not landed first, this change can spend work rewriting fences that #4019 removes.
- If the pause/resume CI harness calls `write-design-env --claude-pid` without `CLAUDE_PLUGIN_ROOT`, it can fail for the wrong reason.
- If the launcher lacks a shebang or executable mode, every post-Step-0a fence can fail before reaching its wrapper.
- If launcher writing fails but `write-design-env` exits 0, Step 0a can report false success.
- If `--claude-pid` allows a missing or invalid plugin root, the launcher can bake a broken exec path and defer failure.
- If the launcher path or ancestor symlink guard is skipped, launcher creation can be redirected.
- If `CLAUDE_PLUGIN_ROOT` is not exported by the launcher, wrappers that check plugin root before sourcing session env can fail.
- If Step 3 prose keeps manual sourcing or pause handling, orchestration can duplicate wrapper-owned behavior.
- If reference prose keeps old pause-prelude instructions, docs can direct extra prelude work before launcher commands.
- If the structure regex misses one old fence, always-loaded boilerplate remains.
- If a launcher fence spans multiple physical lines, it violates the acceptance shape.
- If the validator rejects quoted argv or braced `:?` parameter expansion, valid one-line launcher fences can fail the structure test.
- If a launcher-routed fence passes `--session-env-path` or `--claude-pid`, boilerplate remains despite using the launcher.
- If a reference keeps the old inline command, docs drift from the new contract.
- If Step 0a fails before writing the launcher, later fences cannot run.
