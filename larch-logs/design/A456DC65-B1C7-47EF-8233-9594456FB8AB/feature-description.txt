## Plan

## Implementation Plan — sh-to-py B2: tokens/timing/cost accounting modules

### Approach

Port 20 token/timing/cost bash scripts to two Python modules following `docs/python-migration.md`. The work falls into five phases:

1. **Implement Python modules** — extend `python/tokens.py` and create `python/timing.py`.
2. **Register CLI verbs** — add `token` and `timing` domains to `python/cli.py`.
3. **Cut over consumers** — update every bash caller to invoke `python3 .../cli.py <domain> <verb>` and update Python callers (`checks.py`, `run_logs.py`) to import directly.
4. **Delete retired artifacts** — scripts, `.md` siblings, bash test harnesses.
5. **Sweep and verify** — update `python/migrated-scripts.tsv`, run `make lint + py-lint + py-test`.

**token-report.sh / timing-report.sh reconcile**: `token-report.sh` renders per-session token reports by parsing Claude transcripts (742-line jq script). Reconcile by porting to Python using stdlib `json` for transcript parsing and reusing `report_tokens_cost.py` for per-bucket pricing — no jq dependency. `timing-report.sh` renders TSV timing data; port to `timing.py` directly. Both `run_logs.py` reference constants are updated to call Python functions.

**harness-timer.sh**: Used as the universal Makefile test wrapper in ~200+ targets. Migrate by bulk-updating the Makefile with `sed -i 's|bash scripts/harness-timer.sh |python3 python/cli.py timing harness-mark |g'`. The `timing harness-mark` verb replicates the 14-line script's behavior exactly.

**step-telemetry-mark.sh** already calls `python3 cli.py session read-key`; its remaining calls to `token-ledger.sh` and `timing-ledger.sh` are replaced by calling the new Python verbs.

**lib-* files** are sourced-only; their logic becomes module-level constants/validators in the corresponding Python module.

## Edge cases

- **`validate_ledger_path` traversal**: reject paths containing `../`, symlinks that escape allowed roots. Mirror the bash `validate_under_roots` behavior using `Path.resolve()`.
- **`token-ledger.sh` vendor `"claude"` rejection**: preserve this invariant in `TokenLedger.record_vendor()` — raise `ValueError` for vendor `"claude"`, accept `"claude_sub"`.
- **`TokenLedger.mark` needs jq in bash but Python uses stdlib json**: no jq dependency in Python path.
- **`timing-ledger.sh record-round` end < start**: clamp duration to 0, set status to `unknown`. Preserve in `TimingLedger.record_round`.
- **`token-report.sh` transcript scanning**: transcript JSONL files can be large. Use streaming `json.loads` line-by-line; do not read all into memory at once.
- **`harness-timer.sh` exit propagation**: `harness_mark_main` must propagate the inner subprocess exit code as its own exit code (not swallow it).
- **Makefile `$@` pattern**: the `$@` expands to the make target name. In `timing harness-mark $@ bash scripts/test-foo.sh`, `$@` is correctly the first positional argument.
- **`token-tally.sh` dir validation**: must accept paths under `/tmp/` and larch cache session root only — mirror the bash `validate_dir` logic in `TokenTally`.
- **`checks.py` direct import**: after cutover, `checks.py` imports `tokens` and `timing` at the top level. Both modules must be importable without side effects.

---

## Failure modes

- **CLI dispatch mismatch**: if a `token` or `timing` verb is registered in `cli.py` but maps to a non-existent function, `cli.py` returns exit 2 with a clear error. All callers use `|| true` for telemetry calls, so a missing function degrades gracefully in production. Tests catch dispatch mismatches.
- **Stale bash reference post-delete**: `make lint-retired-scripts` catches any tracked file still referencing a retired path. All 20+ scripts must be in `migrated-scripts.tsv` before the PR merges.
- **`run_logs.py` direct call failure**: if `token_report()` or `TimingReport.render()` raises, `run_logs.py` catches exceptions in the same place it previously checked `is_file()` — wrap in `try/except` with the same `|| true` semantics.
