## Implementation Plan: sh-to-py B2, tokens/timing/cost accounting modules

_Tier: SIMPLE. Approach: hard cutover, no shell shims, pytest replaces retired bash harness coverage._

### Scope corrections from accepted review

- **Do not delete before full cutover.** Every live caller of the retired scripts must move to `python3 .../python/cli.py <domain> <verb>` in the same change set as deletion.
- **Keep `tokens.py` stdlib-only at import time.** `measure-md-cost` and `measure-realized-cost` keep their `tiktoken` boundary lazy or subprocess-isolated, with diagnostics only for those verbs.
- **Preserve hydrated report environments.** Direct `run_logs.py` rendering must preserve `_report_subprocess_env` semantics by passing explicit paths or an env mapping into token and timing report resolution.
- **Keep checks timing skill as `implement`.** Do not derive `TimingLedger.skill` from checks site names.
- **Do not narrow token ledger vendors.** Reject only literal vendor `claude`; accept arbitrary non-claude vendor rows. Keep `codex`, `cursor`, and `claude_sub` as dedicated ordered report lanes.
- **Timing vendor allowlist includes Claude.** `timing.py` must accept `codex`, `cursor`, and `claude` vendor-task rows.
- **Timing vendor output stores basenames only.** `record_vendor_task` stores `Path(output).name`, then sanitizes before appending. It must not write absolute output paths.
- **Retain bounded timing ledger locks.** Use exclusive `flock` with bounded wait. On timeout, warn, skip append, and never write unlocked.
- **Do not add harness telemetry.** `timing harness-mark` is sentinel-only. It runs the child, prints `LARCH_HARNESS_TIMING`, and returns the child exit code.
- **Do not add new report text format.** Token and timing reports support `markdown` and `json` only. Preserve `--markdown` as an alias for `--format markdown`.
- **Pin timing JSON schema.** Preserve keys consumed by run-log and summary readers.
- **Cut over live design token marks.** Include the Step 0 `/design` `token-ledger.sh mark` call in `skills/design/SKILL.md`.
- **Preserve Step 2 token budget windows.** Keep existing Step 2 gating. Do not double-record or move marks for active Codex/Cursor external-runner flows.
- **Do not conflate `/research` token tally with ledger aggregation.** `token-tally.sh` becomes lane sidecar write/report verbs, not JSONL ledger summing.
- **Preserve Claude transcript usage deduplication.** Streaming transcript parsing must keep current request/message dedupe keys and null-id fingerprint behavior.
- **Preserve safe Claude session-id grammar.** `token claude-source` only accepts session ids matching `^[A-Za-z0-9_-]{1,128}$`; bad ids fall back safely instead of selecting unsafe paths.
- **Use flat Python imports.** Runtime modules import `tokens` and `timing`, not `python.tokens` or `python.timing`.
- **Use the manifest schema.** `python/migrated-scripts.tsv` gets one `path<TAB>#3671` row per deleted path. No symbol column.
