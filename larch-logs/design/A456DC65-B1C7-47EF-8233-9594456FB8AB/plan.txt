## Implementation Plan: sh-to-py B2, tokens/timing/cost accounting modules

_Tier: SIMPLE. Approach: hard cutover, no shell shims, pytest replaces retired bash harness coverage._

### Scope corrections from accepted review

- **Full cutover before deletion.** Every live caller of retired scripts must move to `python3 .../python/cli.py <domain> <verb>` before deletion.
- **One pricing authority.** Move token-cost arithmetic, env-rate parsing, display-rate defaults, and `DisplayRates` resolution into `python/report_tokens_cost.py`. Update `report_tokens_cli.py`, `report_tokens_render.py`, and `tokens.py` to delegate there.
- **Stdlib-only token import.** Keep `python/tokens.py` importable without `tiktoken`. Lazy-load or subprocess-isolate `measure-md-cost` and `measure-realized-cost`.
- **Hydrated report environments.** Preserve `_report_subprocess_env(ctx)` semantics when `run_logs.py` calls Python directly.
- **Test `run_logs.py` integration.** Add `python/test_run_logs.py` coverage that stubs token and timing renderers, asserts hydrated env propagation, refresh JSON writes, and both larch-log batch calls.
- **Keep checks timing skill as `implement`.** Do not derive `TimingLedger.skill` from checks site names.
- **Token vendors.** Reject only literal vendor `claude`. Accept arbitrary non-Claude vendor rows.
- **Token report dynamic vendor objects.** Preserve the current JSON sibling object for every arbitrary non-Claude vendor, each with `per_step` and `totals`. Keep `codex`, `cursor`, and `claude_sub` as ordered costed lanes.
- **Token JSON schema.** Pin consumed fields: each vendor `totals` object keeps numeric `input`, `output`, `cache_read`, `cache_create`, and `total`; each `per_step` item keeps `step` plus a `totals` object with those fields.
- **Timing vendors.** Accept `codex`, `cursor`, and `claude` vendor-task rows.
- **Timing output basenames.** `record_vendor_task` stores `Path(output).name`, then sanitizes. It never writes absolute output paths.
- **Timing ledger validation.** Reject traversal, symlink escapes, symlink ledger paths, directories, FIFOs, sockets, devices, and any existing non-regular ledger file before append.
- **Bounded timing ledger locks.** Use exclusive `flock` with bounded wait. On timeout, warn, skip append, and never write unlocked.
- **Harness telemetry.** `timing harness-mark` is sentinel-only. It runs the child, prints `LARCH_HARNESS_TIMING`, and returns the child exit code.
- **Report formats.** Token and timing reports support only `markdown` and `json`. Preserve `--markdown` as an alias for `--format markdown`.
- **Timing JSON schema.** Preserve keys consumed by run-log and summary readers.
- **Design workflow path fallback.** For `LARCH_TIMING_SKILL=design`, resolve `workflow_path` from `DESIGN_TMPDIR/run-params.json` first, then the ledger dirname. Implement reports must not inherit polluted `DESIGN_TMPDIR`; their workflow path remains unknown unless implement data provides it.
- **Dump stdout contract.** `token dump` and `timing dump` print the resolved ledger path on stdout line 1, then ledger contents when present. No-root telemetry-safe cases keep current no-stdout behavior.
- **Bootstrap marks.** `scripts/implement-bootstrap.sh` has four token/timing mark sites: preflight, tracking issue, plan materialization, and coder select. Cut over all four and preserve label bytes exactly, including labels such as `Step 0 — preflight`.
- **Design token marks.** Include the Step 0 `/design` `token-ledger.sh mark` call in `skills/design/SKILL.md`.
- **Step 2 budget windows.** Keep existing Step 2 gating. Do not double-record or move marks for active Codex/Cursor external-runner flows.
- **Research tally separation.** `/research` token tally becomes lane sidecar write/report verbs, not JSONL ledger summing.
- **Claude transcript dedupe.** Preserve request/message dedupe keys and null-id fingerprint behavior.
- **Claude session id safety.** `token claude-source` only accepts `^[A-Za-z0-9_-]{1,128}$`; bad ids fall back safely.
- **Flat imports.** Runtime modules import `tokens` and `timing`, not `python.tokens` or `python.timing`.
- **Manifest schema.** `python/migrated-scripts.tsv` gets one `path<TAB>#3671` row per deleted path. No symbol column.
- **Lint-fix-loop test harness.** Include `scripts/test-lint-fix-loop.sh` in the cutover inventory. Retarget its sandbox stubs to `python3 .../cli.py token record-vendor`, or remove copied retired scripts once launchers call Python.
