## Edge cases

- **Agent-lint pins:** A shorter paragraph can still fail if a literal path pin disappears. Keep exact pinned path strings.
- **S017 frontmatter:** The `description:` line is outside the prose body but still lint-gated. Any edit to that line risks `desc-no-trigger` even when token targets are met.
- **Closure harvesting:** `MANDATORY — READ ENTIRE FILE` and `Read … completely` clauses are harvest anchors, not generic prose. Paraphrasing them alters direct markdown closure membership. Do not add or remove always-loaded references unless already required by the existing prose.
- **design-background-wait.md anchors:** Multiple `Read and apply … design-background-wait.md completely` lines are separate harvest surfaces; compress surrounding prose only.
- **Line ratchet headroom:** Avoid increasing `skill_md_lines` while reducing tokens. The new ratchet includes lines and tokens.
- **Contract prose:** Some repetition is intentional for compaction resilience. Leave repeated NEVER, anti-halt, background wait, and continuation directives intact.
- **Baseline freshness:** A shrink passes the one-way growth check but fails `test_committed_baseline_matches_fresh_scan` unless the baseline is regenerated.

## Failure modes

- The token reduction is too small because edits only remove blank lines or light wording.
- `scripts/test-design-structure.sh` fails because a pinned literal moved, disappeared, or changed spelling.
- `agent-lint` fails because an S030/S017 literal was removed or because `description:` lost its `Use when …` trigger form.
- `agent-lint` or closure drift because a `MANDATORY — READ ENTIRE FILE` / `Read … completely` line was paraphrased and no longer harvests the same reference file.
- `skill-closure-growth` fails because the baseline was not regenerated, closure references changed unintentionally, or `--write` ran after a harvested `files` entry dropped.
- Plan-review behavior changes if mandatory Step 3 launch, dynamic scout, voting, or tally wording is weakened. Keep those directives explicit.
