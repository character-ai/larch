### Edge cases

- Production `run_relevant_checks` / `_finish_logged_result` currently always returns `skipped=False`; `RELEVANT_CHECKS_SKIPPED=true` is emitted only when the child sets `skipped=True` and `--allow-skip` is present. This PR wires composites to pass `--allow-skip` so skip envelopes are honored when emitted; it does not add new production skip sites in `checks.py`.
- A skipped relevant-checks child must be treated as pass-like only when it emits `RELEVANT_CHECKS_SKIPPED=true`.
- A timed-out checks leg with partial skip or pass output must still fail closed as `checks-leg-timeout`.
- Composite skip success envelopes differ by entrypoint: `checks_commit_route_main` emits `NEXT_ACTION=continue`; `checks_step5_resume_main` relays skip output and runs the resume leg without emitting composite `NEXT_ACTION=continue` on success.
- Composite skip integration tests must mock downstream commit/resume (and 7.r when flagged) legs; mocking only `_run_leg_with_timeout` still exercises real subprocess paths and can flake offline.
- The rebase checkpoint budget must affect only the Step 6 composite path that runs folded `7.r`; Step 5 self-review and other `14700000` pins stay unchanged.
- Bumping only the Python constant without SKILL/structure pins recreates the latent `7.r` kill; all three surfaces must move together for Step 6.
- Existing direct `implement run-step-checks` behavior should remain unchanged unless it intentionally needs `--allow-skip`; this plan does not change it.
- Runtime-dispatch tests should not depend on actual Codex, Cursor, Claude, git, or gh availability.

### Failure modes

- If `--allow-skip` is omitted from composite argv, legitimate skip envelopes still route to `checks-failed` even when the child would emit `RELEVANT_CHECKS_SKIPPED=true`.
- If the rebase budget is added to the wrong composite or SKILL fence, Step 5 self-review timing may expand unnecessarily.
- If only `CHECKS_COMMIT_ROUTE_OUTER_TIMEOUT_MS` changes while SKILL/structure literals stay at `14700000`, pytest budget tests may pass while runtime still kills folded `7.r`.
- If composite skip tests mock `_run_relevant_checks_for_site`, they pass even when argv omits `--allow-skip`.
- If composite skip tests mock only `_run_leg_with_timeout` without downstream leg mocks, tests may invoke real commit/resume/7.r subprocess paths and flake or fail offline despite passing the skip assertion.
- If composite skip tests assert `NEXT_ACTION=continue` on `checks_step5_resume_main`, CI fails or encodes the wrong contract relative to SKILL and `implement_dispatch.py`.
- If `agent_voters` tests only mirror registry tuples after import, runtime dispatch can drift while registry tests still pass.
- If `voting-protocol.md` updates overcorrect, `/design` plan-review voter docs may become stale.
