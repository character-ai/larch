`python/implement_dispatch.py` `_run_relevant_checks_for_site` (~line 743) invokes `checks run-relevant` **without** `--allow-skip`. `python/checks.py` `checks_run_relevant_main` (~line 1136) prints `RELEVANT_CHECKS_SKIPPED=true` **only** when `--allow-skip` is set. Fix: pass `--allow-skip` from `_run_relevant_checks_for_site` (matching the `python/review_and_fix.py` path that already handles skip), and add a regression test for the skip→continue path on the composite sites. Originally raised in the #5283 review (run E79F3F0B, round 2); rejected below threshold.

Fix: give the folded rebase leg its own budget allocation in the outer timeout (or raise `_COMPOSITE_OUTER_SLACK_MS` to cover a worst-case rebase), and add a timeout-budget assertion. Originally raised in the #5399 review (run 33A6D738, round 1); rejected below threshold.
