## Failure modes

- A malformed scout block could otherwise break plan drafting. Make scout parse fail-open when the plan remains valid.
- A malformed scout block inside the plan could contaminate `plan.txt`. Sanitize misplaced scout spans and assert no scout markers or scout JSON remain.
- Requiring summary sentinels could reject currently valid no-summary drafter output. Keep summary zero-or-one.
- Reordering summary after the plan could reject existing summary-before-plan output. Preserve legacy summary-first acceptance.
- Moving `diff_lines: <N>` outside the plan block could break extracted plan artifacts. Keep it inside the plan block and test that `plan.txt` ends with it.
- A stale design manifest could add reviewers from a prior inline fallback. Clear stale sidecars before inline fallback review.
- A stale implement manifest could add reviewers from a prior run. Clear stale sidecars before external launches and Claude fallback exits.
- A weak drafter validation path could bypass reserved-slug and cap rules. Filter with existing wrapper rules before canonical write.
- A supplied valid pre-scout file could bypass low-risk dynamic skips. Keep classifier skip gates ahead of pre-scout synthesis.
- A supplied invalid pre-scout file could accidentally trigger the old scout. Treat supplied-invalid as static-only.
- A valid pre-scout file could be accepted without dynamic slot synthesis. Share the successful scout synthesis path.
- A missing external coder sidecar could re-enable per-round scout. Use the external-scout eligibility marker and pass pre-scout mode anyway.
- A missing Step 2 eligibility marker could re-enable per-round scout. Force static-only review from `run-step5-review.sh`.
- Claude fallback could re-enable legacy scout if no pre-scout flag is passed. Force static-only review for Claude fallback Step 5.
- Repurposing `step2-spawn-coder.txt` could break tmpdir reuse guards. Preserve it and add a separate eligibility marker.
- Generated implementer prompts can drift from `agents/_implementer-base.md`. Regenerate both generated files and update rendering tests.
- Tests may pin exact prose. Quote edited literals verbatim in grep assertions.
