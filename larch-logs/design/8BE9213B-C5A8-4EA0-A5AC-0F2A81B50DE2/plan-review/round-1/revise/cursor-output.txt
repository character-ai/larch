## Edge cases

- `MANIFEST_PATH` is empty on manifest-reuse, Claude fallback, bailed Step 2, and other non-dispatch paths.
- A design manifest env file is not a valid ship manifest.
- Step 5 can stall before Step 8 and may already have seeded `ship-pr-state.sh`; Step 8 must not re-seed.
- Step 8 re-entry after OOS filing, CI repair, transient retry, or conflict handoff must invoke only `step-8-ship.sh`.
- Re-seeding on re-entry would overwrite driver-progressed keys (`PHASE`, `PR_NUMBER`, stall keys, `ITERATION`, `RESUME_PHASE`, etc.).
- Python &lt;3.11 on first Step 8 entry must hit the STALLED JSON fallback **before** `seed-initial-state`, not exit 2 from the seeder alone.
- Phantom probe `PHANTOM_*` KVs must not corrupt the JSON stdout contract.
- `NO_ADMIN_FALLBACK=true` must survive driver state refreshes once allowed in `_ALLOWED_SHIP_STATE_KEYS`.

## Failure modes

- Seeder validation failure or create-if-absent refusal should stop before `oos file` and before the ship driver.
- A non-empty invalid `MANIFEST_PATH` should fail early with clear stderr and no partial state file.
- A symlinked state or temp path should fail closed.
- Attempting to seed when a non-empty state file already exists should fail closed with a clear initial-create-only error.
- Unexpected phantom probe failure may stop the wrapper under `set -e`; the helper is intended to exit 0, so do not mask failures unless tests show an existing advisory contract requires it.
