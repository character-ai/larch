## Edge cases

- **Missing CI checkpoint `RUN_ID`:** treat as stale on timeout recovery. This prevents old delegates from being trusted.
- **Lint-fix no-op before `main-agent-required`:** stall as before. Do not create empty commits.
- **Lint-fix commit failure:** fail closed with a stall reason. Do not proceed toward ship with dirty work.
- **Step 7a flush on rebase failure with `--no-logs-commit`:** emit `skipped-no-logs-commit`; preserve probe rc; do not imply a committed flush occurred.
- **Step 7a flush failure on probe failure:** surface the degraded/failed flush status while preserving the probe rc.
- **Design-OOS partial success:** keep filed URLs visible, but do not create the complete sentinel or seed the cross-session cache, either of which would suppress re-filing on rerun.
- **Execution-issues idempotency:** source truncation remains valid only when the sentinel matches or the batch already contains all normalized sections.
- **Contract drift:** any Step 7a flush-behavior change must land with `rebase-checkpoint-routing.md`, `step-7a.md`, `test-step-7a.sh`, and `test-step-7a.md` in the same PR so runtime and harness stay aligned.

## Failure modes

- **Tally write fails:** Step 5 stalls with `tally-flush-failed`; final report may avoid stale tally data.
- **Timing row write fails:** `_record_coder_vendor_task` remains best-effort and must not block main-agent fallback.
- **Finalize read-key fails:** defaults are used, and teardown still runs.
- **Run-log flush fails during Step 7a rebase failure:** the failure status is emitted, and the original rebase failure rc is preserved.
- **OOS annotate partial failure:** rerun can file failed blocks because no complete sentinel exists.
- **Stale Step 7a docs/harness:** PR fails `test-step-7a.sh` or leaves operators reading a retired `skipped-rebase-checkpoint` contract.
