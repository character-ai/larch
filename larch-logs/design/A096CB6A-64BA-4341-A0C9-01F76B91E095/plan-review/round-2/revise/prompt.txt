## Approach

Keep `scripts/hook-anti-read-poll.sh` as the Claude hook entrypoint, but make it a thin fail-open wrapper around `python3 "${PLUGIN_ROOT}/python/cli.py" hook anti-read-poll`.

### Ingress and early exit

- Read hook JSON from stdin once.
- Parse `tool_name` immediately after JSON decode. On any non-`Read` event (including `Bash`), exit 0 with no stdout and perform **zero** state-directory opens, hashing, or filesystem mutation.

### Session-key and cwd contract (preserve shipped partitioning)

Pin the exact ladder from the current Bash hook:

1. `cwd` from JSON; default empty/missing `cwd` to `/` (`${cwd:-/}`).
2. `session_id` from JSON; if empty, `conversation_id` from JSON.
3. `session_key`:
   - if the resolved session id string is non-empty → use it;
   - elif `HOOK_ANTI_READ_POLL_DISCRIMINATOR` is set → `nosession-${HOOK_ANTI_READ_POLL_DISCRIMINATOR}`;
   - else → `nosession`.
4. `cwd_hash` = stable digest of the defaulted cwd string.
5. `session_hash` = stable digest of `session_key`.
6. State basename = `read-${cwd_hash}-${session_hash}.state` (never embed raw cwd or session strings in filenames).

Use `hashlib` for digest components instead of shell `cksum`. Existing advisory state may reset once after upgrade.

### On-disk state contract (preserve shipped layout)

- State root: `${TMPDIR:-/tmp}/larch-read-poll`.
- State row file: tab-separated `path_hash&lt;TAB&gt;offset&lt;TAB&gt;count&lt;TAB&gt;epoch`.
- `path_hash` = digest of `tool_input.file_path`; **never** persist or compare raw paths in state files.
- Fail open on empty/missing `file_path`.
- `offset` defaults to `0`; non-numeric offsets default to `0`.

### fd-bound mutation

- Open the temp root and `larch-read-poll` using `os.open(..., dir_fd=..., O_DIRECTORY, O_NOFOLLOW)` where available.
- Create the state directory relative to the verified parent fd.
- Run `os.fchmod(state_dir_fd, 0o700)` on the opened directory fd, not by path.
- Read and write state files relative to `state_dir_fd`.
- Create temp state files with `os.open(temp_name, O_CREAT | O_EXCL | O_NOFOLLOW, 0o600, dir_fd=state_dir_fd)`.
- Promote with `os.replace(temp_name, state_name, src_dir_fd=state_dir_fd, dst_dir_fd=state_dir_fd)`.
- Reject unsafe state basenames and non-regular state entries. Do not follow symlinked state files. If cheap, unlink a symlinked leaf state entry relative to the verified directory fd before replacing it with a regular state file.


- `additionalContext` is fixed literal text; it must never contain the requested path, basename, offset, cwd, or session identifiers.
- Use `json.dumps` with stable key order sufficient for tests to parse and assert shape.

### Wrapper contract

## Edge cases

- `TMPDIR` may be absent, non-directory, symlinked, or removed during execution. Fail open.
- Platforms may lack `O_NOFOLLOW`, `O_DIRECTORY`, or full `dir_fd` support. Use feature checks where needed, but keep the safety posture conservative. If fd binding cannot be enforced, fail open rather than falling back to path-based mutation.
- `hashlib` digest format differs from legacy `cksum`; advisory counters may reset once after upgrade.
- Absent session metadata must not fail open solely for missing ids; use the `nosession` ladder instead.
- Concurrent hook invocations may race. Use exclusive temp names and atomic replace. A lost advisory count is acceptable; writing outside the verified state directory is not.
- The hook must never block tool use because Python, JSON parsing, filesystem validation, or state writing failed.

## Failure modes

- A wrapper that exits non-zero can make Claude Code treat the advisory hook as failed. Force exit 0.
- A helper that prints diagnostics to stdout can inject unexpected hook context. Print only the structured reminder on the exact threshold.
- Echoing `file_path` into `additionalContext` or state files reintroduces prompt-injection risk. Keep both path-free.
- A path fallback after fd validation would reintroduce TOCTOU bugs. Keep all state reads, temp creation, chmod, unlink, and replace relative to the verified fd.
- Tests that only check symlink preconditions may miss the swap-after-check window. Keep at least one seam test that swaps after creation and before verified open.
- Bash pre-parsing stdin before Python can desync ingress or skip events. The wrapper must inherit stdin unchanged.
