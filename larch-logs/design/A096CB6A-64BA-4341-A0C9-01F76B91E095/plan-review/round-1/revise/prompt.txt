## Edge cases

- `TMPDIR` may be absent, non-directory, symlinked, or removed during execution. Fail open.
- Platforms may lack `O_NOFOLLOW`, `O_DIRECTORY`, or full `dir_fd` support. Use feature checks where needed, but keep the safety posture conservative. If fd binding cannot be enforced, fail open rather than falling back to path-based mutation.
- State filename hashing can change. This only resets advisory counters.
- Concurrent hook invocations may race. Use exclusive temp names and atomic replace. A lost advisory count is acceptable; writing outside the verified state directory is not.
- The hook must never block tool use because Python, JSON parsing, filesystem validation, or state writing failed.

## Failure modes when non-trivial

- A wrapper that exits non-zero can make Claude Code treat the advisory hook as failed. Force exit 0.
- A helper that prints diagnostics to stdout can inject unexpected hook context. Print only the structured reminder on the exact threshold.
- A path fallback after fd validation would reintroduce the bug. Keep all state reads, temp creation, chmod, unlink, and replace relative to the verified fd.
- Tests that only check symlink preconditions may miss the swap-after-check window. Add at least one test seam that swaps after creation and before verified open.
