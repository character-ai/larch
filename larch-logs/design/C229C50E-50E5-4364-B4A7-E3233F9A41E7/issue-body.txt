## Description

`python/agent_waterfall.py` `_load_slots` (around line 273) raises `ValidationError` on the first slot row that sets neither `agent` nor `prompt_file`, which aborts the entire `/design` Step 3 plan-review panel before any reviewer launches — the failure mode behind #4765. After the #4765 producer fix every emitted row is valid, but the consumer stays fail-closed: a single future malformed or unrenderable slot would still take down the whole panel and ship an unreviewed plan. Defense-in-depth follow-up (plan Open Question #3): teach the panel path to drop a single invalid or unrenderable slot and continue launching the remaining valid slots (recording the drop as a degraded-panel warning), instead of aborting all reviewers. Suggested scope: change `_load_slots` (or the dispatch wrapper in `python/plan_review_panel.py`) to collect per-row validation errors, skip the bad row, and proceed when at least one valid slot remains; add a test for the mixed valid/invalid manifest case. Out of scope for the #4765 field fix because it changes the consumer's deliberate fail-closed validation contract, which is a separate design decision.
