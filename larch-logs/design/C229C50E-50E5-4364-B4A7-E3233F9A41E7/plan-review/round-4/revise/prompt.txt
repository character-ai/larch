## Edge cases

- **Bad JSON row before a valid row:** skip it only with `--skip-invalid-slots`.
- **Non-dict row (scalar or array):** skip it at waterfall load with the flag; downstream manifest readers skip it via `iter_jsonl_dicts`.
- **All rows invalid:** fail closed even with the flag; no launches, no paths file.
- **Blank lines only:** keep the current no-slot-rows failure.
- **Output path contains newline:** treat as structurally invalid and droppable only with the flag.
- **Missing prompt file:** do not drop at load time.
- **Invalid-slot sidecar write failure:** fail closed before any `_launch_slot`; no paths file; no running reviewers.
- **Existing no-fallback result drops:** keep `DROPPED_SLOTS_FILE` separate from invalid manifest drops.
- **Panel succeeds with drops:** round completes; operator sees `DEGRADED_PANEL_WARNING` at Step 3 boundary via result env and wrapper stdout replay.

## Failure modes

- If the invalid-slot sidecar cannot be written pre-launch, raise `ValidationError` before any `_launch_slot` call; partial panels from late sidecar failure are explicitly out of scope.
- If the panel cannot read the sidecar, still emit a generic `DEGRADED_PANEL_WARNING` using the count.
- If the waterfall exits non-zero, preserve current panel failure reporting instead of converting it to a degraded warning.
- If `execute_round` manifest readers regressed, a mixed manifest could still crash collection during `_compose_findings_from_collector`; the `iter_jsonl_dicts` guard is the mitigation.
