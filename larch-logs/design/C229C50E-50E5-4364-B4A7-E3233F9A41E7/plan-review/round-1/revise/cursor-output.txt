## Plan

Implement graceful degradation at the shared waterfall boundary, but keep it opt-in. Close the downstream manifest-reader and Step 3 propagation gaps identified in review.

- Add `--skip-invalid-slots` to `agent dispatch-waterfall`.
- Keep default `_load_slots` behavior unchanged.
- When the flag is set:
  - collect structurally invalid slot rows,
  - skip them,
  - launch the valid slots,
  - fail closed if no valid slots remain.
- Write the invalid-slot sidecar **before any reviewer launch**.
- Have `plan-review panel-dispatch` pass the new flag.
- Surface skipped rows as a visible `DEGRADED_PANEL_WARNING`.
- Harden `plan_review_round` manifest readers so non-dict rows cannot crash collection after a successful degraded dispatch.
- Propagate `DEGRADED_PANEL_WARNING` through the production `/design` Step 3 result boundary.

Do not drop rows whose `prompt_file` is missing or empty. The loader does not check prompt-file readability today, and that stays out of scope.

## Edge cases

- **Bad JSON row before a valid row:** skip it only with `--skip-invalid-slots`.
- **Non-dict row:** skip it at waterfall load with the flag; downstream manifest readers skip it via `iter_jsonl_dicts`.
- **All rows invalid:** fail closed even with the flag.
- **Blank lines only:** keep the current no-slot-rows failure.
- **Output path contains newline:** treat as structurally invalid and droppable only with the flag.
- **Missing prompt file:** do not drop at load time.
- **Invalid-slot sidecar write failure:** fail closed before any launch; no paths file.
- **Existing no-fallback result drops:** keep `DROPPED_SLOTS_FILE` separate from invalid manifest drops.
- **Panel succeeds with drops:** round completes; operator sees `DEGRADED_PANEL_WARNING` at Step 3 boundary.

## Failure modes

- If the invalid-slot sidecar cannot be written, raise `ValidationError` before any `_launch_slot` call.
- If the panel cannot read the sidecar, still emit a generic `DEGRADED_PANEL_WARNING` using the count.
- If the waterfall exits non-zero, preserve current panel failure reporting instead of converting it to a degraded warning.
- If `execute_round` manifest readers regressed, a mixed manifest could still crash collection; the `iter_jsonl_dicts` guard is the mitigation.
