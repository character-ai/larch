## Edge cases

- Anchor file exists but is empty → treat as absent (`-s` test); fall back to the legacy chain. `plan-review-loop.sh` already errors upstream when materialization produces an empty anchor.
- `--scope-anchor-file ''` (empty value) → treated as unset; no KV emitted.
- Anchor path containing CR/LF → tally argv usage error (fail closed, mirrors loop-side check).
- A literal file named `-` → not reachable for the marker helper: stdin mode is selected only when `--file` is absent; all callers pass real paths. The consolidated helper must still use `python3 -c` or equivalent so stdin mode can read caller data.
- `tally-error` terminal paths intentionally do not emit `SCOPE_ANCHOR_FILE`: Step 3 short-circuits to Step 3b on tally-error and the anchor is unused there.
- Missing `SCOPE_ANCHOR_FILE` in re-tally output → refreshed Step 3 envs omit it rather than carrying a stale value.
- Assessor feature file contains delimiter-like text (`</feature>`, `<instructions>`) → rendered as escaped literal evidence under framing prose; assessor instructions remain outside the block.
