## Edge cases

- **No Python duration rows**: abort selected Python rebalancing before writing.
- **Skipped tests**: tests absent from `--durations=0` stay unassigned and use global collection-index fallback.
- **New tests after assignment generation**: unassigned tests shard by collection index `(i % shard_count) + 1`, same as today.
- **Removed tests**: the next rebalance drops stale nodeids because it writes only measured nodeids.
- **Shard count mismatch at runtime**: pytest ignores the JSON assignment map when it is non-empty and `max(assignments.values()) != PYTEST_SHARD_COUNT` (covers both too-few and too-many generated IDs).
- **`--n-python-shards` mismatch at rebalance time**: script aborts before writes with a clear error naming the observed CI shard count.
- **Malformed assignment JSON**: pytest fails closed with a clear `ValueError`.
- **Timestamped GitHub logs**: parser should still find duration rows.
- **Parametrized nodeids**: parser must preserve the nodeid exactly.
- **`--kind all` partial data**: collect both baselines before writes so one missing dataset does not create a partial PR.
- **`--kind all` harness validation failure**: revert `Makefile` only; assignments file must not exist on disk afterward.
- **Python verification with zero rows**: treat as hard failure (not harness-style warning); print PR URL when a PR was created.
- **Python verification with partial shard coverage**: e.g. only shards 1–3 present in `median_shard_totals` when `n_python_shards=4` — hard failure with missing shard IDs listed.

## Failure modes when non-trivial

- **CI log format drift**: Python parser may find no rows. The script should fail before writes with a message naming `python-tests` and `--durations=0`; Python verification with zero parsed rows after PR creation also fails closed with PR URL.
- **GitHub CLI failure**: keep current explicit errors for run list, log reads, workflow dispatch, PR creation, and verification.
- **Python verification spread above threshold**: leave the PR open, print the PR URL, and exit non-zero.
- **Python verification empty or incomplete timing**: leave the PR open, print explicit error and PR URL, exit non-zero (distinct from harness warning-only semantics).
- **Harness verification spread above threshold**: print the existing warning and tables; exit 0 (unchanged harness contract).
- **No file changes after packing**: exit `0` before branch creation.
- **Assignment file corruption in a PR**: `make py-test` should fail during collection instead of silently dropping tests.
- **Partial artifact commit under `--kind all`**: prevented by kind-aware staging that adds every changed selected path before commit.
