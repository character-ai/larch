## Findings

### 1. Baseline medians must dedupe retried attempts (important)

Verification dedupes by `attempt`, but packing does not. Retried `python-tests` jobs can skew LPT weights and produce assignments that verification scores differently than the data used to build them.

### 2. Commit failure must restore the original branch (important)

Rollback prose covers path restore for commit-hook failure, but branch restoration is only explicit for push failure. That matches a real gap in the current script and would persist after `_revert_written_paths` unless the plan pins branch restore on commit failure too.

### 3. Explicit `pack()` → assignments flatten (latent)

Small contract gap: invert `pack()` output and pass `guard=""` when packing nodeids.
