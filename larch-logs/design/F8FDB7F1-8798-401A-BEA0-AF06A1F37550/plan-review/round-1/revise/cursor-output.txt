## Plan

### Approach

- Treat `NO_SKETCHES` as binding.
- Consolidate the three legacy Step 18 shell wrappers into one **two-phase** script: `step-18.sh`.
- **Phase contract** (replaces a single-call design that skipped Step 18a.5):
  - `--phase gate` (default): four-layer stall resolution only. Emits `STALL_*` and `STALL_RECOVERY_REQUIRED`. Exits `0` on stall so the orchestrator can run `stall-recovery.md`. Does **not** run final-report, markers, or teardown.
  - `--phase finalize`: runs Step 18b final-report refresh, optional marker body, closing token/timing marks, and teardown. **Never** re-runs the active-stall gate. Invoked only after prompt-side Step 18a.5 completes (or is skipped by its predicates).
- **Orchestrator ordering** (prompt-side, not inside the wrapper):
  1. After Step 17, print Step 18 breadcrumb.
  2. `step-18.sh --phase gate --stall-tracking-memory "${STALL_TRACKING:-false}"`.
  3. If `STALL_RECOVERY_REQUIRED=true`: load and run the full `stall-recovery.md` procedure. On `clear-stall` `CLEARED=true`, treat in-memory `STALL_TRACKING` as `false`. On terminal path completion (`stall-recovery-terminal-report.env` written), **do not** re-invoke `--phase gate` (disk `STALL_TRACKING` may remain true by design).
  4. When the active stall gate is clear, recovery succeeded with `CLEARED=true`, or terminal recovery finished: run the **full Step 18a.5** procedure from `SKILL.md` / `stall-recovery.md` (unchanged semantics).
  5. `step-18.sh --phase finalize --step17-emitted <true|false>`.
  6. Parse finalize stdout for `EMIT_BODY`, `WFR_RC`, markers, and teardown tail KVs. Emit marker body to top chat when eligible. Write `.step17-emitted` per sentinel ownership below.
- **Match the live SKILL path** for Step 18b: call `python3 "$PLUGIN_ROOT/python/cli.py" final-report step18b` only. Do **not** resurrect dormant `step-18b-final-report.sh` steps (`cleanup.sh --help`, `token report --full`, `timing telemetry-mark "Step 18 — cleanup"`).
- **Stream contract**: do **not** call `larch_quiet_init` in `step-18.sh`. Stall KVs, `STALL_RECOVERY_REQUIRED`, `EMIT_BODY` / `WFR_RC`, marker lines, and teardown tail records must land on captured Bash stdout (same pattern as `step-18a-gate.sh`, `step-16-17.sh`, `step-18-finalize.sh`).
- Keep the active Python `final-report step18b` verb unchanged unless shell sequencing becomes awkward during implementation.
- Delete the six legacy `.sh` / `.md` wrapper files after the new wrapper and tests cover their behavior.
- Append the **deleted** legacy paths to `python/migrated-scripts.tsv` (not the new live files).

## Edge cases

- **Stall truthiness**: preserve existing true-value handling for all four layers on `--phase gate`.
- **Step 18a.5 placement**: always prompt-side after gate clearance / recovery / terminal completion and before `--phase finalize`; never inside gate early-exit.
- **Post-terminal recovery**: disk `STALL_TRACKING=true` after `seed-terminal-state` is expected; orchestrator skips gate re-entry and runs finalize after 18a.5 skip.
- **Plugin root rehydration**: support both `plugin-root.env` and `session-env.sh`.
- **`--step17-emitted true`**: wrapper creates sentinel before `step18b` only; does not satisfy post-emit ownership when wrapper prints markers.
- **Step 18 first emission**: orchestrator writes `.step17-emitted` after marker or bounded Read fallback chat emission.
- **Empty summary**: never emit markers when `summary-final.md` is absent or empty.
- **`final-report step18b` failure**: relay `WFR_RC`, append failure best-effort, no markers.
- **Teardown deletion**: emit marker body before teardown removes `$IMPLEMENT_TMPDIR`.
- **Ordering**: closing token/timing marks before teardown (#3425).
- **Stdout capture**: no `larch_quiet_init` in `step-18.sh`.

## Failure modes

- A gate-phase wrapper that exits non-zero on stall breaks recovery routing.
- Running `--phase finalize` before Step 18a.5 skips escalation-success reporting on happy paths.
- Re-running `--phase gate` after terminal recovery loops instead of reaching teardown.
- Resurrecting dormant `step-18b-final-report.sh` steps changes production token/timing artifacts vs the live SKILL path.
- `larch_quiet_init` before stall KVs or markers hides contract output from Bash capture.
- Wrapper-owned unconditional `.step17-emitted` writes suppress required Step 18 body emission.
- Adding live `step-18.*` paths to `migrated-scripts.tsv` breaks `lint-retired-scripts`.
- Missing `agent-lint.toml` exclusion breaks `make lint` on Makefile-only harness references.
- Stale machine-reachability pins to retired helpers break agent-lint G004 after deletion.
