## Failure modes

- CLI behavior can drift from bash due to newline, glob, or awk parsing differences.
- Reimplementing diff-mode gather context instead of delegating to `scripts/gather-branch-context.sh` can break merge-base, diff file, or KV parity.
- Omitting the trailing diff-mode `SCOPE_FILES_COUNT=0` and `MODE=diff` KVs can break review-core env binding.
- Delegating panel dispatch incorrectly can break round 1 peer-drop semantics and round 2+ fallback behavior.
- Dropping `DISPATCH_WATERFALL` override semantics can make tests launch real reviewers and hide no-fallback regressions.
- Parsing Claude outputs before `.done` sentinels can miss findings or parse partial output.
- Dispatching aggregation without `scripts/dispatch-with-waterfall.sh` can break waterfall argv, `.meta` sidecars, or fail-open behavior.
- Dropping `LARCH_AGGREGATOR_DISABLED=1` can rewrite findings or change disabled-mode KVs.
- Mis-ordering `review_core` aggregate, tally, and emit stages can break aggregation, voting, or handoff artifacts.
- Dropping post-threshold panel-failed gates can let degraded static coverage proceed to voting.
- Dropping exhaust-side tally or emit can break `aggregator-validation-exhausted` parity.
- Dropping OOS snapshot/restore can wipe parent OOS artifacts on zero-findings or prune-skipped paths.
- Resolving parent OOS state from `IMPLEMENT_TMPDIR` before `SESSION_ENV_PATH` can restore files to the wrong directory.
- Dropping `IMPLEMENT_TMPDIR` inheritance can break nested `/implement` parent artifact copies and round logs.
- Skipping emit-tally on MAV can break rejected/OOS handoff artifacts.
- Omitting tally scope-fit checks can accept out-of-scope findings as in-scope.
- Omitting plan-mode scope-reduction handling can merge, drop, or reject leading `[SCOPE-REDUCTION]` findings.
- Treating multi-word Python CLI defaults as executable paths can break nested review-and-fix.
- Leaving `-x` preflight checks on Python CLI defaults can prevent review-and-fix from running review-core or compose-findings.
- Redaction may drift if compose-review moves from shell pipelines to in-process helpers.
- Deleting `.md` contract files before updating skill prose can break review structure tests.
- Keeping retired path literals in fixtures, topology docs, CI guards, or lint allowlists will fail `make lint-retired-scripts`.
- Keeping `scripts/test-relevant-checks.sh` routing fixtures pointed at retired harnesses will fail relevant-checks tests.
- Keeping bare retired script basenames in user-facing docs can point operators at deleted entrypoints even when path lint passes.
- Omitting `cap-reached` from review-core status handling can break the round-cap contract.
