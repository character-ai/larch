### UPDATED: `scripts/lib-implement-round-cap.sh`
Item 4. Append a direct-execution block at the end of the file, guarded so sourcing stays side-effect-free. Do **not** add top-level `set -euo pipefail`; keep the existing shebang and the `count_prior_degraded_rounds` sourcing behavior byte-unchanged.

```bash
if [[ "${BASH_SOURCE[0]}" == "${0}" ]]; then
  set -euo pipefail
  _lib_round_cap_usage() {
    printf 'usage: lib-implement-round-cap.sh --count-prior-degraded <IMPLEMENT_TMPDIR> <current_round>\n' >&2
    exit 2
  }
  case "${1:-}" in
    --count-prior-degraded)
      [ "$#" -eq 3 ] || _lib_round_cap_usage
      case "$3" in
        ''|*[!0-9]*) _lib_round_cap_usage ;;
      esac
      [ "$3" -ge 1 ] || _lib_round_cap_usage
      count_prior_degraded_rounds "$2" "$3"
      ;;
    *)
      _lib_round_cap_usage
      ;;
  esac
fi
```

`--count-prior-degraded <tmpdir> <round>` prints `count_prior_degraded_rounds` for that round (the Step 5 banner passes round **1** → 0 on a fresh run). `<round>` must be a positive integer, else usage error exit 2. Bash 3.2 compatible.

## Edge cases

- Item 1: fresh Step 0 initial entry with no tmpdir/env uses the SKILL.md caller fallback before the first plugin-script expansion. Direct wrapper execution with `CLAUDE_PLUGIN_ROOT` unset still self-derives from `$0`. `cd` failure → empty `CLAUDE_PLUGIN_ROOT` → unchanged `:?` abort (broken layout still fails loudly). Already-exported value is left untouched (`-z` guard).
- Item 3: `USAGE=` is added only on the `fail_usage` (exit 1) class; exit-2 I/O errors keep their existing two-line `FAILED=`/`ERROR=` output.
- Item 3: the new test harness is Makefile-only, so `agent-lint.toml` must carry explicit exclusions; Makefile/shard wiring alone is not sufficient for `agent-lint`.
- Item 4: round `0` and non-numeric round are usage errors (exit 2). Round `1` returns `0` (empty prior range). The Step 5 banner block treats non-integer stdout as a local hard error before printing misleading copy. Sourcing the lib must remain inert.

## Failure modes

- **Item 1 caller still env-only**: if Step 0 keeps using `${CLAUDE_PLUGIN_ROOT}/scripts/implement-bootstrap-invoke.sh` before setting a fallback, fresh initial entry can fail during shell path expansion before wrapper self-derivation runs. Mitigation: caller-level no-tmpdir harness mirrors the Step 0 prelude with both env vars unset. Warning signal: `CLAUDE_PLUGIN_ROOT: parameter null or not set` or `No such file or directory` before wrapper stdout exists.
- **Item 1 over-broad derivation**: if the script were ever invoked from outside the plugin tree, `dirname "$0"/..` could point elsewhere. Mitigation: derivation only fires when `CLAUDE_PLUGIN_ROOT` is unset, and the `:?` guard plus downstream `"${CLAUDE_PLUGIN_ROOT}/scripts/implement-bootstrap.sh"` path resolution surface a bad root immediately. Warning signal: bootstrap child "No such file or directory".
- **Item 3 parser regression**: a consumer parsing the first `ERROR=` line could mis-handle the new `USAGE=` line. Mitigation: `USAGE=` is appended after `ERROR=`, on its own key; the `ERROR=usage:` contract is unchanged. Warning signal: harness assertion on the three-line envelope.
- **Item 3 agent-lint regression**: the new Makefile-only harness can be implemented and sharded correctly but still fail `agent-lint` as dead/unreferenced. Mitigation: `agent-lint.toml` exclusions sit beside the analogous append-tool-failure harness entries with a Makefile-only rationale. Warning signal: `bash scripts/relevant-checks.sh` fails only in agent-lint after tests pass.
- **Item 4 empty banner count**: if SKILL.md only tells the orchestrator to run the CLI but does not assign stdout before `effective_round_cap` math, the banner can ignore degraded history or error on an empty variable. Mitigation: fenced Step 5 banner-prep block captures and validates `prior_degraded_rounds` before `round_cap` math. Warning signal: banner shows 5 rounds after prior degraded rounds, or arithmetic expansion fails.
- **Item 4 sourcing regression**: a malformed guard could run the CLI (and `exit 2`) at source time, breaking `run-step5-review.sh` / `review-and-fix.sh`. Mitigation: `[[ "${BASH_SOURCE[0]}" == "${0}" ]]` guard plus an explicit "sourcing does not trigger CLI" harness assertion. Warning signal: Step 5 loop aborts at source.
