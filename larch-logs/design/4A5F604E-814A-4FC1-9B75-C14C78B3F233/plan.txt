Add `scripts/test-implement-fence-shape.sh` for the two acceptance invariants. ## Edge cases

- Pre-bootstrap fences (L98-103 pin, both `step-0-bootstrap.sh` call fences) must keep the awk fallback + `export CLAUDE_PLUGIN_ROOT` for legacy resume tmpdirs without `plugin-root.env`; the fence-shape allowlist covers exactly those lines.
- `step-18-finalize.sh` must preserve the exact env pins `DESIGN_TMPDIR=''` and `LARCH_TIMING_SKILL=implement` on the timing calls, and keep `|| true` guards so report failures never block teardown.
- `step-5-resume.sh --record-only` covers the terminal-stall branch (record round timing, no commit, no loop re-invoke); a missing `round-start-s` file stays non-fatal.
- `step-8-ship.sh` 3.11-guard failure must still emit the structured JSON line on stdout and exit 4 (structure-test pin).
- `step-8-oos-checkpoint.sh` keeps `command grep` probes (BASH_AUTHORING §1 applies inside scripts too) and the exit-1 vs exit-2 vs other-rc site selection byte-for-byte.
- `.step17-emitted` stays orchestrator-side (it records a chat emission; a script cannot assert it). `.step17-printed` moves into `step-17.sh` under the same condition.
- Indented fences (Preflight examples, 2.5 larch-log append) are inside the fence-shape scan; placeholder argv (`<N>`, `<specific-files>`, `$(cat …)`) is allowed within the single invocation command.
- `${BASE_ARGS[@]+…}` Bash-3.2 guard disappears with the flag change; run `make lint-bash32` over all new scripts.
- agent-lint S030/G004 reachability: scripts referenced only in moved prose (`check-phantom-dirty.sh`, `append-execution-issue.sh`, `git-rebase-abort.sh`, `gh-run-logs.sh`, …) must stay reachable via the new reference files; if agent-lint does not scan them, add machine-reachability lists under the retained SKILL.md headings (existing pattern at the Execution Issues section).

## Failure modes

- Missed harness anchor → red CI. ~60 files reference `skills/implement/SKILL.md`; most pin prose that stays. Mitigation: run the full relevant harness set locally before PR; fix drift in any failing harness (`test-implement-anti-halt.sh`, `test-implement-relevant-checks-anti-halt.sh`, `test-quick-mode-docs-sync.sh`, `test-audit-runs.sh` are the likely stragglers).
- Behavior drift while parameterizing `step-8-ship.sh` / `step-0-bootstrap.sh` → copy fence bodies verbatim first, parameterize second, diff-review against the original fence text.
- Orchestrator-visible KV loss (a wrapper swallowing child stdout) → every wrapper re-emits child KV tails unchanged; harnesses assert the load-bearing keys (`OOS_CHECKPOINT_RC`, `EMIT_BODY`, routing-envelope keys, `STALL_TRACKING_*`).
