## Edge cases
- No `--risk` passed: `RISK=""` → outer `.meta` keeps `OUTER_LAUNCHER_RISK=high` (unchanged). Round-trip test asserts this default branch too.
- Invalid `--risk` value passed at the launcher: existing `[[ -n "${2:-}" ]]` guard still rejects empty; any non-empty value flows to the function, which normalizes anything other than `high|low` to `high` (fail-closed). No new validation added at the launcher (matches current contract).
- FINDING_6 empty 6th arg: function still emits no `STDERR_SINK=` line, so the sink-absent meta invariant holds; existing meta tests stay green.
- Collector outer-retry tests must use canonical `launch-review.sh` and valid vendor-shaped `CMD_JSON`; invalid launcher paths or inner-command shapes fail closed before forwarding is exercised (do not weaken validation).
- Test stubs: argv-recording must not perturb exit codes/timing the harness already asserts; reuse existing stub plumbing rather than introducing a new global stub.

## Failure modes
- Risk capture wired in only one `launch-review.sh` lane → asymmetric behavior. Mitigation: the round-trip test runs in both the codex and cursor lane blocks; a one-lane fix fails the other lane's assertion.
- Runtime assertion targets leaf argv or outer-only duplicate `STDERR_SINK=` after `OUTER_LAUNCHER=` → false green (FINDING_2). Mitigation: require the first `^STDERR_SINK=` line before the first `^OUTER_LAUNCHER=` on primary launch-review `.meta`; keep the existing `grep -Fxq` line check as secondary evidence.
- Outer-retry test uses non-canonical `OUTER_LAUNCHER` stub → harness fails closed or pressures validation weakening (FINDING_3). Mitigation: keep `$REPO_ROOT/scripts/launch-review.sh`, stub leaf CLI only (case Q pattern).
- CMD_JSON retry embeds `run-external-agent.sh` or other disallowed argv → retry rejected or wrong path (FINDING_4). Mitigation: valid `json_array bash "$HELPER"` cursor fixture (case A); assert `${retry}.meta` wrapper ownership.
- A converted runtime test depends on a stub that differs from real `run-external-agent.sh` → false green/red. Mitigation: keep `scripts/run-external-agent.sh` and canonical `launch-review.sh` real; stub only leaf binaries on PATH.
