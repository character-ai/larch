## Edge cases

- The task-output file may be missing or empty at notification time; treat missing/empty as spurious -> silent-yield. Non-empty (real terminal KVs) -> single terminal-sentinel probe, then routing.
- Removing the arm entirely also fixes the `#5925` foreign-clone case: a session's `Read` of its own task output no longer denies when a foreign clone holds a live marker.
- A `Read` of a result-env or reviewer artifact under the live tmpdir must still deny until the terminal sentinel releases the marker.
- Bash commands that read `tasks/*.output` remain polling probes and must still deny.

## Failure modes

- Over-broad hook exemption could reopen polling. Mitigate: exempt only the `Read` tool arm; keep Bash-probe and `TaskOutput` denials.
- Docs could imply repeated polling is allowed. Mitigate: precise wording -- exactly one `Read` after a notification for emptiness classification, not progress polling.
- Stale pinned literals in test-design-structure.sh could fail CI. Mitigate: update pins in the same change and run the structure test locally.
