## Approach

1. Add `_ensure_directory_fd(path: Path) -> int`.
   - Reuse the current fd-relative parent traversal in `_ensure_directory`.
   - On success, return the **live** final verified directory fd to the caller; do **not** close it before returning.
   - On failed traversal only, close any intermediate fds in the error path (same per-step close-on-failure pattern as today at lines 203–205).
   - **Do not** copy `_ensure_directory`'s outer `finally: os.close(current_fd)` (lines 208–209) into `_ensure_directory_fd`; that close belongs only in the `_ensure_directory` wrapper after the fd is transferred.
   - Handle the root directory case by returning a verified root fd instead of no-oping.

2. Rewrite `_ensure_directory(path: Path) -> None`.
   - Delegate to `_ensure_directory_fd`.
   - Close the returned fd immediately in a `finally` block; this wrapper alone owns post-success cleanup.

3. Add `_open_or_create_subdir(parent_fd: int, name: str) -> int`.
   - Validate `name` with `_validate_dir_entry_name`.
   - Open `name` relative to `parent_fd` with `_dir_open_flags()`.
   - If missing, create it with `os.mkdir(..., dir_fd=parent_fd)`, tolerate a same-time creator, then open it again by fd.
   - `fstat()` the opened fd and reject non-directories (and symlinks when `O_NOFOLLOW` applies) with helper-specific `OSError` text such as `refusing non-directory progress path`.
   - Close the child fd on failed verification.
   - Caller must close the returned live fd.

4. Rewrite `activate_run()`.
   - Validate `run_id` once.
   - Open or create `clone_dir` with `_ensure_directory_fd`.
   - Open or create the run subdir with `_open_or_create_subdir(clone_dir_fd, safe_run_id)`.
   - Close the run subdir fd after creation verifies.
   - Write `current` with `_atomic_write_in_dir(clone_dir_fd, CURRENT_RUN_FILENAME, ...)`.
   - Remove the old path-based symlink checks around `_ensure_directory`.
   - Keep final file safety through `_atomic_write_in_dir` and `_assert_safe_destination`.

5. Rewrite `append_breadcrumb_for_run()`.
   - Build the breadcrumb line first, preserving current validation and best-effort return behavior.
   - Validate `run_id` once.
   - Open or create the clone dir with `_ensure_directory_fd`.
   - Open or create the run dir with `_open_or_create_subdir`.
   - Append `breadcrumbs.log` with `_append_line_in_dir(run_dir_fd, ...)`.
   - Remove the old path-based symlink checks around `_ensure_directory`.
   - Keep `False` on `OSError`, `TypeError`, or `ValueError`.

6. Keep descriptor cleanup explicit.
   - Use nested `try/finally` blocks or `contextlib.ExitStack`.
   - Never leave `clone_dir_fd` or `run_dir_fd` open on error.
   - Do not convert returned fds into long-lived global state.
   - Avoid double-close: only the fd owner closes; transfer ownership once from helper to caller `finally`.

## Edge cases

- Root path input to `_ensure_directory_fd` must return a valid root fd and not double-close it.
- Existing non-directory entries in the parent chain must still fail closed.
- Existing symlinked clone or run directories must still fail closed where `O_NOFOLLOW` is available.
- A same-time creator between `os.mkdir` and `os.open` must not break idempotency.
- A path swap after fd acquisition must not redirect `current` or `breadcrumbs.log` outside the pinned directory.
- Temporary current-file creation must still clean up failed temp files.
- `_ensure_directory_fd` must not hand callers a closed fd after the wrapper's `finally` pattern is mistakenly inlined.

## Failure modes

- Descriptor leak on exceptions during traversal, subdir creation, append, or atomic replace.
- Closing the same fd twice after transferring ownership from `_ensure_directory_fd` to caller or from `_ensure_directory`'s wrapper.
- Accidentally using `Path.mkdir`, `Path.open`, or full-path `os.open` in the two run-scoped write paths.
- Preserving a stale test that only verifies old path-based re-checks or symlink-only `match="symlink"` wording while fd helpers emit different `OSError` text.
- Over-broad edits to flat breadcrumb writes, cleanup, statusline rendering, or public CLI behavior.
