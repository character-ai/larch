## Main tradeoff

The change loosens a deliberately conservative rule: a misbehaving aggregator could now erase a nonempty ballot if it emits the attestation token without doing real dedup work. The mitigating guards are: (a) the token is an explicit machine contract required by the pattern gate and the orchestrator-aggregator prompt; (b) preamble-contradiction detection still rejects outputs that reference finding IDs in prose without producing valid blocks; (c) the strip path runs in the shell wrapper, not the validator, so the `printf '\n' >"$merged_tmp"` fallback ensures findings.md ends up empty (not unchanged) for the attestation-only path.
