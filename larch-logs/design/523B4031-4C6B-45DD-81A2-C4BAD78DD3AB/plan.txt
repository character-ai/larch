## Edge cases

- `CLAUDE_PLUGIN_ROOT` may be unset in direct-checkout execution. Only survivor Bash code should derive the root from `SCRIPT_DIR`.
- `git phantom-probe` must not write duplicate warning entries when called through `lib-phantom-probe.sh`.
- `git commit --pathspec-from-file --pathspec-file-nul` must preserve NUL-delimited paths with spaces and must not sweep unrelated staged content.
- `snapshot-untracked` and `check-remote-branch` parse failures must remain fail-open where callers rely on that shape.
- `git rebase-abort` must stay safe when no rebase is active.
- `push branch` must exit with the final failed push status, not success after retry exhaustion.
- `push force` must fail closed on dirty worktrees.
- Retired path literals in live docs, dev skills under `.claude/`, Python docstrings, or static harness needles will fail `lint-retired-scripts` once manifest rows are added.
- `make test-implement-structure` and `make test-implement-step8-exit3-first-fixer` pin ship and phantom surfaces; they must flip in the same PR as `step-8-ship.sh` and `ship-pr-exit-matrix.md`.

## Failure modes

- A live consumer still references a deleted script. `make lint-retired-scripts` should catch path-shaped references.
- A Makefile target still shells out to a deleted Bash harness. `make lint` or the target itself will fail.
- A pytest fixture embeds a retired path literal. `lint-retired-scripts` may fail after manifest update.
- `lib-phantom-probe.sh` delegates with `${CLAUDE_PLUGIN_ROOT}` and fails under `set -u` in direct checkout use. Use the script-dir root instead.
- Phantom warnings get appended twice if both Bash and Python append paths remain active.
- Parity drift in exit codes can silently change orchestrator routing. Pin every known non-zero and fail-open path in pytest.
- `scripts/test-implement-structure.sh` still requires `phantom-probe-with-warn.sh` after `step-8-ship.sh` cutover. `make test-implement-structure` fails on lint shard 12.
- `scripts/test-implement-step8-exit3-first-fixer.sh` still requires `scripts/git-push.sh` after exit-matrix cutover. The Step 8 exit-matrix harness fails.
- `python/test_migration_lint.py` keeps a G12 manifest literal and self-fails `make lint-retired-scripts`.
