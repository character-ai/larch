## Edge cases

- Dynamic reviewer records must not affect static threshold denominators.
- Collector `NOT_SUBSTANTIVE` must not be upgraded by non-empty raw output.
- Dropped static slots must count once even when output files also exist.
- Round 2+ Codex specialist suppression must not remove the generic Codex reviewer when Cursor is available.
- `LARCH_REVIEWER_PRUNE=off` must disable pruning.
- Corrupt prune ledgers must fail open.
- Description mode with zero scoped files must return zero findings without launching reviewers.
- Dirty-tree sidecars must recover tracked and untracked changes best-effort.
- Quiet-mode KVs must still go to the contract stream.
- Materialized plan-review embedded assets must still prune on rounds 3–4 after bash script deletion.

## Failure modes

- Native parser drift can break skill `.md` KV parsing.
- Retired path literals in `agent-lint.toml`, topology rules, or structure harnesses can fail `make lint-retired-scripts` even when dispatch moves to Python.
- Leaving gzip-embedded plan-review assets on deleted prune script paths can break `python3 python/cli.py plan-review run` before rounds 3–4 complete.
- Deleting `run_legacy` can break retained façades unless they move to `python/review_legacy.py`.
- Replacing shell harnesses can miss bash parity cases. Cover baseline behavior, not every old harness line.
- Dynamic scout prompt rendering can regress if tests inspect source text instead of rendered prompt output.
