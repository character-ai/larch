## Findings

### 1. `test-review-structure.sh` verb registry (in_scope / important / risk-integration)
`scripts/test-review-structure.sh:64-79` hard-codes eight `review` CLI verbs. The plan adds `review reviewer-prune` but only says to register it “when appropriate.” Without updating the array length check and verb list, `make test-review-structure` fails on every lint run.

### 2. Structure harness collect-findings pins (in_scope / important / correctness)
Pins (13), (16), and (17) still require `run_legacy("collect-findings.sh"` and grep contract strings from `python/legacy_review_shell/collect-findings.sh` (see `scripts/test-review-structure.sh:314-379`). That file is deleted by this PR. The plan mentions updating the structure harness but not these specific pins or the `#659` literal comment line the harness depends on.

### 3. Missing `review_legacy` relay tests (in_scope / important / risk-integration)
`run_legacy` moves to new `python/review_legacy.py` for retained façades, but the plan only says to remove `run_legacy` tests from `python/test_review_pipeline.py`. Façade modules still depend on quiet/KV relay behavior; losing those tests risks silent contract drift on aggregate/tally/compose paths.

### 4. Embedded plan-review prune cutover (in_scope / important / correctness)
G1 ports `/review` `dispatch-panel` in Python, but `/design` Step 3 still runs gzip-embedded `dispatch-plan-review-panel.sh` and `plan-review-loop.sh` via `plan_review_panel.dispatch_panel` → `run_legacy_script`. Prune for plan-review slots is documented in `skills/design/references/plan-review.md:63` and is not fixed by the review-pipeline port alone. Step 4 ordering (before script deletion) and `_decode_legacy_asset` extension are necessary; the failure-mode callout in the plan is correct but should be treated as blocking work, not advisory.

### 5. [OUT_OF_SCOPE] Audit whether `plan-review-loop` blob needs prune patches
The plan patches both embedded assets. If decoded `plan-review-loop.sh` does not reference prune scripts (prune may be confined to the panel dispatcher blob), loop-only edits are optional churn. Verify decoded bodies before editing both gzip entries.
