## Approach

- Treat an empty `composed-plan.md` or other target plan file as a composition/precondition failure.
- Do not dispatch Codex or Cursor auto-fix when the target file is zero bytes.
- Keep `design-publish.sh` unchanged. Its `[[ -s ... ]]` guard already enforces missing-or-empty `composed-plan.md`.
- Clarify docs so readers understand that `--skip-validate` skips only ordinary command validation, not the missing-or-empty precondition.

## Edge cases

- A zero-byte target file under a valid design tmpdir should not create `plan-autofix/`.
- A whitespace-only target file is not in scope for this guard. The existing validator should handle it.
- A missing target file remains an invalid invocation, not an `empty-target` outcome.
- A symlink target remains invalid.

## Failure modes

- If `plan.stat()` raises unexpectedly after `plan.is_file()`, let the existing command fail normally rather than adding broad recovery.
- If downstream code depends only on `AUTOFIX_STATUS`, it will see the existing `unavailable` value.
- `FINAL_VALIDATE_STATUS=empty-target` gives operators more precise evidence without adding a new top-level status.
