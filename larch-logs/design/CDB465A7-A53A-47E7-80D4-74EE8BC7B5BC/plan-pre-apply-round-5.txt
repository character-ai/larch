## Failure modes

- Python rewrite can change stdout ordering. Pin important KV order in tests.
- In-process review-core can leak `REVIEW_CORE_*` KVs. Route every Step 5 review-core call through the capture helper and test Step 5 stdout.
- `review_pipeline.run_legacy()` can relay legacy KVs through `logging_util.emit()`. Capture the emit sink as well as stdout.
- Capture wrappers can leave global output state mutated after failure. Restore sinks in `finally` and test failure cleanup.
- Direct function calls can leak quiet-mode state. Initialize quiet mode per CLI entry and avoid global mutable output state.
- Loop mode can emit per-round `REVIEW_AND_FIX_*` KVs. Suppress round KVs and hand off structured state to the final envelope.
- Deleting single-round launcher behavior can break direct Step 5 invocations. Preserve `--mode single` and `--round-num` parity.
- MAV apply can break handoff gates if it writes pre-coder heads under the wrong directory. Pin relocated snapshot behavior.
- MAV apply can break consumers if it omits `mav-apply-done` or `CODER_STATUS`. Pin both stdout KVs.
- Degraded retries can leave stale reviewer-prune rows. Clear unsettled round rows and test the path.
- Early stall or cap exits can skip run-log batches. Port `flush_review_batches` and cover at least one early stall.
- Deleting shell harnesses before pytest parity can lose coverage. Port tests before deletion.
- Stale path literals can fail `lint-retired-scripts`. Run repo-wide stale-reference checks after every deletion batch.
- Codex dispatch can fail auth lint. Route through the authenticated helper or wrapper, not a blanket allowlist.
- Prompt fences can fail on resume if they bypass `larch-run.sh`. Keep `larch-run.sh` in prompt-side Step 5 loop, single-round, and MAV fences.
- Step 5 progress can remain stuck if done markers are not written on every exit path. Test success, failure, and fallthrough exits.
- Stall-recovery can lose escalation evidence if status branches are not ported exactly. Pin `coder-main-agent-required` and `main-agent-vote-required` branches in tests.
- External coder launch behavior can drift. Keep argv-level tests for Cursor and authenticated Codex dispatch.
- Pre-scouted manifests can change review-core dynamic slot behavior if forwarded without eligibility. Test eligible, ineligible, and MAV cases.
- Missing `--prune-ledger` can break later-round pruning. Assert the argv on every Step 5 review-core call.
- Missing `round-meta.json` can hide Review Phase Detail. Assert meta is written before run-log flush.
- Missing post-round gates can change stall and continuation behavior. Test lint cap, bulk skip cap, and prune-skipped branches.
