## Approach

- Keep the top-level publish gate as a denylist; do not rewrite to an allowlist.
- Anchor exclusions on real producer names and real diagnostic file names.
- Distinguish manifest slot names (`codex-plan-*`, `dyn-codex-plan-*`, …) from output basenames (`codex-primary-plan-*-output.txt`); collector failure logs follow slot names.
- Use `*-output*.txt` so phased waterfall outputs like `-output-phase2.txt` remain covered.
- Keep implementation, tests, sibling docs, and `SECURITY.md` in sync.

## Edge cases

- Phased fallback transcripts are excluded by `*-output*.txt`.
- `claude-plan-assessor-round-N.txt` does not match `claude-plan-*-output*.txt` and remains out of scope.
- Vote outputs are not touched.
- Cursor `.json` sidecars are excluded; codex `.json` is intentionally not added.
- Existing committed run logs are forensic records and must not be edited.
- Collector failure logs use slot slugs (`codex-plan-arch-collector.failure.log`), not output basenames (`codex-primary-plan-arch-output.txt`); do not deny `codex-primary-plan-*-collector.failure.log` (no producer).
- `plan-review-collector.stderr` can contain failed-agent stderr tails and launcher diagnostics.
- Dropped-slot diagnostics and collector failure logs can contain transcript/stderr snippets, so they are excluded even though they are not transcript files themselves.

## Failure modes

- Over-broad glob excludes canonical artifacts. Mitigation: patterns are anchored to plan-review transcript/diagnostic names; tests keep canonical artifacts published.
- Missed sidecar or aggregate stderr leaves raw output publishable. Mitigation: tests cover every new deny arm, including Claude `.meta`, full `.stderr`, slot-derived collector failures, `plan-review-collector.stderr`, dropped slots, and generic prompt.
- Dead pattern reintroduced. Mitigation: use only names verified from producer scripts (`plan-review-loop.sh` slot slugs vs `dispatch-plan-review-panel.sh` output paths) and fixture them with real names.
- Documentation drift. Mitigation: update `.sh`, sibling `.md`, tests, and `SECURITY.md` in the same change.

- `bash scripts/test-design-log-publish.sh`
- `bash scripts/test-lib-design-round-artifacts.sh`
- `bash scripts/relevant-checks.sh` or `make lint`
