**1. [correctness]** Sidecar globs must use `*-output*.txt`, not `*-output.txt`

The plan correctly requires `*-output*.txt` for phased transcripts (plan.txt:54) and cites a phased sidecar example (`cursor-plan-arch-output-phase3.txt.stderr-tail`, plan.txt:14). It does not state that every new sidecar deny arm must use the same `output*` middle glob.

`design_round_artifact_included()` already uses the narrower `*-output.txt.meta` form:

```14:15:scripts/lib-design-round-artifacts.sh
        *-output.txt.prompt|*-output.txt.meta|*-output.txt.json|*-output.txt.cap-hit|*-vote-prompt.txt)
            return 1
```

An implementer copying that shape into `design_artifact_excluded()` would still publish phased sidecars. Committed logs already contain names like `larch-logs/design/85D65C76-9683-4199-8746-AF323F6EDD12/cursor-plan-arch-output-phase2.txt.meta` and `.../cursor-plan-arch-output-phase2.txt.tsv`.

**Suggested revision:** Require `cursor-plan-*-output*.txt.<suffix>` (and the codex-primary / claude-plan equivalents) for every listed sidecar suffix, matching the transcript alternation.

**2. [correctness]** Phased sidecar fixtures missing from the publish test plan

The fixture list (plan.txt:26) renames fictional `codex-plan-*` names to real `codex-primary-plan-*` producers (verified in `skills/design/scripts/dispatch-plan-review-panel.sh:191-227`) and adds static-arch sidecars plus `codex-primary-plan-arch-output-phase3.txt.stderr-tail`. It omits phase2 `.meta` / `.tsv` / `.stderr-tail` files that production runs actually leave at the design tmpdir top level.

Static-only fixtures would not catch the `*-output.txt.*` mistake above.

**Suggested revision:** Extend `scripts/test-design-log-publish.sh` deny-loop entries with at least `codex-primary-plan-arch-output-phase2.txt.meta`, `cursor-plan-arch-output-phase2.txt.meta`, and `cursor-plan-arch-output-phase2.txt.tsv`.
