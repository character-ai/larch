### Approach

The launcher computes `SESSION_TMPDIR = dirname("$MANIFEST_PATH")`. Moving `MANIFEST_PATH` to a subdir auto-narrows `SESSION_TMPDIR` without any changes to the `--add-dir "$SESSION_TMPDIR"` line itself. The new transcript-directory assertion in the launcher enforces that all three Codex-written files share a parent — preventing accidental mismatched configurations from future callers.

`step2-implement.sh` is the only caller of `launch-codex-implement.sh` in the main implement path; the direct-call harness (`test-codex-implementer.sh`) tests the launcher in isolation with arbitrary caller-controlled paths.

---

### Edge cases

- **Resume invocations**: `step2-implement.sh` always runs `rm -f "$MANIFEST_PATH" "$MANIFEST_RAW_PATH" "$QA_PENDING_PATH" "$TRANSCRIPT_PATH" "$SIDECAR_LOG"` before launch to clean stale outputs. After our change, this `rm -f` targets the subdir paths — correct.
- **Manifest-schema-invalid recovery**: `mv "$MANIFEST_RAW_PATH" "$TMPDIR_ARG/manifest-raw.invalid.json"` stays unchanged (MANIFEST_RAW lives in `$TMPDIR_ARG`).
- **Launcher's MANIFEST_DIR existence check**: `mkdir -p "$STEP2_OUT_DIR"` in step2-implement.sh runs before `run_launcher`, so the subdir always exists when the launcher validates it.
- **Old run logs**: step-7a.sh uses `[ -f ... ] &&` guards — if the file isn't at the new path (e.g., from a run before this change), the log-write silently skips, same as today.

---

### Failure modes

1. **Subdir not created before launcher fires**: Fixed by placing `mkdir -p "$STEP2_OUT_DIR"` before `run_launcher`. The launcher exits 2 with "session tmpdir does not exist" if the dir is missing.
2. **step-7a.sh paths not updated**: Transcript wouldn't be flushed to the run log (silent data loss). Addressed by updating all five hardcoded references.
3. **Test 17a/17b/17c META path mismatch**: Tests would silently read `TIMEOUT=` from an empty/nonexistent file, producing an empty string and failing the equality check. Addressed by updating META paths.
