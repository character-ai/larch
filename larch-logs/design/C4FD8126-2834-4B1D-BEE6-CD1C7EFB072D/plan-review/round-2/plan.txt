## Implementation Plan: Narrow Codex Step-2 implementer --add-dir grant

### Context

`scripts/launch-codex-implement.sh` currently grants `--add-dir "$SESSION_TMPDIR"` where `SESSION_TMPDIR` equals the entire `$IMPLEMENT_TMPDIR`. This lets the sandboxed Codex process write anywhere in the session tmpdir — including orchestrator-trusted control files (`session-env.sh`, plan file, etc.). The fix mirrors #3305's approach: create a dedicated `codex-step2-out/` subdir, relocate the three Codex-written outputs there, and grant `--add-dir` only to that subdir. The launcher auto-narrows because `SESSION_TMPDIR` is derived from `dirname("$MANIFEST_PATH")`.

### Approach

The launcher computes `SESSION_TMPDIR = dirname("$MANIFEST_PATH")`. On the codex path only, moving `MANIFEST_PATH` into `codex-step2-out/` auto-narrows `SESSION_TMPDIR` without changing the `--add-dir "$SESSION_TMPDIR"` line. The new transcript-directory assertion enforces that all three Codex-written files share a parent.

`step2-implement.sh` is the only production caller of `launch-codex-implement.sh`; `test-codex-implementer.sh` exercises the launcher in isolation with caller-controlled paths.

---

### Edge cases

- **Resume invocations**: `rm -f` before launch targets codex subdir paths on the codex path — correct.
- **Manifest-schema-invalid recovery**: `manifest-raw.invalid.json` quarantine under `$TMPDIR_ARG` unchanged.
- **Launcher's MANIFEST_DIR existence check**: codex-only `mkdir -p "$STEP2_OUT_DIR"` runs before `run_launcher`.
- **Old run logs**: step-7a `[ -f ... ] &&` guards skip missing legacy paths.
- **`claude_fallback` / cursor-unhealthy**: early exits before the codex subdir block — no `codex-step2-out/` created.
- **Cursor Step 2**: manifest/qa/transcript remain at `$TMPDIR_ARG/` root; test 3e unchanged.

---

### Failure modes

1. **Subdir not created before launcher fires**: codex-only `mkdir -p` before `run_launcher`.
2. **step-7a.sh paths not updated**: silent transcript log loss — five references updated.
3. **Test META / STEP2_MANIFEST_PATH / qa-pending mismatch**: empty `TIMEOUT`, manifest-missing, or test 16 `STATUS=bailed` (`qa-pending-missing`) — all codex dispatch stubs in the table updated; test 16 stub + `QA_PENDING_16` retargeted to `codex-step2-out/`.
4. **Codex subdir applied to Cursor**: would break test 3e and Cursor layout — prevented by `CODER=codex` gate.
5. **SECURITY.md stale full-tmpdir grant**: operators mis-scope tamperable artifacts — paragraph updated alongside launcher doc.
