**1. [correctness]** `scripts/larch-log.sh` commit path — Plan walks `$RUN_DIR/breadcrumbs/`, but runtime streams live at `$IMPLEMENT_TMPDIR/breadcrumbs/` (sibling of `larch-logs/`), not inside `larch_log_run_dir`. Commit only copies the staging tree, so breadcrumbs would silently never publish (matches failure mode #3). Resolve session tmpdir from `--log-root` / `IMPLEMENT_TMPDIR` and stage into `src_path/breadcrumbs/` before `cp`/git.

**2. [correctness]** `scripts/larch-log.sh` — Same tmpdir hosts `.done`, `.status`, `.quiet`, `.surfaced`, and monitor offset/state files. Walking “each regular file” without an `*.ndjson` filter can commit operational sidecars. Restrict to stream NDJSON basenames only.

**3. [correctness]** `scripts/ci-wait.sh` — Migrating progress `larch_errf` → `emit_breadcrumb` breaks the unset-stream stderr contract (`larch_errf` → fd 4; `emit_breadcrumb` → stdout/quiet log). Conflicts with the planned `test-ci-wait.sh` unset assertion. Add `emit_breadcrumb_stderr` per the earlier #2790 design.

**4. [risk-integration]** `scripts/ci-wait.sh` — Keeping timeout/bail on `larch_err` when `LARCH_BREADCRUMB_STREAM` is set means the foreground monitor never surfaces those lines from the stream during background CI wait. Use categorized `emit_breadcrumb` (or `_stderr`) for those tiers when the stream is set.

**5. [correctness]** `scripts/larch-log-batches.sh` — “sanitizer-required” is not in the `none|mermaid|plan-goals|json-lines|json-object` enum; `scripts/test-larch-logs-batches.sh` will fail if a batch row is added without plumbing. Plan omits harness updates.

**6. [correctness]** `scripts/test-larch-log.sh` — Synthetic `RUN_DIR/breadcrumbs/` tests can pass without proving copy from `$IMPLEMENT_TMPDIR/breadcrumbs/`. Add an integration case with the real tmpdir layout.

**7. [correctness]** `scripts/larch-log.sh` — Mid-walk redaction failure can leave a partial `src_path/breadcrumbs/` with no rollback step before `cp`.

**8. [security]** `scripts/redact-secrets.sh` — Unterminated PEM in streaming mode exits 0; larch-log “non-zero fail-closed” may not trigger on truncated PEM tails.

**[OUT_OF_SCOPE] 9. [architecture]** `scripts/design-log-publish.sh` — Does not copy the `breadcrumbs/` subdirectory; `/design` streams are out of this plan’s commit wiring.
