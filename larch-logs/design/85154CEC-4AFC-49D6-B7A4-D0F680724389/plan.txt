## Edge cases

- Empty `head_sha` must not serialize as `""` in `architectural-guideline-outcome.json`; `write_guideline_ship_outcome` raises before `_write_json_atomic` when `head_sha` is blank.
- Broken symlinks may return `exists() == False`; check `is_symlink()` before applying absence exemptions.
- `guidelines_status="invalid"` and `"absent"` must still produce clean outcomes with their existing reasons.
- `guidelines_status="present"` with an empty note and a drop reason must remain `dropped`.
- Pre-cutover runs without outcome artifacts should stay informational when the artifact is truly absent.
- `implement_step9a1_reachable` chain call must receive the same `pr` as the direct bail-signal call.

## Failure modes

- A too-broad symlink check could make old gc-slimmed runs fail. Limit failure to symlink or non-file artifacts.
- A too-broad `head_sha` guard could block tests that intentionally omit tmpdir or skip sidecar writes. Guard only the sidecar write path.
- Step 8 reachability changes can affect both audit scan and required-file checks. Add focused tests for both call paths or update one existing test per path.
