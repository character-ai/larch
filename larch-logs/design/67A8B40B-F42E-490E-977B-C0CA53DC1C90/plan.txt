## Edge cases

- **Already latest:** Cleanup still runs before `No upgrade needed.` via `clean_test_files_from_cache(current)` using the canonical cache parent, even when `CLAUDE_PLUGIN_ROOT` is not cache-shaped.
- **Unknown installed version:** Cleanup skips when `actual` or `current` is empty or unsafe.
- **Unverified post-install:** Cleanup still runs after install returncode 0 once `actual` is read, even when `verified` is false and prune is skipped.
- **Same-version cone repair:** Reinstall occurs, then cleanup runs on `actual` before verification gating.
- **Dropped dev top-level dirs:** Remove direct-child `.claude/`, `.github/`, `.gemini/`, and `tests/` with confined `shutil.rmtree()`.
- **Directory safety:** Skip symlink version dirs, symlink directory candidates, non-direct-child directory candidates, and resolved escapes.
- **`skills/test-issue/`:** Remove explicitly via `DEV_ONLY_SKILL_CLEANUP_PATTERNS`; skip the path prefix when applying `SKILL_HARNESS_CLEANUP_GLOBS`.
- **Glob overreach:** Patterns are constants and evaluated under the confined `version_root`; remove only files and symlinks that pass confinement checks.
- **Root files:** Cone mode keeps root files, so cleanup must delete `Makefile` and `parallel-tests.py`.
- **Retained `python/` tree:** Also delete `python/review_test_support.py`, `python/harness_*.py`, `python/requirements-test.txt`, `python/requirements-dev.txt`, `python/pyrightconfig.json`, and `python/.pylintrc`.

## Failure modes

- A file cannot be deleted because of permissions or a race. Emit a warning and keep the upgrade successful.
- A dev top-level directory cannot be deleted because of permissions or a race. Emit a warning and keep the upgrade successful.
- `claude plugin list` cannot verify the installed version. Skip cleanup for an unsafe or empty version, then preserve existing verification behavior.
- A malformed cache layout, symlinked version directory, symlinked cleanup directory, or escaped candidate would delete outside the version root. Confinement checks skip unsafe targets.
- An old running Claude session still has old plugin code loaded. Keep the existing restart guidance.
