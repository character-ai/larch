## Approach

Route the `/implement` Step 2 coder to Cursor `grok-4.5` for MODERATE difficulty only. Keep TRIVIAL and HARD on Codex. Price the new lane correctly: grok-4.5 is a Cursor first-party model, exempt from the $0.25/M Teams Token Rate (verified 2026-07-10 via cursor.com/docs/models-and-pricing and forum thread 165207).

1. Add `CODER_TOOL_ORDER_BY_DIFFICULTY` and `CURSOR_IMPLEMENT_MODEL_BY_DIFFICULTY` in config.py as the single source of truth for per-tier routing.
2. Wire `_phase_coder` in bootstrap.py to use the difficulty-keyed order for MODERATE.
3. Extend dispatch_step2.py to forward difficulty to both external launchers and resolve the Cursor model from the new map.
4. Make `resolve_model_args` honor `default_model` for Cursor (parity with Codex).
5. Add the `grok-4.5` rate row without the Teams surcharge; add grok-4.5 pricing slots to the full report stack (argv split, DisplayRates, cost calc, render, PR body).
6. Update the `implement.step2_coder` `doc_fallback` text and regenerate topology artifacts.

TRIVIAL and HARD coder routing stays unchanged. All explicit `--coder` overrides and `LARCH_CURSOR_MODEL`/`CLAUDE_PLUGIN_OPTION_CURSOR_MODEL` env overrides are unaffected.

## Edge cases

- Missing, malformed, or unreadable difficulty prior: retain Codex-first default order.
- MODERATE with Cursor unavailable: falls through to Codex with `gpt-5.6-sol`.
- Explicit `--coder codex` at MODERATE: Codex wins.
- `LARCH_CURSOR_MODEL`/`CLAUDE_PLUGIN_OPTION_CURSOR_MODEL` override: beats `grok-4.5`.
- TRIVIAL and HARD: unchanged, Codex-first.
- Cursor Auto model tokens: unaffected; price at zero via existing auto bucket.
- Unknown cursor model in by-model bucket: falls back to surcharged composer-2.5 rate.

## Failure modes

- If difficulty is not forwarded to the Cursor launcher, the launcher still uses `composer-2.5` despite Cursor being selected.
- If grok-4.5 tokens aggregate into the surcharged composer bucket, cost reports overstate MODERATE cursor cost.
- If bootstrap applies the difficulty order before explicit `--coder` handling, operator overrides break.
- If the topology regeneration is skipped, `doc_fallback` text drifts from the generated docs.
- If rater attribution and launcher resolution differ, token and difficulty records name different models.
