## Edge cases

- Round 1 with missing `round-start-s` keeps phase-start (`window_start_s`) fallback.
- Round N > 1 with missing `round-start-s` uses only round N−1 `v1 round` end, then current round dir mtime; never whole-phase start, never round N−2 or older ends.
- Round N > 1 with no round N−1 timing row falls back to current round directory mtime only.
- Existing `round-start-s` files are never overwritten.
- Symlinked `round-start-s` paths are not followed by the design-shell helper.
- Symlinked `plan-review/round-N` parent directories are not followed; persist is skipped rather than writing through a symlink.
- Pre-body persist must succeed when `plan-review/round-N` does not exist yet (mkdir before write).
- Vendor rows with repeated basenames across rounds remain safe because selection is window-based.

## Failure modes

- If `round-start-s` cannot be written (including mkdir failure or symlink parent), the hardened renderer still avoids whole-phase fallback for round N > 1.
- If the timing ledger lacks a round N−1 row, the live chart may show less elapsed setup time but must not include older rounds.
- If the embedded design blob is not regenerated, `python/test_plan_review.py` fails.
- Mid-round Step 5 or sourced design-loop test deadlock if the event is never released; harness must use timeout / `finally` release.
