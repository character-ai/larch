### FINDING_1: Plan omits extending `cleanup_cache_sessions_root` for injected env
- **Reviewer(s)**: Cursor-Arch, Cursor-Pragmatic
- **Severity**: important
- **Concern**: The plan requires `implement_session_roots` / `resolve_implement_tmpdir` to honor an injected env mapping via `cleanup_cache_sessions_root`, but never specifies extending `cleanup_cache_sessions_root` itself (or threading env through all resolver lookups). Scenario: unit tests passing `env={XDG_CACHE_HOME: ...}` (and env-carried `LARCH_TOKEN_SESSION_ID` / `LARCH_IMPLEMENT_TMPDIR_TTL_SECONDS`) still read `os.environ` unless every lookup is threaded; implementers may re-encode the cache-root formula inside `implement_session_roots` to satisfy tests, violating the plan's no-re-encode rule and drifting from the bash three-root literal pinned in both hooks.
- **Suggested revisions (informational for voters; coder decides)**:
  - From Cursor-Arch: Add an explicit plan step: extend `cleanup_cache_sessions_root(*, env: Mapping[str, str] | None = None)` to read `XDG_CACHE_HOME`/`HOME` from `env` or `os.environ`; have `implement_session_roots` call it with the same `env` passed to `resolve_implement_tmpdir`
  - From Cursor-Pragmatic: Add an explicit plan step: extend `cleanup_cache_sessions_root(*, env=None)` (and `resolve_implement_tmpdir` env reads) so all resolver env access uses the passed mapping with `os.environ` fallback only when `env` is `None`

### FINDING_2: CLI stdout must be newline-free for bash capture
- **Reviewer(s)**: Cursor-Innovation
- **Severity**: blocking
- **Concern**: CLI stdout must be newline-free like bash `printf '%s'`. Scenario: Bash returns the path with no trailing newline; hooks capture via `IMPLEMENT_TMPDIR=$(python3 ...)` and then test `[[ -f "$IMPLEMENT_TMPDIR/review-round-summary.md" ]]`. A `print()` or `_emit()` path adds `\n`, so file probes miss and Stop/SessionStart fail open silently.
- **Suggested revisions (informational for voters; coder decides)**:
  - From Cursor-Innovation: Document and implement: write with `sys.stdout.write(path)` (flush, no `\n`); add a pytest asserting captured stdout is byte-identical to the path
