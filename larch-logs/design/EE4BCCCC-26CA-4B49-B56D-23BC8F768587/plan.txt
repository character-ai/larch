## Edge cases

- **Fork mode**: `push checkpoint-probe --forked-target true` must still use `upstream/main` unless explicit base flags override it.
- **Checkpoint routing**: `/implement` routing depends on `ROUTE=`, not only process exit code.
- **Larch-log conflicts**: routine checkpoint rebases with only `larch-logs/*` conflicts must auto-resolve and return `ROUTE=continue`, not stall on `ROUTE=conflict`.
- **Mixed conflicts**: only trivial paths are auto-resolved; non-trivial paths must remain in re-derived `CONFLICT_FILES` with no phantom probe.
- **Empty continue**: already-applied commits must skip via `rebase --skip`, not bail.
- **Retired-path linter**: tests must not introduce fixture literals for newly retired paths.
- **Release skill**: release PR creation still needs file-backed PR bodies and a 31 minute CI wait timeout.
- **Pause skill**: repo resolution must still degrade cleanly when no repo can be resolved.
- **PR-body recovery**: `extract-closes-issue-from-pr.sh` must still return empty `REPO` on resolver failure without breaking exit 0.
- **Structural harnesses**: `make lint` harness shards 4, 14, and 16 must pass after helper deletion.
- **Compatibility diagnostics**: keep old helper names in stderr only where Python tests pin compatibility. Prefer CLI verb names in prose and comments.

## Failure modes

- **Parity gap found during retargeted harness run**: fix the Python verb, add a focused Python test, rerun the affected harness, then delete it.
- **Larch-log pre-pass missing**: `/implement` checkpoints 1.r/4.r/7.r/7a.r stall on log conflicts; port Bash loop before deleting probe.
- **`lint-retired-scripts` reports stale references**: update the caller or prose (including `skills/shared/*` and structural harnesses). Do not remove the manifest row to silence the linter.
- **Makefile shard drift**: removing harness targets can leave stale shard references. Run `make test-harnesses-shards-coverage` if available through `make lint`.
- **Agent lint drift**: deleting scripts can leave obsolete allowlist entries. Remove the allowlist entries, not the lint rule.
- **Checkpoint probe breaks `/implement`**: restore missing `ROUTE`, trivial-conflict loop, `PHANTOM_*`, and skip-precedence contracts before deleting the Bash probe.
