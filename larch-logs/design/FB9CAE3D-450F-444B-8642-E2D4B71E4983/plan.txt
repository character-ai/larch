## Plan

**Approach**

- Scope this to **`/combine-issues --oos`**.
- Keep the **standard combine flow** unchanged.
- Add CLI verbs so the skill orchestrates tested Python graph logic instead of reimplementing it in prose.
- Use **direct native GitHub dependency APIs** for inherited edges.
- Fail closed when dependency reads, classification, approvals, write results, blocked-source status, or inherited writes are unresolved.
- Deduplicate all planned writes as **`(client_issue, blocker_issue)`**.
- Skip **self-edges** after source-to-combined remapping.
- Require operator approval for:
  - Any inherited or audit edge where a non-OOS open issue would be blocked by a newly combined **`[OOS]`** issue.
  - Every **Tier-2 semantic audit** edge, even if it appears safe.
- Partition deferred source closure by **combined issue host**.
- Bound Tier-2 audit to explicit trigger pairs only.
- Remap prose references to consumed source issues through **`source_to_combined.json`** before audit dedupe or writes.

**Sequence**

1. OOS skill fetches and validates OOS items as today.
2. OOS skill records any source issues that remain blocked or unconsumed by OOS validation in **`blocked_sources.json`**.
3. OOS skill applies each approved group with **deferred source closure**.
4. OOS skill records **`source_issue -> combined_issue`** from apply output.
5. OOS skill records each new combined issue number and title.
6. OOS skill fetches **blocked-by** and **blocking** edges for all source issues.
7. OOS skill fetches the full paginated open-issue metadata set.
8. OOS skill runs **`combine-issues plan-inherited`** to remap, dedupe, classify, and produce initial per-source eligibility.
9. OOS skill writes safe inherited edges.
10. OOS skill surfaces inherited exception edges for operator approval.
11. OOS skill writes only approved inherited exception edges.
12. OOS skill refreshes the full paginated open-issue metadata set before closure.
13. OOS skill reruns **`combine-issues plan-inherited`** with refreshed metadata.
14. OOS skill resolves formerly unknown inherited edges when the refresh makes them classifiable.
15. OOS skill writes newly safe inherited edges and gates newly classified exception edges.
16. OOS skill leaves still-unknown inherited edges unresolved and close-blocking.
17. OOS skill runs **`combine-issues close-eligible`** to compute final source closure partitions from the refreshed inherited plan, decisions, write results, source mapping, and blocked-source input.
18. OOS skill closes only eligible sources, partitioned by their mapped combined issue.
19. OOS skill refreshes the full paginated open-issue metadata set for audit.
20. OOS skill builds a concrete **`existing_edges.json`** from actual inherited write successes and already-present inherited results only.
21. OOS skill builds a separate **`decided_edges.json`** for rejected, unresolved, and prior audit decisions.
22. OOS skill runs Tier-1 prose audit with source-reference remapping.
23. OOS skill records bounded best-effort Tier-2 semantic audit candidates in the same audit-candidate schema.
24. OOS skill runs **`combine-issues plan-audit`** to merge, dedupe, classify, and decide which audit candidates need approval.
25. OOS skill asks before writing audit exception edges and all Tier-2 edges.
26. OOS skill writes Tier-1 safe audit edges and approved audit edges.
27. OOS skill prints dependency summary counts and any sources left open.

**Edge cases**

- A source issue has no dependencies.
  - Emit empty lists and continue.
- Two source issues have the same dependency.
  - Write one edge.
- A source issue depends on another source issue in the same combined group.
  - Remap to the same combined issue and skip as self-edge.
- A source issue depends on a source issue in another combined group.
  - Remap both endpoints to their combined issues.
- A source issue blocks a non-OOS issue.
  - Treat as an inherited exception if it would make the non-OOS issue blocked by a new **`[OOS]`** issue.
  - Prompt before source closure.
  - Write only if approved.
- A source has remaining blocked or unconsumed OOS items.
  - Add it to **`blocked_sources.json`**.
  - Do not close it.
- Inherited edge metadata is missing.
  - Mark classification unknown.
  - Reattempt classification after the metadata refresh.
  - Do not write the edge automatically while still unknown.
  - Do not close contributing sources while still unknown.
- GitHub dependency API is unavailable.
  - Warn and continue with audit where possible.
  - Mark affected dependency reads failed.
  - Do not close affected source issues.
- Blocking-direction read endpoint is unavailable.
  - Emit an operator-visible warning.
  - Treat affected sources as dependency-read failures.
  - Fail closed for source closure.
- A dependency write already exists.
  - Treat existing idempotent success from **`issue add-blocked-by`** as success.
- Source closure fails after dependency writes.
  - Warn and keep summary honest.
- Eligible sources span multiple combined issues.
  - Close them in separate **`close-sources`** calls by combined issue.
- Audit proposes an already inherited edge.
  - Deduplicate before writing.
- Audit proposes an inherited edge that was rejected or unresolved.
  - Use **`decided_edges.json`** to avoid accidental re-prompt loops.
  - Do not claim it already exists.
- Audit proposes a Tier-1 safe edge.
  - Write it after audit approval-required decisions are resolved.
- Audit proposes a Tier-2 edge.
  - Surface it as a proposal.
  - Write only if approved.
- Open archival issues exist.
  - Include them in the audit open-issue set.
- Prose says **`Blocks #N`** instead of **`Blocked by #N`**.
  - Convert to **`(#N, current_issue)`** when **`#N`** is in scope and open after remapping.
- Prose references a consumed source issue.
  - Remap the reference to the combined host before self-edge checks and dedupe.
- Prose appears only in a comment.
  - Parse it the same way as issue-body prose.
- Tier-2 trigger pairs exceed the bound.
  - Skip excess pairs.
  - Summarize skipped counts.
  - Do not fall back to a full audit.

**Failure modes**

- Native dependency reads may fail per issue.
  - Keep partial results.
  - Mark affected sources as not close-eligible.
  - Include warnings in the final dependency summary.
- Deferred closure can leave source issues open if dependency or close steps fail.
  - This is safer than orphaning dependencies.
  - Emit the remaining open sources.
- Inherited classification can lack metadata.
  - Refresh metadata and reattempt classification.
  - Treat still-unknown classifications as unresolved.
  - Keep affected sources open.
- Inherited exception approval can be cancelled.
  - Do not write unresolved exception edges.
  - Do not close affected sources.
- Inherited exception approval can reject an edge.
  - Do not write the edge.
  - Record the rejection as an explicit decision.
  - Include it in the summary.
- OOS validation can leave a source blocked or unconsumed.
  - Preserve that state in **`blocked_sources.json`**.
  - Keep that source out of **`eligible_by_combined`**.
- Prose parsing can miss implicit dependencies.
  - Tier-2 skill review covers only bounded explicit trigger pairs.
- Tier-2 reasoning can be speculative.
  - Require explicit approval before writing every Tier-2 edge.
- Prose parsing can find stale references.
  - Remap consumed source references.
  - Check open state before proposing an edge.
- Audit exception approval may be skipped by operator cancellation.
  - Do not write unresolved approval-required audit edges.
  - Continue with Tier-1 safe audit edges only.
- Audit edge writes may fail.
  - Warn and count failures.
  - Do not revise already completed source-closure decisions.
