## Edge cases

- **Unset vs empty `LARCH_SHIP_PR_IMPL`:** Both select Python; only literal `bash` selects legacy path.
- **`=bash` byte-stable:** Fenced `Invoke:` and bash exit matrix unchanged in substance; bash-only gates added.
- **`--no-logs-commit` and `--state-file`:** On Python selector argv only after merge lands in `python/ship.py`.
- **OOS / disposition checkpoint:** May read merged `ship-pr-state.sh`; re-entry uses Python argv, no `--resume-phase`.
- **Pre-Step-8 stall:** `ship-pr-state.sh` seeded, no `finalize-state.sh` → Step 18 **runs** restore on Python path.
- **Python postmerge success:** `finalize-state.sh` present → Step 18 **skips** restore on Python path.
- **Python exception / NEEDS_USER_INPUT:** Driver writes stall-shaped `finalize-state.sh` before JSON; restore skip safe.
- **Token drift:** SKILL phrases and `grep -Fq` / awk pins must match exactly (FINDING_9).
- **Cached plugin:** Operators on old cache see bash-default until upgrade + load; notice must say so.
- **Missing `python3` 3.12+:** Operator sets `LARCH_SHIP_PR_IMPL=bash` before session.

## Failure modes

- **Partial flip (docs lag SKILL.md):** Mitigation: enumerated files + `rg` sweep.
- **Default path still runs bash `Invoke:`:** Stale delegation or missing continuation sentences. Mitigation: routing pins + manual matrix.
- **Seeded keys dropped:** `--state-file` without merge. Mitigation: `python/ship.py` merge + tests.
- **Teardown without `finalize-state.sh`:** Exception path skips write; restore wrongly skipped. Mitigation: terminal finalize writes + conditional restore.
- **Restore clobbers Python postmerge:** Restore runs when `finalize-state.sh` exists on Python path. Mitigation: Step 18 gate pins.
- **Stall recovery switches to bash:** Unupdated `stall-recovery.md`. Mitigation: step8-shippr + Step 9 bullets.
- **Pin false pass / false fail:** Loose tokens or bash `Invoke:` satisfies file-wide `--state-file` grep. Mitigation: awk-scoped pins (FINDING_10/11).
- **Operators expect Python before cache refresh:** Missing restart note. Mitigation: installation-and-setup cross-links.
