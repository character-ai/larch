## Edge cases
- **Token drift between SKILL.md and the pin.** The flipped SKILL.md wording and the three `grep -Fq` tokens must match exactly (backticks included). Implement both in the same edit and run the harness to confirm.
- **`=bash` still byte-for-byte.** With `LARCH_SHIP_PR_IMPL=bash`, Step 8+ must invoke `scripts/ship-pr.sh` exactly as today. The flip only re-gates the default; it must not alter the bash contract block, its argv, or its exit-code handling.
- **Empty vs unset selector.** Both unset and empty `LARCH_SHIP_PR_IMPL` must select python (same "default" branch); only the literal value `bash` selects the legacy path.
- **`--no-logs-commit` on Python path.** After the flip, default-path runs must pass `"$no_logs_commit"` into `python/ship.py` the same way the bash `Invoke:` block does; verify with `/implement --no-logs-commit` manual check.
- **Adjacent stale prose.** `python/README.md`, `docs/`, and `python/config.py` may carry more than one "soak" / "Phase 7" / "not wired" sentence; reconcile each surfaced hit, not just the primary line per file.
- **Stale Step 8+ delegation.** If the opening "mechanically delegated to ship-pr.sh" sentence survives, orchestrators may ignore the selector; the delegation rewrite and pre-`Invoke:` sentence are load-bearing.

## Failure modes
- **Partial flip (docs lag SKILL.md).** A reader trusts `docs/configuration-and-permissions.md`, `python/README.md`, or `python/config.py` still claiming bash-default / soak-only / not wired. Signal: repo-wide sweep (see Testing strategy). Mitigation: enumerated file list plus post-edit `rg` gate.
- **Pin tokens do not match the rewritten sentence.** `make lint` / `test-implement-structure` fails (or, worse, a too-loose token passes while the real default is wrong). Mitigation: copy the exact backticked phrases between the SKILL.md edit and the assertions; run the harness locally.
- **Orchestrator follows bash `Invoke:` on python default.** Stale delegation or missing pre-`Invoke:` sentence causes `ship-pr.sh` despite unset env. Mitigation: routing sentences + structure-test routing marker.
- **`--no-logs-commit` dropped on default path.** Log commits still run despite explicit flag. Mitigation: include flag in selector argv list; manual unset-vs-bash matrix includes `--no-logs-commit`.
- **Scope creep into python-path choreography.** Rewriting the broader bash exit matrix or soak fixes risks colliding with open blockers. Mitigation: confine SKILL edits to selector + two routing sentences + `--no-logs-commit`; leave fenced bash block and exit matrix untouched.
