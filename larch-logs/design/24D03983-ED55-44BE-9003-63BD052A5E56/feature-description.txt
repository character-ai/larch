# Make python/ship.py the default ship driver (LARCH_SHIP_PR_IMPL bash→python)

## Summary

Flip the default of `LARCH_SHIP_PR_IMPL` so the **Python** ship driver (`python3 python/ship.py`) is selected by default at `/implement` Step 8+, and the legacy bash `scripts/ship-pr.sh` path becomes **opt-in** via `LARCH_SHIP_PR_IMPL=bash`.

## Background

Phase 7 of the ship-pr→Python rework (umbrella #3132, child #3240, merged) introduced the `LARCH_SHIP_PR_IMPL` selector with default `bash` and `python` opt-in. Per umbrella #3132 locked architecture decision #2, the cutover lifecycle is:

> default bash → soak → **default python** → delete bash

This issue covers the **"default python"** flip (soak → default-python). Bash `scripts/ship-pr.sh` removal stays deferred to a later step.

## Change

Flip the default so unset/empty `LARCH_SHIP_PR_IMPL` selects `python3 python/ship.py` at `/implement` Step 8+; the legacy bash `scripts/ship-pr.sh` path is selected only when `LARCH_SHIP_PR_IMPL=bash` is set explicitly.

## Affected surfaces (implementer to confirm during /design)

- `skills/implement/SKILL.md` — the "Python driver selector" block currently states `default LARCH_SHIP_PR_IMPL=bash runs the bash contract ... When LARCH_SHIP_PR_IMPL=python, replace ...`; flip so python is the default and bash is the explicit opt-in.
- `AGENTS.md` — the `python/` section currently says the live `/implement` path is "wired behind `LARCH_SHIP_PR_IMPL` (default `bash`, optional `python`)"; update to python-default.
- `docs/configuration-and-permissions.md` and any other docs documenting the env-var default.
- Any test harness / selector pin that encodes the default (see the SKILL Python-branch selector pin requested in #3446).

## Acceptance

- With `LARCH_SHIP_PR_IMPL` unset, `/implement` Step 8+ invokes `python/ship.py` (JSON stdout contract), not `ship-pr.sh`.
- With `LARCH_SHIP_PR_IMPL=bash`, Step 8+ invokes the legacy `ship-pr.sh` byte-for-byte as today.
- `skills/implement/SKILL.md` + `AGENTS.md` + docs reflect python-default / bash-opt-in.
- `make lint` and relevant harnesses pass; any selector-default pin updated.
