## Edge cases

- Sentinel basenames may collide. Keep index as the only stable key.
- Sentinel contents may be empty, whitespace-only, or non-numeric. Emit `unknown`.
- Wait timeout must not fail the CLI. Emit `TIMEOUT` rows and exit `0`.
- Wait usage errors must fail fast and remain distinguishable from sentinel timeout.
- Usage errors must remain visible before quiet routing is initialized.
- Poll intervals may be decimal. Preserve Bash `MAX_POLLS` math, including the `0.001` bias and minimum-one clamp.
- `classify_diff(path)` must stay silent and return `generic` for ordinary failure cases.
- `classify_diff_main(argv)` must be the only diff-classifier entry point that emits `DIFF_MODE`.
- Diff CLI usage and missing-file errors must exit `2`.
- Diff headers with spaces or unexpected shapes must classify as `generic`.
- Generated-path classification depends on exact path matches in repo-root anchored `scripts/generators.tsv`.
- Generated classification must not depend on caller cwd.
- Rendering must not depend on the deleted Bash classifier path existing.
- Branch-context git failures should exit non-zero and avoid partial success KVs.
- Failure-log output must stay non-empty even when all reviewer sidecars are missing.
- Failure-log tail caps must be enforced in encoded bytes, including multibyte text.
- Redaction must apply before embedding launch stderr content.
- Classifier default calls in `dispatch-panel.sh` must be argv-safe and not rely on a multi-word scalar.
- Harness stubs must intercept the new Python CLI verbs, not the deleted shell paths.
- Harness contract docs must describe the new Python CLI seam, not the deleted shell seam.
- Quiet FD-3 behavior must remain active. Do not bypass it with CLI machine-stdout allowlist entries.
- Manual retired-reference greps must not pull `larch-logs/**` or other lint-excluded surfaces into scope.

## Failure modes

- **Quiet FD regression**: machine output may go to quiet logs instead of the contract stream. Test FD-3 behavior.
- **Usage diagnostic regression**: argv errors may disappear into quiet logs if validation happens after `quiet_init()`. Validate argv first.
- **Library/CLI contract regression**: `classify_diff()` may emit output, initialize quiet routing, or raise instead of returning `generic`. Keep side-effect tests.
- **Generated TSV anchor regression**: `classify_diff()` may read `scripts/generators.tsv` from cwd and force generated diffs to `generic` in fixture repos. Anchor to the plugin repo root and test cwd changes.
- **Rendering guard regression**: `_classify_diff_mode()` may still gate on the deleted Bash script and force all specialist rendering to `generic`. Remove the existence check and test non-generic routing in `python/test_rendering.py`.
- **Wait poll drift**: simplified timeout math may change `TIMEOUT` timing. Port Bash `MAX_POLLS` math exactly.
- **Caller retarget typo**: shell callers may pass arguments after the verb incorrectly. Add grep and targeted harness coverage.
- **Harness false-green**: retained Bash harnesses may keep stubbing deleted shell helpers. Update temp plugin roots to stub `python/cli.py agent ...` instead.
- **Harness-doc stale seam**: retained `.md` contracts may still instruct maintainers to stub `wait-for-reviewers.sh`. Sweep basename prose references and keep only intentional diagnostic strings.
- **Retired-literal lint failure**: docs, contracts, fixtures, or comments may still mention deleted script paths. Run the scoped grep and `lint retired-scripts`.
- **Scope creep from historical logs**: a broad grep may hit committed run logs. Exclude lint-ignored surfaces and do not rewrite logs for this port.
- **Bash parity drift**: wait timing, classifier path patterns, and failure-log tail bounds are easy to subtly change. Keep pytest fixtures close to existing harness cases.
- **Tail cap parity regression**: character-based truncation may exceed the Bash 5120-byte cap for multibyte stderr. Enforce byte truncation and test multibyte input.
- **Atomic-write regression**: composer errors could leave partial output. Test invalid args do not create the target file.
- **Shard coverage gap**: Makefile targets may exist but not run under harness shards. Attach new pytest-backed targets to a shard and run `make lint`.
