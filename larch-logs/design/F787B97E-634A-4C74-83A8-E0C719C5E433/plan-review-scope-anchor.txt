## Proposed Design Outline

### Goals
- Fix `scope_disposition.compute_coverage` so a firm plan path ending in `/` is credited as covered when any touched path lives beneath it.
- Stop spurious `proceed-partial` dispositions and follow-up issues (e.g. #7083) for fully-implemented directory firm-paths.
- Ship an executable regression test that reproduces the false "untouched" classification.

### Non-goals
- No changes to `python/tests/support/` (already complete on main via PR #7085).
- No broad proactive lint/assertion guard (surgical fix only, per operator).
- No change to exact-match behavior for file (non-directory) firm-paths.

### Approach sketch
- Add one small `scope_disposition` helper deciding plan-path coverage: exact match for files, directory-prefix (trailing `/`) match for directories.
- Route `compute_coverage`'s touched/untouched partition through the helper so `touched_paths`/`untouched_paths` stay in plan-path space and the fingerprint stays deterministic.
- Keep `load_coverage`/`_coverage_from_mapping` self-consistency intact: the validation recompute must agree with `compute_coverage`.

### Surfaces in scope
- `python/larch/implement/scope_disposition.py` (coverage matching).
- `python/tests/implement/test_scope_disposition.py` (regression test).
