## Edge cases

- `gh pr create` stdout with trailing newline or multiple URLs → `_recover_pr_from_conflict_text` takes the last match.
- `pr_for_branch` transiently fails right after successful create → URL-parse fallback; if both fail, `ShipError` → JSON STALLED (#4), not a crash.
- OID poll: genuine mismatch exhausts cap → `MERGE_RESULT_ERROR` (no infinite loop).
- Volatile-only skip: refresh sidecars only; canonical token/timing reports commit on substantive deltas.
- Volatile-only skip: failed `restore`/`clean`/`reset` or leftover repo-wide porcelain → `ShipError` → STALLED (#4), **not** no-op success (FINDING_1).
- Post-create PR resolution: list failure/lag must not bypass stdout URL fallback.
- Selector: `python3` == 3.11 passes; < 3.11 fails loudly; 3.12 still passes.
- `/report-tokens`: probe matches docs/pyproject (≥ 3.11).
- parse-bootstrap: file-first pre-populated keys + stdout fallback loop must source cleanly under `set -e`.
- Integration test: CI without `gh` uses fixture replay; local dev with `gh` may exercise live path when enabled.

## Failure modes

1. **Run-log completeness regression from removing pre-merge flush.** Signal: run-log-completeness checks / missing token-timing batches. Mitigation: earlier implement commits + convergence test + existing verification.

2. **OID poll masks real mismatch or hangs.** Mitigation: cap at `MERGE_PR_POST_PUSH_UNKNOWN_RETRIES` × 5s; ERROR on exhaustion; match only on exact OID equality.

3. **Volatile-only classifier drops substantive logs or leaves dirty porcelain.** Mitigation: refresh-sidecar-only allowlist; **fail-closed** git steps + repo-wide empty porcelain (FINDING_1); commit on any non-allowlisted change; tests (e)-(g) in `test_run_logs.py`.

4. **#3446 / exit-map drift (OOS_1, latent).** Parallel #3446 may edit `OUTCOME_EXIT_MAP` or STALLED routing while this branch pins `Outcome.STALLED: 4` in `test_ship.py`. Signal: `test_outcome_exit_map_matches_bash_contract` or #4 STALLED tests fail after rebase onto main. Mitigation: respect blocked-by order (`#3466` after `#3446` when possible); on conflict, reconcile map + tests in one commit before #3462 cutover.
