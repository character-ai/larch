## Approach

- One stdlib-only module per linter under flat `python/`, each exposing `main(argv: list[str] | None = None) -> int` with `argparse`, mirroring `python/migration_lint.py`. Preserve each linter's **exact** exit-code behavior (see Per-linter parity contracts) and the set of violations it catches — there is no single global exit mapping.
- Register six `("lint", "<verb>")` entries in `python/cli.py` `_REGISTRY`; additive, merge-order-agnostic with in-flight `[DESIGNING]` #3668 (F2).
- `lint-skill-invocations.py` imports `pyyaml`; the runtime is stdlib-only (enforced by `python/test_stdlib_only.py`). Replace the YAML read of the SKILL.md `allowed-tools:` frontmatter with a small stdlib parser (see Per-linter parity contracts for accepted shapes + exit precedence). No third-party imports.
- `lint-mermaid-fences` is the heaviest port (changed-file set + render mode); see Per-linter parity contracts for the full behavior. `scripts/lint-mermaid-puppeteer.json` is referenced by repo-root path — **not** retired; stays at `scripts/`.
- `lint-readability-preamble`: **do not relocate its `.tsv` data this PR.** The Python port keeps the bash `--root`-relative manifest lookup (`<root>/scripts/lint-readability-preamble.tsv`); `scripts/lint-readability-preamble.tsv` / `.tsv.md` stay in place and are retired by E1 with `relevant-checks.sh`. This avoids a migrated-manifest exclusion exception and keeps the existing parity harness (which stages variant TSVs under `<root>/scripts/`) working without a new flag (reconciles accepted FINDING_3/FINDING_17 round 4 with FINDING_6 round 2).
- `lint-gh-body-inline`: the new module **and** its pytest fixtures must avoid raw `gh --body` / `gh --notes` source literals (construct strings, or add the `# lint-gh-body-inline: ok` pragma) — otherwise the hook scans the new `.py` and fails `make lint` before pytest runs.
- Repoint consumers through the shared pre-commit seam, Makefile, CI, and the retained `test-mermaid-fragments` harness; the deferred orchestration scripts are untouched and reach the new linters through pre-commit.
- Parity-gate the existing `test-*.sh` harnesses once against the new CLI (using command arrays, not `$LINT` single-path helpers — see Testing strategy), then delete them and replace with colocated pytest (playbook steps 5–6).

## Per-linter parity contracts

Capture each linter's exact behavior in the module + pytest; do not normalize to a generic mapping (accepted FINDING_16 round 4).

- **mermaid-fences** (FINDING_10/11): exit **1** on usage / unknown-flag / `--changed-only` combined with explicit files; exit **2** on CI `changed_files`/git-diff failures and missing `mmdc`; **push** range falls back to `HEAD~1..HEAD` when `GITHUB_EVENT_BEFORE`/`GITHUB_SHA` are absent; **non-CI** `origin/main` unavailable or git-diff failure → exit **0** (informational, lint nothing); **CI** ref/range failure → fail-closed exit **2**. Resolver order: repo-local `mermaid-lint/node_modules/.bin/mmdc`, else `shutil.which("mmdc")`, else exit 2. Run `--help` capturing stdout+stderr and use `--parseOnly` only when present, otherwise SVG render with repo-pinned `scripts/lint-mermaid-puppeteer.json` when present (preserve missing-config fallback). Preserve the GFM indented-fence regex (`^[[:space:]]{0,3}` + 3+ backticks) and per-file `mktemp -d` extraction subdirs.
- **skill-md-flag-signature** (FINDING_15): scan root `skills/`, **depth-2 `SKILL.md` only**; preserve fence-type handling, multiline continuation parsing, the inline-pragma handling, and **WARN-not-fail** when a referenced target script is missing; `--root` missing/empty path semantics → exit **0** where the bash original does.
- **readability-preamble**: `--root`-relative manifest at `<root>/scripts/lint-readability-preamble.tsv`; preserve the expected-count validation and exit 0/1/2.
- **gh-body-inline**: scan tracked `.sh`/`.py`; preserve `--root`, the pragma exemption, and exit 0/1/2.
- **codex-exec-auth**: preserve `--root` and exit 0/1/2.
- **skill-invocations** (FINDING_13): stdlib frontmatter parser accepts the `allowed-tools:` shapes the bash/yaml original did — quoted-scalar comma-split, flow list `[Bash, Skill]`, and block/multi-line sequence; **parse failure or non-mapping → allowed-tools gate `false`** (do not crash); preserve the **exit-2-over-exit-1 precedence** (non-UTF-8 / internal error wins over violation); cases a–u are the oracle.

## Failure modes

1. **Behavior drift in a port** (most likely): a regex, the mermaid `changed_files()`/render path, an exit code, or the frontmatter parser differs from the original. Earliest signal: the retargeted `test-*.sh` parity run + absorbed `test-mermaid-fragments` cases + colocated pytest. Mitigation: parity-gate each harness against the CLI (command arrays) before deleting; encode the Per-linter parity contracts as pytest assertions.
2. **Broken consumer seam**: a wrong repointed pre-commit `entry:`, Makefile recipe, or the `lint-mermaid` CI step (incl. missing `setup-python`). Earliest signal: `make lint`, `make lint-mermaid` / CI `lint-mermaid` job, `lint-only`. Mitigation: mirror `lint-retired-scripts`; run `make lint` **and** `make lint-mermaid`; add `setup-python` to the mermaid job.
3. **Stale retired-path / self-lint flags**: a surviving literal in `agent-lint.toml`, the kept `lint-readability-preamble.tsv.md`, `skills/shared/*.md`, or a raw `gh --body` literal in the gh-body port trips `lint-retired-scripts` / `lint-gh-body-inline`. Earliest signal: `python3 python/cli.py lint retired-scripts`, `make lint`. Mitigation: full sweep incl. the kept `.tsv.md`; construct gh-body fixtures.
4. **Shard imbalance after harness deletion**: removing four `test-*.sh` from the 20 shards skews wall-clock. Earliest signal: `scripts/test-harness-shards-coverage.sh` + CI timings. Mitigation: out of scope to rebalance here; fast-follow / OOS for `rebalance-test-harnesses`.
