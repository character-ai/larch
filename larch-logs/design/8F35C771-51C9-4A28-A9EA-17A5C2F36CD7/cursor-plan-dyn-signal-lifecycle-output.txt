**1. [correctness]** `plan.txt:88-89` — Proposed KILL-escalation test uses `trap '' TERM; sleep 1860 &` in the harness parent. Bash traps are not inherited by background children, so `sleep` still dies on SIGTERM and the SIGKILL path is never exercised. Revise test (b) to launch a TERM-ignoring child (e.g. `bash -c 'trap "" TERM; while sleep 1; do :; done' &`) and assert ~5s grace before the process disappears.

**2. [correctness]** `plan.txt:10` — 32-byte PID read mechanism is unspecified. Specify `head -c 32` (or `dd`), strip trailing CR/LF/whitespace only, require `^[0-9]+$` and `(( pid > 0 ))`; avoid bare `read`, which strips IFS whitespace.

**3. [correctness]** `plan.txt:10` — Positive-integer validation must reject `0`/`000` after digit match, not only non-empty digits.

**4. [correctness]** `plan.txt:10` — Kill loop needs an explicit 5-iteration `for` with `kill -0` then `sleep 1` before SIGKILL; do not use an unbounded `while kill -0` loop.
