## Edge cases

- **Round-1 ledger missing or malformed**: pruning must fail open, not crash the loop.
- **Round-1 ledger present but no productive rows**: round 2 should prune all rows and converge.
- **Dynamic scout produces a different round-2 archetype**: no round-1 history means the new dynamic row is pruned.
- **Codex unavailable**: Codex rows are omitted or dropped. Cursor rows still run. No Codex-to-Claude or Cursor-to-Codex backfill. Static coverage must not treat `tool-absent` Codex drops as panel failure.
- **Cursor unavailable**: Cursor rows are omitted or dropped. Codex rows still run when Codex is present. No backfill.
- **Both reviewers unavailable**: reviewer rows drop. Existing degraded-panel or prune-to-empty completion paths should surface the condition without adding Claude reviewer substitutes.
- **Explicit old env values**: `LARCH_DYNAMIC_ARCHETYPES_MAX=2` or `3` must now fail validation or be ignored with a warning, depending on the existing caller-env contract.
- **`LARCH_REVIEWER_PRUNE=off`**: round 2 runs the full manifest for operator/debug use; document this override and keep harness coverage.

## Failure modes when non-trivial

- **All round-2 reviewers pruned due to a join-key regression**: prevent with the #5733 non-zero ledger test.
- **Round 2 silently becomes a full panel**: prevent by inverting `reviewer_prune_filter()` early return (not only `prune_window_evaluated`) and with dispatch tests that inspect pruned manifests.
- **Fallback reintroduces hidden cost**: prevent with tests that assert `--no-fallback` on review and plan-review panel dispatch.
- **No-fallback vendor absence trips panel-failed**: prevent with static-coverage `tool-absent` excuse tests.
- **Docs drift from generated topology**: regenerate `docs/topology.md` and run topology docs checks.
- **Dynamic cap drift through session env or drafter**: update scout, session writer, drafter filter, and caller-env validation tests together.
- **Config pin tests left stale**: prevent by updating `test_external_role_defaults.py` in the same change as `config.py`.
