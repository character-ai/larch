# contract-unification [FEATURE] Vendor descriptor table for agent launchers

​#### Problem

`python/larch/agents/` re-instantiates one launch skeleton (validate, auth preflight, model args, build argv, run with retries, record timing/usage, promote done, emit KVs) in 12 launcher bodies totaling ~1,400 lines: `_drafter.py:78-207, 224-357, 706-851, 867-1022`, `_review_launcher.py:796-908, 1120-1231`, and six in `_ci_launcher.py`. Duplicated rituals: the codex-exec argv is assembled 7 times, the max-mode prompt wrapper 6 times, the cursor config-dir mkdtemp+copy ritual 4 times — with verified drift (`_ci_launcher.py:379-381` copies without `contextlib.suppress(OSError)` while `:989-991` and `_review_launcher.py:916-918` suppress) — the claude JSON-envelope unwrap 3 times, and the token-budget cap-hit check twice (~35 lines each). A second fixer-dispatch stack exists: `checks.py:3` documents that "Local fixer dispatch mirrors ``python/cli.py checks lint-fix`` (#3207)" (verified), with per-vendor builders in `checks_lint_fix.py:1004-1078` beside `ci_fixer_lane.py`'s `_launcher_for`/`_dispatch`.

​#### Goal

A vendor descriptor table (binary, preflight fn, home/config context manager, argv builder, capture mode, quota mirror, usage recorder) in `_types.py` or a new `_vendor.py`, plus one `run_vendor_launch(descriptor, family_hooks)`; launcher families supply only prompt build and postprocess. Both fixer lanes consume the same table; lane policy (classification, salvage) stays local. Fold cap-hit and model-arg extraction into shared helpers first as cheap independent steps.

​#### Size

~1,600 lines involved; net reduction 600-800, and vendor changes (auth, model args, exit parsing) become one-site edits.
