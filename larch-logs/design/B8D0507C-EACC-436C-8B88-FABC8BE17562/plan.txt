## Edge cases

- **No completed rounds and no round dirs**: render the section heading plus `No review rounds completed.`.
- **In-flight round dirs only**: render the section heading plus `No review rounds completed.`.
- **Missing `jq`**: keep the old empty best-effort behavior.
- **Omitted `--rounds-root`**: keep usage error exit 2.
- **Provided missing rounds root**: keep best-effort empty output.
- **Unreadable provided root**: keep best-effort empty output.
- **Missing timing ledger**: keep the table, omit charts.
- **`--no-gantt` passed**: keep the table and no-completed-round message, omit charts.
- **Round timing absent**: keep the table, omit that round chart.
- **Vendor task overlaps round edges**: clamp to the round window.
- **Vendor task outside the round**: exclude it.
- **Vendor task `$4` differs from round `$4`**: include it if it overlaps the round window.
- **Zero or negative duration after clamp**: exclude it.
- **More than 25 tasks**: render the first 25 by normalized start time, then end time, then label.
- **Round longer than 59 minutes**: use `axisFormat %H:%M:%S`, not `%M:%S`.
- **Missing panel manifest**: use `derive.awk`.
- **Bad output basename**: fall back to `vendor/task_kind`.
- **Unsafe Mermaid labels**: sanitize labels and keep ids independent.
- **No `/design` plan-review directory**: invoke the renderer against a valid empty root so the final summary says no rounds completed.
- **Progress report caller**: pass `--no-gantt` so terminal output does not include Mermaid headings, fences, or task lines.

## Failure modes

- Mermaid syntax can break if labels or ids contain unsafe text. Use deterministic ids and sanitized labels.
- Mermaid time fields can render misleading charts if duration suffixes are used with `dateFormat X`. Emit integer start and end seconds.
- Mermaid `%M:%S` can wrap after 59 minutes. Use `%H:%M:%S`.
- Off-by-one windows can double-count boundary rows. Use overlap math, not only start-in-window.
- Existing callers may pass committed run directories where live `panel-manifest.ndjson` is absent. Preserve fallback attribution.
- A stale or malformed `timing-ledger.tsv` can contain short rows. Ignore malformed rows.
- In-flight rounds can look like no completed rounds. Render the no-completed-rounds message for valid readable roots.
- Design vendor rows may record a different skill than design round rows. Do not filter vendor rows by skill.
- Shared renderer changes can leak rich Markdown into terminal progress callers. Pass `--no-gantt` from `python/progress_report.py`.
