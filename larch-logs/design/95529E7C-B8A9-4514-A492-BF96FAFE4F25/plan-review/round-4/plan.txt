## Failure modes
- A direct/manual caller relying on `design-log-publish.sh` returning exit 0 + `PUBLISH_OK=false` for a bad repo now sees `exit 1`. Mitigation: all in-repo callers pre-resolve/validate the repo and forward `--repo` only when non-empty; `design-pause-save.sh` treats exit-non-zero + empty `PUBLISH_OK` as `publish-failed`. Earliest signal: `test-design-log-publish.sh` green.
- Omitting the `render-run-summary.sh unknown` guard leaves a fake `larch-logs/design/unknown/` path on a `publish-skipped` summary. Mitigation: `test-render-run-summary.sh` + primary/fallback `test-render-final-summary.sh` cases assert **Run logs** is `N/A`.
- SKILL.md gate wording could drift from the pinned test. Mitigation: keep the existing substring intact, add the new `(27)` assertion, run `bash scripts/test-design-structure.sh`.
- Pause-save could still write a resume marker when publish exits non-zero but stdout carries `PUBLISH_OK=true`. Mitigation: contradictory-envelope normalization in `design-pause-save.sh` + `test-design-pause-resume.sh` `rc-ok-false` stub case; `rc-false-recovery` locks the valid recovery marker path.
- Broadening pause-save to fail on **every** non-zero publish exit would break post-push `RECOVERY_BRANCH` resume. Mitigation: narrow gate per reviewer feedback; regression stub `rc-false-recovery`.
- Step 0b clarify could regress to trusting `PUBLISH_OK=true` after a non-zero publish exit, lose recovery metadata, or advertise successful run logs after failed publish. Mitigation: SKILL.md sub-step 3 fail-closed/recovery prose plus structural assertions pinned to that bullet.
- Malformed `--repo` on direct `design-pause-save.sh` could reach `gh issue view` before publish validation. Mitigation: entry `validate_repo` + pause-resume test case.
- Non-default repo pause checks could still resolve hub default if a call site omits `--repo`. Mitigation: SKILL.md call-site edits plus structural assertion that pause-check invocations forward `REPO`.
- `publish-skipped` not added to the `render-final-summary.sh` enum would `exit 2`. Mitigation: enum edit + primary/fallback `test-render-final-summary.sh` cases.
