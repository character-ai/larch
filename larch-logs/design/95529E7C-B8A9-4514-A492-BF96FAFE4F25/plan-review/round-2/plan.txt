# Implementation Plan — fix 4 latent defects in the design-publish flush path (#3453)

SIMPLE tier. Four accepted review findings (FINDING_17, _11, _25, _4) in the
`/design` Step 5c publish tail, plus the entangled `render-run-summary.sh`
unknown-run-id leak that shares FINDING_4's root cause (Round 1 Decision 1,
"Full honest fix"). Each fix is surgical and independent; no shared refactor.
Scope, the FINDING_11 exit convention, and the FINDING_4 outcome shape are
fixed by Round 1 (`discussion-round1.md`).

Finding → fix:
- FINDING_17 — `design-publish.sh` trusts `PUBLISH_OK=true` on a non-zero publish exit. Force `PUBLISH_OK=false` on **any** non-zero exit (fail-closed).
- FINDING_11 — direct `design-log-publish.sh --repo` is unvalidated. Add a fail-closed `validate_repo` at entry; `exit 1` on a malformed repo (Round 1 Decision 2).
- FINDING_25 — `.completed/step-5c` is written on `PLAN_WRITE_OK` alone, so a failed publish advances past Step 5c. Gate the sentinel on publish success. The writer is **SKILL.md Step 5c**, not `design-publish.sh` (the finding misattributes it; verified).
- FINDING_4 — empty `SESSION_ID` renders an `approved` summary. Add a `publish-skipped` outcome so the summary is honest, and stop the shared `render-run-summary.sh` from advertising `larch-logs/design/unknown/` for that run.

## Approach
Five narrow, independent edits plus their tests and contract docs. No shared
helper or refactor. Each finding is fixed at its true site: FINDING_17 and
FINDING_4 in `design-publish.sh` (+ `render-final-summary.sh` for the new
outcome and `render-run-summary.sh` for the honest Run-logs path), FINDING_11
in `design-log-publish.sh` (entry `validate_repo` plus header contract), FINDING_25
in SKILL.md (the real sentinel writer) plus its pinned structural test, and
FINDING_17 parity in `design-pause-save.sh` so the pause publish path cannot
trust stdout `PUBLISH_OK=true` on a non-zero publish exit. The FINDING_11
exit-1 choice and the `publish-skipped` outcome follow Round 1. The direct
Step 0b clarify publish path receives the same fail-closed non-zero-exit
handling before any rename gate.

## Edge cases
- FINDING_17: success path (exit 0 + `PUBLISH_OK=true`) is untouched; only non-zero exits flip to false. Exit 0 + `PUBLISH_OK=false` still routes through the `elif` (rc bumped to 1 for the failure log).
- FINDING_17 pause parity: `design-pause-save.sh` recovery-branch and local-recovery paths still require `PUBLISH_OK=false` on exit 0; only the contradictory non-zero-exit + stdout-true case is newly blocked.
- FINDING_11: empty `--repo` is "no repo" (hub default) — validation runs only when `REPO` is non-empty, so omitting `--repo` is unaffected; `owner/repo` passes.
- FINDING_4: `publish-skipped` only fires when `SESSION_ID` is empty (so always `RUN_ID=unknown`); the normal non-empty-`SESSION_ID` flow keeps `approved` / `failed-publish`. **Run logs** stays `N/A` via the `render-run-summary.sh` guard.
- FINDING_25: empty-`SESSION_ID` (no publish) and `PUBLISH_OK=true` both still write `step-5c`; only an attempted-and-failed publish withholds it.

## Failure modes
- A direct/manual caller relying on `design-log-publish.sh` returning exit 0 + `PUBLISH_OK=false` for a bad repo now sees `exit 1`. Mitigation: all three in-repo callers pre-resolve/validate the repo and forward `--repo` only when non-empty; `design-pause-save.sh` already treats exit-non-zero + empty `PUBLISH_OK` as `publish-failed`. Earliest signal: `test-design-log-publish.sh` green.
- Omitting the `render-run-summary.sh unknown` guard leaves a fake `larch-logs/design/unknown/` path on a `publish-skipped` summary. Mitigation: `test-render-run-summary.sh` + `test-render-final-summary.sh` assert **Run logs** is `N/A`.
- SKILL.md gate wording could drift from the pinned test. Mitigation: keep the existing substring intact, add the new `(27)` assertion, run `bash scripts/test-design-structure.sh`.
- Pause-save could still write a resume marker when publish exits non-zero but stdout carries `PUBLISH_OK=true`. Mitigation: broaden `design-pause-save.sh` publish_rc gate + `test-design-pause-resume.sh` `rc-ok-false` stub case.
- Step 0b clarify could regress to trusting `PUBLISH_OK=true` after a non-zero publish exit. Mitigation: SKILL.md fail-closed prose plus the new structural assertion that the clarify path records the non-zero-exit warning and forces `PUBLISH_OK=false` before rename.
- `publish-skipped` not added to the `render-final-summary.sh` enum would `exit 2`. Mitigation: enum edit + `test-render-final-summary.sh` case.
