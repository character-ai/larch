## Edge cases

- **Both tools down, first interactive pass:** bootstrap emits `DEGRADED_PROMPT_REQUIRED=true`, relays the full explanation block, and skips 1.r.
- **Both tools down, Continue selected:** prompt-side writes the sentinel and reruns resume bootstrap; resume restores prior coder and runs 1.r internally.
- **Both tools down, Abort selected:** prompt-side sets stall state and skips to cleanup as today.
- **Both tools down, non-interactive:** bootstrap writes the sentinel, logs the full explanation block, and runs 1.r internally.
- **One tool down, interactive:** bootstrap prints the full explanation block once, writes the sentinel, and runs 1.r internally.
- **Missing or malformed `BOTH_DOWN`, interactive:** bootstrap fails closed to `DEGRADED_PROMPT_REQUIRED=true`.
- **Missing or malformed `BOTH_DOWN`, non-interactive:** bootstrap returns a contract failure rather than auto-proceeding or prompting.
- **Resume after dirty-tree recovery:** prior `coder` is restored before the absorbed tail.
- **Forked target:** bootstrap passes only `--forked-target true`; probe defaults still choose `upstream/main`.
- **Rebase conflict:** bootstrap returns rc `0` with `ROUTE=conflict` and `REBASE_RC=<probe_rc>`, so Step 0 itself is not treated as a wrapper failure.
- **Probe stdout includes `PHANTOM_*`:** bootstrap emits it on stdout only and excludes it from `bootstrap-routing.env`.

## Failure modes

- If the degraded gate subprocess fails unexpectedly, emit a bootstrap contract failure with a redacted diagnostic.
- If degraded gate output is missing the explanation block while reporting degraded state, emit a bootstrap contract failure before prompting.
- If `BOTH_DOWN` is missing or malformed in an interactive degraded run, fail closed to prompt-required routing.
- If `BOTH_DOWN` is missing or malformed in a non-interactive degraded run, emit a bootstrap contract failure.
- If the rebase probe emits no usable `ROUTE` after it runs, emit `ROUTE=bail`, `REBASE_OUTCOME=failed`, synthesized `REBASE_RC=<probe_rc>`, and a sanitized `REBASE_ERROR`.
- If `ROUTE` is absent because `DEGRADED_PROMPT_REQUIRED=true`, do not treat that as rebase failure.
- If `bootstrap-routing.env` is symlinked or non-regular, keep existing refusal behavior and still emit the current stdout envelope.
- If advisory `PHANTOM_*` append/logging fails, keep it advisory and never gate Step 2.
