## Edge cases

- Both invariant and guideline artifacts missing: publish refuses invariant first; Step 5c orchestration surfaces the invariant Return-to-Gate-C path first. After Gate C persists invariants, the existing guideline refusal can still catch a missing guideline artifact.
- Violations identified and remediated: Gate C must use the remediated-violations sidecar persist branch, not `--assessment clean`, so the audit trail records that violations were found and fixed.
- Present invariant file with no parsed `I-*` entries: no artifact is required; use the no-flags persist branch to remove stale artifacts.
- Invalid invariant file: no artifact is required, and stale artifacts should be removed by the no-flags persist call.
- Missing marker symlink: summary and log-publish code must not follow it.
- Direct log publish can continue, but it must record the missing invariant artifact as a committed warning.
- `approved-partition` runs with non-empty invariants require the invariant assessment artifact for publish refusal and run-log completeness.
