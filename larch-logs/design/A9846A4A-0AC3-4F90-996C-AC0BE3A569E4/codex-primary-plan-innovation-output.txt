1. **correctness** `scripts/launch-claude-review.sh:30-48`  
The planned parser arm cannot deliver the documented `exit 2` missing-value behavior. `${2:?…}` exits the shell directly with status 1 when `--context-files` is trailing, and it does not catch `--context-files --timeout 5` as missing because `--timeout` is a non-empty `$2`. Add explicit validation for this flag before `shift 2`.

2. **security** `scripts/launch-claude-review.sh:95-108`  
The plan’s containment test is incompatible with the proposed implementation. Since `append_context_file` adds each context file’s directory to `allow_root_args`, the subprocess will accept an explicit file outside the default roots. Decide whether explicit operator paths are meant to authorize their own root; then align implementation, docs, and test case 6.

3. **risk-integration** `scripts/launch-claude-subprocess.sh:134-165`  
The dedup test’s proposed `claude` argv capture cannot observe `--context-files`; the subprocess consumes those flags and only sends rendered prompt text to `claude` on stdin. Capture stdin and count rendered context blocks/content, or intentionally add a subprocess override hook and test through that.

4. **code-quality** `scripts/launch-claude-review.sh:92-108`  
The delimiter-string dedup is an avoidable edge-case trap. Indexed arrays plus a tiny equality loop stay Bash 3.2-compatible and avoid path delimiter ambiguity without much code.
