I would implement this as a thin launcher-surface extension, not a subprocess contract change. `launch-claude-subprocess.sh` already owns the authoritative context-file security contract: regular non-symlink files, allowed-root containment, 1 MB each, and max 20 files. `launch-claude-review.sh` should parse repeatable `--context-files <file>` flags, canonicalize/validate them early enough to hard-error with `larch_err` and exit `2` for empty, missing, symlink, or invalid paths, then pass the deduped list through to the subprocess. Existing implicit context flags should keep working unchanged.

The main script change belongs in [scripts/launch-claude-review.sh](<OPERATOR_REPO_PATH>/scripts/launch-claude-review.sh): replace the current scalar/silent `append_context_file` behavior with array-based collection for implicit context plus explicit `--context-files`. Dedup by canonical path across `--diff-file`, `--scope-files`, `--plan-file`, `--feature-file`, and repeated explicit entries, while preserving first-seen order. For every forwarded context file, add its canonical parent directory to `--allow-root` once, matching today’s behavior for implicit context. I’d also add a launcher-side combined count precheck so callers get a direct `launch-claude-review.sh` error before the subprocess cap trips, while keeping the subprocess cap authoritative. The docs in [scripts/launch-claude-review.md](<OPERATOR_REPO_PATH>/scripts/launch-claude-review.md) should explicitly say `--context-files` is role-orthogonal: reviewer/voter changes prompt rendering only, not context forwarding.

The main risk is duplicating validation logic from `launch-claude-subprocess.sh`; keep the launcher precheck minimal and aligned with the subprocess’s `canonical_existing_file` rules so errors are early but not divergent. Another risk is accidental behavior change for legacy implicit context paths: today unreadable implicit paths are silently skipped, so I would preserve that for existing flags unless design explicitly tightens it, while making explicit `--context-files` fail hard as clarified. Extend [scripts/test-launch-claude-review.sh](<OPERATOR_REPO_PATH>/scripts/test-launch-claude-review.sh) with cases for reviewer and voter explicit context forwarding, missing/empty explicit path exit `2`, dedup across implicit and repeated explicit paths, combined 20-file cap, and `--allow-root` behavior for a context file outside the output session root.
