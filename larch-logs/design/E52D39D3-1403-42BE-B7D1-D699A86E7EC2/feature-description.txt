# [BUG] Codex plan-review slots fail with "Not inside a trusted directory" because run_legacy_script overrides CWD to plugin root

## Context

During a `/design` plan-review run on this repo, all 6 Codex reviewer slots (4 static archetypes + 2 dynamic slots) failed immediately (1–3 s elapsed) while Cursor slots succeeded. The voter Codex call that ran later in the same session succeeded, indicating Codex itself was up.

## Symptoms

Codex sidecar for every failing reviewer slot contained:

```
Reading additional input from stdin...
Not inside a trusted directory and --skip-git-repo-check was not specified.
```

Exit code 1, stdout empty (0 bytes). `execution-issues.md` logged `exit 1 — unknown — auth-retries=1, transient-retries=1` for each slot.

Because the failure produced 0 bytes of output and no recognizable auth-error signal, `external_auth_verdict` returned `"unknown"` (not `"auth"`), so the auth-retry loop in `_run_external_agent_with_auth_retries` exited after 1 attempt without retrying up to the configured limit of 5.

## Root Cause

The call chain is:

```
design-step3-review.sh
  → python3 cli.py plan-review run --mode loop
    → plan_review.py: run_legacy_script(("skills","design","scripts","dispatch-plan-review-panel.sh"), ...)
      → subprocess.run([bash, script, ...], cwd=str(_REPO_ROOT))   ← forces CWD = plugin root
        → dispatch-with-waterfall.sh
          → python3 cli.py agent launch-review --tool codex ...
            → _review_launch_codex():  workdir = str(Path.cwd())   ← returns plugin root
```

`plan_review.py:run_legacy_script` (line 1031) forces `cwd=str(_REPO_ROOT)` when spawning the dispatch bash script. Every subprocess it spawns inherits that CWD. By the time `_review_launch_codex` reaches `workdir = str(Path.cwd())` (line 3540), the CWD is the plugin root:

```
<OPERATOR_REPO_PATH>/plugins/cache/larch-local/larch/50.0.10
```

This path:
- Is not a git repository (it is a sparse checkout / managed cache directory).
- Has no `.git` at its root level.

Codex is then launched with:
```
codex exec --sandbox read-only -C <plugin-root> \
  -c "projects.\"<plugin-root>\".trust_level=\"trusted\"" ...
```

Codex performs a git-repo check on the `-C` working directory. Because the plugin root is not a git repo root, the check fails with "Not inside a trusted directory."

The `OUTER_LAUNCHER_WORKDIR` field in `.meta` files for the failing slots confirms this:
```
OUTER_LAUNCHER_WORKDIR=<OPERATOR_REPO_PATH>/plugins/cache/larch-local/larch/50.0.10
```

The voter Codex call that succeeded later appears to use a different invocation path that does not share the `run_legacy_script` CWD override.

## Prescription

`_review_launch_codex` (`python/agents.py:3540`) must use the **consumer repo root** — the actual git repository being reviewed — not `Path.cwd()`. Two complementary approaches:

**Option A (preferred): resolve consumer repo root before using it as workdir.**

In `_review_launch_codex`, replace:
```python
workdir = str(Path.cwd())
```
with:
```python
workdir = _resolve_consumer_repo_root(str(Path.cwd()))
```

Where `_resolve_consumer_repo_root` runs `git -C <cwd> rev-parse --show-toplevel` and falls back to `<cwd>` on failure. This mirrors the existing `phase_driver_resolve_consumer_repo_root` in `scripts/lib-phase-driver.sh`.

**Option B (belt-and-suspenders): add `--workdir` to `agent launch-review` and pass consumer repo from the caller.**

The dispatch script or `plan_review.py` already knows the consumer repo root (it is where `design-step3-review.sh` was launched from — one level above the plugin root in a standard setup). Pass it explicitly rather than relying on `Path.cwd()` surviving the CWD override.

**Additionally**: the auth-retry gate in `_run_external_agent_with_auth_retries` should also treat `"unknown"` exit-1 with 0 bytes as retry-eligible (at least once), not just explicit `"auth"` failures. A clean exit-1 / empty-output failure from a transient startup issue is indistinguishable from a trust-check failure without retrying.

## Affected code

- `python/agents.py:3540` — `workdir = str(Path.cwd())` in `_review_launch_codex`
- `python/plan_review.py:1031` — `cwd=str(_REPO_ROOT)` in `run_legacy_script` (root cause of the CWD override)
- `python/agents.py:2182` — `external_auth_verdict != "auth"` early-return skips retries on `"unknown"` verdict
