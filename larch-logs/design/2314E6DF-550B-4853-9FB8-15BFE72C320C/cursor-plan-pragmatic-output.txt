**1. [correctness]** `python/rebase.py` (planned step 5) — Step 5 calls `version_bump.apply_bump` but never maps `ApplyResult.applied=False` to `Stalled`. Bash stalls when apply-bump reports `APPLIED!=true` (`scripts/ship-pr.sh:3080-3082`); without an explicit guard the Python path could proceed to `_commit_changelog_after_rebump` and force-push without a fresh bump commit. **Suggested revision:** after `apply_bump`, when `not result.applied`, raise `Stalled`; add a stub test in `python/test_rebase.py`.

**2. [correctness]** `python/rebase.py` (planned step 5) — No failure contract for `classify_bump` errors before the rebump/version-regression guard. `version_bump.classify_bump` raises `ShipError` on git diff failure (`python/version_bump.py:285-287`); an uncaught exception bypasses the `RebaseResult`/`Stalled` escalation model used elsewhere. **Suggested revision:** wrap `classify_bump` in `try/except ShipError` → raise `Stalled` with redacted detail; add a stub test.

**3. [correctness]** `python/rebase.py` (planned `_stage_rebump_bullets`) — Missing bash-parity benign paths for companion changelog drop. Orchestration only stalls on `drop_changelog_commit` `dropped=False` with non-"no match" errors; bash `ship_pr_stage_rebump_bullets` treats script failure (`scripts/ship-pr.sh:660-664`) and no matching commit (`scripts/ship-pr.sh:669-674`) as non-fatal legacy-path fallbacks. **Suggested revision:** treat `DropResult.error == "no changelog commit found"` like bump `"no bump commit found"`; on drop helper failure clear bullets and continue without `Stalled`; extend `python/test_rebase.py`.

**4. [OUT_OF_SCOPE] [architecture]** `python/rebase.py` (planned API) — No `HAS_BUMP`/skip-rebump gate on classify+apply tail. Bash skips the entire classify/apply/changelog block when `HAS_BUMP=false` (`scripts/ship-pr.sh:3020-3107`) for forked/no-skill repos; always-classify would PATCH-bump those paths at Phase 7 wire-up. **Suggested revision:** add optional `has_bump: bool = True` (or `skip_rebump_classify`) to `rebase_and_rebump`; when `False`, run `_sync_local_main` + force-push only; document for the `ship.py` driver.
