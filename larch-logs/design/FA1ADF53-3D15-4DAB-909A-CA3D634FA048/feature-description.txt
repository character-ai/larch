# [DESIGNING] Phase 1/4: implement-bootstrap.sh skeleton + phase_infra (umbrella #2732)

## Context

Phase 1 of 4 in the consolidation of `/implement` Step 0 into `scripts/implement-bootstrap.sh`. See umbrella issue #2732 for the full plan, rationale, naming choice (`implement-bootstrap.sh` pairing with `implement-finalize.sh`), and acceptance criteria.

This phase establishes the script skeleton and absorbs Step 0 calls #1–#5 only (infrastructure setup). Phases 2–4 add tracking adoption, plan materialization, and the implementer waterfall in turn.

## Goal

1. Create `scripts/implement-bootstrap.sh` with a working `phase_infra` function. Other phase function bodies stub out as `not_yet_implemented` placeholders that emit `IMPLEMENT_BAIL_REASON=not-yet-implemented-phase-N` so the orchestrator can route to Step 18 cleanly while later phases are in flight.
2. Create sibling `scripts/implement-bootstrap.md` documenting the full envisioned contract (argv, all output KV keys, breadcrumb list, exit codes, bail-reason enum) — even though only `phase_infra` is implemented in this PR.
3. Create offline harness `skills/implement/scripts/test-implement-bootstrap.sh` covering `phase_infra` paths.
4. Register `test-implement-bootstrap` in `Makefile` + `docs/linting.md`.
5. Add `implement-bootstrap.sh` to `scripts/lint-foreground-markers.sh` DENYLIST.
6. Edit `skills/implement/SKILL.md` to call `implement-bootstrap.sh` for Step 0 calls #1–#5 only. The remaining Step 0 prose (#6–#16 + waterfall) stays as today; the script returns early with the `phase_infra` outputs and the orchestrator continues with the existing fenced blocks.

After this phase: `/implement` Step 0 transcript shows 1 Bash call for calls #1–#5 (down from 5 separate calls), and the orchestrator still uses the legacy fences for the remaining 12+ calls. End-state convergence happens in phases 2–4.

## phase_infra contents

Absorbs:

1. `create-branch.sh --check` → `CURRENT_BRANCH`, `IS_MAIN`, `IS_USER_BRANCH`, `USER_PREFIX`
2. `session-entry-gate.sh` → `ENTRY_GATE`, `SKIP_BRANCH_CHECK`
3. `session-setup.sh --prefix claude-implement [--skip-branch-check] --check-reviewers` → `SESSION_TMPDIR`, `SESSION_ID`, reviewer-availability KV, `REPO`, `REPO_UNAVAILABLE`
4. Inline composite: `write-session-id.sh` + `token-claude-source.sh` + `write-session-env.sh` + `token-ledger.sh mark` + `timing-ledger.sh mark` → `CLAUDE_SOURCE_OK`, `LARCH_TOKEN_SESSION_ID`
5. Rehydrate block (read-session-env-key × 3) — moved entirely inside script

Reads `--caller-env` when `forked_target=true`. Emits `**⚠ Codex/Cursor not available/healthy …**` warnings via `emit` (operator-visible via lib-quiet FD-3). Emits one breadcrumb: `→ step0: infra ready (tmpdir=$IMPLEMENT_TMPDIR session=$SESSION_ID)`.
