/design skill gets new optional --skip-approve/-s argument (make sure -s is not already used) which, if passed skips asking the user for approval of plan outline in between Q&A and plan review, and also skips asking user approval for final plan, i.e., acts as though the user approved both. Of course, it should not skip or auto-answer any questions the model may have for the user other than these 2 approvals.


## Approved direction (outline)

## Proposed Design Outline

### Goals
- Add public boolean flag `--skip-approve` (short `-s`, default false) to `/design`. `-s` is currently unused.
- When set, auto-approve exactly two operator gates: Step 1d.7 outline-approval and Step 4b Gate C final-plan approval — as if the operator chose "Approve".
- Rename the existing public flag `--approve` → `--per-round-approval` (hard cutover; old spelling becomes an unknown-flag error). Disambiguates it from the new `--skip-approve`.

### Non-goals
- Do NOT skip or auto-answer any other prompt: Step 1c clarify, Step 1d round-1, degraded-tools gate, plan-size hard/drift brakes, validator escalation, dirty-tree recovery, decomposition panel all still fire.
- Do NOT change Gate B finding-apply behavior (still auto-applies by default; `--per-round-approval` still opts into per-round prompts).
- No deprecated `--approve` alias; no change to the internal `approve_requested` run-params key/binding.

### Approach sketch
- Thread one new boolean `skip_approve_requested` through the existing argv → run-params → gate-read plumbing, mirroring how `approve_requested` already flows.
- Parser (`parse-design-argv.sh`): accept `--skip-approve`/`-s`, emit `SKIP_APPROVE_REQUESTED=`, dup-guard it; rename the `--approve` arm to `--per-round-approval`.
- Persist `skip_approve_requested` in `run-params.json` (schema bump) via `write-run-params.sh`, forwarded by `design-init-runparams.sh` + SKILL.md Step 0b (argv bind, KV count, route/resume jq-merge).
- Gates read the flag from `run-params.json` (same jq pattern as the Gate B `APPROVE_REQUESTED=` read): at 1d.7 and Gate C, when true → print the outline / final-plan preview, emit `⏩ … auto-approved (--skip-approve)`, take the Approve branch, fire no `AskUserQuestion`.

### Surfaces in scope
- `skills/design/scripts/parse-design-argv.sh` (+ `.md`), `scripts/write-run-params.sh` (+ `.md`), `skills/design/scripts/design-init-runparams.sh` (+ `.md`)
- `skills/design/SKILL.md` (flag table, Step 0-pre/0b fences, Step 1d.7, Step 4b), `skills/design/references/flags.md`, `references/design-outline.md`, `references/approval-gates.md`
- Test harnesses: `test-parse-design-argv.sh`, `test-write-run-params.sh`, `scripts/test-design-structure.sh`, `test-step0b-router-flag-recovery.sh` (+ any flag/rename pins)
