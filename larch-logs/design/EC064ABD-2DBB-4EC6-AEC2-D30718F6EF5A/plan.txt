## Edge cases

- Markdown wrapping can raise line count while reducing bytes. Prefer compact physical lines for these three files.
- Do not collapse pinned literals across line breaks.
- Do not delete rules only because they appear verbose.
- `BASH_AUTHORING.md` may cross-link `AGENTS.md` for the shared residual-Bash rule, but only the shared rule.
- `AGENTS.md` Honesty can point to `KARPATHY_CLAUDE.md` §1 only for overlapping philosophy, not for concrete reporting obligations.

## Failure modes

- CI fails if caps are set before prose is trimmed.
- CI fails if an exact `AGENTS.md` literal pinned by `scripts/test-implement-anti-polling-rule.sh` is rewrapped or renamed.
- CI fails if `BASH_AUTHORING.md` drops its unique hook, sessionstart fallback, or residual-bash-paths guidance while cross-linking `AGENTS.md`.
- A too-low cap may tempt semantic deletion. Raise the cap to the final safe trimmed count instead.
- A linter path outside `python/cli.py` would violate the Python-first convention. Keep the ratchet behind `python3 python/cli.py`.
