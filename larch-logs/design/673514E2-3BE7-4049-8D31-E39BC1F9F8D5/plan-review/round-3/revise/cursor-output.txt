# Implementation Plan — #3420: thin Step 0b (cancel/resume into drivers)

## Goal

Move the non-LLM rendering of Step 0b's two consumption fences out of `SKILL.md` and into the phase drivers, so each driver emits a single STATUS + exit code and the orchestrator fences collapse to capture → parse result-env → branch into only the genuinely-LLM routes (proceed/tier, clarify loop, already-planned prompt, resume continuation). Behavior across all seven routing outcomes is preserved; only WHERE the rendering happens moves.

## Approach

Two phase drivers already own routing/init logic and emit a result-env + stdout KV contract via `lib-phase-driver.sh` (`emit_kv`, `phase_driver_write_result_env`, `larch_err`). This change extends each driver to also own the operator-facing rendering that currently lives inline in `SKILL.md` Step 0b, then thins the SKILL.md fences.

Key moves:
- `design-route.sh` gains ownership of: cancel-route `render-final-summary.sh` (after result-env is written), cancel reject banners (`larch_err`/`larch_errf`), reentry-guard banner composition, and resume `write-design-current-env.sh` (including `manual_gate_b` from `run-params.json`).
- `design-init-runparams.sh` gains ownership of its two failure banners (contract-drift, env-refresh-failed) — it already sets `INIT_STATUS` and exits 1; it will additionally print the detailed operator message itself.
- `SKILL.md` Step 0b: both consumption fences shrink. The route fence keeps capture, exit-2/exit-1 aborts, file-first result-env read, and `_route_valid`; add `--session-id "$SESSION_ID"` to the driver invocation. **Cancel handoff (FINDING_1):** collapsed `case` bodies for `cancel-title-filter` / `cancel-reentry-guard` are **no-ops** inside the bash fence (no `exit 1`, no inline render); the fence ends with **exit 0** when `design-route.sh` exits 0. **Post-fence orchestrator prose** (Step 5c item 3 pattern) reads `ROUTE` from the parsed result contract (`$DESIGN_TMPDIR/.design-route-result.env` and/or merged stdout KVs — **not** on overall fence failure), and when `ROUTE` is `cancel-title-filter` or `cancel-reentry-guard` and `[ -s "${FINAL_SUMMARY_PATH:-$DESIGN_TMPDIR/final-summary.md}" ]`, emits `final-summary.md` verbatim, **then** aborts `/design` before sub-step 3. `cancel-pause-load` keeps its orchestrator abort banner + fence `exit 1`. `resume@*` on `_route_rc=0` prints `resumed from STEP=` only (no inline env refresh).
- **Operator channel split:** reject banners are driver stderr (`larch_err`/`larch_errf`) during the bash tool call; structured summary body is orchestrator chat text after the fence when non-empty. Visible ordering: reject banner in Bash stderr first, verbatim summary in chat second, then orchestrator abort — **mandatory even though the route fence exits 0** on cancel paths.

**Quiet-driver contract (post-`larch_quiet_init`).** Every moved operator-facing banner and resume/init failure diagnostic MUST use `larch_err` / `larch_errf`, not raw `printf`/`echo` `>&2`. Child stderr of `render-final-summary.sh` and `write-design-current-env.sh` MUST use the quiet-aware bridge below.

### Critical hazard — render-final-summary.sh stdout vs. the KV contract

`render-final-summary.sh --post-publish-only` prints the summary body on stdout and performs GitHub upsert + `final-summary.md` write. Driver stdout IS the KV stream consumed by `_route_out=$(...)`; summary stdout MUST be redirected (`>/dev/null`, **no** `2>&1`). Wrap each cancel render in `set +e` / `|| true` so a non-zero render does not abort the driver under `set -e` before KV emit — still emit `ROUTE=cancel-*` and the reject banner.

**Renderer / child stderr under quiet (FINDING_3, FINDING_4).** Mirror `render-run-summary.sh` `emit_diag`: when `[ "${LARCH_QUIET_PID:-}" = "$$" ]`, invoke children as `… >/dev/null 2>&4`; otherwise `>/dev/null` only (stderr to default). Apply to **both** `render-final-summary.sh` and resume `write-design-current-env.sh`. Do not claim "live stderr" without the `2>&4` redirect.

**CLI flags (not env-only).** `render-final-summary.sh` requires `--outcome` and `--mode` argv. Cancel branches pass `--outcome cancelled-title-filter` + `--mode N/A`, or `--outcome cancelled-reentry-guard` + `--mode` from `jq -r '.design_classification // "N/A"'` on `run-params.json`, plus `${REPO:+--repo}`.

### Result-env before side effects (FINDING_4)

On cancel routes, **write and validate** `$DESIGN_TMPDIR/.design-route-result.env` (symlink refusal via `phase_driver_write_result_env`) **before** any `render-final-summary.sh` call. Refactor `emit_route_result` into helpers, e.g.:
1. `route_build_kvs` → array of KVs for current `ROUTE` / guard fields.
2. `route_write_result_env` → `phase_driver_write_result_env` only; on refusal `exit 1` (no render, no upsert).
3. `route_emit_cancel_side_effects` → reject `larch_err`/`larch_errf`, command-scoped render (below), **no** stdout KV emit yet.
4. `route_emit_stdout_and_exit` → `emit_kv` loop + `exit 0`.

Cancel-title-filter / cancel-reentry-guard call (2) → (3) → (4). Proceed/clarify/already-planned/resume keep today's single tail emit unless they gain cancel-like side effects.

### Session / issue identity for render (FINDING_1, FINDING_5, FINDING_6)

`render-final-summary.sh` reads `DESIGN_TMPDIR`, `ISSUE_NUMBER`, and `SESSION_ID` from the environment. Module `SESSION_ID` remains **pause-load-only** for `SESSION_ID=` result-env KVs on `resume@*` — never assign argv into it.

- Add required `--session-id` argv → `SESSION_ID_ARG`.
- **Validation (FINDING_5):** add `validate_session_id_arg` that rejects newline/CR only (**empty string allowed**). Require the flag be present; do **not** use `validate_plain_scalar` (which rejects `''`). Empty `SESSION_ID_ARG` preserves today's `render-final-summary.sh` degradation (`RUN_ID=unknown`).
- **Command-scoped render env (FINDING_6):** do **not** `export SESSION_ID="$SESSION_ID_ARG"` (that clobbers module `SESSION_ID` before `emit_route_result`). Invoke render as:

  ```bash
  DESIGN_TMPDIR="$DESIGN_TMPDIR" ISSUE_NUMBER="$ISSUE" SESSION_ID="$SESSION_ID_ARG" \
    render-final-summary.sh --outcome … --mode … --post-publish-only >/dev/null 2>&4
  ```

  (adjust `2>&4` per quiet predicate). Resume `write-design-current-env.sh` uses pause-loaded module `SESSION_ID` for `--session-id`, with the same quiet stderr bridge on the child invocation.

## Edge cases
- **SESSION_ID split:** `SESSION_ID_ARG` for render only; module `SESSION_ID` pause-load-only; never `export SESSION_ID` for cancel render (FINDING_6).
- **Empty SESSION_ID_ARG (FINDING_5):** allowed at argv parse; render uses `RUN_ID=unknown` fallback.
- **Cancel summary skipped (FINDING_1):** orchestrator must emit when file non-empty regardless of fence exit code; gate on parsed `ROUTE`, not fence success alone.
- **Result-env refusal (FINDING_4):** no render/GitHub upsert when `phase_driver_write_result_env` fails (`exit 1`).
- **render stdout pollution:** redirect stdout only; KV stream stays clean.
- **render non-zero under set -e:** `set +e` / `|| true` before stdout KV emit.
- **Empty final-summary.md:** orchestrator `[ -s … ]` gate skips emit; operator still sees driver `larch_err` reject banner.
- **Resume env-refresh failure:** driver `exit 1`, no `ROUTE=resume@*`; orchestrator generic `_route_rc` abort; child stderr via `2>&4`.
- **manual_gate_b missing run-params.json:** treat as `false`.
- **Operator message order:** reject in Bash stderr during driver; summary verbatim after fence; then abort.
- **cancel-pause-load:** no driver summary; orchestrator banner only; fence `exit 1`.
- **Brainstorm-prefix banner:** stays orchestrator-side.
- **Stale docs:** grep `docs/`, `README.md`, `SECURITY.md` for inline Step 0b cancel/resume rendering references.

## Failure modes
- **KV stream pollution:** mis-parse `ROUTE`. Mitigation: `>/dev/null` on render stdout; allowlisted KV emit only.
- **Summary never emitted (FINDING_1):** in-fence `exit 1` or abort before post-fence read. Mitigation: cancel `case` no-op + fence `exit 0` + mandatory post-fence emit pin.
- **Lost GitHub upsert:** keep `--post-publish-only`, redirect stdout only.
- **Lost renderer / resume diagnostics:** quiet log swallow. Mitigation: `2>&4` under quiet; pins in `$DESIGN_ROUTE_SH`.
- **Side effects without contract (FINDING_4):** render before result-env. Mitigation: write result-env first; `exit 1` on refusal before render.
- **SESSION_ID clobber (FINDING_6):** wrong resume KVs. Mitigation: command-scoped render env only.
- **Pin under-coverage (FINDING_7):** weak moved anchors. Mitigation: exact literal `grep -Fq` table above; delete old SKILL.md pins when adding driver pins.
