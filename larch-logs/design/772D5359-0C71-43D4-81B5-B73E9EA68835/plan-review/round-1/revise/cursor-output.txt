## Edge cases

- **No rejected findings**: emit nothing. Do not print a heading.
- **All rejected findings filtered by applied-key ledger**: emit nothing. Do not print a heading.
- **Ledger missing**: emit the raw rejected body, framed only when `--report-framing` is passed.
- **Unrecognized rejected body with ledger present**: preserve current fail-closed empty emit and warning behavior.
- **CLI failure in tail wrapper**: fallback still frames the raw file so the operator does not see the stale "unimplemented" label.
- **Manual Step 3 re-run from Gate C**: reviewers get the current `plan.txt` through the existing `--plan-file` path. No new state is needed.
- **Premature empty notification**: yield or probe `.completed/step-3-terminal` first; print the post-notification table only after confirmed completion, before parsing result env.
- **Audit finds no `/implement` hits**: document "no `/implement` change needed" explicitly; do not add drive-by `/implement` edits.
