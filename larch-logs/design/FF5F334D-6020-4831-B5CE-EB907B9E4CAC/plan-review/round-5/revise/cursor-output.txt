Reviewing the codebase for astroid/Pylint ingestion and the current parity gate so the revised plan matches existing patterns.
## Plan

## Approach

- Keep the existing `python-lint-duplicate-code` CI job.
- Replace its `pylint -j 1` duplicate-code invocation with `python3 python/cli.py lint duplicate-code`.
- Add a Python runner that delegates comparison semantics to **Pylint 4.0.5** `pylint.checkers.symilar` via a minimal **`PyLinter` + `SimilaritiesChecker`** bootstrap (not hand-rolled `expand_modules` glue plus bare `Symilar.append_stream`). **Do not copy or vendor Pylint GPL comparison loops**; call pinned APIs and fail closed with exit `2` on import or API drift.
- **R0801 equivalence contract**: file set, ignore rules, stripping, threshold (`> min_similarity_lines`, not `>=`), global message enablement (`--disable=all --enable=duplicate-code`), per-module `process_tokens` / `file_state`, per-line pragma handling, astroid `Module` ingestion before `process_module`, and `SimilaritiesChecker.close()` reportability must match today's `cd python && pylint --disable=all --enable=duplicate-code -j 1 .` baseline. Output text may differ; pass/fail decisions and **reportable cluster membership** must not tighten or loosen vs pinned R0801.
- **Ingestion (single-threaded, O(files))**: bootstrap one `PyLinter` from the rcfile, pin message state to the legacy job (`--disable=all --enable=duplicate-code`), discover modules through Pylint's normal expansion path, then for each discovered module run the same sequence Pylint uses before similarities comparison: set current module, tokenize, `process_tokens`, **build an astroid `nodes.Module` for the file**, then `SimilaritiesChecker.process_module(node)`. Build `linesets` on the checker-owned configured `Symilar` instance. **Do not** call `process_module` with a path string or token stream alone; Pylint 4 `process_module` expects an astroid `Module` and reads `node.stream()`. **Do not** build line sets with standalone `Symilar()` plus `append_stream` alone; bare `Symilar` does not wire `line_enabled_callback` to `linter._is_one_message_enabled` and ignores `# pylint: disable` pragmas during `stripped_lines`.
- **Threshold config**: configure `min_similarity_lines` and the four `[SIMILILARITIES]` `ignore-*` flags on the checker/`Symilar` namespace (pylint 4.0.5 reads `self.namespace.min_similarity_lines` inside `_find_common`; there is no standalone `self.min_similarity_lines` property). Pass parsed yn values explicitly; never rely on bare `Symilar()` constructor defaults for the four ignore flags.
- **Parallelism (pair comparisons only)**: after ingestion, enumerate candidate pairs with `itertools.combinations(range(len(linesets)), 2)` and parallelize **unordered file-pair comparisons** across workers. Parent holds one configured checker/`Symilar` instance and the full `linesets` list. Workers call **`symilar._find_common(linesets[i], linesets[j])`** on that instance-bound object only. **Do not** use Pylint `-j > 1`. **Do not** shard by file slices. **Do not** use `Symilar._iter_sims` for pair partitioning (it already calls `_find_common` per pair and would double work).
- **Exit / fail path**: after merging worker `Commonality` results, run `_compute_sims`-equivalent deduplication and the same `is_message_enabled` / multi-file attribution checks `SimilaritiesChecker.close()` uses before deciding reportability. Exit `1` only when at least one cluster would produce R0801 under pinned semantics. **Do not** treat every non-empty `_find_common` yield as a failure.
- **Pre-cutover parity gate (merge blocker)**: before swapping the Makefile target, run both the legacy pylint command and the new CLI on the unchanged `python/` tree and require:
  1. **Exit-code equality** (`0`==`0` or `1`==`1`; any `2` from either command fails the gate).
  2. **Reportable-cluster signature equality**: a normalized digest of clusters that would emit R0801 under pinned `close()` semantics must match between legacy and new runners. Treat exit-code-only agreement as a fast precheck; cluster mismatch is a merge blocker even when both exit `1`.
- **Speed acceptance (hard gate)**: the issue is **not complete** until GitHub Actions `python-lint-duplicate-code` wall time is **≤ 90s** on `ubuntu-latest`. If within-runner pair parallelism alone does not meet ≤90s after Makefile cutover, **include the required `.github/workflows/ci.yaml` matrix-sharding change in this same PR/issue** before close. Do not close with only a linked follow-up while the job remains above 90s.

### NEW: `python/duplicate_code.py`

Add the new runner module. Module docstring must state **pylint==4.0.5** and document threshold parity: Pylint reports only when `filter_noncode_lines` effective common lines are **strictly greater than** `namespace.min_similarity_lines`.

**Lazy Pylint imports**: defer all `pylint.*` and `astroid.*` imports until `duplicate_code_main` runs (or a dedicated `_import_pylint_backend()` helper it calls). Top-level module load must not require Pylint so `test_all_registry_targets_resolve_to_callable_mains` can import the module when only stdlib/test deps are present.

Key pieces:

- `DuplicateCodeConfig`
  - Load rcfile (default `python/.pylintrc`).
  - Parse `[SIMILARITIES]`:
    - `min-similarity-lines` (int).
    - All four `ignore-*` flags using Pylint **yn** yes/no parsing (`yes`/`no`, case per Pylint config parser).
  - Reuse `[MAIN]` ignore settings needed for module discovery parity: `ignore`, `ignore-patterns`, `ignore-paths`.

- **PyLinter bootstrap (discovery + ingestion parity)**
  - `--root` default `python`; run with `cwd=root` semantics so discovery and ignore matching are **root-relative**, matching `cd python && pylint .` (e.g. `ignore-paths=.venv/` excludes `python/.venv/` when invoked from repo root with `--root python`).
  - Construct a minimal `PyLinter` loaded from the rcfile (or equivalent pinned bootstrap).
  - **Pin global R0801 message state** to the legacy Makefile invocation: apply the equivalent of `--disable=all --enable=duplicate-code` on the linter/checker **before** building line sets or wiring `line_enabled_callback`. The main `.pylintrc` disables `duplicate-code`; without this step `_is_one_message_enabled` suppresses every R0801 and exit `0` on real duplicates.
  - Discover modules through Pylint's normal expansion path on that linter (not independent `rglob` plus ad hoc ignore glue).
  - Register/obtain `SimilaritiesChecker` on the linter; configure its `Symilar` namespace with parsed `[SIMILARITIES]` values (`namespace.min_similarity_lines` and all four `ignore-*` flags).
  - **Per-module ingestion sequence** (single-threaded): for each discovered module, run the same order Pylint uses:
    1. set current module on the linter
    2. tokenize
    3. `process_tokens` (builds per-module `file_state` for line/block disables)
    4. **parse the file into an astroid `nodes.Module`** (same source path / encoding Pylint uses for that module)
    5. `SimilaritiesChecker.process_module(node)` (appends to checker `linesets` with `line_enabled_callback` wired to `linter._is_one_message_enabled` for `duplicate-code` / R0801)
  - Sort paths for stable output. Keep tests in scope unless Pylint excludes them.
  - Apply Pylint's three distinct ignore rules via the linter bootstrap: `ignore` (base names), `ignore-patterns` (regex on base names), `ignore-paths` (regex on paths).

- **Line sets and disable parity**
  - **Do not remove disabled files from `linesets` before pair enumeration**; Pylint still compares disabled modules when emitting R0801 for an enabled peer.
  - `line_enabled_callback` must come from the `PyLinter` + `process_tokens` + `process_module` path, not a hand-built `LineSet(...)` without `file_state`.
  - After building the full `linesets` list on the checker-owned configured `Symilar`, derive unordered pair indices with `itertools.combinations(range(len(linesets)), 2)`. **Do not** use `Symilar._iter_sims` for enumeration or chunking in the parallel path.
  - For each `(i, j)` pair, call **`symilar._find_common(linesets[i], linesets[j])`** on the configured instance (instance method: `self`, `lineset1`, `lineset2`). **Never** call unbound `Symilar._find_common(...)`; that binds the first `LineSet` as `self`, drops the real second operand, and breaks threshold semantics.
  - On missing symilar/checker symbols or incompatible signatures: print clear stderr and exit `2`. **No copy-source fallback.**

- **Parallelism**
  - Parent completes ingestion once (configured `PyLinter` + `SimilaritiesChecker` + full `linesets`).
  - Materialize the full pair-index list from `itertools.combinations(range(len(linesets)), 2)`.
  - Partition **pair indices** into chunks (not file slices).
  - `ProcessPoolExecutor` workers receive pair indices and call **`symilar._find_common(linesets[i], linesets[j])`** on the parent-built configured instance. On POSIX, prefer `fork` multiprocessing context when available so workers inherit the parent-built `symilar` and `linesets` cheaply; when fork is unavailable, pass the configured instance and line sets to workers explicitly rather than rebinding unbound methods.
  - `--jobs 1`: run the same `combinations` loop in the parent (no pool) using the same configured `symilar` instance; deterministic debugging path.
  - Default workers: `os.cpu_count()` capped by pair count.
  - `--jobs` and `LARCH_DUPLICATE_CODE_JOBS` for override; `--jobs 0` means auto (same as Pylint jobs=0 semantics). Reject invalid values with exit `2`.

- **Reportable-cluster digest (parity gate support)**
  - Add `--emit-cluster-digest` (or equivalent internal helper callable from tests) that runs the full ingestion + close-equivalent merge path and prints a **stable normalized signature** of reportable clusters: sorted tuples of participating file paths plus normalized line spans (or a close()-derived digest with the same sort order). Human-readable finding text is not part of the digest.
  - Digest must reflect `close()` reportability, not raw `_find_common` yields.

- **Output and exit codes**
  - Collect `_find_common` results from workers (or the parent loop when `--jobs 1`).
  - Merge and deduplicate with `_compute_sims`-equivalent logic, then apply the same `is_message_enabled` / attribution rules `SimilaritiesChecker.close()` uses before printing findings.
  - Stable-sort reportable clusters by path and line number, then print findings.
  - Exit `0` when no cluster would emit R0801 under pinned semantics.
  - Exit `1` when at least one cluster would trigger R0801 under the pinned checker after close-equivalent gating.
  - Exit `2` for usage, config, import, API drift, or internal/worker errors.
  - Message text need not be bit-identical to Pylint R0801.

Focused `tmp_path` tests only; no full-repo scans.

Required cases:

- **Config parsing**
  - Reads `min-similarity-lines=8`.
  - Reads all four `ignore-*` flags with yn parsing (`yes`/`no`); assert explicit values passed to symilar namespace config, not `Symilar()` defaults alone.
  - Assert configured threshold lives on `namespace.min_similarity_lines`, not a nonexistent `min_similarity_lines` attribute.
  - Honors basic ignore settings.

- **Global message enablement**
  - With rcfile that disables `duplicate-code` in `[MESSAGES CONTROL]`, bootstrap still enables only R0801 (legacy `--disable=all --enable=duplicate-code` parity).
  - Fixture with reportable duplicate fails exit `1` when global state is correct; monkeypatch that leaves R0801 globally disabled must not be used as the production path.

- **Per-module ingestion (`process_tokens` → astroid `Module` → `process_module`)**
  - Spy or monkeypatch: for each module, `process_tokens` runs before `SimilaritiesChecker.process_module`.
  - Assert `process_module` receives a real astroid `nodes.Module` (not a path, not `None`, not a mock token stream).
  - Fixture where block-level disable depends on `file_state` from `process_tokens` matches legacy pylint pass/fail.

- **Ignore-rule parity (three rules)**
  - Fixture excluded only by `ignore` (base name) is not scanned.
  - Fixture excluded only by `ignore-patterns` (base name, e.g. `__pycache__`) is not scanned.
  - Fixture excluded only by `ignore-paths` (path regex, e.g. `.venv/` under `--root`) is not scanned.

- **Root-relative ignore-paths**
  - Under `--root` subdir layout, a file under `root/.venv/` is excluded when rcfile has `ignore-paths=.venv/` (parity with `cd root && pylint .`).

- **No duplicates**
  - Two files with similar shape but fewer than threshold normalized lines pass with exit `0`.

- **Duplicate detected (strict greater-than)**
  - Two files with a duplicate block of **`min_similarity_lines + 1`** normalized lines fail with exit `1`; output names both files.
  - Two files with a duplicate block of **exactly `min_similarity_lines`** pass with exit `0` (Pylint 4.0.5 parity).

- **Threshold guard**
  - Block below `min-similarity-lines` passes.
  - Block at `min-similarity-lines` passes.
  - Block at `min-similarity-lines + 1` fails.

- **Pylint disable fixtures (compare all pairs; suppress at close-equivalent collection)**
  - Disabled files remain in `linesets`; pair enumeration still covers disabled↔enabled combinations.
  - File with `# pylint: disable=all` containing an otherwise-reportable duplicate paired with an enabled file: no report when only the disabled side would attribute R0801.
  - File with `# pylint: disable=duplicate-code` likewise excluded from attribution while pairs are still compared.
  - Enabled peer with a reportable duplicate against a disabled file still fails with exit `1` when legacy pylint would.

- **Close-equivalent exit gating**
  - Fixture where raw `_find_common` yields exist but `close()` would not emit R0801 (multi-file attribution / enable gating): exit `0`.
  - Fixture where `close()` would emit R0801: exit `1`.
  - Assert decision uses merged `_compute_sims`-equivalent path, not non-empty `_find_common` alone.

- **Cluster digest stability**
  - Same fixture tree produces identical digest across serial (`--jobs 1`) and parallel paths.
  - Digest changes when a reportable cluster is added or removed.

- **Configured instance binding**
  - Spy or monkeypatch: serial and parallel paths call `symilar._find_common(linesets[i], linesets[j])` on the parent-built configured instance, not unbound `Symilar._find_common(...)`.

- **Pair enumeration (not `_iter_sims`)**
  - Monkeypatch or spy: parallel and serial paths enumerate pairs via `itertools.combinations(range(len(linesets)), 2)` and call instance-bound `_find_common` per pair; `Symilar._iter_sims` is not used for partitioning or pre-scan.

- **Cross-file shard guard**
  - At least three files; duplicate spans files that naive file-slice sharding would split.
  - `--jobs 2` still fails; `--jobs 1` same pass/fail class.

- **Import / API failure**
  - Monkeypatch symilar/checker import or `_find_common` resolver; assert exit `2` and clear stderr (no silent pass, no copied fallback).

## Edge cases

- Empty Python file set: exit `0`; empty cluster digest.
- One Python file: exit `0` (zero pairs from `combinations`).
- Missing rcfile: exit `2`.
- Invalid `min-similarity-lines` or yn flag values: exit `2`.
- Astroid parse failure for a discovered module: exit `2` (fail closed; do not skip silently).
- `--jobs 1`: deterministic debugging path; same pass/fail and digest as parallel path.
- `--jobs 0`: auto worker count (documented and tested).
- Worker exceptions: fail closed with exit `2`.
- Exactly-at-threshold duplicate: exit `0` (Pylint parity).
- Disabled↔enabled pairs: still compared; suppression applies at close-equivalent merge/print, not by dropping disabled files from `linesets`.
- No-duplicate full tree: parallel path must not pre-run all comparisons single-threaded via `_iter_sims` before workers start.
- `.pylintrc` disables `duplicate-code` globally: runner must override to legacy `--disable=all --enable=duplicate-code` before ingestion.
- Legacy and new both exit `1` but cluster digests differ: parity gate fails (merge blocker).

## Failure modes

- **Pylint internal API drift** breaks the adapter.
  - Mitigation: pin `pylint==4.0.5` in `requirements-dev.txt` and `requirements-test.txt`; import-failure and API-missing paths exit `2`; adapter-layer tests monkeypatch symilar/checker entry points.
- **Missing astroid `Module` before `process_module`** diverges from pylint ingestion and breaks `file_state` / pragma wiring.
  - Mitigation: explicit astroid parse between `process_tokens` and `process_module`; test asserts real `nodes.Module` argument.
- **Bare `Symilar.append_stream` ingestion** ignores pragma disables and diverges from legacy pylint.
  - Mitigation: `PyLinter` bootstrap + per-module `process_tokens` + astroid `Module` + `SimilaritiesChecker.process_module`; disable fixtures and parity gate.
- **Wrong threshold attribute** (`min_similarity_lines` vs `namespace.min_similarity_lines`).
  - Mitigation: configure and test `namespace.min_similarity_lines` explicitly.
- **Missing global R0801 enablement** leaves duplicate-code disabled via `.pylintrc`.
  - Mitigation: pin `--disable=all --enable=duplicate-code` message state before ingestion; dedicated test with rcfile that disables duplicate-code.
- **Unbound `_find_common` calls** mis-bind `LineSet` as `self` and break threshold semantics.
  - Mitigation: one parent-built configured `Symilar`; all paths call `symilar._find_common(...)`; dedicated test asserts instance binding.
- **Raw `_find_common` yields used as exit signal** diverge from `close()` reportability.
  - Mitigation: `_compute_sims`-equivalent merge plus `is_message_enabled` gating; dedicated close-equivalent tests; cluster digest uses same path.
- **Exit-code-only parity gate** passes while reportable clusters differ.
  - Mitigation: mandatory cluster-digest equality in pre-cutover gate; dedicated parity test module.
- **Misusing `_iter_sims` for parallel partitioning**.
  - Mitigation: enumerate with `itertools.combinations`; dedicated test asserts `_iter_sims` is not used for chunking.
- **Pair sharding accidentally becomes file sharding**.
  - Mitigation: cross-file shard guard test; pair indices from `combinations(range(len(linesets)), 2)`.
- **File-set drift vs current job**.
  - Mitigation: PyLinter discovery bootstrap plus three-rule ignore tests; mandatory full-tree exit-code **and** cluster-digest parity gate before Makefile cutover.
- **Stdlib-only gate regression**.
  - Mitigation: `test_stdlib_only.py` allowlist entry for `duplicate_code` → `pylint`, `astroid`.
- **Speed goal not met after cutover**.
  - Mitigation: ≤90s GHA wall time is a **hard** acceptance gate; if exceeded, ship required `ci.yaml` matrix sharding in this same PR before close.
- **Output text differs from R0801**.
  - Acceptable if CI gate pass/fail and cluster digest match pinned Pylint for the same tree and rcfile.
