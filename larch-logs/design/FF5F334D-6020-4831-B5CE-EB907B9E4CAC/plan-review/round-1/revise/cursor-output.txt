## Plan

## Approach

- Keep the existing `python-lint-duplicate-code` CI job.
- Replace its `pylint -j 1` duplicate-code invocation with `python3 python/cli.py lint duplicate-code`.
- Add a Python runner that delegates comparison semantics to **Pylint 4.0.5** `pylint.checkers.symilar` (not `pylint.checkers.similar`, which does not exist in this pin). **Do not copy or vendor Pylint GPL comparison loops**; call pinned APIs and fail closed with exit `2` on import or API drift.
- **R0801 equivalence contract**: file set, ignore rules, stripping, threshold (`> min_similarity_lines`, not `>=`), and per-line `pylint: disable` handling must match today's `cd python && pylint --disable=all --enable=duplicate-code -j 1 .` baseline. Output text may differ; pass/fail decisions must not tighten or loosen vs pinned R0801.
- Parallelize **unordered file-pair comparisons** across workers while building normalized `LineSet` objects once in the parent. **Do not** use Pylint `-j > 1`. **Do not** shard by file slices (that misses cross-shard duplicates).
- Do not change `.github/workflows/ci.yaml` unless implementation measurement shows the within-runner parallel path still misses the target.

### NEW: `python/duplicate_code.py`

Add the new runner module. Module docstring must state **pylint==4.0.5** and document threshold parity: Pylint reports only when `filter_noncode_lines` effective common lines are **strictly greater than** `min_similarity_lines`.

**Lazy Pylint imports**: defer all `pylint.*` imports until `duplicate_code_main` runs (or a dedicated `_import_symilar()` helper it calls). Top-level module load must not require Pylint so `test_all_registry_targets_resolve_to_callable_mains` can import the module when only stdlib/test deps are present.

Key pieces:

- `DuplicateCodeConfig`
  - Load rcfile (default `python/.pylintrc`).
  - Parse `[SIMILARITIES]`:
    - `min-similarity-lines` (int).
    - All four `ignore-*` flags using Pylint **yn** yes/no parsing (`yes`/`no`, case per Pylint config parser). **Never** rely on bare `Symilar()` constructor defaults for these four flags; pass parsed values explicitly into `LineSet` / `Symilar`.
  - Reuse `[MAIN]` ignore settings needed for module discovery parity: `ignore`, `ignore-patterns`, `ignore-paths`.

- **File discovery (Pylint parity, not hand-rolled rglob)**
  - `--root` default `python`; all discovery and ignore matching use paths **relative to `--root`**, matching Pylint's behavior when `cwd=root` (e.g. `ignore-paths=.venv/` excludes `python/.venv/` when invoked from repo root with `--root python`, not only repo-root `.venv/`).
  - Build the scanned module/file list the same way Pylint does for `pylint .` under that root: minimal `PyLinter` / `expand_modules` bootstrap (or equivalent pinned helper), not independent `rglob` plus ad hoc ignore glue.
  - Apply Pylint's **three distinct** ignore rules on the root-relative basis:
    - `ignore`: base names.
    - `ignore-patterns`: regex on base names (e.g. `__pycache__`).
    - `ignore-paths`: regex on paths (e.g. `.venv/`, `.mypy_cache/`).
  - Sort paths for stable output. Keep tests in scope unless Pylint excludes them.

- **Pylint symilar integration (pinned API only)**
  - Import `pylint.checkers.symilar` (`Symilar`, `LineSet`, and helpers such as `hash_lineset` / `filter_noncode_lines` as needed).
  - Construct a configured `Symilar` instance with parsed `[SIMILARITIES]` flags and `min_similarity_lines`.
  - Build `LineSet` objects via `Symilar.append_stream` (or `LineSet` + `stripped_lines`) for each discovered file.
  - **Per-line message-enable callback**: when building line sets, honor the same R0801 message-enable path Pylint uses so files with `# pylint: disable=all` or `# pylint: disable=duplicate-code` are excluded from duplicate reporting (equivalent to Pylint's `is_message_enabled` for `duplicate-code` / R0801). Skip disabled files before pair enumeration.
  - Enumerate candidate pairs from `Symilar._iter_sims` (or the pinned equivalent that yields the full unordered pair index space). **Do not** reimplement pair comparison logic.
  - For each pair, call `Symilar._find_common` (or the pinned pair helper it delegates to) so threshold extension (`remove_successive`), non-code filtering, and `> min_similarity_lines` semantics stay inside Pylint.
  - On missing symilar symbols or incompatible signatures: print clear stderr and exit `2`. **No copy-source fallback.**

- **Parallelism**
  - Parent builds all `LineSet` objects and the configured `Symilar` namespace once.
  - Materialize the full pair index list from `Symilar._iter_sims` (all `N * (N - 1) / 2` pairs).
  - Partition **pair indices** into chunks (not file slices).
  - `ProcessPoolExecutor` workers receive pair indices and call `Symilar._find_common` against the shared parent-built namespace.
  - Default workers: `os.cpu_count()` capped by pair count.
  - `--jobs` and `LARCH_DUPLICATE_CODE_JOBS` for override; `--jobs 0` means auto (same as Pylint jobs=0 semantics). Reject invalid values with exit `2`.
  - On POSIX, prefer `fork` multiprocessing context when available so workers share parent-built line sets cheaply; fall back to default context when fork is unavailable.

- **Output and exit codes**
  - Print findings with file paths and line ranges; stable sort by path and line number.
  - Exit `0` when no duplicates meet Pylint's `> min_similarity_lines` rule.
  - Exit `1` when at least one duplicate cluster would trigger R0801 under the pinned checker.
  - Exit `2` for usage, config, import, API drift, or internal/worker errors.
  - Message text need not be bit-identical to Pylint R0801.

### NEW: `python/test_duplicate_code.py`

Focused `tmp_path` tests only; no full-repo scans.

Required cases:

- **Config parsing**
  - Reads `min-similarity-lines=8`.
  - Reads all four `ignore-*` flags with yn parsing (`yes`/`no`); assert explicit values passed to symilar config, not `Symilar()` defaults alone.
  - Honors basic ignore settings.

- **Ignore-rule parity (three rules)**
  - Fixture excluded only by `ignore` (base name) is not scanned.
  - Fixture excluded only by `ignore-patterns` (base name, e.g. `__pycache__`) is not scanned.
  - Fixture excluded only by `ignore-paths` (path regex, e.g. `.venv/` under `--root`) is not scanned.

- **Root-relative ignore-paths**
  - Under `--root` subdir layout, a file under `root/.venv/` is excluded when rcfile has `ignore-paths=.venv/` (parity with `cd root && pylint .`).

- **No duplicates**
  - Two files with similar shape but fewer than threshold normalized lines pass with exit `0`.

- **Duplicate detected (strict greater-than)**
  - Two files with a duplicate block of **`min_similarity_lines + 1`** normalized lines fail with exit `1`; output names both files.
  - Two files with a duplicate block of **exactly `min_similarity_lines`** pass with exit `0` (Pylint 4.0.5 parity).

- **Threshold guard**
  - Block below `min-similarity-lines` passes.
  - Block at `min-similarity-lines` passes.
  - Block at `min-similarity-lines + 1` fails.

- **Pylint disable fixtures**
  - File with `# pylint: disable=all` containing an otherwise-reportable duplicate is not reported.
  - File with `# pylint: disable=duplicate-code` likewise excluded.

- **Cross-file shard guard**
  - At least three files; duplicate spans files that naive file-slice sharding would split.
  - `--jobs 2` still fails; `--jobs 1` same pass/fail class.

- **Import / API failure**
  - Monkeypatch symilar import or `_find_common` resolver; assert exit `2` and clear stderr (no silent pass, no copied fallback).

## Edge cases

- Empty Python file set: exit `0`.
- One Python file: exit `0`.
- Missing rcfile: exit `2`.
- Invalid `min-similarity-lines` or yn flag values: exit `2`.
- `--jobs 1`: deterministic debugging path.
- `--jobs 0`: auto worker count (documented and tested).
- Worker exceptions: fail closed with exit `2`.
- Exactly-at-threshold duplicate: exit `0` (Pylint parity).

## Failure modes

- **Pylint internal API drift** breaks the adapter.
  - Mitigation: pin `pylint==4.0.5` in `requirements-dev.txt` and `requirements-test.txt`; import-failure and API-missing paths exit `2`; adapter-layer tests monkeypatch symilar entry points.
- **Pair sharding accidentally becomes file sharding**.
  - Mitigation: cross-file shard guard test must fail against naive file-slice implementations; pair indices sourced from `Symilar._iter_sims`.
- **File-set drift vs current job**.
  - Mitigation: `expand_modules` bootstrap plus three-rule ignore tests; optional local parity spot-check against `pylint -j 1` on the same tree during implementation.
- **Threshold tightening**.
  - Mitigation: strict `>` semantics delegated to `Symilar._find_common`; tests assert at-threshold passes and min+1 fails.
- **Output text differs from R0801**.
  - Acceptable if CI gate pass/fail matches pinned Pylint for the same tree and rcfile.
