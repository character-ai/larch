## Approach

All changes are documentation-or-display-only. No drafter logic, no plan-writing path, and no test infrastructure outside of `test-emit-design-plan-preview.sh` is modified.

`emit-design-plan-preview.sh` already uses `emit_plan_body` which handles all threshold/summary/outline paths. Adding a `step2b` case is ~10 lines. The SKILL.md display replacement removes 5 lines and adds 3.

The `_drafter_structural_ok` gate continues to require that `SUMMARY_WRITTEN=true` and `plan-summary.md` is non-empty for large plans. When that gate passes, `plan_summary_is_fresh` inside `emit_plan_body` will find a fresh summary (the drafter writes both `plan.txt` and `plan-summary.md` atomically before the display block runs).

## Edge cases

- `git -C "$PWD" rev-parse --show-toplevel` fails when not in a git repo: the fence exits non-zero before the drafter is invoked — same fail-loud behavior as other guard checks in that fence.
- `emit-design-plan-preview.sh --variant step2b` with missing or disallowed `DESIGN_TMPDIR`: script prints `**⚠ 2b: ...**` warning and exits 0, matching the graceful-degrade contract of the other variants.
- The `_summary_threshold` variable in the display fence is still computed for `_drafter_structural_ok`; removing it from the display path is safe because `emit_plan_body` normalizes `LARCH_DESIGN_PLAN_SUMMARY_THRESHOLD` independently.

## Failure modes

Not applicable — all changes are documentation/display-only with no behavioral risk to plan writing or review.
