### Item 2 — Drafter/subprocess duplication and architecture rollup (14 capped items)

- **Surfaced by**: Multiple reviewers (capped rollup)
- **Phase**: design + implement
- **Severity**: latent
- **Focus area**: architecture / correctness / risk-integration

Aggregated from the OOS_5 cap rollup in #3873. Key concerns:

- **Duplication**: New launcher largely duplicates `launch-claude-subprocess.sh` JSON `.result` promotion, token/timing sidecars, meta/done/diag handling, and sidecar logic. Two copies drift on security fixes. [Files: `launch-claude-subprocess.sh`, `scripts/launch-claude-drafter.sh:1-91`]
- **TOKEN_RAW attribution**: `TOKEN_RAW=claude_draft` attribution pointed at `timing-ledger.sh` but mapping lives in `launch-claude-subprocess.sh ~119-122`. Future refactors must port both. [Files: `launch-claude-subprocess.sh`, `scripts/launch-claude-drafter.sh:59`, `timing-ledger.sh`]
- **Harness wiring**: New drafter harness not wired into `Makefile` / `agent-lint.toml` like `test-launch-claude-subprocess`. Launcher regression may not run in CI. [Files: `Makefile`, `agent-lint.toml`, `scripts/test-launch-claude-drafter.sh:225-230`]
- **`--repo-root` uses `$PWD`**: Drafter `--repo-root` uses `$PWD` instead of `git rev-parse --show-toplevel`. If `/design` runs outside repo root, `--add-dir "$PWD"` scopes read access to a subdirectory. [Files: `skills/design/SKILL.md:132`]
- **Dual summary pipelines**: Step 2b success prints drafter prose summary while Step 3 and Gate C use `emit-design-plan-preview.sh`. Two presentation paths can diverge on threshold, outline, and fallback behavior. [Files: `emit-design-plan-preview.sh`, `skills/design/scripts/emit-design-plan-preview.sh:61-80`]
- **`MODE=baseline-delta` sidecar grammar diverges**: Custom `MODE=baseline-delta` and bespoke `REASON` tokens invented instead of reusing `check-mid-run-dirty-tree.sh` / `lib-dirty-tree-sidecar.sh`. [Files: `check-mid-run-dirty-tree.sh`, `lib-dirty-tree-sidecar.sh`, `scripts/launch-claude-drafter.sh:46-53`]
- **No Bash-tool timeout budget**: Launcher timeout is 1800s but plan does not state the orchestrator Bash invocation must set `timeout: 1800000`. [Files: `skills/design/SKILL.md:181-191`]
- **voting-protocol.md stale voter-launch docs**: `voting-protocol.md` "Launching Voters" still documents Agent-tool Claude voter launch after C2/C3 panel-line edits. [Files: `skills/shared/voting-protocol.md:112-170`]
- **`.meta` spec incomplete**: `.meta` spec lists only `CMD_JSON`; subprocess contract also writes `OUTER_LAUNCHER`, `TOOL`, and `TIMEOUT`. [Files: `scripts/launch-claude-subprocess.sh:208-213`]
- **`token-ledger.md` enum missing `raw=claude_draft`**: Plan introduces `raw=claude_draft` without updating `token-ledger.md` enum list. `/report-tokens` grouping may bucket draft tokens incorrectly. [Files: `scripts/token-ledger.md:41`]
- **Dispatch voters `--role` without `--model` plan verification gap**: C2 relies on dispatch voters passing `--role voter` without `--model` but plan verifies only `test-launch-claude-review.sh`, not dispatch call sites. [Files: `scripts/dispatch-code-voters.sh:120-127`, `scripts/dispatch-plan-voters.sh:97-105`]
