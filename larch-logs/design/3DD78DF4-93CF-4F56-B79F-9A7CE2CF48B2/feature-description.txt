# We set up claude to run with GLM 5.2, and need to update pricing

main agent can now run with glm-5.2.  When it does, currently, pricing is not going to work properly.  We need to update the pricing table to account for it.  In particular, pricing report line in final report must replace Claude main agent value, e.g., in example below:
```
- Cost: 💰 TOTAL ~$38.23: Claude $18.03, Codex-5.6 $11.24, Codex-mini $0.07, Cursor $8.09, Claude (subprocess) $0.80  |  Tokens: 74240k
```
it should replace $18.03 with the computed for token pricing value of GLM-5.2 followed by that same value divided by 15 (estimated plan cost)
e.g., it should read: `Claude token $15.00 (estimated $1.00)`
It should also append an explanation line after the `- Cost` line, concisely explaining that token cost is what it would have cost had we be paying GLM-5.2 token costs, whereas estimated is actual cost given we are on a plan.
