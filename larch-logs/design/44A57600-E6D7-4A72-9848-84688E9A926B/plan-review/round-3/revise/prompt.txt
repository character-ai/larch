## Edge cases

- **Nested functions and methods:** resolve the nearest enclosing qualified symbol for stable baseline keys.
- **Recursive tree layout:** `python/analysis/*.py` and any future nested production packages are in scope; only the explicit exclusion list is skipped.
- **Multiple calls in one function:** `occurrence` indexes all matching sites in source order within the qualified symbol before any suppression; identity never uses line numbers.
- **Pragma on one of several sibling calls:** sibling occurrences keep their pre-suppression ordinals.
- **Malformed baseline JSON:** exit `2`.
- **Malformed exemptions JSON:** exit `2`.
- **Missing exemptions file:** treat as empty.
- **Baseline record missing or empty `reason`:** exit `2` on load and on `--write` when reasons cannot be preserved.
- **Duplicate config env values:** fail closed with exit `2` on synthetic fixture configs; when bootstrapping against live `config.py` that already contains duplicate values, pick the first sorted constant name and document that choice in a test.
- **Pragma without reason:** do not suppress. Report a clear error or violation.
- **Syntax errors in scanned files:** follow the convention from `lint_keyword_only.py`; do not invent a different policy.
- **Exemption rows missing `file`:** reject on load with exit `2` (both linters).

## Failure modes

- **Baselines hide too much:** keep records more granular than file-only. Use qualified symbol, access kind (env linter), callee (subprocess linter), and pre-suppression occurrence.
- **Line churn causes baseline churn:** avoid raw line numbers in baseline identities; occurrence is positional within symbol, not line-based.
- **Occurrence renumbering on unrelated edits:** occurrence counts all matching sites before suppression so inserting a new call shifts later ordinals by design; document that removing grandfathered calls requires baseline cleanup, not automatic renumber preservation.
- **CLI-glue exemptions become a dumping ground:** require non-empty `file` and `reason` on every exemption row; keep subprocess exemptions file-scoped only.
- **Env linter flags harness variables:** skip unknown literals and `*_SH` values as agreed.
- **Env linter misses assignments:** Store-context `os.environ[...]` must be flagged alongside Load/get forms.
- **Nested modules escape enforcement:** recursive scan plus `^python/.*\.py$` pre-commit filter closes the gap.
- **Pre-commit runs too often:** hooks are `always_run` by design and scan the full `python/` tree.
- **Incomplete baseline schema:** env baseline rows missing `file`, `qualified_symbol`, or `occurrence` can cause cross-symbol collapse or unstable ratchet matching; full identity tuple validation on load prevents this.

Develop a Python linter (under `python/`, wired into `make lint` / pre-commit, with a regression harness and an allowlist mechanism) for each. These are the two IDs deliberately excluded from the guidelines-file issue.

## Linter 1 — subprocess-via-Runner (would-be G-Py-9)

Flag `subprocess.run` / `subprocess.Popen` / `subprocess.check_output` / `subprocess.call` in library modules under `python/` that should route through the injected `proc.Runner` seam.

- Verified inconsistency: **58 source modules reference `Runner`, 57 call `subprocess` directly, and 3 do both in the same file** (`python/run_logs.py`, `python/agents.py`, `python/pr_body.py`).
- Detection: simplest high-signal rule is a module that accepts / holds a `Runner` but also calls `subprocess.*` directly. Broader rule is any library module (exclude `python/proc.py`, tests, and an allowlist of CLI-glue modules) calling `subprocess.*`.
- Allowlist CLI-glue / entrypoint modules with a documented reason.

## Linter 2 — env-via-config-constant (would-be G-Cfg-2)

Flag `os.environ.get("X")` / `os.environ["X"]` outside `python/config.py` where a `config.ENV_*` constant has the value `"X"`.

- Verified: 56 `ENV_*` constants exist; bare literals recur in `python/plan_review.py`, `python/phantom.py`, `python/design_legacy.py`.
- Detection: parse `config.py` for `ENV_* = "value"` pairs; flag bare-literal env access matching a value, outside `config.py`.
- Exempt test-only override seams (`*_SH`) and external / harness vars with no constant.

## Acceptance criteria

- Each linter ships with a regression harness and is wired into the lint targets (`make lint` and / or pre-commit).
- An allowlist / suppression mechanism with inline reason exists.
- Existing violations are either fixed or allowlisted with a reason.
