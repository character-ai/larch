**1. correctness — `skills/review/scripts/dispatch-panel.sh:398-399`**

The plan’s Decisions block correctly calls out #2449’s `codex_present_for_waterfall="false"`, but the `### UPDATED: dispatch-panel.sh` steps never say to change it. Today the waterfall is invoked with Codex forced absent:

```398:399:skills/review/scripts/dispatch-panel.sh
codex_present_for_waterfall="false"
waterfall_args=(--slots-file "$manifest" --codex-present "$codex_present_for_waterfall" --cursor-present "$CURSOR_AVAILABLE" --mode "$MODE" --timeout 1800)
```

`dispatch-with-waterfall.sh` only launches a slot when `present_for_tool` is true for that row’s tool. Codex manifest rows with `--codex-present false` never run in phase 1 and only enter the legacy fallback queue—so re-adding `codex-specialist-*` rows without flipping this flag does not actually re-enable Codex. `/design` already passes `--codex-present "$CODEX_PRESENT"` (`dispatch-plan-review-panel.sh:241`).

**Suggested revision:** Add an explicit line item: set `codex_present_for_waterfall="$CODEX_AVAILABLE"` and extend `test-dispatch-panel.sh` to grep the stub waterfall argv for `--codex-present true` when Codex is available.

**2. risk-integration — `skills/review/scripts/dispatch-panel.sh:398-406`**

The plan’s duplicate-Codex mitigation depends on `--no-fallback`, but review’s waterfall call has no `--no-fallback` at all, and the dispatcher only accepts it globally (`dispatch-with-waterfall.sh:53`). With the default multi-phase path and `codex_present` restored, a failed Cursor row can still invoke phase-2 Codex even when a Codex peer row exists—exactly failure mode #2 in the plan.

If `--no-fallback` is added unconditionally (as `/design` does for plan review), both-down and single-vendor paths lose phase-3 Claude fallback, which conflicts with the plan’s “Cursor-primary → Claude” edge cases.

**Suggested revision:** Gate `--no-fallback` on both vendors being available (peer layout only); leave legacy waterfall for cursor-only / both-down. Cover with dispatch-panel harness cases.
