## Approach

- Add one Python CLI helper for prompt-side `KEY=value` extraction.
- Route it through `larch.io.kv_value` and `larch.io.read_kv`.
- Replace only the 13 approved `awk -F=` KV-parsing call sites:
  - 6 in `.claude/skills/release/SKILL.md`.
  - 4 in `skills/pause/SKILL.md`.
  - 3 in `skills/deps/SKILL.md`.
- Preserve duplicate-key behavior:
  - release: first match.
  - pause: last match.
  - deps: first match is acceptable because `deps resolve-repo` emits one row per key.
- Add a static lint for bare awk `$<digit>` field references inside `SKILL.md` shell fences.
- Keep shell positional parameters like `case "$1"` out of lint scope.
- Keep the `$0` bootstrap-recovery awk idiom as a documented lint exception. Do not convert it through `python/cli.py`, because that path is circular before `CLAUDE_PLUGIN_ROOT` is known.

## Edge cases

- Values may contain `=`. The helper must return everything after the first `KEY=` prefix.
- Empty values remain empty unless a call passes `--default`.
- Missing keys should not fail the release or pause fallback paths.
- `pause` must keep last-match behavior.
- `release` must keep first-match behavior.
- `deps` must not start sourcing or evaling `resolve.env`.
- The lint must not flag shell argument parsing such as `case "$1" in`.

## Failure modes

- If `kv get` is not in `_MACHINE_STDOUT_KEYS`, quiet-mode banners can corrupt command substitutions. Add it there.
- If the pause test stub does not implement `kv get`, the harness can fail for the wrong reason. Update the stub.
- If the lint flags the bootstrap `$0` line without an exemption, `make lint` will fail on an approved non-goal.
- If the lint only greps `$1`, it may miss `$0` or `$3`. Match `$[0-9]+`.
- If the helper changes duplicate-key behavior, pause can regress. Test `--match last`.

## Testing strategy

- Run targeted Python tests:

  - `python3 python/cli.py lint skill-awk-field-refs`
- Run local relevant checks if dependencies are available:
  - `python3 python/cli.py checks run-relevant`
- For full confidence before merge:
  - `make lint`
  - `make py-test`
