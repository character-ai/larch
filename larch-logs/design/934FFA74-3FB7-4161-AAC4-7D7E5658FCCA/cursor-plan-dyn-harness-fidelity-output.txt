### 1. correctness — `skills/design/SKILL.md` (proposed §6 + §11a)

Gate B(c)/Gate C(b) sends control to Step 1e, but the plan deletes Step 1e’s standalone prelude while §11a still requires clearing stale `step-1e`…`step-2b` before a Step 1e pause-check. With no bash host on that path, pause during post–Gate B discussion can resume at a later folded step using stale markers from the prior pass.

**Suggested revision:** Add a minimal re-entry fence on the Step 1e path (source-env → `rm` stale markers → pause-check), or document which surviving host runs those clears before any Step 1e LLM work; pin it in structure and pause-resume harnesses.

### 2. correctness — `scripts/test-design-structure.sh` (proposed §3)

The planned `assert_folded_sentinel_writes` map treats conditional hosts (no-brainstorm `step-1d.5`, HARD-only `step-2a` in 2a.5 prelude, `PLAN_WRITE_OK`-gated `step-5c`) like unconditional literal-line matches. A single unconditional `: > …/step-1d.5` or early `step-5c` write would pass without enforcing the branch contract.

**Suggested revision:** Require guard-scoped line-order proofs inside extracted fence bodies, not just presence of write lines.

### 3. correctness — `scripts/test-design-structure.sh` (proposed §2–3)

The zero-sketch degraded fence is not the first bash block after `<!-- step:2a`. The existing `extract_first_bash_fence_after` helper cannot reach it, so the planned source-env → writes → pause-check contract for that branch would be unenforced.

**Suggested revision:** Name a dedicated fence marker and register a separate extractor entry in `assert_folded_sentinel_writes`.

### 4. correctness — `scripts/test-design-structure.sh:961-962`

Check 15b’s section-wide `architecture-diagram.skipped` grep survives in the plan while branch-local assertions are added elsewhere. Prose at `skills/design/SKILL.md:1260` satisfies the weak check without the planned branch-local `rm -f` + write fence.

**Suggested revision:** Retire the section grep and assert skip/architectural branch fences with ordering, matching proposed SKILL §15.

### 5. risk-integration — `skills/design/scripts/test-design-pause-resume.sh` (proposed §9)

Backward-loop fixtures assert resumed `STEP` only. They do not prove stale `.completed` files were removed before pause-check, so structure tests and runtime pause/resume can diverge.

**Suggested revision:** After seeding stale markers, run the re-entry prelude and assert marker files are gone before `design-pause-save.sh`, then assert load `STEP`.
