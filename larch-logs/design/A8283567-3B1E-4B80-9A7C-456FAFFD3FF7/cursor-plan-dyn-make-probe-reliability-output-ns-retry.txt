[risk-integration] plan.txt:101-102 — The edge-case text specifies `make -n test-harnesses-7 2>/dev/null`, which hides stderr but not stdout from a successful dry run; any implementer copying that literally risks polluting FD-1 beside the FD-3 quiet contract — suggested revision: probe with `>/dev/null 2>&1` (or run the probe in a context that captures both streams).

2. [architecture] plan.txt:80-83; plan.txt:99-107 — `run_per_job_local_fix_loop` iterates each fixable row independently without deduping `LOCAL_CMD`; combined with the planned fallback to `make test-harnesses` when a shard target is missing, several failed shards can each trigger a full umbrella matrix (each with its own cap-3 inner loop), which is far heavier than a single local rerun of the failed harness set — suggested revision: merge identical `LOCAL_CMD` values (especially the full-matrix fallback) into one synthetic job before entering the capture/fix loop.
