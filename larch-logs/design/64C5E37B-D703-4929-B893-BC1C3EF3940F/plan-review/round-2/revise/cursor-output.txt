8. On success, emit `NEXT_ACTION=ship` and return 0.

Keep stdout machine-readable. Emit exactly one `NEXT_ACTION=...` line from the new verb on every path. Forward captured child stdout and stderr to stderr so guard STALLED JSON and `oos file` JSON do not pollute the new stdout contract.

**Guard stdout isolation (blocking fix).** `step8_python_guard_main` prints STALLED JSON to stdout on Python <3.11. Do not call it bare in `ship_pre_driver_main`. Emit only `NEXT_ACTION=stall` on stdout afterward.

**OOS stdout isolation (blocking fix).** `oos file` always emits a JSON line on stdout (`python/oos_filer.py` `cmd_file`). Mirror the guard capture pattern and the stderr-only replay discipline in `step8_oos_checkpoint_main`, but do not forward OOS JSON to stdout.

### Edge cases

- **State file exists with comments or junk but no KV:** treat as absent for seeding, matching current create-if-absent behavior.
- **State file has any shell KV entry:** skip seeding and continue to OOS filing.
- **Python guard fails in-process:** guard JSON and errors go to stderr only; stdout is exactly `NEXT_ACTION=stall`; exit 4; orchestrator sets `STALL_TRACKING=true` and continues to Step 16 then Step 18.
- **Python <3.11 at cli entry:** pre-version-gate emits `NEXT_ACTION=stall` and exits 4 before global version rejection exit 2.
- **Seeder fails:** halt before OOS and ship driver.
- **OOS filing fails:** halt before ship driver; preserve Tool Failures logging contract.
- **OOS filing succeeds with no issues:** OOS JSON on stderr only; stdout is exactly `NEXT_ACTION=ship`; proceed to ship.
- **Turn recovery while pre-driver predicate still matches:** re-run `ship pre-driver` once; do not expect three separate fences.

### Failure modes

- If the new verb emits extra stdout, Step 8 routing can misparse `NEXT_ACTION`.
- If guard stdout is not captured, STALLED JSON pollutes stdout and breaks parsing.
- If OOS uses `_run_cli_forward`, `oos file` JSON prepends stdout and breaks single-line `NEXT_ACTION` parsing.
- If the pre-version-gate fast path is missing, Python <3.11 exits 2 instead of stall exit 4.
- If stall routing skips Step 16, operators lose rejected-findings replay and final-report side effects on pre-driver guard failure.
- If the seed skip test uses only file size, a junk state file could bypass seeding.
- If OOS output is swallowed, operators lose diagnostics on halt.
- If SKILL recovery prose still describes guard → seeder → `oos file` as three fences, orchestrators may skip `ship pre-driver` on retry.
- If `test-implement-structure.sh` is not updated, `make lint` fails via harness pins even when fence-shape passes.
