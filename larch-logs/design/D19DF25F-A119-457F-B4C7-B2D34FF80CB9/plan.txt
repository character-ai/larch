## Edge cases

- `_classify_failed_run_for_rerun` returns `"not_ready"` or `"error"` beyond log-wait budget: the new guard `kind != "ready_transient"` also fires for these, returning failure immediately. This is correct — if logs never become ready within budget, we should not burn a rerun.
- `DESIGN_TMPDIR` not set or not a directory in `quiet_init`: falls through to `ENV_IMPLEMENT_TMPDIR` as before; no regression.
- `_dlship_stderr_log` path: `DESIGN_TMPDIR` is validated before this code block runs in `design-log-publish.sh`, so the path is always writable.
