### FINDING_2: DESIGN_TMPDIR is not exported to the Python bridge
- **Reviewer(s)**: Cursor-Edge, Cursor-Innovation, Cursor-Requirements, Codex-Requirements
- **Severity**: important
- **Concern**: The planned `quiet_init` change to prefer `DESIGN_TMPDIR` is incomplete because `scripts/design-log-publish.sh` parses `--design-tmpdir` into a shell variable but does not export it or prefix the Python bridge invocation.   - From Cursor-Requirements: Add export DESIGN_TMPDIR (or DESIGN_TMPDIR="$DESIGN_TMPDIR" on the python3 line) immediately before the ship design-log bridge in design-log-publish.sh and document that step under Finding #3 in the plan.
  - From Codex-Requirements: Export DESIGN_TMPDIR after validation or prefix the python bridge command with DESIGN_TMPDIR="$DESIGN_TMPDIR" so the planned quiet_init change can observe it

### FINDING_3: quiet_init test may corrupt pytest file descriptors
- **Reviewer(s)**: Codex-Edge
- **Severity**: latent
- **Concern**: The planned `quiet_init` test patches only `os.open`, but `quiet_init` also mutates file descriptors through `os.dup2` and `os.close`. Running that directly in-process can corrupt pytest stdout/stderr capture or inherited fd3/fd4 while trying to inspect the selected log path.
- **Suggested revisions (informational for voters; coder decides)**:
  - From Codex-Edge: Patch os.dup2 and os.close as well, or run quiet_init in a subprocess and assert the selected path there
