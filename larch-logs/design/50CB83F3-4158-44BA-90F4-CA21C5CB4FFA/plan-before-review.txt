Add a fail-closed production Python lint. Scan `python/larch/**/*.py`, but exclude `python/larch/git/`, tests, and standard test helpers. Report every list or tuple whose first element is the exact string literal `"gh"`.

Allow only a same-line, reason-bearing `# lint-gh-argv-literal: ok <reason>` pragma. Do not add a baseline. Do not change existing callers or the `subprocess-via-runner` lint.

## Edge cases

- Treat only the exact lowercase string `"gh"` as the banned executable token.
- Inspect literals in every AST context, not only subprocess or runner calls.
- Associate a multiline literal with its opening line for pragma placement.
- Skip symlinks and non-regular files during discovery.
- Do not scan tests merely to require fixture pragmas. The pragma exists for deliberate production-side fixtures or compatibility cases.
- Do not suppress or baseline unresolved callers left by blocked repoint work.

## Failure modes

- If any repoint dependency remains incomplete, the new lint will fail on the live tree. Finish those dependencies before landing this gate.
- AST parse or source-read failures must return the tool-failure exit instead of silently skipping a file.
- A broad pragma parser could accept empty reasons or string contents. Use tokenized comments and test both cases.
- Incremental filename-only pre-commit behavior could miss violations elsewhere. Force the hook to run the full scan.
