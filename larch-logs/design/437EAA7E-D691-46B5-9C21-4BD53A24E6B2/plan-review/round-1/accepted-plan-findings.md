### FINDING_2: Pre-staged carryover can be included in the round commit
- **Reviewer(s)**: Codex-Edge, Codex-Innovation, Codex-dyn-snapshot-parity, Codex-dyn-round-commit-contract, Codex-dyn-regression-harness
- **Severity**: important
- **Concern**: The carryover guard can skip pre-existing staged carryover, but the round commit is unscoped and `git-commit.sh` commits whatever is already staged when no paths are passed. As a result, an outside-manifest path that was staged before coder dispatch can be included in the coder commit, violating the intended carryover exclusion.
- **Suggested revisions (informational for voters; coder decides)**:
  - From Codex-Edge: Scope the round commit to coder-stage-paths.txt, for example via git-commit.sh --only --pathspec-from-file "$stage_manifest", or otherwise unstage/protect outside-manifest carryover before commit
  - From Codex-Innovation: Constrain the round commit to manifest paths, for example git-commit.sh --only --pathspec-from-file "$stage_manifest", and add a staged-carryover regression
  - From Codex-dyn-snapshot-parity: Scope both the primary and follow-up round commits to coder-stage-paths.txt, for example with git-commit.sh --only --pathspec-from-file "$stage_manifest", or fail closed/unstage snapshotted staged carryover before committing; add a staged-carryover regression case so the guard and commit path are tested together
  - From Codex-dyn-round-commit-contract: Commit the round with the existing scoped pathspec contract, e.g. git-commit.sh --only --pathspec-from-file "$stage_manifest", and add a regression with pre-existing staged carryover proving it remains staged/uncommitted while coder delta commits
  - From Codex-dyn-regression-harness: Add the minimum staged-carryover guard: do not exempt paths present in git diff --name-only --cached, or explicitly unstage skipped carryover before git-commit.sh. Add one regression fixture with pre-coder staged other.txt, snapshot present, manifest src/main.py, and assert the guard still fires.
