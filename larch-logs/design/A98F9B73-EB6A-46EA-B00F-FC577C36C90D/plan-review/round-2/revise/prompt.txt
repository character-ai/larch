# architectural-knowledge-IV [FEATURE] Skip the guidelines block in review prompts at TRIVIAL difficulty

From the 2026-07-09 audit of the architectural-knowledge features.

**Motivation.** `_architectural_guidelines_review_section()` (`python/larch/rendering/rendering.py` line 823 at fb6d61294) injects the invariants block plus the full normalized guidelines payload (~7.1k tokens) into every specialist code-review prompt (`render_specialist_main`, line 983) and every plan-review reviewer prompt (`render_plan_review_main`, line 1402). Measured yield: 3 of 84 post-#6373 implement runs show any G-* or I-* citation in committed review artifacts (citations seen: G-Ext-3, G-Sec-3, G-Py-8). The feature's proven value concentrates in the `/design` drafter and Gate C assessments, which keep their full payload. This aligns with the panel-cost direction discussed in #6505.

**Required change.**

1. Skip the guidelines block in specialist-review and plan-review prompts when the run's applied difficulty is TRIVIAL. Keep the invariants block at every tier: invariants are the blocking tier and are small.
2. Plumb the difficulty value to the renderers explicitly (flag or env sourced from run state; rendering.py already threads a `difficulty` value for other outputs, see the parameter near line 270). When the difficulty value is absent or unparseable, include the block: fail open to inclusion.
3. Cache caution: `render_specialist_main` builds a prompt-cache key (`LARCH_RENDER_CACHE_DIR` key_input). The gating input must join the cache key, or a TRIVIAL run can reuse a cached full prompt and a MODERATE run can reuse a cached slim one.
4. Keep the section's untrusted-evidence framing text unchanged when the block is included.
5. Optional extension, designer's call with evidence: also skip for `docs-only` or `generated-only` diff modes (`_effective_diff_mode` already classifies these).
6. Tests: renderer unit tests for TRIVIAL (invariants only), non-TRIVIAL (both blocks), missing difficulty (both blocks), and the cache-key change.

**Acceptance criteria.**

- A TRIVIAL run's rendered specialist and plan-review prompts contain the invariants block and not the guidelines block.
- Non-TRIVIAL prompts are byte-identical to today's output.
- Cache keys differ across the gate's states.
- Payload-bytes telemetry shows the reduction on TRIVIAL runs.
