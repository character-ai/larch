## Failure modes

- **Import-time third-party dependency:** Fails `test_stdlib_only`; keep new modules stdlib-only.
- **CLI registry typo:** `cli.py --help` or callsite tests fail because lazy import cannot find module or main.
- **Stale shell path:** `make lint-retired-scripts` fails after manifest append.
- **Contract drift:** SKILL.md parsing breaks if KV, TSV, NDJSON, or phase-specific key sets change.
- **Release classify drift:** Stale worktree reads during `--head` can produce wrong bump decisions.
- **Release prepare drift:** Missing commits-to-pulls fallback can omit valid PRs or misclassify API failures as unmatched commits.
- **Release prepare NOTE drift:** Emitting URL instead of subject in the API fallback note can break dynamic parity.
- **Release bump override drift:** Manual `--bump` can produce stale `NEW_VERSION` if not recomputed from `CURRENT_VERSION`.
- **Release finish repo drift:** Missing origin-vs-`--repo` guard can tag one repo while creating a release in another.
- **Release tag mismatch:** Must fail closed and not move wrong remote tags automatically.
- **Network partials:** `gh issue create` may succeed server-side with lost response; do not retry create.
- **Temp cleanup:** Redacted notes and issue body temp files should be removed best-effort.
- **Undefined shell variables:** `scripts/implement-finalize.sh` must use existing `PY_CLI` or define any new root variable before use under `set -u`.
- **Wrong plugin root:** `plugin read-version` must not read cwd-relative plugin JSON from arbitrary cwd callers.
- **Quiet routing regression:** Inherited quiet state can hide `LARCH_PLUGIN_VERSION` from command substitution if not reinitialized.
- **Promote-latest failure drift:** Removing already-emitted stdout KVs on post-selection failures can break callers that parse phase progress.
- **Audit concurrency regression:** Omitting `--allow-concurrent` can block documented audit flows.
- **Audit resolve-prs drift:** Missing six-key stdout, wrong key order, or nonzero normal exits can break orchestration.
- **Audit map TSV drift:** Reordered columns or missing placeholders can break positional parsers.
- **Audit run-dir drift:** Missing canonical run-dir guards can scan skill roots or cross-skill run directories.
- **Audit timestamp drift:** Missing `PACIFIC_TIMESTAMP_SOURCE` or stdout on parse failure can mislabel reports.
- **Audit close-priors drift:** Missing TAB-separated `CLOSE_FAILED` rows or upfront failure KVs can hide close failures.
- **Audit bail regression:** Missing `_rf_*` gating can require artifacts for valid bailed runs or skip artifacts for incomplete runs.
