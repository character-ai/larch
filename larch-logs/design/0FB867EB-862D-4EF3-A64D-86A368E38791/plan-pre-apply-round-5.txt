## Approach

The existing implement Step 5 renderer assumes round-local artifacts are live.

Design Step 3 differs:

- Live reviewer slots are usually in `DESIGN_TMPDIR/plan-review-slots.ndjson`.
- Live reviewer outputs are at paths listed by that manifest.
- Round-local `panel-manifest.ndjson`, `round-meta.json`, and summary files may not exist until end-of-round synthesis.
- `round-start-s` may be absent for legacy active runs, while the timing ledger already has the active Step 3 mark.

The design renderer should still use `plan-review/round-N/` to choose the current round number and to render completed detail tables.

It must not use broad Step 3 substring matching.

It must not use root glob fallback output files.

It must not reuse stale root or round-local manifest data from a previous run.

It must not count reused stale output files as returned reviewers.

For active rounds, it should read design-native artifacts only when they are fresh for the selected current round:

- Total reviewers: selected manifest output-path count.
- Returned reviewers: non-empty authoritative output paths from the selected manifest, or from its fresh sidecar when present.
- Output freshness: counted outputs must be newer than the selected manifest or round marker, depending on source kind.
- Elapsed: `round-start-s` when present, else the Step 3 timing mark start.

Keep the fix limited to progress reporting.

Do not change live review-loop artifact lifecycle.

## Edge cases

- `plan-review/` absent: return `""`; `_render_design` uses generic progress.
- Round dir exists but round-local manifest is absent: use root `plan-review-slots.ndjson` only if fresh for that round.
- Round-local manifest exists but predates the Step 3 timing mark or `round-start-s`: reject it.
- New round dir exists before dispatch rewrites the root manifest: return `""`; `_render_design` uses generic progress.
- Root manifest is absent, empty, unreadable, or stale: return `""`; `_render_design` uses generic progress.
- Output sidecar exists from a previous round: ignore it unless its mtime is at least the manifest mtime.
- Fresh sidecar exists with retry paths: prefer sidecar paths, but count only fresh non-empty outputs and cap returned count at total manifest slots.
- Output file path is duplicated: count it once, and never exceed total slots.
- Output file exists and is non-empty but predates the freshness floor: do not count it.
- `round-start-s` absent: use the Step 3 timing mark start for elapsed, but require root manifest freshness against the round dir mtime.
- Both round start and Step 3 timing start are absent: elapsed is `unknown`.
- `render-review-phase-detail.sh` absent or returns non-zero: omit detail and keep the header.
- Step 3.5 or Step 3b labels: always fall through to generic progress.
- Step 3 plan-review label with an empty round dir and no usable fresh manifest: return `""` and fall through to generic.
