### 1. [correctness] Design loop short-circuits may skip per-round timing rows

The plan tells `plan-review-loop.sh` to capture `_round_end` “late, after revise/post-apply when those run.” Many real exits call `_snapshot_terminal_exit_preserving_status` earlier—converged/zero-findings (`1478-1479`), cap-hit (`1536-1540`), tally-error (`1450`), panel-failed (`1437`), revision-failed (`1497`)—without running revise. Those paths still complete a Step 3 round and should get a `rounds[]` entry unless deferred (MAV).

**Suggested revision:** Emit from `_snapshot_terminal_exit_preserving_status` (or `_terminal_exit`) for all non-MAV terminal rounds, using the same `record-plan-review-round-timing.sh` helper and persisted `round-start-s`.

### 2. [correctness] Design MAV must persist `round-start-s` before snapshot

On MAV, the loop calls `_snapshot_terminal_exit_preserving_status` at ```1414:1420:skills/design/scripts/plan-review-loop.sh```. `_snapshot_round_dir` only retains dest files that pass `design_round_artifact_included` when merging into the snapshot tmpdir (```319:399:skills/design/scripts/plan-review-loop.sh```). The plan’s allowlist update is necessary but not sufficient unless `round-start-s` is written to `plan-review/round-$round_num/` **before** that snapshot runs.

### 3. [correctness] Deferred handoff needs explicit SKILL Bash, not prose only

Implement Step 5 already uses a shared resume fence at ```806:812:skills/implement/SKILL.md``` after MAV/coder work. The plan’s new timing call should live in that fence (or equivalent) with `FINAL_ROUND_NUM`, not only as narrative bullets. Design inline MAV at ```1122:1124:skills/design/SKILL.md``` should likewise call `record-plan-review-round-timing.sh` after re-tally with the same round index used for `findings-classification.tsv`.

### 4. [correctness] Implement deferred helper should name fallback files

`review-tally.env` under `$IMPLEMENT_TMPDIR/round-N/` is the authoritative post–main-agent tally artifact (`skills/review/scripts/tally-code-votes.md`). The plan’s fallback regex should not be applied to an unspecified path; document reading `review-tally.env` first, then artifact files, matching the “do not use `IRF_LAST_*`” rule for MAV rounds where core reports `ACCEPTED_COUNT=0` before orchestrator re-tally (`skills/review/scripts/review-core.sh:694-718`).
