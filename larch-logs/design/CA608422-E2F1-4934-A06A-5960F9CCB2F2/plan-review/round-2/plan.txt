## Approach
Single base-order flip per role, plus parity in Python and synced tests/docs.
- Coder: the only logic is the probe order in `_phase_coder_implicit`; flipping the two `if` branches + warnings is sufficient.
- CI fixer: flip only the base `tiers=(...)` tuple; the existing per-attempt rotation and first-fixer bail follow it.
- Merge-resolve: flip the literal `for tier in ...` list.
- Python: one tuple in `config.py`; all consumers derive from it, so no consumer edits.
- Python tests: `test_config.py` plus `test_ci_monitor.py` tier-order mocks/assertions; grep after tuple flip.
- Tests assert observed launcher order or warning strings; update stubs/assertions to the codex-first order. Most ship-pr cases are order-agnostic and stay.
- Docs: sync the prose that states the old order (including `SECURITY.md` and `docs/external-reviewers.md`), respecting the SKILL.md arrow-substring guard.

## Edge cases
- **Explicit `--coder` unchanged:** the implicit flip must not alter `_phase_coder_explicit*`; covered by the existing `#3207` explicit-waterfall assertions (kept green).
- **Start-tier rotation:** `run_ci_fix_vendor` rotates start tier per outer attempt; attempt 0 now starts at Codex. The `first-fixer-non-health` bail keys on `first_tier`, so it now bails when Codex (first) fails non-health — this is the intended new behavior and is what the rewritten `t4`/first-fixer tests assert.
- **Both externals unavailable:** all three roles still fall through to Claude (terminal tier preserved).
- **SKILL.md guard:** the synced wording must avoid the literal `Codex → Cursor → Claude` arrow string (commas instead) or `test-implement-step2-routing.sh` fails.
- **Python is parity-only:** `python/` is not wired into the live path until Phase 7; the flip is for parity and has no live runtime effect yet.

## Failure modes
- **Missed order assertion** in a test file → CI red. Mitigation: grep each touched test for `cursor`/`codex` ordering and run the three named harnesses locally before finalizing.
- **Stale prose left behind** (a doc still says "Cursor → Codex") → drift. Mitigation: grep `scripts/ship-pr.md`, `scripts/implement-bootstrap.md`, `skills/implement/SKILL.md`, `SECURITY.md`, `docs/external-reviewers.md`, and `docs/linting.md` for the old order after editing.
- **Accidentally flipping an out-of-scope cursor-first surface** (plan-review / brainstorm) → scope creep against Decision 1. Mitigation: those surfaces are listed in the report section below and are explicitly NOT edited.
