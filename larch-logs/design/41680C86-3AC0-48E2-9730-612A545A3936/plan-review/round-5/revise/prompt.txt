- **Legacy schemas:** use existing TSV schema helpers so compact and tool-column schemas keep working; map compact `v1`/`v2`/`v3` before rollup instead of skipping them.
- **Mixed panels:** code-review and plan-review rows aggregate by base tool, not panel, after voter-label rewrite to `panel=global`.
- **Design multi-round sessions:** multiple `plan-review/round-*` TSVs under one design session directory count as one run for windowing.
- **Flat review layout:** `review/&lt;RUN_ID&gt;/review-findings-classification-round-*.tsv` must window per `&lt;RUN_ID&gt;`, not collapse all review sessions into `larch-logs/review`.
- **Fallback tools:** labels such as `cursor-plan-fidelity`, `cursor-pragmatism`, `Claude`, `Codex`, and `Cursor` map to their actual base tool via case-insensitive normalization.
- **Malformed env window:** fallback to 100 for both dispatch env reads and snapshot CLI env reads.
- **Kill-switch:** `LARCH_VOTER_CALIBRATION_FEEDBACK=0` skips snapshot computation and render flags entirely on both code-review and plan-review paths.
- **Snapshot failure:** dispatch continues without feedback; stale tmpdir snapshots must not be passed through.
- **Plugin cwd:** snapshot creation in consumer repos must not read plugin-checkout `larch-logs` because child subprocess `cwd` is pinned to the plugin; use `_resolve_voter_calibration_log_root` with env or design-tmpdir anchors.
- **Ambiguous waterfall tool:** omit calibration only for tools with no resolvable prompt/stats pairing; never skip fallback-vendor renders because phase-1 primary was absent.
- **Waterfall relaunch:** phase-2 and phase-3 launches must use the prompt file for the executing tool; missing `prompt_files[tool]` must drop the slot, not fall back to legacy primary `prompt_file` or launch without a prompt.
- **Plan-review semantic labels:** voter 2 never authors cursor calibration prompts; voter 3 never authors codex calibration prompts.
- **Replay fidelity:** calibration replay must not inject live prompt-feedback into historical ballot reproduction.
- **Prompt stability:** no stats or absent `--voter-tool` must mean byte-stable render output for existing callers.

- **Run-log parse drift:** avoid by reusing `voter_agreement_rows_from_tsv` and schema support checks.
- **Wrong corpus / empty feedback:** avoid by `_resolve_voter_calibration_log_root` with env and design-tmpdir precedence, and passing the resolved path explicitly from dispatch callers.
- **Run-dir miscount:** avoid by mirroring `_ground_truth_run_dir` exactly, including flat review `path.parent` fallback.
- **Performance regression:** compute one snapshot per dispatch, not once per voter.
- **Prompt overreach:** keep feedback advisory. Do not alter parser, ballot, tally, or quorum behavior.

- **Tool misattribution:** centralize base-tool normalization, launchable-tool enumeration, manifest `prompt_files`, and launch-time selection in `agent_waterfall`; test cursor-only, claude fallback, and waterfall substitution paths.
