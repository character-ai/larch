- Re-enable strict `C901` / `PLR0911` / `PLR0912` / `PLR0913` / `PLR0915` enforcement per package where the package is now clean.
- Document the re-tightened policy in `docs/linting.md`.

#### Acceptance

- Strict complexity rules enforced per cleaned package.
- `make py-lint` green.

#### Value (LLM-only repo)
