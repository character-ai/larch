1. [correctness] `scripts/lint-readability-preamble.sh:90-104`

The plan changes orchestrator failures to print `found <count>`, but `count` is only assigned inside the `orchestrator-inline` case after `[ -f "$file" ]`. If an orchestrator manifest path is absent, the proposed error branch can expand an unset `count` under `set -u`.

Suggested revision: initialize `count=0` before the `[ -f "$file" ]` block for each row, or only use the count-specific error when the file exists and keep the generic missing-file message otherwise.
