## Failure modes

1. **Rare path loses a required contract.**
   - Signal: `make test-design-structure` fails, or review finds missing rc / option text.
   - Mitigation: compare moved body against the original block before deletion; verify branch-local `MANDATORY — READ ENTIRE FILE` sits immediately before each moved-body entry.

2. **Reference not loaded before use.**
   - Signal: call site has only a vague mention, not a mandatory-read pointer at the exact branch.
   - Mitigation: pin `MANDATORY — READ ENTIRE FILE` at drafter fail-safe entry (missing-rows paths only), Step 2b.5 item 3 (retained callers), Step 2b.5 branches 4–7 direct entry on Gate A hard-size and Override paths (not `gate-b-hard-size`), validator-failure shared entry (before Step 5c checks and autofix).

3. **G004 reachability regresses.**
   - Signal: agent-lint or structure tests complain about wrapper/helper contracts.
   - Mitigation: keep Wrapper contract inventory and Plan helper contracts inline in `SKILL.md`.

4. **Split-path unreachable after rc-handling move.**
   - Signal: hard/partition branches in the reference still say "run Split-path below" with no back-pointer.
   - Mitigation: rewrite only those cross-file anchors to explicit `SKILL.md` subsection pointers.

5. **Context savings defeated by maintainer table reload.**
   - Signal: sentinel host table uses `MANDATORY — READ ENTIRE FILE` in the always-loaded prelude.
   - Mitigation: maintainer-only optional pointer; load table only when auditing sentinels.

6. **Settle Gate A hard-size bypasses rc-handling reference or runs with empty KVs.**
   - Signal: `gate-a-hard-size` or Gate A rc `12` hits hard/partition/drift branches without loading `step2b5-rc-handling.md`, or branches run with empty `PLAN_LINES` / `SIZE_TRIGGER_FIRED` because items 1–2 were skipped and prose still requires `_plan_size_out`.
   - Mitigation: retained-branch-entry gate in `SKILL.md` plus explicit READ rows in `settle-rc-dispatch.md` for `gate-a-hard-size` and Gate A rc `12` only; direct-entry KV bind from `.design-postplan-emit-result.env` documented in `step2b5-rc-handling.md` Contract; rewrite metric-source prose to **direct-entry KV bind or `_plan_size_out` when present**; run soft-advisory breadcrumbs on direct-entry before branches 4–7.

   - Signal: `gate-b-hard-size` or Gate B rc `12` loads `step2b5-rc-handling.md` and presents Step 2b.5 Cancel/Final-summary/Split site-aware options instead of the Gate B hard plan-size prompt.
