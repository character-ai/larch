## Implementation Plan

Collapse the 41 inline awk plugin-root rehydration fences in `skills/implement/SKILL.md` into a single sourced env file. A sanctioned writer emits a minimal `plugin-root.env`; post-Step-0 Bash blocks source it instead of re-deriving `CLAUDE_PLUGIN_ROOT` with a 4-line awk block. Three pre-bootstrap sites retain a one-line session-env.sh awk fallback when the sibling is absent (legacy resume tmpdirs). `implement-bootstrap.sh` resume-tail syncs the sibling before later blocks. Refactor-only: same resolved value, ~110+ fewer lines of prompt boilerplate. Scope is `/implement` only (Round 1). SIMPLE tier — smallest change that achieves the goal.

## Approach
- One sanctioned writer (`write-session-env.sh`) gains one new output; the prompt only ever **sources** it. NEVER #14 (no prompt-side `session-env.sh` writes) stays intact — `plugin-root.env` is a new writer output, not a prompt-side `printf`/`>>`.
- Resume/dirty-tree legacy tmpdirs: bootstrap resume-tail calls the same `emit_plugin_root_env` helper when the sibling is missing; pre-bootstrap SKILL fences keep a one-line awk fallback until sync runs or the sibling already exists from a prior write.
- The writer change is general (fires for any `--write-session-env` caller), which also seeds the deferred `/design`+`/review` harmonization OOS without coupling to it.
- Replacement is mechanical: 37 post-Step-0 source-only sites + 3 pre-bootstrap source+awk sites (Round 1 decision); the prose example is handled as documentation, not as an executable site.

## Edge cases
- **Cold start / first post-Step-0 site**: `plugin-root.env` may not exist yet and `CLAUDE_PLUGIN_ROOT` is already in the env. The `-z` guard (already set) and `-f` guard (file absent) each make the source line a no-op. Writer emits the file at Step 0 via `session-setup.sh --write-session-env` before any later block runs.
- **Resume / dirty-tree / legacy tmpdir (`--resume-plan-tail`)**: `session-env.sh` exists but `plugin-root.env` may not (resume branch skips `write-session-env.sh`). Pre-bootstrap SKILL blocks (Step 0 foreground, dirty-tree recovery) use source-then-awk so the first touch still resolves from `LARCH_CLAUDE_PLUGIN_ROOT=`; bootstrap resume-tail then emits the sibling for the rest of the run. Post-Step-0 blocks after bootstrap see only the source line.
- **`set -u`**: `${CLAUDE_PLUGIN_ROOT:-}` and `${IMPLEMENT_TMPDIR:-}` keep the test no-fail when either is unset; the bare `"$IMPLEMENT_TMPDIR/plugin-root.env"` is reached only after `[ -n "${IMPLEMENT_TMPDIR:-}" ]` passes.
- **Unconditional-export nuance**: the awk form ran `export CLAUDE_PLUGIN_ROOT` unconditionally; the source line exports only when it fires. Since `CLAUDE_PLUGIN_ROOT` is never inherited into a post-Step-0 block, the `-z` guard is true at every block top, so the source line always fires and exports — behavioral equivalence holds.
- **`/dev/null` output**: sibling write skipped, mirroring the main-output `/dev/null` carve-out (avoids writing `/dev/plugin-root.env`).
- **Sourced writer / bootstrap errexit**: resume-tail `. write-session-env.sh` must not run top-level `set -e` or argv parsing in the parent shell; the `BASH_SOURCE` guard scopes those to argv0 only.
- **Child-script `read_kv()` idiom is unrelated**: `skills/implement/scripts/{write-final-report,post-tracking-issue,slack-issue-announce,refresh-execution-issues}.sh` use a generic parameterized `awk -v k=...` KV reader, not the rehydration fence. Out of scope; do not touch.

## Failure modes
- **`plugin-root.env` not emitted at Step 0** (writer guard wrong, or `--write-session-env` path unexpected) → every post-Step-0 block silently fails to resolve `CLAUDE_PLUGIN_ROOT`, breaking `${CLAUDE_PLUGIN_ROOT}/...` calls. Earliest signal: writer-roundtrip regression fails; `/implement` Step 1+ helper calls error with empty path. Mitigation: the new `test-session-env-roundtrip.sh` assertion pins emission; keep the `-f` guard so a missing file is a clean no-op rather than a sourced error.
- **Resume tmpdir without sibling sync** (bootstrap resume branch omits `emit_plugin_root_env`) → pre-bootstrap blocks still recover via awk fallback; post-Step-0 blocks after bootstrap fail if sync never ran. Earliest signal: resume-tail regression in `test-session-env-roundtrip.sh`; `/implement` Step 0 resume then Step 1+ empty `${CLAUDE_PLUGIN_ROOT}`.
- **Invariant C left awk-only** → CI fails on every post-Step-0 fence after SKILL migration even if grep parity passes. Earliest signal: `make test-implement-timing-rehydration` immediately after SKILL edit; mitigation: rewrite Invariant C and `test-implement-timing-rehydration.md` invariant 4 in the same PR.
- **Stale awk-form assertion left in `test-implement-timing-rehydration.sh`** → CI passes vacuously (0==0) while silently no longer testing rehydration. Earliest signal: caught now in plan; mitigation: replace with absent-old / present-new assertions above.
- **`emit_plugin_root_env` uses `exit` on skip/invalid when called from sourced bootstrap** → bootstrap aborts mid resume-tail; Step 0+ may never run. Earliest signal: resume with invalid `LARCH_CLAUDE_PLUGIN_ROOT` or empty value after read. Mitigation: `return 0` on skip/invalid inside the function; argv0-only `exit`.
- **`write-session-env.sh` sourced with top-level `set -e` outside the guard** → errexit leaks into `implement-bootstrap.sh`; benign helper/cmd failures abort resume. Earliest signal: resume-tail path fails on non-fatal errors. Mitigation: keep `set -euo pipefail`, lib-quiet init, and argv parsing inside `BASH_SOURCE==$0` only; only `emit_plugin_root_env` outside the guard.
- **Non-uniform replacement** (a fence left as awk, or a `read_kv()` idiom edited by mistake) → mixed rehydration mechanisms or a broken child script. Earliest signal: `make lint` / `grep -Fc` of the awk line on SKILL.md != 0. Mitigation: match on the exact 4-line block; verify post-edit grep count is 0 in SKILL.md and child scripts are untouched.
