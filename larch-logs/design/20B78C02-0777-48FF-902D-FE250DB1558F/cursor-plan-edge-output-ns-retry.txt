1. **risk-integration** `scripts/write-session-env.sh` (proposed) — The plan adds `. "$SCRIPT_DIR/write-session-env.sh"` from `implement-bootstrap.sh`, which runs with `set -uo pipefail` and **without** `-e` (`scripts/implement-bootstrap.sh:4-7`). In Bash, a sourced script’s top-level `set -euo pipefail` and any `exit 1` from the argument-parser path apply to the **caller** shell. The plan only says to wrap the “main body” and does not explicitly require `set -euo pipefail`, `source lib-quiet.sh`, `larch_quiet_init`, and all `exit` paths to live inside the `BASH_SOURCE` guard. — Mis-scoped guard enables errexit mid-resume or aborts bootstrap on the empty-`--output` check while sourcing. — State in the plan that everything from `set -euo pipefail` through the main write must be inside `if [[ "${BASH_SOURCE[0]}" == "${0}" ]]; then … fi`; only `emit_plugin_root_env` stays outside.
