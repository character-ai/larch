## Edge cases

- **No `jq`:** New Python paths must work without `jq`.
- **Malformed JSON:** Skip bad JSONL or NDJSON rows where bash previously ignored parser failures.
- **Missing round roots:** Review detail returns empty output for missing or unreadable roots, except the no-rounds message for a readable root with no completed rounds.
- **Partial round artifacts:** Render available counts and labels. Do not fail, fail final reports.
- **Design security OOS:** Preserve subtraction of security OOS items from design OOS accepted or rejected counts.
- **Panel-manifest snapshots:** Design round-meta must still materialize `panel-manifest.ndjson` from the round-local slots file or the session-root fallback.
- **Token ledger windows:** Keep inclusive `[start_s, end_s]` attribution for vendor cost rows.
- **Dual timing windows:** Table Time/Cost uses skill-filtered round windows; Gantt uses skill-agnostic round windows. Do not unify them.
- **Gantt overlap:** Since #4546 overlaps this area, keep the current Gantt text stable unless tests prove a required difference.
- **Phase-detail timeout:** Large or pathological ledgers must hit the 15s best-effort ceiling and return `""`, not block Step 17 final-report, design publish, or live progress. Explicit CLI `progress render-phase-detail` may run unbounded.
- **Implement meta-write best-effort:** Malformed or partial implement round artifacts must not raise through `review_and_fix` round completion; flush and downstream batches still run (#4038).
- **Design meta-write override:** When `WRITE_DESIGN_ROUND_META_SH` is set, run the override command; when unset, run the Python CLI default. Neither path may abort post-revise dedup.
- **Run-log GC guards:** Repo-root, `larch-logs`, dirty-tree, and main-branch checks run before enumeration and before any dry-run or apply path. Guards apply to dry-run and apply alike.
- **Run-log GC symlinks:** Never follow symlinks when enumerating or deleting/slimming run dirs.
- **Run-log GC staging:** Stage only under `larch-logs/`, never repo-wide `git add -A`.
- **Status KV key names:** `status check` must emit `CODEX_BINARY_FOUND`, matching `skills/status/scripts/status.sh` and `skills/status/SKILL.md`. A `CODING_BINARY_FOUND` typo breaks `/status` KV parsers.
- **Status:** A failed probe must still produce a complete KV set with conservative values.
- **Retired-script manifest:** Do not leave any `migrated-scripts.tsv` path on disk.

## Failure modes when non-trivial

- **Retired-script lint failures:** Adding deleted paths to `migrated-scripts.tsv` will make stale prose references fail. Update docs, tests, allowlists, and `SECURITY.md` in the same change.
- **Hidden test dependencies:** Bash harnesses may copy or stub retired scripts. Remove those fixtures or convert them to Python CLI stubs.
- **Behavior drift in markdown tables:** The review phase detail output is regression-sensitive. Use golden-ish assertions for headings, rows, totals, Gantt header, and sentinel-free markdown.
- **Post-revise meta refresh skipped:** Dropping the `-x` gate without `|| true` can abort Step 3 after a successful revise and leave stale `round-meta.json`.
- **Design override silently dropped:** Replacing the post-revise block with an unconditional Python call breaks harnesses that set `WRITE_DESIGN_ROUND_META_SH` and hides the override contract.
- **Implement meta-write raises:** A raising in-process helper can skip `flush_round_log_after_coder` and leave committed run logs missing per-round batches (#4038).
- **Silent bogus final summaries:** Missing `render run-summary` usage validation can publish `unknown` summaries with `STATUS=ok`.
- **Unbounded in-process renderer hang:** Dropping the 15s wrapper on best-effort paths can stall `/implement` Step 17 or design final-summary publish on large token/timing ledgers.
- **GC external side effects:** Non-dry-run GC creates branches, commits, pushes, and PRs. Tests must stub external commands and run in temp repos.
- **GC guard ordering drift:** Running enumeration or dry-run before guards can mutate or report on invalid state.
- **GC symlink escape:** Following symlinked run dirs can delete or slim files outside `larch-logs/`.
- **Quiet stream drift:** `gc-run-logs run` and `status check` must keep KV output parseable. Avoid raw diagnostics on stdout.
- **Status KV typo:** Emitting `CODING_BINARY_FOUND` instead of `CODEX_BINARY_FOUND` breaks `/status` consumers that parse the live contract.
- **Module naming mismatch:** The discussion says `agent.py`, but the repo uses `python/agents.py`. Implement in `python/agents.py` and register `status check` there.

  - `make py-lint`
  - `make py-test`
  - `make lint`
