### 1. Pre-scan guards must cover `--dry-run` (correctness)

The bash script refuses dirty trees and non-`main` branches **before** enumeration and **before** the dry-run exit:

```88:99:skills/gc-run-logs/scripts/gc-run-logs.sh
if [ -n "$(git -C "$REPO_ROOT" status --porcelain 2>/dev/null)" ]; then
    larch_err "gc-run-logs: working tree is dirty — ensure no /implement or /design session is active before running GC"
    emit_kv STATUS "error"
    exit 2
fi

CURRENT_BRANCH="$(git -C "$REPO_ROOT" rev-parse --abbrev-ref HEAD 2>/dev/null)" || CURRENT_BRANCH=""
if [ "$CURRENT_BRANCH" != "main" ]; then
    larch_err "gc-run-logs: must be run from the main branch (currently on: ${CURRENT_BRANCH:-detached})"
```

Plan edge case 463 only says "Never mutate **non-dry-run** state when the tree is dirty…", which can be read as allowing dry-run on a dirty tree. Pin guard order and apply guards to both dry-run and apply paths.
