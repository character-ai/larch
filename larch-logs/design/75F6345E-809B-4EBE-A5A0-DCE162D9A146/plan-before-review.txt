## Failure modes

- Broad text matching could turn genuine main-agent stalls into automatic retries. Match explicit helper-exhaustion evidence only.
- Returning `main-agent-edit` without a valid ledger would prevent the orchestrator from recording and locating the failure evidence. Require successful ledger population before returning the action.
- Widening the supported-site set would alter ship or Step 5 contracts. Reuse the existing set without additions.
- A new classifier pattern would require extra machine-consumer updates. Prefer an existing safe pattern unless implementation proves a distinct token is necessary.
