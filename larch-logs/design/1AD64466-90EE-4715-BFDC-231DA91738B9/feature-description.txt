**Changes.**

- **Demote the Step 7a read of `skills/implement/references/summary-comment-template.md`.** `skills/implement/scripts/step-7a.sh` owns the `larch:diagrams` upsert via `python3 python/cli.py diagrams upsert`; the orchestrator composes no comment at Step 7a. Keep the conditional Step 2.5 Q/A load site. The reference's own "When to load" section already frames it as an editing-time document.
- **Delete the MANDATORY read of `skills/implement/references/phantom-probe.md`.** The probe is advisory by contract, and `scripts/phantom-probe-with-warn.sh` already prints the operator warning and appends the execution-issues entry itself. Replace the directive with one sentence in SKILL.md: trailing `PHANTOM_*` KVs are advisory telemetry; do not act on them.
- **Make the rebase-routing load conditional.** Have `scripts/rebase-checkpoint-probe.sh` emit `ROUTE=continue|conflict|bail` alongside its existing KVs, and mandate reading `skills/implement/references/rebase-checkpoint-routing.md` only when `ROUTE` is not `continue`. Green-path runs then skip the read at 1.r, 4.r, 7.r, and 7a.r.
- **Inline the interactive predicate.** The Step 0 degraded-gate paragraph sends the orchestrator to `skills/shared/external-reviewers.md` for the one-sentence canonical interactive predicate. Inline that sentence (or pass an `--interactive` flag to the gate and parse `PROMPT_REQUIRED=`) so the shared file is not loaded at runtime.
- **Remove dead text.** The `Cross-Skill Presence Propagation` section header has an empty body yet is named as a required post-Step-5 action at several sites; restore its body or delete the references. Remove the dangling "close Step 3 telemetry:" and "close Step 6 telemetry:" sentences whose bodies moved into wrappers. Compress the removed NEVER entries (#2, #10, #13) to one-line stubs.
- **Pin the semantic-materiality probe budget.** Tighten Preflight item 6 wording from "reasonable inspection" to "a single batched Bash probe block" so materiality checking stays one tool call.

**Acceptance.**

- A green-path `/implement` run mandates none of: `phantom-probe.md`, `summary-comment-template.md` (outside Step 2.5 Q/A), `rebase-checkpoint-routing.md`.
- `make lint`, the implement structure harnesses, and the halt-rate harness tokens stay green.
