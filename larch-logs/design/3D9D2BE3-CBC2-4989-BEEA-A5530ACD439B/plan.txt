- `CI_NOT_READY` must still wait and retry as it does today.
- `MAIN_ADVANCED` pre-rebase flush must not read stale merge state through `state_file`.
- `MAIN_ADVANCED` must not fall through into the old shared `CI_NOT_READY` tail.

- `PrePushConflictHandoff` must preserve resume state without advancing rebase or iteration counters.
- Rebase fallback ingestion must not read a stale `${output}.token-record` from a prior attempt.

## Failure modes

- If pre-rebase log flush skips for a disallowed reason after `MAIN_ADVANCED`, return the same stalled shape as the existing `goto_rebase` path.
- If `MAIN_ADVANCED` remains in the shared `CI_NOT_READY` branch, the new iteration-delta test should fail.
- If `MAIN_ADVANCED` does not `continue` immediately after the rebase sequence, the new fallthrough test should fail.
- If sidecar pre-clear fails due to permissions or filesystem errors, fail closed before launching the conflict fixer.
- If the research snippet regresses to `if ! command; then rc=$?`, the structural test should fail.
- If the progress filter leaks into design plan review, the design regression should fail.
- If the progress filter drifts from the shell committed-report filter, the mixed-row test should catch the visible CI-row leak.
