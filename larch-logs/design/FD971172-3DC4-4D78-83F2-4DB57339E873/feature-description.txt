# bash-to-py-mop-up: Migrate oos-file-conflict-deps.sh union-find algorithm to Python

**What:** Port `skills/implement/scripts/oos-file-conflict-deps.sh` (~346 lines) to a Python module behind `python3 python/cli.py`.

**Why:** This is a non-thin orchestration body, not a thin wrapper. It hand-rolls a union-find / connected-components graph algorithm plus interval-overlap conflict detection in pure Bash. A code comment states the file-backed predecessor cost "~5500 awk invocations on a 22-item chain" and the author reimplemented union-find in Bash arrays for performance. Pure algorithmic logic belongs in Python for correctness and testability. It was overlooked by the migration: it appears in neither `docs/python-migration.md`, `python/migrated-scripts.tsv`, nor `scripts/residual-bash-paths.txt`.

**Evidence:** Invoked from `skills/implement/SKILL.md` Step 9a.1 (file-conflict pre-pass). Already calls `python/cli.py issue parse-input` and `python/cli.py voting file-line-regex`.

**Scope:**
- New module under `python/` (e.g. `oos_file_conflict.py`) registered as a `cli.py` verb.
- Port union-find, path-safety checks, range-overlap, cluster-cap chain-degradation, atomic TSV output, and the env knobs `OOS_FILE_CONFLICT_CLUSTER_CAP` / `OOS_FILE_CONFLICT_GLOBAL_CAP`.
- Repoint `skills/implement/SKILL.md` to the new verb (no shim).
- Migrate the regression harness `test-oos-file-conflict-deps.sh` to colocated pytest.
- Delete the `.sh` and record it in `python/migrated-scripts.tsv`.

**Acceptance:** Existing fixtures pass against the Python verb (same-file serialization, disjoint-range parallelism, malformed-item index preservation, root-level path forms, Tier-1 chain degradation, Tier-2 cap failure, atomic output). `make lint-retired-scripts` clean.
