## Edge cases

- **Rehydrate before pause-complete:** `step6_main` must parse argv and rehydrate session env before removing or honoring `.pause-save-complete`.
- **Pause before guards:** Pause must still win over `.bg-wait-active`.
- **Pause after `step-5d`:** Prelude must still write `step-5d` before the second pause check.
- **Stale background marker:** A valid Step 5c sidecar must override stale `.bg-wait-active`.
- **Missing sidecar:** Do not clean up. Exit 0 with preserved/skipped status rows even when `CLAUDE_PLUGIN_ROOT` is unset.
- **Log publish failed:** If `SESSION_ID` is non-empty and `PUBLISH_OK` is not `true`, preserve tmpdir.
- **Standalone heavy failed:** Preserve tmpdir when `STANDALONE_HEAVY_FAILED=true`.
- **Cleanup ineligible:** Preserve tmpdir when `CLEANUP_ELIGIBLE=false`.
- **Combined pause resume:** `.pause-save-complete` must stop cleanup only when prelude created it in the current run, using the rehydrated tmpdir rather than a stale pre-rehydration marker.

## Failure modes

- **Wrong quiet routing:** Status rows may disappear. Pin the verbs in `_DESIGN_LIFECYCLE_STDOUT_KEYS` and add at least one CLI or main-level stdout test.
- **Sentinel order regression:** Cleanup may delete the tmpdir before `step-6` is visible. Use a monkeypatched cleanup function to assert `step-6` exists before deletion.
- **Unsafe sidecar parsing:** Shell-sourcing the Step 5c sidecar would widen trust. Parse allowlisted `KEY=value` rows in Python.
- **Early plugin-root abort:** Calling `_design_require_plugin_root` before skip/preserve gates would break missing-sidecar recovery. Require plugin root only on timing-mark and cleanup-deletion paths.
- **Stale pause-complete marker:** Removing or honoring `.pause-save-complete` before session rehydration can skip cleanup incorrectly. Rehydrate first and test through `--session-env-path`.
- **Retired-path literals:** Adding manifest rows before clearing `python/test_upgrade_larch.py` will fail `make lint-retired-scripts`. Update that test before appending the Step 6 manifest rows.
- **Launcher drift:** Saved or generated launchers may still pass `design-step6.sh`. Keep basename mapping in `python/session_env.py` while SKILL.md moves to bare `step6`.
