## Approach Synthesis

All four personality sketches converged on the same core mechanical approach with no architectural contest. The plan below incorporates their points of strongest agreement and the nuanced reminders that the Cursor sketches surfaced.

### Full agreement across all 4 sketches

1. Add `ALLOW_FINDINGS_OUTSIDE_TMPDIR="false"` variable initialization; argv parses `--allow-findings-outside-tmpdir true|false` with strict boolean grammar matching `--codex-present` / `--cursor-present`. Default `false` preserves byte-equivalent behavior for all current `/review` and `/design` call sites.
2. The rejection branch of `case "$_findings_canon"` (current aggregate-findings.sh lines 54–62) becomes flag-gated. Canonicalization itself stays unconditional so when the flag is `true`, the resolved absolute findings path is still well-formed for the rest of the pipeline.
3. The symlink rejection at line 50 stays unconditional regardless of flag value. The flag relaxes one safety guarantee (containment), not two.
4. Error message hint is appended **only** to the containment `larch_err` at line 59 — `(use --allow-findings-outside-tmpdir=true to bypass)` — and never to the symlink-rejection, missing-file, or unresolvable-tmpdir errors. Hint placement is intentional: it tells the operator exactly which rule they can opt out of.
5. Surfaces are strictly the three files in scope. No changes to `review-core.sh`, `plan-review-loop.sh`, or any caller; future multi-round-loop callers wire the flag when their partition lands.
6. Regression harness extension: minimal pair — (a) findings-file outside tmpdir + `--allow-findings-outside-tmpdir true` succeeds (use existing `AGGREGATE_DISPATCH_SH` stub pattern to avoid LLM dispatch); (b) same setup with flag absent or `false` rejects with exit 2 and includes the new hint substring in stderr.

### Synthesis decisions on nuanced points (no architectural contest)

- **Asymmetric containment model**: Both Cursor sketches explicitly highlight that the **post-dispatch output check at lines 735–744** (`_cand_canon` must resolve under `--review-tmpdir`) stays strict. The Codex sketches do not address it but their proposed change set implicitly preserves the same shape. The plan adopts the asymmetric model: input (`--findings-file`) relaxation only; output containment remains enforced. The `aggregate-findings.md` must document this asymmetry so future callers do not assume the flag widens output policy.
- **Implementation ordering** (Cursor-Arch + Cursor-Edge): parse argv → validate the new boolean → resolve `REVIEW_TMPDIR_CANON` → unconditional symlink rejection → canonicalize findings path → flag-gated containment `case` → existing `--codex-present` / `--cursor-present` / `--mode` / `--input-mode` validation → rest of pipeline unchanged. This preserves cheap fail-closed behavior.
- **`mv` blast radius note** (Cursor-Edge): `mv -f "$merged_tmp" "$FINDINGS_FILE"` at line 678 can now overwrite files outside `--review-tmpdir` when the flag is on. Document in `aggregate-findings.md` that opt-in callers should snapshot or stage findings if they need rollback, since success always clobbers in place (validator failure already preserves input).
- **Innovation alternative** (Codex-Innovation): a `--findings-root DIR` allowlist instead of a binary flag was proposed for policy-stronger future callers. Synthesis call: reject as overscope for this partition. The boolean flag is sufficient for the immediate R4/FINDING_2 unblock; a later partition can widen to a root-based policy if multiple-root-aware callers emerge.

### Personality highlights folded into plan

- **Architecture/Standards** (Cursor): reuse existing boolean-grammar pattern; no new shared library; resist widening the flag to dispatch output or symlinks; the explicit flag is the audit signal so no `LARCH_*` env equivalent is needed.
- **Pragmatism/Safety** (Codex): preserve rc 2 for misconfiguration; preserve byte-equivalent default behavior; do not move existing argv parsing or validation order; explicit narrow opt-in is the safest widening of a file-read/write primitive.
- **Edge-case/Failure-mode** (Cursor): hint only on containment error; consider an additional symlink-with-flag-still-rejected test case (not strictly required by user's Step 1c choice of "minimal pair" but a reasonable extension if the harness already has a symlink helper); `mv -f` blast radius doc note; do not relax the post-dispatch output check.
- **Innovation/Exploration** (Codex): the rejected `--findings-root DIR` alternative is preserved here as a future option for a follow-up partition if needed; flag-digest verification is overbuilt for an internal default-off script flag.
