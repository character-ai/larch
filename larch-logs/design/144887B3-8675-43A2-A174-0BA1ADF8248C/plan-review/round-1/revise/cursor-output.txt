## Edge cases

- `DESIGN_TMPDIR` missing, invalid, or relative.
- Folded Step 2a sentinel prep failure.
- Pause requested before drafter launch.
- Pause requested during postplan rc11.
- Invalid Claude model with whitespace.
- Git status failure while capturing baseline (must unlink stale porcelain).
- `feature-description.txt` missing or empty after artifact reset (rc `1`, no action).
- Dirty sidecar present with `STATUS=dirty` and `MODE=baseline-delta`.
- Dirty sidecar absent but baseline porcelain differs.
- Drafter writes a plan without `PLAN_WRITTEN=true`.
- Drafter succeeds structurally but scout manifest is missing or invalid.
- Codex vendor with `skip_reason` set: no launch, `drafter_rc == 2`, sidecars still appended.
- Postplan rc10 schedules inline retry only when the current logic says so (depends on conditional `.step2b-postplan-fallback-used` seed).
- Dialectic candidate promotion failure warns but does not fail the run.
- Handler return codes must not be dropped by a thin main (no double emission).

## Failure modes

- Helper extraction can reorder stdout or stderr. Preserve the current order.
- Helper extraction can move a side effect across the dirty-tree check or feature-description gate. Do not do that.
- Folding codex sidecars into the launch helper drops ledger updates on skip paths.
- Unconditional `true` for `.step2b-postplan-fallback-used` breaks rc10 inline-retry scheduling.
- Leaving baseline porcelain after git-status failure can misroute dirty-tree recovery.
- Regenerating the baseline before the refactor can lock in bad metrics. Regenerate only after refactoring.
- New helpers can become new complexity offenders. Keep them small.
- Thin main that ignores handler `int` returns can fall through and double-emit `DRAFTER_NEXT_ACTION`.
