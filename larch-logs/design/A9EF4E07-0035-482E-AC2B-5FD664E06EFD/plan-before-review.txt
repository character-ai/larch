## Edge cases

- Preserve `False` for commands whose stdout is human-facing.
- Preserve `True` for every current machine consumer, including design and plan commands previously included through the deleted spread set.
- Keep `_MACHINE_STDOUT_KEYS` available as a derived, immutable view because tests outside the firm scope import it.
- Leave facade modules intact for consumers outside `_REGISTRY`.
- Preserve lazy imports and existing exit-code propagation.

## Failure modes

- A missed `True` flag can re-enable quiet suppression for `KEY=value` output.
- A wrong defining module can fail lazy import, callable lookup, or existing monkeypatch seams.
- An outdated two-field unpack can fail registry-wide tests or dispatch.
- A hand-maintained compatibility set would recreate the silent-omission defect.
