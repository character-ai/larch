## Edge cases

- **No accepted findings**: no apply coder runs; no apply row appears. Existing no-task and reviewer-only behavior remains.
- **Cursor unavailable**: `_run_coder_cursor` returns `False` before launch; no timing row is recorded. Codex fallback unchanged.
- **Cursor apply fails**: a `signal` row may be recorded. Final shell renderer does not filter by status; live progress filters to complete rows. Preserve current behavior.
- **Flat `/review` layout**: ledger resolver writes to `review_tmpdir/timing-ledger.tsv` even when session env lacks `LARCH_TIMING_LEDGER`; `_record_coder_vendor_task` still passes `--ledger` explicitly.
- **`/design` plan revise-waterfall**: no new design-loop instrumentation; existing `codex-plan-autofix` / `cursor-plan-autofix` rows with `*-output.txt` are labeled `codex/apply` / `cursor/apply` by kind.
- **Ledger round window vs verification gap**: chart axis spans full `gantt_rrange` duration; CI/check rows stay excluded, so a tail gap after the last bar may remain.
- **Cross-skill rounds**: unfiltered `gantt_rrange` must still union all `type=round` rows for the round number so implement vendor tasks inside a design-skilled round window remain visible (Test 12).

## Failure modes when non-trivial

- **Timing ledger unavailable**: renderer still omits charts or renders partial output and exits `0`.
- **Timing record write fails**: `timing record-vendor-task` keeps warning-and-continue behavior; apply may run without a chart bar.
- **Apply row exceeds 25-row cap**: existing cap may omit it in very busy rounds. Do not change the cap.
- **Unknown task-kind warnings**: adding review-fix kinds to `TIMING_TASK_KINDS_ALLOWED` prevents noisy warnings for new and existing apply rows.
- **Harness drift on axis switch**: both `test-render-review-phase-detail.sh` and `test-write-final-report.sh` must expect ledger-window title spans, not filtered-task spans.
