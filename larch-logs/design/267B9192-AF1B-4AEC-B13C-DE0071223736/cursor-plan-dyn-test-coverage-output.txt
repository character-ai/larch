### 1. **correctness** — `plan.txt:60-64,106-108`; `python/plan_review.py:1150-1151,1327-1342`

The plan treats `run-step3-review.sh` as “move `larch_quiet_init` after the existing validate,” but `plan-review run` has no in-process validator before `_run_legacy` (contrast `emit_design_plan_preview` at `python/plan_review.py:1117-1124`). The new substring invariant only compares first global occurrences, so it may not catch a preview-only validate branch while loop/single paths still quiet-init or write before embedded validation.

**Suggested revision:** Require an explicit `session validate-design-tmpdir` on non-preview paths before canonicalize/write/quiet-init, and add a run-step3-specific test branch check.

### 2. **[OUT_OF_SCOPE] risk-integration** — `python/test_plan_review.py:875-891`; `python/plan_review.py:865-908`

`test_embedded_waterfall_dispatchers_call_agent_verb` exercises substituted decoded bodies only. It does not prove the raw gzip blobs still carry the retired waterfall markers that `_decode_legacy_asset` rewrites at runtime.

**Suggested revision:** Add a minimal `_decode_asset` raw-marker assertion next to the existing waterfall test; keep manual decode-diff review as a secondary gate.

### Assessment of the plan’s other test choices

- **Iterating `_LEGACY_ASSETS`:** Sufficient for the universal quiet/validate ordering invariant across every embedded script that calls `larch_quiet_init`.
- **Using `legacy_asset_bytes()` for the invariant:** Acceptable; waterfall substitutions do not alter `session validate-design-tmpdir` or `larch_quiet_init` tokens.
- **Preserving `test_embedded_waterfall_dispatchers_call_agent_verb`:** Necessary but not sufficient for the raw round-trip contract (finding 2).
