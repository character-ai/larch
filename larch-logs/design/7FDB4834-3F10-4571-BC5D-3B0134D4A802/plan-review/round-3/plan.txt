## Failure modes

- **Stale-restore drift:** a verbatim #1896 paste could reference deleted anchor surfaces. Mitigation: reconstruct against current helpers and checkpoint flow.
- **Pre-checkpoint stats drift:** documenting run-statistics inside the new pipeline or leaving NEVER #5's sentinel-recovery `run-statistics` clause unchanged could persist stats before disposition passes. Mitigation: narrow NEVER #5 to `oos-issues` only on sentinel recovery; `oos-pipeline.md` Contract + step 3 precedence; Step 7 defers stats to post-checkpoint SKILL.md; structure test pins both.
- **Security predicate mismatch:** a broader `focus-area=security` filter could exclude blocks the gate still counts as non-security, causing checkpoint failure after filing. Mitigation: cite `oos-disposition-gate.md` Counting rules / `oos-non-security-block-count.awk` in step 1; structure-test pin dedicated field-line wording.
- **Duplicate disposition loss:** all-deduplicated batches could have no `ISSUE_<i>_URL`. Mitigation: parse and record `ISSUE_<i>_DUPLICATE_OF_URL`.
- **Design-source mismatch:** filing could miss design OOS that checkpoint still sees. Mitigation: document the same design-source resolution order as checkpoint.
- **Manifest harvest gap:** Codex/Cursor `oos_observations[]` could never reach Step 9a.1 inputs. Mitigation: step 1 `$MANIFEST_PATH` harvest; structure-test pin `oos_observations[]`.
- **Filed-only early-exit gap:** already-filed design OOS could lack checkpoint evidence. Mitigation: explicitly materialize/reuse URL evidence before returning.
- **Partial-failure sentinel poisoning:** reruns could skip failed OOS items. Mitigation: suppress sentinel writes on non-zero `/issue` or `ISSUES_FAILED>0`.
- **Partial-failure gate false-pass:** recording any URL from a failed batch in `oos-issues` NDJSON could clear `OOS_PENDING` while items remain undispositioned. Mitigation: step 4/6 forbid gate-visible accepted URL rows until the batch succeeds with no failed items; structure-test pin 8b.
- **Guard rot:** one load directive or helper-name mention could pass while a runtime path remains unwired. Mitigation: fixed-string count for two load directives and invocation-fragment assertions.
- **Sentinel format drift:** heading-only guard could pass with a gutted format. Mitigation: pin table header, filed tally, and `issues/<n>` URL-token shape.
