### FINDING_1: Split-path section scope leaks into Step 3 and misclassifies plan-review.md
- **Reviewer(s)**: Cursor-Innovation, Cursor-Pragmatic
- **Severity**: blocking
- **Concern**: The planned section-scoped conditional detector closes `#### Split-path (decomposition panel)` only at the next equal-or-shallower markdown heading. In `skills/design/SKILL.md`, that next heading is `### External Reviewer Setup` (line 385), with no intervening `## Step 3`. Step 3 prose at `<!-- step:3 — Plan Review -->` (line 366) and the eager `plan-review.md` MANDATORY READ at line 382 therefore sit inside the open Split-path scope. With no other eager directive for `plan-review.md`, eager-wins dedup cannot recover it; the file moves from eager to conditional-only. That drops roughly 215 lines / ~6k tokens below the issue acceptance target while a regenerated baseline can still look self-consistent. Planned isolated fixtures and byte-equality baseline checks do not exercise this Split-path-then-Step-3 layout, so the regression would not be caught.
- **Suggested revisions (informational for voters; coder decides)**:
  - From Cursor-Innovation: End named conditional sections at the next `<!-- step:` HTML comment boundary (e.g. close Split-path at line 366 `<!-- step:3 — Plan Review -->`) in addition to heading-depth closure, or limit section-scoped classification to directives within a small line window under the heading. Add an explicit regression test that `skills/design/references/plan-review.md` stays in the eager section.
  - From Cursor-Pragmatic: End design conditional section scope at <!-- step:N --> HTML comment boundaries (already used throughout skills/design/SKILL.md), not heading depth alone. Add a regression test on the real design scan (or a fixture mirroring Split-path then step comment then eager read) asserting skills/design/references/plan-review.md stays in result.files.
  - From Cursor-Pragmatic: Add one integration test that scans a fixture (or repo design SKILL) where #### Split-path precedes <!-- step:3 --> and a subsequent eager MANDATORY READ, and assert that file remains eager-only while decompose-panel.md is conditional-only.
