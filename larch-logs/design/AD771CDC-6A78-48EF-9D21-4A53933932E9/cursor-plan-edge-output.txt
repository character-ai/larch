If `write_failed_agent_stderr_tail` propagates that status, `launch-claude-subprocess.sh` can abort before writing `.done` (```222:222:scripts/launch-claude-subprocess.sh```), causing sentinel hangs. Specify that `write_failed_agent_stderr_tail` always returns 0 after cleanup and add a harness for failed runs with an empty stderr source.
