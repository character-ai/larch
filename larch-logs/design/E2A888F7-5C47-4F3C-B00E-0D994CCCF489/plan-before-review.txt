## Edge cases

- Preserve caller-supplied field and label order.
- Do not emit empty optional flags.
- Accept empty paginated output as an empty result.
- Reject valid JSON objects or scalar pages where issue-list arrays are required.
- Keep arbitrary GitHub state and field values as caller data. Do not introduce policy validation that would block future `gh` values.
- Do not combine mutation retries with read retries.

## Failure modes

- A non-transient list or view failure raises `ShipError`.
- Exhausted transient read failures raise `TransientNetworkError` with the final result attached through the existing retry path.
- Invalid or incorrectly shaped list JSON raises `ShipError`.
- Close and label-edit failures remain inspectable through their returned `CommandResult`.
- An incorrect argv order or missing optional flag is caught by exact runner-call assertions.
