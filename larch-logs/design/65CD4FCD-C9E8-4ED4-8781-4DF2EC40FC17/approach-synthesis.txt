# Approach Synthesis (Step 2a.4)

## Sketch summaries

**Codex-Generic** (substantive, ~2.1KB): `scripts/render-run-summary.sh` already emits `- **Cost**:` every time it runs (with `N/A` fallback when no token data), so the omission must come from one of two places: (a) a caller-side degraded fallback that bypasses the renderer entirely, or (b) prompt-side prose that replaces the rendered block at end of turn. Concrete trigger identified: `skills/implement/scripts/write-final-report.sh` has a degraded path (the `if [ "$rr" -ne 0 ] || [ ! -s "$body_tmp" ]` block) that writes a minimal stub of only title + Outcome + sentinel — no cost line at all — when `render-run-summary.sh` exits nonzero or returns an empty body. `/design`'s `render-final-summary.sh` has a related-but-different risk: when the token report fails or all per-bucket counts are zero with non-empty stderr, it calls `render-run-summary.sh` with NO token args, yielding `- **Cost**: N/A` — but this still emits the line (different from the implement degraded-stub failure mode).

Codex recommends: harden the implement degraded path so it ALWAYS includes a cost bullet (either by re-entering `render-run-summary.sh` with normalized N/A/zero inputs, or by inlining a small shared "degraded-summary with full bullet schema" helper); add SKILL.md NEVER rules in both `/implement` and `/design` against free-form "Run complete" recap prose that replaces the rendered block; extend `test-write-final-report.sh` and `test-render-final-summary.sh` with the renderer-failure / token-report-failure cases.

## Decisions incorporated into the plan

4. Extend `test-write-final-report.sh` and `test-render-final-summary.sh` with renderer-failure and token-report-failure cases.
