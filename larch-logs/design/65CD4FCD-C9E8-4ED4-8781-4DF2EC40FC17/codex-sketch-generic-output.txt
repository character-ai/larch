I’d make `scripts/render-run-summary.sh` the hard single source of truth for terminal summaries. It already emits `- **Cost**:` whenever it runs, so the omission is upstream: either a caller falls back around it, or prompt-side prose later replaces the rendered block. The concrete trigger I found is `/implement`’s degraded render path in `skills/implement/scripts/write-final-report.sh`: if `render-run-summary.sh` exits nonzero or produces an empty body, it writes a minimal stub with only title/outcome/sentinel, no cost line. `/design` has the same architectural risk through `skills/design/scripts/render-final-summary.sh`: token-report failure is handled separately, but renderer failure is not converted into a guaranteed full summary body.

I’d modify `skills/implement/scripts/write-final-report.sh` and `skills/design/scripts/render-final-summary.sh` so both normalize token-report states into one shared contract: valid bucket/aggregate counts produce the priced cost line; missing/unparseable token data produces an explicit `- **Cost**: N/A`; no path produces a summary without a cost bullet. The implement fallback should either re-enter `render-run-summary.sh` with safe `N/A`/zero-normalized inputs or use a small shared degraded-summary helper that preserves the full bullet schema. I’d also update `skills/implement/SKILL.md` and `skills/design/SKILL.md` to prevent free-form terminal “Run complete” recap prose from replacing the rendered final-summary block; if a final recap is printed, it should relay the generated `final-summary.md` body.

Main tradeoff: avoid misleading `$0.00` when cost data is unavailable. That means the fix should distinguish “real zero tokens” from “token report failed/missing” and render `N/A` for the latter. Regression coverage should extend `skills/implement/scripts/test-write-final-report.sh` and `skills/design/scripts/test-render-final-summary.sh` with token-report failure / renderer-failure cases, plus keep existing `test-render-run-summary*` shape tests intact. The post-merge `/implement` path must remain tmpdir/API-only: no post-merge log commit.
