## Findings

**1. [correctness] `python/design_publish.py:402-443` / `python/design_lifecycle.py:3720-3790` — Scrub failure needs exit code 5**

The plan correctly targets the asymmetry where scrub failure today returns `(False, "", "", "", "0")` from `_publish_design_logs` and `log_publish_main` always exits 0 (`python/design_log_publish_flow.py:300-302`, `430-436`). It does not pin how `publish_core` should propagate that failure.

`publish_core` never reads `publish.returncode` and always returns 0 after the log-publish subprocess (`python/design_publish.py:402-443`). Step 5c only hard-aborts into `failed-publish-tail` when `publish_rc` is outside `{0, 1, 3, 4}` (`python/design_lifecycle.py:3720-3738`). Exit 1 is still treated as a normal partial-success path; with `PLAN_WRITE_OK=true` the run outcome stays `approved` (`design_lifecycle.py:3786-3790`).

**Suggested revision:** In the `python/design_publish.py` section, require `return 5` when `log-publish` exits non-zero for scrub failure; skip the rotation warning on that path; keep recoverable push/PR failures at subprocess rc 0 with `PUBLISH_OK=false`. Add a regression test that scrub failure reaches `failed-publish-tail`, while `test_log_publish_pr_failure_keeps_tree_clean_and_emits_recovery` behavior is unchanged.

**2. [risk-integration] `python/design_log_publish_flow.py:152-191` / `421-436` — Preserve recoverable GitHub failure contract**

The plan’s `SecretScrubFailure` approach is the right minimum change for Item 3. The main integration risk is over-broad fail-closed: mapping push/PR failures to non-zero would break the existing recovery contract (`python/test_design_log_publish_flow.py:166-184` expects rc 0, `PUBLISH_OK=false`, `RECOVERY_BRANCH`).

**Suggested revision:** State explicitly in `### UPDATED: python/design_log_publish_flow.py` that only scrub/redact/residual-secret paths raise `SecretScrubFailure` and exit non-zero; push/PR/create failures keep rc 0 with `PUBLISH_OK=false` and recovery branch KVs. Add the paired tests the plan already lists for scrub abort vs PR failure.
