Move the `[DESIGNING]`→`[DESIGNED]` title rename in `design-publish.sh` to immediately after architecture-diagram upsert, dropping the `PUBLISH_OK==true` gate and not introducing a scrub gate for admission. Keep a `design-log-publish.sh --scrub-only` preflight, but make it a log-publish preflight after admission rename, not an admission gate. If scrub-only fails closed, skip the full flush, report log-publish failure/recovery, and leave `[DESIGNED]` admission intact when rename succeeded. If scrub-only reports redactions with `SCRUB_OK=true`, emit an immediate operator-visible SECURITY diagnostic before full flush and dedupe the final WARN. Stale `final-summary.md` cleanup must run before scrub-only/full publish.

Accepted review revisions add: Step 5c parser support for new result keys; full flush skipped on `SCRUB_OK=false`; `SCRUB_OK=false` tests asserting no flush; stale-summary cleanup before scrub checks; `SECURITY.md` update; scrub-only tests covering `git push` side effects; Step 5d/footer split on admission state; scrub-failed guidance aimed at scrub/redaction gate logs, with rotation only for `SECRET_SCRUB_VIOLATIONS`.

## Approach

Make title rename the admission boundary and run it before all log-publish work. Scrub-only remains useful to prevent unsafe log flushes, but it cannot block or undo admission. Admission is explicit through `ADMISSION_READY` / `ADMISSION_BLOCK_REASON`; scrub status is separate log-publish state.

## Edge cases

- `SESSION_ID` empty: rename/scrub/publish/marker skipped.
- Rename no-op: `ADMISSION_READY=true`.
- Rename failure/unknown: admission blocked until fixed.
- Scrub-only failure after rename: full flush skipped; admission remains ready; log recovery separate.
- Publish failure after admission: `[DESIGNED]` remains; `/implement` may proceed.
- Secret redactions with `SCRUB_OK=true`: immediate SECURITY diagnostic before full flush; deduped final WARN.
- Marker remains publish-gated.

## Failure modes

1. Scrub accidentally gates rename — violates feature. Signal: ordering tests.
2. Full flush runs after `SCRUB_OK=false` — contradictory state. Signal: publish harness single-call assertion.
3. Step 5c parser drops new keys — Step 5d/footer wrong. Signal: parser/admission tests.
4. Render reads result env too early — stale admission notes. Signal: render export tests.
5. `RENAMED=false` misclassified — false operator recovery. Signal: no-op tests.
6. Scrub-only has push/PR side effects — security regression. Signal: direct scrub-only test.
7. Scrub-failed guidance says rotate by default — operator confusion. Signal: render/Step 5d prose review.
