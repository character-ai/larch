## Approach

Reorder plus gate swap: rename before full publish, `SCRUB_OK` not `PUBLISH_OK`. Factor `--scrub-only` from existing staging+scrub block. Admission semantics are explicit (`ADMISSION_READY` / `ADMISSION_BLOCK_REASON`) so tracking-issue no-op (`RENAMED=false`, title already `[DESIGNED]`) does not read as failure. Render receives live exports before `write_result_env_and_emit`, matching `DESIGN_LOG_*` today.

Tests pin **scrub-only** and **full-flush** positions separately so correct dual-publish implementations cannot fail ordering assertions.

`/implement` unchanged (title-keyed); earlier `[DESIGNED]` is the optimization.

## Edge cases

- **`SESSION_ID` empty**: scrub, rename, publish, marker skipped (unchanged).
- **`SCRUB_OK=false`**: rename skipped; `ADMISSION_BLOCK_REASON=scrub-failed`; footers must not claim `/implement` ready.
- **Publish fails after admission ready**: `[DESIGNED]` + `larch:plan`; `failed-publish` summary; `/implement` proceeds when `ADMISSION_READY=true`.
- **Rename no-op** (`RENAMED=false`, success): `ADMISSION_READY=true`; footers must not say “fix rename.”
- **Rename command failure**: `ADMISSION_BLOCK_REASON=rename-failed`; no admission-ready bullet.
- **Scrub violations with `SCRUB_OK=true`**: SECURITY warn before rename; dedupe on full publish if needed.
- **Spurious `/design` after publish failure**: marker still publish-gated; `[DESIGNED]` title → `cancel-title-filter` (unchanged).

## Failure modes

1. **Ordering pins anchor scrub as flush** — first-match `publish_log_line` or `head -1` publish position breaks harness/structure tests. Mitigation: separate `scrub_pos` / `flush_pos` and `--scrub-only`-aware greps. Signal: `test-design-publish.sh` / `test-design-structure.sh`.
2. **Stub omits `SCRUB_OK=true`** — rename never runs in harness. Mitigation: stub branch default. Signal: happy path / `SCRUB_OK=false` case.
3. **Render reads result env too early** — wrong admission bullet. Mitigation: export before render; env-first contract. Signal: `test-render-final-summary.sh` + publish integration render log.
4. **Scrub warn only on full publish** — early admission after secret exposure without rotation guidance. Mitigation: parse `SECRET_SCRUB_VIOLATIONS` on scrub-only. Signal: scrub-only harness + code review.
5. **`RENAMED=false` misclassified** — operators chase rename on no-op or skip scrub block. Mitigation: `ADMISSION_*` keys. Signal: failed-publish bullet tests (no-op + scrub-failed cases).
6. **`--scrub-only` ships with PR path** — security/admission bypass. Mitigation: direct `test-design-log-publish.sh`. Signal: new harness cases.
7. **Regex / structure pin drift** — keep `[DESIGNED]` + `rename failed` in warn; preserve Step 5c sentinel substring.
