# /design Steps 3b-4b: scripted diagram classifier and single tail wrapper

**Problem.** The Step 3b skip path is three consecutive mechanical calls (`design-step3b-entry.sh --mode entry`, `--mode skip`, `design-step3b-complete.sh`). The architectural path adds a raw `mv` promotion of `architecture-diagram.candidate.md`, prompt-side sanitizer-failure cleanup plus failure-log appends, then `design-step3b-complete.sh`, `design-step4.sh`, a separate read of `rejected-findings.md`, and `design-step4b.sh`; only Gate C needs the orchestrator. Gate C "See full plan" also directs a raw `cat` of `plan.txt`.

**Proposal.**

- Move the non-architectural classifier into `design-step3b-entry.sh`: parse the `NEW:` / `UPDATED:` / `REWRITTEN:` heading paths from `plan.txt`; doc, config, and plain-text extensions route to skip; `.sh`, `.py`, SKILL.md, or any uncertainty routes to architectural (conservative default preserved). Entry emits `DIAGRAM_REQUIRED=`; the skip path runs branch-local cleanup and the completion boundary internally (one call).
- `design-step3b-sanitize.sh` absorbs candidate promotion, rejected-path cleanup and failure-log append, and the completion boundary; it prints the promoted diagram between stable BEGIN/END markers for verbatim re-emission.
- One tail wrapper covers 3b-complete plus Step 4 plus Step 4b entry: it emits the `rejected-findings.md` body between markers (no separate Read) and then the Gate C preview plus `SKIP_APPROVE_REQUESTED`.
- Add `--variant full` to `emit-design-plan-preview.sh` so Gate C full-plan displays stop using raw `cat`.

**Acceptance.**

- Skip path: one Bash call. Architectural path: entry, LLM candidate write, one sanitize-plus-complete call, one tail call into Gate C.
- Diagram and rejected-findings bodies re-emitted verbatim from captured output; sanitizer rejection warnings byte-compatible.
