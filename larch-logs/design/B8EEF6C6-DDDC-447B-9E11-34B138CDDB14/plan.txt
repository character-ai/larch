## Edge cases

- Missing `plan.txt`: classify as architectural and emit `DIAGRAM_REQUIRED=true`.
- Empty `plan.txt`: classify as architectural.
- No plan headings found: classify as architectural.
- Backtick-wrapped plan paths such as ``### UPDATED: `docs/foo.md` ``: strip one surrounding backtick pair and classify as `docs/foo.md`.
- Heading tails with extra whitespace: trim before token extraction.
- Mixed docs and script changes: classify as architectural.
- `SKILL.md` anywhere in the normalized path: classify as architectural.
- Uppercase extensions: normalize before classification.
- Sanitizer rc 1 or `STATUS=rejected`: delete candidate, append warning, continue without a diagram.
- Sanitizer rc 2 or unreadable candidate: treat as handled sanitizer failure when possible, append warning, continue without a diagram.
- FINALIZE failure: exit non-zero and preserve tmpdir for repair.
- Old paused sessions with `.completed/step-3b` but no `.completed/finalize`: tail wrapper keeps the Step 4 compatibility FINALIZE guard.
- Pause-save during Gate C preview: tail wrapper exits 0 before skip-approve read and before `.completed/step-4`.
- Gate C full-plan warning path: `--variant full` should warn and exit 0 when tmpdir or plan is unavailable.

## Failure modes

- A classifier bug can skip a needed diagram. Mitigate with a conservative default.
- Missing backtick normalization can misroute docs-only plans to architectural. Normalize path tokens before extension checks.
- A marker collision in diagram or rejected-findings content can confuse prompt-side re-emission. Use unlikely stable marker names and document verbatim body extraction.
- A failed `run-log append-failure` must not block the workflow. Keep `|| true`.
- A failed FINALIZE must block Step 5. Preserve the existing warning and exit behavior.
- Leaving raw Gate C `cat` language in `SKILL.md` or `approval-gates.md` can reintroduce the old path. Replace all Gate C full-plan mentions in both files.
- Missing `.pause-save-complete` early exit after Gate C preview can mark Step 4 complete mid-pause. Mirror the existing guard and pin it structurally.
