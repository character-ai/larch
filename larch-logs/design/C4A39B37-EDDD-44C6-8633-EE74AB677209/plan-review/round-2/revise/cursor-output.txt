## Failure modes

- Bad launcher verb validation can block all post-session Step-0/1 fences while leaving Step 2+ broken if the `*.sh` branch is dropped or non-hyphenated verbs are omitted from the allowlist.
  - Cover dual dispatch and all 11 verbs in `scripts/test-design-structure.sh` and `python/test_session_env.py`.
- Dropping a KV line or degraded explanation relay can break prompt-side parsing or operator `needs-degraded-decision` prompts.
  - Use stdout contract tests for every parsed key and explanation passthrough.
  - Register verbs in `_DESIGN_LIFECYCLE_STDOUT_KEYS` so quiet mode does not suppress KVs.
- Reading shell env with `eval` would create injection risk.
  - Parse generated env files with strict allowlists and `%q` decode rules.
- Subprocess pause-save return instead of `sys.exit` would let orchestration continue after `.pause-requested`.
  - Terminal `check_pause_and_exit` on every ported verb at the bash-equivalent checkpoint.
- Writing `step-0c` before pause-check can skip folded discussion on resume.
  - Enforce pause-before-sentinel ordering in `step0c_main` and pytest.
- Omitting `step-2a.5` from Gate A/B re-entry cleanup can skew Step 3 direct-review restore.
  - Mirror exact bash `rm -f` list in `step1e_reentry_main` and pytest.
- Deleting retired scripts before SKILL repoint can break runtime.
  - Repoint SKILL and launcher first, then delete.
- Leaving retired path references outside `python/migrated-scripts.tsv` can fail `make lint-retired-scripts`.
  - Run targeted grep and `make lint-retired-scripts`.
