## Edge cases

- Existing paused sessions may have old pause blocks. Preserve pause marker bytes and `docs/issue-anchored-plan.md` payload fields.
- Re-invoked `/design` must regenerate the per-PID launcher through `write-design-env`.
- `ROUTE=clarify` must still let clarify publish use `.design-step0-route-state.env` as a repo fallback.
- `gh issue view` failures must abort with the existing Step 0b diagnostic.
- `cancel-pause-load` must exit non-zero before normal route stdout (orchestrator must not parse a success `ROUTE=` line); **captured-route subprocess parity prevents in-process `route_main()` from leaking `ROUTE=cancel-pause-load` to stdout.**
- Missing or malformed result env files must fail closed.
- Symlinked result env files must remain refused by `read-result-env`.
- `run-params.json` reads must work without `jq`.
- Parsed-env `%q` values with spaces or shell metacharacters must round-trip through write/load.
- Session-bound `REPO` must not be overwritten by `resolve_repo` when already set.
- **`step0-init` must read `ROUTE` from `.design-route-result.env`; stale or absent route-state alone must not gate `feature-description.txt`.**
- **`step0-init` must subprocess `design init-runparams` with captured stdout; wrapper stdout must not leak `INIT_STATUS=` / `RENAMED=` KVs.**
- **Session setup stderr-only `PREFLIGHT_ERROR` lines must reach the operator via combined-stream print after parse KVs and before exit.**
- **`step0-session` must always parse (including zero argv) and relay parse KVs before session setup so Step 0-pre bindings and verbal routing never read stale `step0-parsed-$pid.env`.**
- **`step0-route` must re-validate `POSITIONAL_KIND` from parsed env before `gh issue view`; invalid or stale kinds abort with existing stderr messages.**
- **`relay_degraded_tools_gate_stdout` must track `BOTH_DOWN_SEEN`; `degraded-one-down` requires a seen `BOTH_DOWN=false` line plus `.degraded-tools-gate-prompted`.**
- **`--plugin-root` must export `CLAUDE_PLUGIN_ROOT` before `write-design-env` or launcher generation fails when the env var is unset.**
- Resumed `/design` with new `--partition` / `--brainstorm` / approval flags must OR-merge through `route_main` because `step0-route` forwards parsed-env router flags.
- **`step0-parse` / session inline parse must reject unexpanded argv templates, `parse-argv` rc `3`, and invalid `POSITIONAL_KIND` before session setup proceeds.**
- **`step0-clarify-hard-halt` launcher invocations with custom `--exit-code` / `--failure-detail-log` must forward into terminal-state staging.**
- `agent collect-results` non-zero exits must still continue collection cleanup and log the failure.
- Launch failure rows must remain idempotent via **`.brainstorm-<log-basename>.runlog-appended`**, including basename fallback sinks when `.meta` is absent.
- Dirty-tree sidecars must override a clean checkpoint when any sidecar reports dirty or unknown.
- `LARCH_SKILL_NON_INTERACTIVE=true` must not trigger an interactive degraded-tools prompt path.
- Step 0c pause during folded discussion must not write `step-0c` (resume must replay Step 0c).
- Unported Step 2+ fences (`design-step2a.sh`, `design-step3-review.sh`, `design-clarify.sh`, etc.) must continue working through launcher `*.sh` branch after cutover.

## Failure modes

- Bad launcher verb validation can block all post-session Step-0/1 fences while leaving Step 2+ broken if the `*.sh` branch is dropped or non-hyphenated verbs are omitted from the allowlist.
  - Cover dual dispatch and all 11 verbs in `scripts/test-design-structure.sh` and `python/test_session_env.py`.
- Dropping a KV line or degraded explanation relay can break prompt-side parsing or operator `needs-degraded-decision` prompts.
  - Use stdout contract tests for every parsed key and explanation passthrough.
  - Register verbs in `_DESIGN_LIFECYCLE_STDOUT_KEYS` so quiet mode does not suppress KVs.
- **Skipping parse KV relay or zero-argv parse can leave Step 0b on stale argv state or empty positional bindings.**
  - Always parse before setup; print parse KVs first; pytest zero-argv cache overwrite and KV ordering.
- **Omitting `BOTH_DOWN_SEEN` can mis-emit `needs-degraded-decision` after explicit Continue on one-down paths.**
  - Port `design-step0-session.sh:168-207`; pytest prompted-sentinel and false-without-seen cases.
- **Missing `CLAUDE_PLUGIN_ROOT` export can prevent `design-run-$PPID.sh` generation.**
  - `require_plugin_root` before `write-design-env`; pytest with absent inherited env.
- **Capturing session setup stdout only can hide `PREFLIGHT_ERROR` and break operator diagnostics.**
  - Capture `2>&1`, print full stream after parse KVs, then parse KVs; pytest the stderr-only failure path.
- **Calling `route_main()` or `init_runparams_main()` in-process can leak orchestrator KVs (`ROUTE=`, `INIT_STATUS=`) before abort branches.**
  - Subprocess with captured stdout for both route and init; pytest no leaked KVs on failure paths.
- Reading shell env with `eval` would create injection risk.
  - Parse generated env files with strict allowlists and `%q` decode rules.
- Subprocess pause-save return instead of `sys.exit` would let orchestration continue after `.pause-requested`.
  - Terminal `check_pause_and_exit` on every ported verb at the bash-equivalent checkpoint.
- Writing `step-0c` before pause-check can skip folded discussion on resume.
  - Enforce pause-before-sentinel ordering in `step0c_main` and pytest.
- Omitting `step-2a.5` from Gate A/B re-entry cleanup can skew Step 3 direct-review restore.
  - Mirror exact bash `rm -f` list in `step1e_reentry_main` and pytest.
- **Skipping route `POSITIONAL_KIND` re-validation can let stale parsed env reach `gh` or `design route`.**
  - Mirror `design-step0-route.sh:101-121`; pytest invalid kind and non-numeric issue positional.
- **Omitting router-flag forwarding into `design route` argv can break resumed flag OR-merge in `run-params.json`.**
  - Mirror bash subprocess argv in `step0_route_main` and pytest flag forwarding.
- **Using route-state `ROUTE` for init gating can skip or mis-write `feature-description.txt`.**
  - Read `ROUTE` only from `.design-route-result.env`; pytest route-state-only negative case.
- **Skipping parse validation can let bad argv reach session setup or emit unusable parsed env.**
  - Mirror `design-step0-parse.sh:104-158` in `step0_parse_main` and session inline path; pytest rc `3`, template literal, invalid `POSITIONAL_KIND`.
- **Omitting clarify-hard-halt `--exit-code` / `--failure-detail-log` breaks legacy launcher contracts.**
  - Forward defaults and clamped detail log into `design-stage-terminal-state.sh`; pytest argv.
- **Omitting `.brainstorm-<basename>.runlog-appended` can duplicate `External Reviewer Issues` rows on collect retry.**
  - Port `design_collect_launch_failure_once` exactly; pytest second pass idempotency.
- Deleting retired scripts before SKILL repoint can break runtime.
  - Repoint SKILL and launcher first, then delete.
- Leaving retired path references outside `python/migrated-scripts.tsv` can fail `make lint-retired-scripts`.
  - Run targeted grep and `make lint-retired-scripts`.
- **Dropping `timeout: 1260000` on the brainstorm collect Bash fence can kill collection early.**
  - Pin in `brainstorm.md` and `scripts/test-design-structure.sh`.
