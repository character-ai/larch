## Edge cases

- Existing paused runs may contain old run-params fields. Resume should ignore unknown keys, not branch on them.
- Existing paused runs may contain legacy tier metadata. Pause-load must treat it as inert data and must not emit tier-bearing output.
- Existing paused runs may point at `STEP=2a.5`. Pause-load must remap them before registry validation to the one-flow path after repairing `NO_SKETCHES` artifacts.
- Legacy `2a.5` repair must not overwrite non-sentinel sketch or dialectic artifacts. It should fail with a clear recovery message if overwrite would be required.
- Old logs under `larch-logs/` may still contain uppercase tier strings. The acceptance grep excludes them.
- `git grep -nE 'SIMPLE|HARD'` also catches uppercase substrings such as `SHARD`. Rename those identifiers when the required acceptance grep reports them.
- Safety preambles with old uppercase labels must keep the read-only and no-mutation content after the label and variable rename.
- Plan-size threshold names change, but thresholds and exit-code behavior stay stable.
- `--partition` must still route to decomposition when no size trigger fires.
- `--hard` must fail as an unknown public flag before session setup mutates state.
- Report-token scans must keep historical design runs parseable even when old workflow fields exist.
- Final summaries must accept `cancelled-plan-size` and must not read or print mode/path fallbacks for design.
- Shared run-summary rendering must suppress design `Mode`, including fallback `N/A`, without changing implement behavior.
- Deleted sketch, dialectic, debate-retry, and snapshot helper docs must not remain as shipped contracts.
- CI fixers must not try to run deleted local commands.
- Effort-prose and research-structure harnesses must not pin deleted prompt or protocol paths.
- Design diagrams, progress output, and degraded-tool warnings must not describe retired sketch or dialectic behavior.
- Discussion rounds must not anchor on sketch agents, contested decisions, or dialectic resolutions.

## Failure modes

1. **Partial rename breaks shell contracts**
   - Signal: tests fail because one script emits `HARD_TRIGGER_FIRED` while a caller reads `SIZE_TRIGGER_FIRED`.
   - Mitigation: update producer, parser, result env propagation, docs, and tests in one pass. Grep both old and new keys.

2. **Paused-run compatibility regresses**
   - Signal: resume tests fail, legacy `2a.5` attempts to invoke deleted orchestration, old `run-params.json` fields cause branching, or pause-load rejects the legacy step before remap.
   - Mitigation: ignore old fields. Remap `2a.5` before registry validation. Do not reject a run-param file solely because it has extra keys.

3. **Pause-load tier metadata survives**
   - Signal: pause-load emits `TIER`, `RESTORED_DESIGN_CLASSIFICATION`, default classification, or source literals that fail the acceptance grep.
   - Mitigation: drop tier marker persistence, validation, defaulting, and emission together. Update pause-save, pause-load docs, and resume tests in the same patch.

4. **Sentinel repair overwrites restored data**
   - Signal: legacy resume replaces non-sentinel sketch or dialectic artifacts with `NO_SKETCHES`.
   - Mitigation: keep conflict checks. Only write missing or known sentinel artifacts. Fail clearly on non-sentinel conflicts unless a safe backup path is deliberately implemented and tested.

5. **Final-summary flow fields survive**
   - Signal: final summaries still show Mode or Path, pass `--workflow-path`, emit `Mode: N/A`, or reject `cancelled-plan-size`.
   - Mitigation: update `render-final-summary.sh`, `design-publish.sh`, `design-route.sh`, `design-step-final-summary.sh`, `render-run-summary.sh`, shared renderer tests, render-cost callsite tests, and Bash 3.2 coverage together.

6. **Deleted files remain wired into checks**
   - Signal: `make lint`, relevant checks, agent lint, CI, CI fixer, or local rerun mapping fails on missing snapshot, sketch, dialectic, protocol, or debate-retry files.
   - Mitigation: remove Makefile targets, CI steps, Python CI maps, shell ship maps, relevant-checks mappings, lint TSV rows, effort-prose paths, research-structure pins, agent-lint pins, rule pins, and docs references in the same change set as deletions.

7. **Acceptance grep fails on unrelated uppercase substrings**
   - Signal: final `git grep -nE 'SIMPLE|HARD' -- ':!larch-logs'` reports unrelated fixture text or uppercase identifiers.
   - Mitigation: run the grep repeatedly near the end. Rename unrelated uppercase identifiers to neutral names only where the required grep reports them.

8. **Safety prompt hardening is weakened by literal cleanup**
   - Signal: external Codex/Cursor tests no longer assert a read-only no-mutation preamble.
   - Mitigation: rename only labels, variables, and comments to strict wording. Preserve safety body text and update launcher tests to assert the renamed preamble.

9. **Active references still describe the retired path**
   - Signal: brainstorm, outline, discussion, decompose, diagram, progress, or degraded-tool references mention sketches, dialectic, contested dispositions, or hard triggers.
   - Mitigation: update those references with the `/design` skill rewrite and their harnesses in the same pass.

10. **Plan-review loses proportionality guidance**
   - Signal: plan-review prompts become tier-neutral but no longer tell reviewers or drafters to prefer minimum necessary change.
   - Mitigation: make the minimum-change guidance unconditional. Remove only the deleted tier branch and classification read.

11. **Step 3 cap handling calls deleted classification reader**
   - Signal: cap-reached tests fail after `session read-classification` is removed, or cap output still contains tier wording.
   - Mitigation: remove the classification call and use a tier-neutral cap-reached message. Add direct test coverage.

12. **Debate-retry machinery survives without a caller**
   - Signal: `python/cli.py render debate-retry`, `render_debate_retry_main`, or debate-retry tests still ship after deleting dialectic execution.
   - Mitigation: remove the route, helper, tests, migrated-script rows, agent-lint pins, and docs mentions together unless a non-dialectic caller is found.

13. **Snapshot helper call sites survive helper deletion**
   - Signal: `review-design-step3-loop.sh` calls `step3_loop_run_hard_snapshots` after the function or helper script is removed.
   - Mitigation: remove the function and all invocations in the same patch. Keep rc `12` as warn-and-continue without snapshot side effects.

14. **Classification defaults survive in wrapper scaffolding**
   - Signal: `design_classification` remains in active design wrappers such as `design-step-validator-autofix.sh`.
   - Mitigation: grep all `skills/design/scripts/*.sh` wrappers for classification defaults and remove them consistently.
