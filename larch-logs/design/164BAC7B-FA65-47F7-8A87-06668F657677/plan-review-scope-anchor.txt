The `code-review-tally.flush.err` sidecar `#6228` added now captures the cause: `write_tally_main` stages its record file through the ambient `$TMPDIR`, and in the live orchestrated Step 5 process that `$TMPDIR` resolves to a malformed, nonexistent path. `NamedTemporaryFile` fails with `ENOENT`, the write returns nonzero, and the inner `run-log write` never runs. This is the deferred `#6228` root-cause remainder and the outstanding blocker on umbrella `#5993`'s "real Code review line" close condition.

## Root cause analysis

`write_tally_main` (`python/larch/review/voting.py:1466`) calls `tempfile.NamedTemporaryFile("w", ..., prefix="write-tally-record.")` with no `dir=` argument, so it stages the record under the ambient `$TMPDIR`. In the live Step 5 process `$TMPDIR` resolves to a malformed, nonexistent path (session-cache root plus the absolute system tmpdir). `NamedTemporaryFile` cannot create the file there and raises `ENOENT`. The nonzero return code means the inner `run-log write` for the tally never runs, so run-root `code-review-tally.json` is never written. The findings-batch leg survives because it uses a direct `run-log write` that does not stage through that `NamedTemporaryFile`.

Inference, not yet confirmed: the malformed `$TMPDIR` likely originates in session bootstrap or an env snapshot that builds a per-session tmpdir by joining the session root with the inherited absolute `$TMPDIR` without stripping the leading path. This locus is unconfirmed; see Open questions.

## Suggested fix(es)

1. Stage the tally record under a known-good directory. In `write_tally_main`, pass an explicit `dir=` (the implement or run tmpdir, or the `--log-root`) to `NamedTemporaryFile`, or validate and repair `$TMPDIR` before the call. Keep the write loud: a failed record stage should surface, not silently drop the tally.
2. Investigate where the malformed `$TMPDIR` is set under `python/larch/state/`. Fix at source if that is the cleaner locus. Route `write_self_review_tally` through the same hardening, since it shares the path.
3. Add a regression test: with `$TMPDIR` set to a nonexistent nested path, `flush_review_batches` and `write_self_review_tally` still write run-root `code-review-tally.json` and leave no `code-review-tally.flush.err`.

Acceptance: a fresh live `/implement` run on a fix-bearing version commits run-root `code-review-tally.json` with no sidecar, and summaries render from the tally.
