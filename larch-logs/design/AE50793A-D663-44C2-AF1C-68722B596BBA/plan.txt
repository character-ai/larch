## Approach

Implement the fix in four layers.

1. **Prompt contract**: remove the per-status-change reviewer tracker. Replace it with a twice-per-wait table.
2. **Yield contract**: make each immediate-background fence say to end the turn after the launch ack. State that this is not a halt.
3. **Intent rule**: update the shared NEVER list to ban all progress-observation probes while a background task is in flight.
4. **Mechanical guard**: add a PreToolUse hook that denies Bash/Read probes when a live `.bg-wait-active` marker exists.

Use `design-step5c.sh` as the Step 5c marker writer. Do not add a marker to `design-publish.sh` directly, because the immediate-background fence launches `design-step5c.sh`.

Write the per-slot final reviewer status artifact in `plan-review-loop.sh`. It already owns dispatch, collection, round timing, and terminal snapshots. Avoid changing `record-plan-review-round-timing.sh`.

## Edge cases

- **Pause requested before launch**: do not write the marker before pause-save `exec`.
- **Wrapper crash**: EXIT trap removes the marker.
- **Hook sees stale marker**: ignore or reap when PID is dead or age exceeds timeout.
- **Multiple session markers**: deny only when the tool target clearly matches a live marker’s tmpdir or task-output shape.
- **Post-notification reads**: pass because the wrapper has exited and removed the marker.
- **Clean final summaries**: no warning or note when the denial sidecar is absent or zero.
- **No jq in hook runtime**: allow silently.

## Failure modes

- **False deny**: user sees the educational deny reason and can wait for notification or set `LARCH_BG_POLL_GUARD_DISABLE=1`.
- **False allow**: prompt rules and PostToolUse reminder still apply.
- **Telemetry write failure**: deny still works; final summary may omit the count.
- **Marker creation failure**: wrapper should continue, because the guard must not break `/design`; structure tests still catch missing literals and marker code.
