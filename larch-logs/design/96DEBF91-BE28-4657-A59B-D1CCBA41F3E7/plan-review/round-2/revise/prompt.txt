## Edge cases

- **JSON empty plus empty text**: `checks_empty=True`, `checks_observed=True`; status remains today's value, usually `pending` when grace is 0.
- **JSON empty plus text present**: classify text; `checks_empty=False`, `checks_observed=True`.
- **Invalid or missing JSON plus empty text**: match current fallback behavior; `checks_empty=True`, `checks_observed=True`.
- **Required checks**: pass `required=True` through the observation path and text fallback.
- **Fetch failure in `gather_status`**: `checks_observed=False`, `checks_empty=False`; `poll_ci` must not treat this as non-empty rollup and must not clear `startup_empty_since`.
- **Behind probe failure (`behind_raw is None`) with empty rollup**: still set `checks_empty=True` and `checks_observed=True` from the pre-probe observation.
- **Error normalization in `poll_ci`**: preserve `checks_empty` and `checks_observed` on the rebuilt pending `CiStatus`.
- **Worker raises inside `future.result()`**: still becomes `DuplicateCodeError`; do not degrade to serial.
- **Pool cannot be created or submit fails with `OSError`**: degrade to serial.

## Failure modes

- A broad `except OSError` wrapped around too much code can hide real worker failures.
  - Keep `_collect_worker_results` outside the fallback intent by relying on its `DuplicateCodeError` translation.
- Adding `checks_empty` or `checks_observed` before existing `CiStatus` fields can break positional construction.
  - Add both last with defaults.
- Pool-fallback test with only two modules never enters parallel path because `_resolve_jobs` caps at `pair_count`.
  - Require at least three modules in the fallback regression fixture.
- Reusing the checks observation can change startup timing if `startup_empty_since` is set after non-wait decisions.
  - Keep the deadline block after `decide(...)` and only run it for `decision.action == "wait"`.
- Treating fetch-failure `checks_observed=False` as rollup non-empty can permanently reset startup deadline accounting.
  - Gate accumulate/clear on `checks_observed`.
- Deadline-expiry or error-normalization `CiStatus` rebuilds that omit copied fields can regress callers reading the expiry snapshot.
  - Mirror today's field copy on both paths.
