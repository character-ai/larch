## Approach
Pure extraction — move arg-assembly, bootstrap run, exit-2 handler, and success envelope parse into one wrapper; thin SKILL.md to exports + wrapper calls + one shared routing-env parse. **Exit-2 contract (FINDING_2):** wrapper owns handler output on **stderr**; SKILL propagates with `exit 2` only (no second print, no stdout operator text). **Success contract:** stdout envelope always carries `IMPLEMENT_TMPDIR` (initial path unknown pre-call); file-first `bootstrap-routing.env` for remaining keys. Wrapper writes only `bootstrap-routing.env`; `implement-bootstrap.sh` retains `session-env.sh` (NEVER #14). Update all edit-in-sync structural pins, including the full 506–526 retarget/invert set (FINDING_1). Grep verify-only consumers (`lint-foreground-markers.sh` DENYLIST, `docs/linting.md`, `skills/shared/subskill-invocation.md`) when stale direct-bootstrap pins appear.

## Edge cases
- Initial: `IMPLEMENT_TMPDIR` from stdout before `bootstrap-routing.env` read.
- Resume: caller-exported `IMPLEMENT_TMPDIR` not clobbered; still in envelope.
- Exit 2 before tmpdir: redaction-log reads tolerate missing `IMPLEMENT_TMPDIR` (as today).
- Command substitution on success must not capture stderr operator text (stderr-only on failure).
- Symlinked / unreadable `bootstrap-routing.env` → stdout fallback.
- Empty `--coder` on initial → omit flag.
- Bash 3.2: no associative arrays; quote envelope values with spaces.

## Failure modes
1. **Dropped envelope key** — silent Degraded-tools / dirty-tree break; mitigate consumer grep + default-keep.
2. **Stale structural pins** — especially 506–526 left asserting `_ib_target_issue` / `_ib_kv_scan` in SKILL; mitigate full invert/retarget list in same change.
3. **Operator-message drift / duplication (FINDING_2)** — stdout handler text + SKILL `printf "$_inv_out"` doubles banners; or stderr paraphrase drops redaction. Mitigate: byte-for-byte handler on stderr; structure pins forbid SKILL exit-2 print; harness asserts stderr-only operator text.
4. **Preamble / dirty-tree bypass** — third harness copy if directive or fence still call `implement-bootstrap.sh` directly. Mitigate: grep + `test-implement-step2-routing` / structure awk.
