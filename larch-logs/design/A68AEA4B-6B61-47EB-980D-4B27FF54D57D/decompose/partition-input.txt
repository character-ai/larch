# [FEATURE] 7196.2: /design Gate C adverse-outcome fix ladder: reviser tier, main-agent tier, and guideline exception block

Partition piece 2 of 2 split from #7196 (operator-directed split; this piece still requires its own /design).

**Scope**: Add the fix ladder for adverse Gate C outcomes (operator policy, 2026-07-12; the /design mirror of the #7193 ladder, applied to the PLAN, not code), per kind, independently. Tier 1, reviser: the existing autonomous plan-revision machinery (the plan-review apply lane) applies a scoped plan fix for the named `violation` or `deviation` and nothing else; exact re-entry wiring is resolved during /design of this piece; the revise lane stays autonomous per the standing operator decision (#6496, #6498). Re-judge: after any fix, a FRESH `larch:arch-assessor` spawn re-assesses the revised plan; the persist verbs revalidate fail-closed; the judge never evaluates its own fix. Tier 2, main agent: for invariants (`violation`) the main agent MUST attempt the plan fix, and if the re-judge still reports `violation`, Gate C must not approve and the run ends through the existing cancellation outcome with nothing published, no waiver. For guidelines (`deviation`) the main agent chooses: fix the plan, or decline and record a documented exception in the persisted Gate C assessment note (mandatory machine-checkable block: an `Exception:` line with rationale, author `main-agent`, and date), surfaced in the Gate C approval presentation and, under `--skip-approve`, in the final summary. Publish-gate rules mirror #7193: `violation` is never publishable; `deviation` publishes ONLY when the note carries the exception block; a bare `deviation` after ladder exhaustion fails closed. Bounds: one tier-1 round and at most one tier-2 round per kind.

**Firm headings**: skills/design/SKILL.md

**Acceptance**:

Fix ladder, reviser tier: a forced invariant violation in the plan is fixed by the plan-revision tier, a fresh assessor re-judges clean, and Gate C proceeds. Fix ladder, hard fail: with reviser and main-agent plan fixes both failing an invariant violation, Gate C does not approve and the run ends via the existing cancellation outcome with nothing published. Fix ladder, guideline exception: with the reviser fix failing and the main agent declining, the persisted Gate C note carries state `deviation` plus the exception block, the exception appears in the Gate C presentation (and in the final summary under `--skip-approve`), and the publish gate accepts it; the same note without the block fails the gate. /design structure tests pass; `make lint` and `make py-test` green for changed files.
