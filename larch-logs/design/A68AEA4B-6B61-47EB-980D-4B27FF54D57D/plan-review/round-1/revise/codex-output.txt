## Plan

## Approach

Implement independent, persisted two-tier Gate C ladders for invariants and guidelines. A scoped `MODE=plan-revise` subagent gets one tier-1 attempt per kind; the main agent gets one tier-2 attempt per kind. Every successful revision must settle through an explicit Gate C postplan site before a fresh assessor re-judges the current `plan.txt`.

Invariant violations never publish. A guideline deviation publishes only with one validated active exception line. Publish and final-summary rendering must use the same fence-aware validation boundary.

## Edge cases

- Process simultaneous invariant and guideline adverse outcomes independently in canonical order.
- A tier-1 no-progress or bail consumes that kind’s tier-1 attempt.
- Failed settle or postplan validation stops before fresh assessment.
- Pause, resume, and repeated Gate C entry cannot reuse an old verdict or reset counters.
- Exception-looking text inside backtick or tilde fences has no authority.
- A valid guideline exception cannot waive an invariant violation.
