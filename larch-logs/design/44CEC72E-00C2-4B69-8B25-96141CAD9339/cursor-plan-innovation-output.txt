## Findings

**1. Step 3b-tail: pick one owner (important, correctness)**  
The plan contradicts itself on `design-step3b-tail.sh`. It says shrink to `plan-review step3b-tail`, but also allows keeping FINALIZE, rejected-findings emission, `SKIP_APPROVE_REQUESTED_GATEC=`, and `.completed/step-4` in the wrapper. The live script does all of that today (lines 93–130). A preview-only thin wrapper would skip Gate C prerequisites.

**2. `RUN_STEP3_PLAN_REVIEW_LOOP_SH` seam (important, risk-integration)**  
Tests depend on substituting the loop body via this env var. The plan requires override tests but does not state the runtime rule in Approach: exec the stub when set, native loop when unset. That seam must survive `_LEGACY_ASSETS` removal.

**3. Orchestrator fence harness (important, architecture / scope)**  
"Retarget OR migrate" for `test-step3-orchestrator-fence.sh` duplicates coverage. Per the sh-to-py recipe, migrate to pytest and delete the shell harness.

**[OUT_OF_SCOPE] 4.** `docs/vendor-agent-diagnostics-audit.md` is optional doc hygiene, not required for the port.
