## Approach

Create one stdlib-only module `python/voting.py` that absorbs the 12 bash scripts. Each absorbed surface becomes an importable function plus a `*_main(argv)` verb registered in `python/cli.py`. Consumers call `python3 "$PLUGIN_ROOT/python/cli.py" voting <verb>` directly — no shims, hard cutover per `docs/python-migration.md`. Behavior spec stays `docs/voting-process.md` + `docs/point-competition.md` (both path-free; no edits). Thresholds, ballot grammar, and scoring semantics do not change.

Sequence (playbook order):

1. Port functions into `python/voting.py`; register verbs in `python/cli.py`.
2. Write `python/test_voting.py` porting all 6 bash harness assertion sets; `make py-lint py-test` green.
3. Cut over all consumers (12 scripts, 8 surviving harnesses, Makefile, agent-lint.toml, SECURITY.md, docs).
4. Parity gate: run the retargeted consumer harnesses once (`test-tally-code-votes`, `test-tally-plan-review`, `test-dispatch-code-voters-*`, `test-dispatch-plan-voters`, `test-findings-classification`, `test-review-findings-classification`, `test-plan-review-scope-anchor`, `test-implement-bootstrap`, `test-review-and-fix`, `test-review-structure`, `test-implement-structure`).
5. Delete the 36 retired files; append rows to `python/migrated-scripts.tsv`; `make lint` green (includes `lint-retired-scripts`, `lint-bash32`).

### Module design rules

- **Stream routing** (mirrors `session_env.py` per-verb routing): `parse-judge-vote`, `write-tally`, and `compose-tally-record` call `logging_util.quiet_init()` and emit through `emit_kv`/`contract_stream` (they self-initialized lib-quiet as subprocesses today). All other verbs print plainly to stdout; every live caller captures via command substitution, so bytes land in the same place.
- **Subprocess seams** via `proc.run`: the retry launchers (`scripts/launch-claude-review.sh`, `scripts/launch-review.sh`), `scripts/append-tool-failure.sh`, and the tally log writer (`scripts/larch-log.sh`). Resolve them from `--plugin-root` when given, else from `voting.py`'s repo root (`Path(__file__).parent.parent`). Keep the `LARCH_WRITE_TALLY_LOGGER` env override (pytest seam); drop `LARCH_WRITE_TALLY_COMPOSER` (composition is in-process; its only consumer was the deleted harness).
- **`LARCH_VPR_CTX` array → repeated `--ctx ARG` flags** appended verbatim to the launcher argv. The optional env fallbacks `LARCH_EXECUTION_ISSUES_LOG`, `SESSION_ENV_PATH`, `IMPLEMENT_TMPDIR` keep being read from the environment.
- **Do not port `is_scope_reduction_block`**: it only delegates to `scripts/check-scope-reduction-marker.sh` (stays bash). Repoint its one caller.
- **Parity details to preserve**: ≥0.8 `JUDGE_ERROR` ratio threshold; diag sidecar field order and first-200-bytes capture; `-parse-rate-diag.txt` / `-parse-retry` / `-first-pass` naming; `.done` sentinel handling; retry preamble texts (code and plan variants) as module constants; `hashlib.sha256` replaces `shasum`; code-review header allowlist validation in `write-tally` (fence skipping + allowed set + `### FINDING_N:` / `### [rejected] FINDING_N` / `# Review Round N` patterns); body-file symlink rejection; `emit_kv` newline rejection.

## Edge cases

- **Subprocess cost in tally loops**: per-finding CLI calls add ~30-50 ms each; a large tally adds a few seconds inside multi-minute review flows. Accepted; later parts absorb the loop owners (`tally-code-votes.sh`, `tally-plan-review.sh`).
- **No-trailing-newline verbs**: `reviewer-for-block`, `classify-result`, `panel-tier` used bash `printf '%s'`; write without a newline for byte parity in pipes.
- **ERE → `re` translation**: translate `[[:space:]]`-class patterns and case-insensitive matching carefully (`vote-for-id` anchored prefix, false-positive keywords, focus-area checks). Pin with pytest cases lifted from the bash harnesses.
- **Last-match-wins semantics**: `vote-for-id`, `parse-judge-vote` (field reset per matching line), and `tally-vote` per-voter scanning all let later lines override earlier ones — preserve.
- **Empty/missing inputs**: empty voter file or zero ballot IDs → `PARSE_RATE_STATUS=OK`; missing voter file in `tally-vote` skipped; missing tally file in `scoreboard` → all-zero scores; `eligible <= 0` → reject/`main-agent-required`.
- **`scoreboard` quoting**: bash `printf '%q'` becomes `shlex.quote`; styles differ on exotic paths but nothing parses the line today — document in the verb docstring.
- **fd-3 inheritance**: quiet verbs route KV to the contract stream after self-initialized quiet, else stdout — exactly the current child-process behavior; callers that capture with `$()` see identical bytes.
- **`split-ballot` partial writes**: bash could leave partial block files on duplicate-heading abort; the port detects duplicates before writing (fail-closed; callers already treat exit 1 as fatal).
- **`--neutral N`**: keep accepting and ignoring the deprecated argv in `write-tally` and `compose-tally-record`.

## Failure modes

- **Missed consumer reference** → `make lint-retired-scripts` fails CI; the manifest rows make this loud.
- **Parse-rate retry regression** → covered by `test-dispatch-code-voters-retry-claude` / `-retry-cursor` / `-regressions-r1-r2` against stubbed launchers in the sandbox.
- **Plan-review KV order drift** → `test-dispatch-plan-voters.sh` pins the interleaved status-block order; the order is a binding stdout-parser contract.
- **`/implement` Step-0 tally break** → `test-implement-bootstrap.sh` B5-plan-green ordering assertions cover the `write-tally` cutover; `test-review-and-fix.sh` covers the flush-failure path via the preserved override env.
- **Sandbox harnesses missing `python/`** → dispatch harness runs fail fast; fixed by the fixture-copy update above.
