# bash-to-py-mop-up: Move scripts/*.py utilities under python/ behind cli.py

**What:** Relocate six already-Python utilities out of `scripts/` into `python/` behind `cli.py`, per the flat-layout decision ("all Python modules live directly under python/"; "cli.py is the canonical entrypoint for all external consumers").

**Why:** Convention drift, not a Bash migration. These bypass `cli.py` and live outside `python/`. Grouped here because they surfaced in the same Bash-to-Python audit. Lower priority than the Bash items; included for completeness.

**Files:** `scripts/check-topology-rule-paths.py`, `scripts/cleanup-implement-logs.py`, `scripts/lint-literal-counts.py`, `scripts/lint-no-raw-stderr-after-quiet-init.py`, `scripts/render-session-transcript.py`, `scripts/retro-v3-sweep.py`.

**Scope:**
- Move each into `python/` as a module plus a `cli.py` verb (or document a deliberate exception if a linter must remain a standalone path for bootstrapping).
- Repoint Makefile / pre-commit / CI callers.
- Keep behavior identical.

**Acceptance:** All callers updated; `make lint` / `make py-lint` / `make py-test` green; no stale references.

**Note:** Confirm whether any must stay standalone for bootstrapping reasons before moving.
