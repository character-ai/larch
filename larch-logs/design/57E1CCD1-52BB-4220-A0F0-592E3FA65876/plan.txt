## Approach

Use delegation, not duplication.

- Move prelude logic into `design-step2b-drafter.sh`.
- Preserve exact sentinel validation semantics.
- Copy the sentinel helper into the drafter wrapper, or extract it into a non-executing include.
- Do not source `design-step2b-prelude.sh`.
- Preserve the prelude order: validate, repair, pause, time, draft.
- Remove the existing early pause-save boundary that would run before validation.
- On drafter success, make preview output machine-row safe.
- Emit wrapper-owned rows only after a post-preview delimiter.
- Hand off to `design-step2b-postplan.sh`.
- Pin the delegated postplan transport argv for session env, Claude PID, and plugin root.
- Keep `design-step2b-postplan.sh` as the authority for postplan rc handling.
- Add missing rc 11 machine rows inside `design-step2b-postplan.sh` before pause-save delegation.
- Route from wrapper-owned `POSTPLAN_*` rows, not the Bash exit code alone.
- Slice `_postplan_out` to the delegated postplan segment so operator prompts do not include plan-preview text.
- Fail closed when drafter success lacks wrapper-owned postplan rows.
- Keep `design-postplan-emit.sh` unchanged as the lower-level merged driver.
- Keep `design-step2b-prelude.sh` for compatibility.
- Keep the inline fallback and retry safety fence.
- Avoid refactoring Gate B or discussion-round2.

This keeps the normal prompt-side success path to one Bash call while preserving a one-time fail-safe postplan fence for incomplete internal output.

## Edge cases

- **Invalid Step 2a artifacts:** drafter wrapper fails before pause-save and before external drafter launch.
- **Prelude script sourced accidentally:** structure and harness tests catch it because top-level prelude execution can exit during sourcing.
- **Loose sentinel content:** multi-line, whitespace-padded, or extra-blank-line sentinels are rejected.
- **Pause requested before drafting:** drafter wrapper runs pause-save after validation and repair, before timing and external work.
- **Pause requested during drafting:** delegated postplan wrapper catches it at the pre-postplan boundary and emits rc 11 rows before pause-save.
- **Postplan driver returns rc 11:** delegated postplan wrapper emits rc 11 rows before pause-save.
- **Missing launcher transport exports:** delegated postplan still receives `--session-env-path`, `--claude-pid`, and `--plugin-root` from the drafter wrapper exec.
- **Drafter dirty-tree mutation:** postplan is skipped until operator recovery completes.
- **Drafter output structurally valid but validator rejects it:** delegated postplan creates inline retry sentinels once.
- **Second validator failure after inline retry:** normal validator-failure routing applies.
- **Plan preview contains `POSTPLAN_*` or `DRAFTER_STATUS=*` text:** routing ignores it because preview output is machine-row safe and parser reads only after the wrapper delimiter.
- **Operator prompt needs postplan output:** `_postplan_out` excludes preview text and contains only the delegated postplan segment.
- **Postplan output is incomplete after drafter success:** routing does not continue to Step 3; it aborts or runs one retained postplan fail-safe.
- **Postplan rc row is non-zero but Bash exit is zero:** routing uses `POSTPLAN_RC=`, not the Bash exit code alone.
- **Plan-size hard trigger:** rc 12 routing stays unchanged.
- **Partition requested:** rc 13 routing stays unchanged.
- **Postplan configuration or infrastructure failure:** delegated wrapper preserves fail-closed abort behavior.
- **Drift advisory:** postplan exits cleanly and records warning as before.

## Failure modes

1. **Pause-save runs too early**
   - **Signal:** invalid Step 2a artifacts trigger pause-save before validation failure.
   - **Mitigation:** drafter harness asserts sentinel failure happens before pause-save.

2. **Loose sentinel validation**
   - **Signal:** multi-line or whitespace-padded sentinel files reach the external drafter.
   - **Mitigation:** copy `step2b_exact_line_file` or extract it into a non-executing helper; harness covers malformed sentinels.

3. **Unsafe prelude sourcing**
   - **Signal:** sourcing `design-step2b-prelude.sh` exits during drafter startup or double-validates in the wrong order.
   - **Mitigation:** forbid sourcing the prelude; structure and harness tests assert the drafter wrapper does not source it.

4. **Missing rc 11 postplan rows**
   - **Signal:** pause-save runs after postplan without `POSTPLAN_RC=11` and `POSTPLAN_STATUS=pause-save`.
   - **Mitigation:** update `design-step2b-postplan.sh`; harness exercises the real wrapper rc 11 path.

5. **Lost launcher context during delegated postplan**
   - **Signal:** pause-save or emit runs with empty issue, repo, session, PID, or plugin-root context.
   - **Mitigation:** pass `--session-env-path`, `--claude-pid`, and `--plugin-root` explicitly on the delegated exec line; harness verifies argv.

6. **Double postplan on normal drafter success**
   - **Signal:** success output includes duplicate postplan sections.
   - **Mitigation:** structure test asserts the retained terminal fence is skipped for complete internal-postplan outcomes without inline retry.

7. **Lost inline retry sentinel**
   - **Signal:** drafter validator defects route straight to operator prompt.
   - **Mitigation:** drafter harness asserts `.step2b-postplan-inline-retry-pending` and `.step2b-postplan-inline-retry-done`.

8. **Misrouting from Bash exit code**
   - **Signal:** rc 10, rc 12, or rc 13 rows are emitted but routing treats postplan as ok.
   - **Mitigation:** SKILL prose and structure pins require routing from `POSTPLAN_RC=` rows.

9. **Misrouting from polluted preview stdout**
   - **Signal:** a plan-preview line containing `POSTPLAN_RC=0` changes routing.
   - **Mitigation:** preview lines are machine-row safe; routing parses only after `STEP2B_DRAFTER_WRAPPER_ROWS_BEGIN=1`.

10. **Operator prompt polluted by preview text**
   - **Signal:** rc 12 or rc 13 prompt includes generated plan-preview text instead of only postplan output.
   - **Mitigation:** bind `_postplan_out` from the delegated postplan segment after `DRAFTER_STATUS=succeeded`.

11. **Misrouting from incomplete postplan output**
   - **Signal:** `DRAFTER_STATUS=succeeded` appears but no wrapper-owned `POSTPLAN_RC=` appears.
   - **Mitigation:** SKILL has a fail-closed branch that aborts or runs the retained postplan fence once.

12. **Existing token sidecar tests fail before launch**
   - **Signal:** harness exits at folded-prelude sentinel validation.
   - **Mitigation:** shared harness setup creates Step 2a artifacts and postplan stubs for existing token sidecar cases.

13. **Outer timeout kills postplan output**
   - **Signal:** drafter succeeds near timeout but no `POSTPLAN_RC=` appears.
   - **Mitigation:** SKILL timeout increases to 2100000 ms and missing rows do not route to Step 3.
