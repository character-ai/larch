1. **[risk-integration]** `skills/implement/scripts/write-final-report.sh:184-190`

   **Concern:** The plan wires `clear-stall` before `normalize-outcome` in `write-final-report.sh`.

   **Breakage:** This runs outside the explicit recovery-success path. If a run has escalation evidence and then stalls again, the new call can clear real `STALL_TRACKING` before Step 18a classifies the terminal stall.

   **Suggested revision:** Remove the `write-final-report.sh` change. Extend `clear-stall`, but invoke it only from the success-after-recovery path that already owns stall clearing.
