## Approach

`approach-synthesis.txt` is `NO_SKETCHES`, so draft from direct repo inspection only.

Implement the minimum shared fixes for **#4886** (no-issues preamble salvage) and **#4888** (launch-failure site labels). Scope is intentionally narrow: primary salvage lives in `research_eval.py` and the Cursor launch normalizer; site threading threads caller labels through `agent launch-review` and its dispatch wrappers. Broader `review_pipeline.py` sentinel parsing changes and `_append_implement_launch_failure` relabeling are **out of scope** for this PR.

1. **No-issues salvage (three-tier, record-first)**
   - Parse structured JSONL/TSV records first.
   - If records exist, return them unchanged.
   - If no records exist, run salvage in this order:
     1. **Joined-body salvage:** when `_json_no_issues("\n".join(lines))` is true (covers multi-line pretty-printed `{"no_issues_found": true}` that already starts with `{`, including Cursor `.result` text that `_review_cursor_normalize_no_issues` leaves unchanged because the first non-blank line starts with `{`).
     2. **Per-line singleton salvage:** when exactly one standalone no-issues sentinel line exists among all non-blank lines (narration/prose on other lines is allowed).
   - Accept a standalone line that is either `NO_ISSUES_FOUND` or a JSON object whose `no_issues_found` value is `true`.
   - Emit a non-failure warning only when the per-line singleton path fires and the sole sentinel index is greater than 0 (joined-body salvage does not emit the preamble warning).
   - Emit the warning via `_emit("WARNING=NO_ISSUES_SENTINEL_RECOVERED_AFTER_PREAMBLE")` on the validator contract stream (stdout via `logging_util.emit`, same channel as `structured records not found after repair`). Do **not** use stderr-only paths.
   - Keep findings output strict.

2. **Cursor parity (findings-safe)**
   - Keep the existing `schema_version` whole-text guard and first-line inline normalization behavior for existing tests.
   - Before any new standalone-sentinel collapse, add a **JSONL findings guard:** do not normalize when any non-blank line parses as a valid structured JSON finding record (same `schema_version` / required-field rules as `_normalize_json_record` in `research_eval.py`) or when any non-blank line is a JSON object containing a `schema_version` key (even if normalization would otherwise fail).
   - Only after the guard passes, add standalone-line detection so prose followed by a lone `{"no_issues_found": true}` collapses to the canonical one-line sentinel.
   - Do not normalize when multiple standalone sentinel lines exist.

3. **Launch-failure site labels**
   - Add `--site` to `agent launch-review`, defaulting to `review Step 2`.
   - Validate and thread it into `_review_append_launch_failure`.
   - Thread it through `agent dispatch-waterfall` and `agent dispatch-voters`.
   - Pass `design Step 3` from plan-review panel and voter dispatch.
   - Pass or derive `implement Step 5` for review-and-fix Step 5 review core and voter dispatch.
   - Persist the validated site in launch-review `.meta` (`OUTER_LAUNCHER_SITE`) on **all** `_review_append_outer_meta` call sites, including preflight failures, and replay it on collect-results outer retries.
   - Leave `_append_implement_launch_failure` unchanged (`--site "2"` stays as today).

4. **Deferred (not in this PR)**
   - `review_pipeline.py` sentinel refactor (`_parse_output` early-return removal, shared standalone-sentinel helpers, `external_files` zero-row guard). The `research_eval.py` fix covers the cited `/design` Step 3 `NOT_SUBSTANTIVE` path via `collect_results._validate_structured`. Track broader review-collection sentinel parsing separately if a live `/review` or `/implement` collision is filed.

## Edge cases

- **Valid findings plus sentinel:** keep findings. Structured salvage never fires when records exist. Cursor normalizer must not collapse when any line is a valid structured finding or carries `schema_version`.
- **Multiple sentinels:** do not salvage (validator or Cursor normalizer).
- **Inline JSON in narration:** only Cursor's existing first-line compatibility path may normalize it. The shared validator requires a standalone line for tier 2.
- **Multi-line pretty-printed sentinel:** joined-body tier 1 via `_json_no_issues("\n".join(lines))` accepts without preamble warning.
- **`schema_version` output:** Cursor normalizer must not collapse findings-shaped output; guard any line with `schema_version`, not only whole-text regex.
- **Site labels with spaces:** allow spaces. Reject control characters.
- **Default callers:** callers that do not pass `--site` keep `review Step 2`.
- **Retry without meta site:** collect-results retry omits `--site` and launch-review falls back to its default.
- **Preflight vs success meta:** auth/model-args preflight bundles that write `.meta` must carry the same `OUTER_LAUNCHER_SITE` as successful launches so outer retries do not lose caller site context.
- **Plan-voter dispatch path:** `dispatch_voters` calls `dispatch-waterfall` inline; `--site` on `dispatch-voters` alone does not fix Step 3 voter launch failures.
- **Warning channel:** `_emit` writes to the validator contract stream (stdout). Tests and `collect_results` diagnostics must scan stdout or combined stdout+stderr, not stderr alone.
- **`Options.site` wiring:** `agent dispatch-voters` must store `site` on the frozen `Options` dataclass, not only parse argv.

## Failure modes

- If joined-body salvage is removed or ordered after per-line-only logic, multi-line pretty-printed no-issues output regresses to exit 5.
- If Cursor normalizer collapses before the JSONL findings guard, valid findings plus a trailing sentinel are silently dropped.
- If the warning is emitted via `_emit` but tests assert stderr only, validator or collector tests will fail spuriously.
- If `--site` is missing from a `_parse_args` allowlist or `Options` field, downstream argv fails with `unknown option: --site` or site threading silently stops.
- If `OUTER_LAUNCHER_SITE` is written only on success/failure epilogues but not preflight meta, outer retries after early auth/model-args failures revert to `review Step 2`.
- If collector tests assert an empty `STRUCTURED_SIDECAR` string instead of the sidecar path, they will fail against the existing OK wire record.
- If `review_pipeline` sentinel refactor is bundled in despite scope reduction, unrelated `/review` markdown parsing can regress without fixing the cited `/design` bug.
