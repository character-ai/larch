1. **[correctness] `skills/design/scripts/tally-plan-review.sh:79-113,310-314`**
   Concern: the always-emit plan is not sufficient as written. The current trap is installed only after `WORKDIR` creation, but several non-zero exits the plan explicitly wants covered happen before that. Also, checking `$?` “at the end of cleanup” is unsafe unless the original rc is saved before `rm -rf`.
   Suggested revision: install the trap early, initialize `WORKDIR=""`, capture `local rc=$?` first in `cleanup`, guard the removal, and base fallback emission on that captured rc.

2. **[risk-integration] `scripts/dispatch-plan-voters.sh:211-236`**
   Concern: the proposed `voter_coverage_emit_voter_kvs` shape is per-slot, while the current contract is not purely per-slot: `VOTER_PATHS_FILE` is emitted between voter path/tool/status groups.
   Suggested revision: either leave the emit block inline, or make the helper responsible for the whole existing output sequence so it preserves `VOTER_PATHS_FILE` and byte-order.
