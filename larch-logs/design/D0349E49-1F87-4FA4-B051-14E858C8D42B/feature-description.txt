# bash-to-py-mop-up: Eliminate sourced Bash libraries (plan-optional-trailers, clone-tag)

**What:** Port `skills/design/scripts/lib-plan-optional-trailers.sh` (~130 lines) and its companion `lib-plan-optional-trailers.awk` into Python; fold the 11-line `skills/implement/scripts/lib-implement-clone-tag.sh` into its consumers or a `cli.py` verb.

**Why:** AGENTS.md states "Do not add terminal shared Bash libraries." These are sourced Bash libraries (no shebang) — a direct policy violation. `lib-plan-optional-trailers.sh` is sourced by 4 design scripts and drives an awk engine for optional-trailer snapshot/validate/dedup used in plan-size gating. A Python home already exists: the `plan` domain (`python/plan_quality.py`) owns plan-size gating.

**Evidence:** `lib-plan-optional-trailers.sh` is sourced by 4 design step scripts; `lib-implement-clone-tag.sh` is sourced by 2 implement consumers.

**Scope:**
- Port snapshot / validate / dedup-preserve logic plus the awk parsing into `python/plan_quality.py` (or a sibling) behind `cli.py plan ...` verbs.
- Repoint the 4 design sourcing sites to direct `cli.py` calls (no shim).
- Replace clone-tag derivation similarly.
- Migrate the trailer harnesses (`test-trailer-*.sh`).
- Delete the libs + awk; record in the manifest.

**Acceptance:** Optional-trailer preservation behavior unchanged; plan-size gating parity; trailer harness assertions ported; `make lint-retired-scripts` clean.
