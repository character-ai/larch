## Edge cases

- `CLONE_TAG` must be passed through unchanged, even if it contains spaces or shell metacharacters.
- CLI KV output must remain safe for `eval`; wrappers must fail closed when the Python verb exits non-zero.
- Empty cwd basenames must produce `CLONE_TAG_FULL=_`; all-invalid basenames like `!!!` must produce `___` (one `_` per invalid byte), not a single collapsed `_`.
- Fallback basename must use logical `PWD`, not physical `Path.cwd().name`, so symlinked clone paths match the retired helper.
- 32-character limit is a **32-byte** truncation on the sanitized byte string.
- Optional trailers must still treat only the final contiguous block above `diff_lines:` as metadata.
- Optional `diff_added: 08` and `diff_deleted: 09` remain rejected.
- Duplicate optional trailers keep last match in file order.
- After manifest append, `agent-lint.toml` must not contain full-path literals for deleted clone-tag files.
- Authoritative contract docs (`step-8-ship.md`, `step-8-seed-initial.md`) must not retain retired-path substrings after helper deletion, or `make lint-retired-scripts` fails even when wrappers are updated.
- `python/test_residual_bash.py` must not retain unsplit literals for any manifest-listed retired path, including both `lib-plan-optional-trailers.sh` and `lib-implement-clone-tag.sh`.
- `test-trailer-helpers.sh` must be deleted with its children; leaving it in `residual-bash-paths.txt` or on disk produces unrunnable dead weight and lint failures.

## Failure modes

- Unsafe KV quoting can break Step 8 wrappers or allow shell interpretation of a hostile `CLONE_TAG`.
- Bare `eval "$(python3 ...)"` can mask CLI failures and leave `EXPECTED_TMPDIR_BASENAME_PREFIX` unset until a later opaque error.
- `Path.cwd().name` instead of `PWD` basename can desync seed/ship prefix from historical runs on symlinked clones.
- Byte-level regex sanitization can collapse multi-byte invalid sequences differently than `tr -c`.
- Stale `agent-lint.toml` G004 exclusions can fail `make lint-retired-scripts` after manifest append even when all skill/harness updates land.
- Stale `step-8-ship.md` prose citing `lib-implement-clone-tag.sh` can fail `make lint-retired-scripts` after manifest append even when shell wrappers are updated.
- Incomplete `migrated-scripts.tsv` append (partial bullet list) can leave deleted paths unmanifested while grep still scans tracked references.
- Unsplit retired-path literals in `python/test_residual_bash.py` (for example `lib-implement-clone-tag.sh` or `lib-plan-optional-trailers.sh`) can fail `make lint-retired-scripts` after manifest append.
- Leaving `test-trailer-helpers.sh` on disk after deleting its libs and children leaves an unrunnable harness and retired-path lint failures.
- Missing docs cleanup can make `make lint-retired-scripts` fail after manifest updates.
- Partial residual inventory cleanup can make `make lint` fail on missing files.
- Accidental optional-trailer behavior changes can alter plan-size gating.
- Updating only one Step 8 wrapper can make seed and ship disagree on expected tmpdir prefix.
