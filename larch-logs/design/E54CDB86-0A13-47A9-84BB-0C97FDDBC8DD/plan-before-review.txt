## Edge cases

- Cursor unavailable: no Cursor reviewer rows should emit, except none can emit if the tool is absent. Codex rows should still work.
- Codex unavailable: Cursor reviewer rows should emit with `cursor_model=auto`.
- TRIVIAL with both vendors: removing the additive lane should reduce the code-review static panel from four rows to three rows.
- HARD Codex model-role overrides should remain Codex-only.
- Dynamic Cursor rows must not fall back to Composer 2.5 due to a missing `cursor_model`.
- `plan-fidelity-forced` must still run only when `PLAN_FIDELITY_FORCED=true`.

## Failure modes

- A Cursor row can launch on `auto` but show `resolved_model=composer-2.5` if manifest attribution is not updated. Tests should check both fields.
- Removing `plan-fidelity-auto` can leave stale references in tally or timing allowlists. Sweep for the literal.
- Reusing the deleted archetype name in forced Codex fallback can break future override lookup or confuse reviewers. Repoint it now.
- Docs can overstate `LARCH_CURSOR_MODEL` after per-slot overrides. Update only the stale claims.
