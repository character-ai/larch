## Approach

Create a thin wrapper that runs Step 2 post-dispatch work in one foreground Bash call: phantom probe tail, branch read, and optional commit SHA. Mirror `step-2-entry.sh` plugin-root rehydration before sourcing shared libs so `larch-run.sh` sessions resolve `CLAUDE_PLUGIN_ROOT` under `set -u`. Keep bail semantics and comparison logic in SKILL.md unchanged. Do not touch the Python dispatcher.

**Orchestrator parse ordering (accepted finding):** On `STATUS=complete`, the orchestrator must **always** token-scan `PHANTOM_*` (and optional `COMMIT_SHA=`) from the combined wrapper stdout **before** evaluating wrapper exit code or binding `BRANCH=` / comparing to `BRANCH_NAME`. This preserves today's two-call behavior where phantom advisory telemetry is consumed even when the subsequent branch read fails (detached HEAD). Only after phantom consumption: gate `BRANCH=` → `CURRENT_BRANCH_POST_DISPATCH` binding and `BRANCH_NAME` byte-compare on wrapper `rc=0`; route `rc!=0` or mismatch to existing `main-branch-post-dispatch` Step 12d bail unchanged.

## Edge cases

- **Detached HEAD**: wrapper runs probe (emits `PHANTOM_*`), then exits 1 on branch read; orchestrator still parses phantom telemetry first, then routes non-zero exit to `main-branch-post-dispatch` (same as today's probe-then-failed-branch-script sequence).
- **Valid branch, SHA unavailable**: wrapper exits 0 with `BRANCH=` and no `COMMIT_SHA=`; orchestrator parses `PHANTOM_*`, binds branch, proceeds; Step 4 skip breadcrumb shows empty `sha=`; no bail.
- **Rev-parse failure under `set -e`**: guarded with `|| true`; must not convert SHA absence into rc=1 or Step 12d routing.
- **`claude_fallback`**: wrapper not called; no `COMMIT_SHA` is set; Step 4 never reaches the external-implementer skip breadcrumb on that path.
- **Missing `CLAUDE_PLUGIN_ROOT` / `IMPLEMENT_TMPDIR`**: bootstrap rehydration from tmpdir artifacts before lib source; unbound-variable fail-fast if still unresolved.
- **Orchestrator gates stdout on `rc=0` before phantom parse**: explicitly forbidden; would drop advisory phantom warnings on detached-HEAD failures.

## Failure modes

- Wrapper exits 1 only on `git symbolic-ref --short HEAD` failure: same `main-branch-post-dispatch` bail as today, but only **after** phantom `PHANTOM_*` consumption from stdout.
- `COMMIT_SHA` empty after rc=0: Step 4 skip breadcrumb degraded display only (not terminal).
- Bootstrap failure before lib source: wrapper exits under `set -u` / missing tmpdir; surfaces as Step 2 tool failure rather than silent wrong-tree sourcing.
- Premature exit-code gating before phantom parse: regression risk — phantom advisory warnings and execution-issues telemetry silently dropped on branch-read failure.
