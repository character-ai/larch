Stdout: `COMMITTED=false`, `COMMIT_OUTCOME=failed`, git error "no changes added to commit". The worktree was dirty only in `python/markdown-heading-fence-state-baseline.json` and `python/suppression-reason-baseline.json`.

**Mechanism**: `_commit_fixes_stage_all` (`python/larch/review/review_and_fix.py:177`) commits only the paths from `_collect_review_fix_stage_paths` (`python/larch/review/coder_runner.py:339`) via `git commit --only --pathspec-from-file`. Every collected path was already committed. The only dirty files were ratchet baselines regenerated after the last fix commit, and they sat outside the collected set. `git commit --only` over clean paths exits 1. The step recorded a hard Tool Failure, and the baseline drift stayed uncommitted into steps 7a and 8. The issue #5715 guard (`review_and_fix.py:195`) covers only the empty-path-list case, not the nonempty-but-all-clean case.

**Proposed fix**: intersect the collected stage paths with `git status --porcelain` dirty paths. Treat an empty intersection as the same benign noop as #5715. Separately, decide ownership of harness-regenerated baseline files: either stage them with the fix commit when checks regenerate them, or revert them, so they cannot strand the tree dirty.

## Proposed Design Outline

### Goals
- Stop `review-and-fix commit-fixes --stage-all` exiting 1 when every collected review-delta path is already committed clean.
- Treat an all-clean collected set as a benign noop, extending the #5715 empty-list guard to the nonempty-but-all-clean case.
- Still commit the dirty subset correctly when the collected set is partially clean.

### Non-goals
- No baseline-ownership logic. Regenerated ratchet baselines (`*-baseline.json`) are not staged or reverted here. That is a separate ownership question.
- No change to `_collect_review_fix_stage_paths` collection semantics.
- No change to `_stage_and_commit_round` in coder_runner.py (sibling commits fresh-edited in-round paths; all-clean is not reachable there).

### Approach sketch
- In `_commit_fixes_stage_all`, after collecting paths, intersect them with the actually-dirty paths from `git status --porcelain`.
- Empty intersection emits the existing noop contract (`COMMITTED=false`, `COMMIT_OUTCOME=noop`) and returns 0.
- Non-empty intersection writes only the dirty subset to the stage file before the existing `git commit --only --pathspec-from-file` call.
- Reuse the `_run` runner and existing KV helpers. No new subprocess pattern.
- G-Fix-1 deviation: list the sibling `_stage_and_commit_round` (coder_runner.py:330) in the PR body as intentionally different.
