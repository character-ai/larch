## Edge cases

- Empty `DIFF_FINGERPRINT` must fail closed before live refresh writes a note, specifically on the `repo_root`+live-materialization branch, not only the simpler staged-fallback branch.
- `OSError` from durable note writing must not surface an unsafe note.
- A moved `origin/main` must be tested through real git state, not only a mock sequence.
- Existing drop-notice behavior must stay intact.
- Mock-call assertions against `materialize_implementation_diff` must use its actual keyword-only signature.

## Failure modes

- A broad monkeypatch can hide the wrong failing write path. Patch `write_implement_note` only for the durable-write failure case.
- The real-git test can be brittle if the remote tracking ref is not set explicitly. Use `git update-ref refs/remotes/origin/main <sha>` in both base states.
- The second moving-base attempt must rewrite staged artifacts before calling ship, so it exercises a fresh pin attempt rather than a previously consumable durable note.
- A mock assertion written against the wrong call shape (positional `origin/main` instead of keyword `base_remote`/`base_ref`) would pass today but silently stop catching a future signature regression.
