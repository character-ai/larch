## Edge cases

- **Resume-hint short-circuit:** `submodule-restricted` must return `RESUME_HINT=none` before step-based routing. A Step 2 submodule stall must not emit `step2-impl`.
- **Lint parity:** `stall-recovery-report.sh lint` compares `doc_retry_policy_lines` to `code_retry_policy_lines`. Both must include `submodule-restricted|1|none`.
- **Bail-token precedence:** `submodule-edit-required-out-of-scope` must classify before stale transient evidence such as `NOTE=network timeout`, for both state-file and argv bail-token paths.
- **No inline submodule recovery:** `submodule-restricted` must not use `RESUME_HINT=step2-impl`. Main Claude can also be blocked by submodule edit hooks.
- **Distinct warnings:** `submodule-restricted` must repeat a submodule-specific warning. It must not reuse the protected-path `.claude-plugin/plugin.json` warning.
- **No escalation record:** `submodule-restricted` has no prompt-side Main Claude handoff, so it must not record `step2-impl` escalation evidence.
- **Existing bail allowlist:** `submodule-edit-required-out-of-scope` is already allowed in `safe_bail_reason_value`; no change is needed there unless the local file lacks that token.
- **Review mode slugs:** `arch`, `edge`, `innovation`, `pragmatic`, and `requirements` remain reserved only in `plan-review` mode. `review` mode must accept them.
- **Step 2 sidecar path:** Step 2 coder-scout normalization must use `--mode review`; otherwise the real `/implement` path strips review-mode slugs before `dispatch-panel.sh` can preserve them.
- **Normalization fallback:** when the Python CLI exits non-zero or produces an unusable manifest, callers fall through to static-only review or canonical empty scout sidecar behavior.
- **prompt_body repair:** Python `filter_manifest()` must preserve the required citation-sentence repair that the removed jq path performed.

## Failure modes

1. **Retry-policy lint drift:** if `stall-recovery-report.md` and `code_retry_policy_lines()` disagree, `bash skills/implement/scripts/stall-recovery-report.sh lint` exits 1.
2. **Stale-evidence regression:** if the early submodule bail arm is placed too late, stale transient evidence can classify as `transient-infra`. The new precedence fixtures should fail.
3. **Misleading resume hint:** if `submodule-restricted` maps to `step2-impl`, recovery can stall after promising inline work that Main Claude cannot perform.
4. **Wrong warning branch:** if escalation recording reuses the protected-path branch, operators can see a `.claude-plugin/plugin.json` warning for a submodule failure.
5. **Python CLI unavailable:** `normalize_scout_manifest` returns 1. Pre-scouted review falls back to static-only.
6. **Step 2 mode regression:** if `normalize_coder_scout_manifest()` omits `--mode review`, `arch` and `requirements` are stripped before Step 5.
7. **PLUGIN_ROOT not set:** `dispatch-panel.sh` already derives `PLUGIN_ROOT` from `CLAUDE_PLUGIN_ROOT`; no new risk.
