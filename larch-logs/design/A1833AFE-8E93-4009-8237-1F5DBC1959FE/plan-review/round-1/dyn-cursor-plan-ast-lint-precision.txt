## Findings

**1. Self-disarmable-gate: `oversize_override` path (major, correctness)**  
`plan_quality._size_trigger_assessment` (452-480) suppresses the hard trigger when `oversize_override == config.OVERSIZE_OVERRIDE_OPERATOR`, but `check_size_main` only passes values from `_trusted_oversize_override` (674, 758), which requires the authority sidecar at 570-586. The plan tests `diff_added` and `mechanical_churn` only and never defines this operator-trust exception, so the lint risks a production false positive on the only gate implementation.

**2. Markdown-heading-fence-state: inline fence gating (major, correctness)**  
The plan’s compliance rule (helper import + fenced-index set) does not cover inline fence loops that already satisfy G-Md-3. `voting._validate_code_review_headers` (1500-1524) and `design_diagram_log.strip_diagram_sections` (46-76) gate heading matches on fence state in the same loop. Flagging them would add noise and suppressions without closing a real hole.

**3. Unreachable-branch baseline keys (major, correctness)**  
The planned baseline uses undefined “structural occurrence” fields. Without a pinned schema and per-function branch occurrence counter (as in `lint_tempfile_dir.py:22-49`), baseline rows will drift on line edits and undermine shrink-only policy.

**4. #6153 fixture vs live `_final_verdict` (minor, correctness)**  
`analyze_bugs._final_verdict` (1227-1238) still has a reachable `if bundle.mechanical_verdict` branch for `NEEDS_DEEP`. The regression test should use synthetic dead code matching the historical shape, not treat line 1236 as unreachable in the current tree.

**5. Heading-regex AST matching (minor, correctness)**  
`compose_plan_goals_test` (1793-1810) is a real splitlines + heading-regex path using `^#{1,3}`. Detection must handle subset quantifiers and require dataflow from `.splitlines()` to the match loop, not just module-level `re.compile` of `^#{1,6}\s`.

**Out of scope (tracked separately)**  
- `learn_from_bugs._split_sections` (252-253): same bug class via `finditer`, outside the plan’s splitlines-only scope.  
- `architectural_guidelines` parsers (317-375): likely baseline grandfather candidates; fixing parsers is optional beyond the lint scaffold.
