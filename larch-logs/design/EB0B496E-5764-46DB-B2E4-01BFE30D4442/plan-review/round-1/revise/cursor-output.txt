- Do not change label generation, label text, `DEFAULT_WIDTH`, or external caller code (`python/progress_report.py` and similar).

- Change `render_gantt` so the default parameter is `width: int | None = None` instead of `width: int = DEFAULT_WIDTH`.

  - When `width` is an explicit `int`: normalize with `width = max(1, int(width))` and **do not** cap.

  - `effective_width = min(width, max(10, 90 - label_width - duration_width - 4))`

- Use the same (possibly capped) `width` for `_axis(...)`, top and bottom borders, `_bar(...)`, and each row track.
- In `gantt_render_main` (same module), pass `width=None` into `render_gantt` when the operator did not supply `--width`, so CLI default rendering gets the cap. When `--width` is present on argv, pass that integer through unchanged and skip the cap.
- Short-label default-path output stays unchanged when the requested width already fits the 90-column budget.

## Edge cases

- Rows filtered outside the window still return `""`; the cap runs only after `filtered` is non-empty.
- Very small user-supplied widths still respect existing positive-width validation.
- Extremely long untruncated labels may still exceed 90 columns on the default path because truncation is out of scope and the plan keeps a minimum 10-cell track.
- Explicit `width=DEFAULT_WIDTH` is not the same as omitting `width`; only the omitted/default path applies the cap.
- CLI renders with omitted `--width` use the capped default path; CLI renders with explicit `--width` preserve the requested track width even when it exceeds 90 columns total.

## Failure modes

- If the cap is applied before `duration_width`, or on the explicit-width path, row lines may still exceed the target or callers may see silent narrowing.
- If `_axis` or borders use a different `width` than row tracks, vertical edges will misalign.
- If `gantt_render_main` always passes `args.width` (always an int), CLI default charts would skip the cap and the reviewer bug could persist on that entrypoint.
- If tests assert exact chart text, they may become brittle. Prefer structural assertions.
