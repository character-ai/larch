### FINDING_2: `gantt_render_main` cannot route omitted `--width` through `width=None`
- **Reviewer(s)**: Cursor-Arch, Codex-Arch, Cursor-Innovation, Codex-Innovation, Cursor-Pragmatic, Codex-Pragmatic
- **Severity**: blocking
- **Concern**: `gantt_render_main` still uses `parser.add_argument("--width", type=int, default=DEFAULT_WIDTH)`, so `args.width` is always an int and the plan's omitted-`--width` → `render_gantt(..., width=None)` path never runs on the CLI. Changing only the call site without updating argparse leaves default charts uncapped. If argparse is switched to `default=None` without updating validation, the existing `if args.width &lt; 1` guard raises `TypeError` on omitted `--width`, breaking CLI paths such as `test_cli_empty_stdout_when_all_rows_filtered_outside_window`. A naive argv-presence check for omission can also misclassify explicit forms like `--width=80` as omitted, silently applying the capped default path to explicit widths.
- **Suggested revisions (informational for voters; coder decides)**:
  - From Cursor-Arch: In ### UPDATED: python/gantt.py, explicitly set parser.add_argument("--width", type=int, default=None), validate args.width &lt; 1 only when args.width is not None, and pass width=None to render_gantt when --width is omitted.
  - From Codex-Arch: Change the parser default to None, treat None as the omitted case, and only run the positive-width validation on explicit widths before calling render_gantt.
  - From Cursor-Innovation: Validate only when args.width is not None (if args.width is not None and args.width &lt; 1: error exit 2); pass width=None through when --width is omitted
  - From Codex-Innovation: Parse `--width` as optional with a `None` sentinel, branch on `args.width is None`, skip the positive-width check for the omitted case, and pass `None` through only when the flag was absent.
  - From Cursor-Pragmatic: Change --width to default=None; validate only when args.width is not None; pass width=None to render_gantt when omitted and the explicit integer when --width is set.
