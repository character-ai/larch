## Edge cases

- **Prelaunch failures**: write a status file when `OUTPUT_CANON` exists. Emit dirty-tree sidecar with `STATUS=unknown MODE=prelaunch`.
- **Baseline unavailable**: fall back to absolute clean/no-baseline behavior exactly as retired launchers did.
- **Pre-existing dirty tree**: only `STATUS=dirty MODE=baseline-delta` blocks fallback as a confirmed new drafter mutation.
- **Scout malformed after plan**: valid plan still succeeds. Status reports `SCOUT_WRITTEN=false` and `SCOUT_FAIL_REASON`.
- **Scout sentinels inside plan or summary**: fatal parse error.
- **Unclosed code fence with standalone scout JSON**: fail closed as the retired parser did.
- **UTF-8 stderr tails and failure diagnostics**: truncate by encoded bytes and avoid splitting invalid UTF-8.
- **Cursor auth on Darwin**: after successful preflight, call `cursor_preread_service_token()` before export so keychain-backed hosts work without `--api-key`.
- **Cursor API key secrecy**: do not add `--api-key` to any Cursor argv.
- **Quota before transient**: keep quota classification precedence over transient empty-output heuristics.
- **Codex events quota**: keep events-to-sidecar quota mirroring before classification.
- **Timing/token sidecars**: failure must not falsely claim token record availability.
- **CI retry diagnostics**: `_ci_failure_source` must not regress to base `.diag` / `.stderr` when a retry-carrier `.failure-diag` exists.
- **Retired-path literals in tracked config**: `agent-lint.toml`, `python/checks.py` `_DIRECT_TARGET_RULES`, and surviving scripts must not cite deleted paths after manifest append.
- **Dead library helpers**: remove only after grep proves no live consumer. Do not invent new behavior for deleted test-only functions.
- **Harness aggregate drift**: every `test-harnesses-N` prerequisite and `.PHONY` name must resolve after individual harness deletion.

## Failure modes

- **CLI argv drift**: external vendor CLIs can receive different flags. Mitigate with explicit argv tests and the `.claude/rules/verify-external-tool-invocations.md` manual checks.
- **Codex drafter missing internal flags**: omitting `--output` or `--timeout` on internal `launch-codex-exec` breaks argparse before Codex runs. Mitigate with full ordered internal-args test.
- **Status KV drift**: Step 2b fallback may misclassify drafter success/failure. Mitigate with status-file tests for both vendors.
- **Dirty-tree false positive**: Step 2b may block inline fallback on pre-existing dirt. Mitigate with baseline-delta tests.
- **Diagnostic data leak or size regression**: stderr-tail or failure-diag may exceed caps, use character slicing, or skip redaction. Mitigate with 16384-byte, multibyte, and redaction-order tests.
- **CI diagnostic source regression**: unified resolver omission can drop retry-carrier excerpts from execution-issues and vendor-failure-diagnostics. Mitigate with `_ci_failure_source` delegation test and retry-carrier precedence fixture.
- **Relevant-checks routing gap**: stale `_DIRECT_TARGET_RULES` rows can skip drafter/parser pytest on `python/agents.py` edits or reference deleted paths post-manifest. Mitigate with tuple cleanup and `python/checks.py` in the retired-path sweep.
- **Retired-script lint failure**: stale references may remain in `agent-lint.toml`, docs, flush scripts, or checks tables. Mitigate with repo-wide reference sweep and `make lint-retired-scripts`.
- **`make test-harnesses` breakage**: orphan aggregate prerequisites after harness deletion. Mitigate by editing all five affected `test-harnesses-N` shards and `.PHONY` before deleting recipes.
- **Scope collision in `python/design_lifecycle.py`**: in-flight G11/G3 may touch the same file. Keep the edit to the drafter command construction only.
