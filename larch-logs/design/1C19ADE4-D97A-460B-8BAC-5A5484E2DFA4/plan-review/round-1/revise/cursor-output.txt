New helper. Interface: `step-telemetry-mark.sh --implement-tmpdir DIR --label "Step N — name"`.
- `set -uo pipefail` (intentionally **omit** `-e`; documented in a comment — pure telemetry, never fatal).

  (export `IMPLEMENT_TMPDIR` too so the ledger scripts' fallback chain matches the old inline fence).
- Run `"$SCRIPT_DIR/token-ledger.sh" mark "$LABEL" || true` then `"$SCRIPT_DIR/timing-ledger.sh" mark "$LABEL" || true`.
- End with explicit `exit 0` so the helper is never fatal even if a sibling script is missing.

## Edge cases
- **Omitted `--implement-tmpdir`** → `IMPLEMENT_TMPDIR` stays `""` → `"${IMPLEMENT_TMPDIR:-}/session-env.sh"`
  is unreadable → reads return `""` → marks still run → `exit 0` (harness-covered).
- Missing/empty `--implement-tmpdir` value → same as above → `exit 0`.
- Missing label → `exit 0`, no fatal.
- Missing/non-executable helper at a call site → 126/127, absorbed by `|| true`; the step continues
  (harness `[[ -x ]]` catches 0644-at-commit; unit test uses direct path).
- `LARCH_TIMING_LEDGER` empty → `timing-ledger.sh` uses its `IMPLEMENT_TMPDIR` fallback (exported by the
  helper), identical to the old inline fence.

## Failure modes
- **Silent telemetry loss**: a converted site stops emitting marks, or helper lands non-executable → 126
  swallowed at call site. Earliest signal: missing Step-N rows in ledgers; harness `[[ -x ]]` + happy-path
  direct invocation; `step_telemetry_mark_count` arithmetic fails if a helper call is dropped.
- **`make lint` false dead-script on harness**: missing `agent-lint.toml` exclusions for
  `test-step-telemetry-mark.*`. Mitigation: Makefile-only exclude pair adjacent to
  `test-implement-timing-rehydration`.
- **Test-count drift**: equality assertions silently mis-tuned. Mitigation: derive
  `step_telemetry_mark_count` from the file, never hardcode; keep `plugin_root_source_count` pinned.
- **`set -u` abort on omitted flag**: avoided by pre-loop initialization (harness omitted-tmpdir case).
- **Behavior change on Step 2 / Step 18-done**: avoided by explicitly excluding both from conversion.
