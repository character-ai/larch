**1. [risk-integration] `agent-lint.toml` — Makefile-only harness not wired for agent-lint**

The plan registers `test-step-telemetry-mark` in the `Makefile` but does not mention `agent-lint.toml`. Peer harnesses such as `scripts/test-implement-timing-rehydration.sh` are explicitly excluded from G004 dead-script detection because only the Makefile invokes them (see `agent-lint.toml` around the existing timing-rehydration comment block). Without the same exclusion, `bash scripts/relevant-checks.sh` can fail after the new harness lands.

**Suggested revision:** Add `scripts/test-step-telemetry-mark.sh` and `scripts/test-step-telemetry-mark.md` to the dead-script exclude list with a short Makefile-only comment, matching `test-implement-timing-rehydration`.

---

**2. [correctness] Proposed `scripts/step-telemetry-mark.sh` — `set -u` vs never-fatal edge case**

The plan requires `set -uo pipefail` (no `-e`), always `exit 0`, and a harness case for missing/empty `--implement-tmpdir`. If the implementer parses `--implement-tmpdir` into `IMPLEMENT_TMPDIR` only when the flag is present, then omits the flag with no inherited env, `"$IMPLEMENT_TMPDIR/session-env.sh"` trips unbound-variable under `-u` before the script reaches the planned `exit 0`. That conflicts with the stated edge case and unit test.

**Suggested revision:** Document and implement an upfront `IMPLEMENT_TMPDIR=""` (or `${IMPLEMENT_TMPDIR:-}` on all path uses) before argument parsing, so empty and omitted tmpdir both degrade to unreadable `session-env.sh` and still finish with `exit 0`.
