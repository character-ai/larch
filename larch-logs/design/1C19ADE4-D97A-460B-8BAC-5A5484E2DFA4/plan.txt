# Plan: extract per-step ledger telemetry preamble to `scripts/step-telemetry-mark.sh`

## Goal

Add one helper that reads the three ledger keys from `session-env.sh` and emits both
`token-ledger.sh mark` + `timing-ledger.sh mark`, then collapse the repeated read+export+mark trio at
the eligible `/implement` step-ENTRY sites in `skills/implement/SKILL.md`. Telemetry behavior stays
identical; this is a context-cost win.

`#3292` (plugin-root awk fence → `plugin-root.env`) already landed (commit `d452399af`), so the
per-step preamble sweep is unblocked. Converted fences keep the sourced `plugin-root.env` one-liner
from `#3292`.

## Files to modify/create

### NEW: `scripts/step-telemetry-mark.sh`
New helper. Interface: `step-telemetry-mark.sh --implement-tmpdir DIR --label "Step N — name"`.
- `set -uo pipefail` (intentionally **omit** `-e`; documented in a comment — pure telemetry, never fatal).
- **Initialize `IMPLEMENT_TMPDIR=""` and `LABEL=""` BEFORE the arg-parse loop**, and reference
  `"${IMPLEMENT_TMPDIR:-}"` so an omitted `--implement-tmpdir` cannot trip `set -u` (never-fatal
  contract holds even when the flag is missing).
- Resolve `SCRIPT_DIR` from `${BASH_SOURCE[0]}` so it calls its siblings without `CLAUDE_PLUGIN_ROOT`.
- Parse `--implement-tmpdir` and `--label`. Unknown flags are ignored (never fatal).
- Read `LARCH_TOKEN_SESSION_ID`, `LARCH_CLAUDE_SOURCE_FILE`, `LARCH_TIMING_LEDGER` from
  `$IMPLEMENT_TMPDIR/session-env.sh` via `"$SCRIPT_DIR/read-session-env-key.sh" --file ... --key ... --default ""`.
- `export IMPLEMENT_TMPDIR LARCH_TOKEN_SESSION_ID LARCH_CLAUDE_SOURCE_FILE LARCH_TIMING_LEDGER`
  (export `IMPLEMENT_TMPDIR` too so the ledger scripts' fallback chain matches the old inline fence).
- Run `"$SCRIPT_DIR/token-ledger.sh" mark "$LABEL" || true` then `"$SCRIPT_DIR/timing-ledger.sh" mark "$LABEL" || true`.
- End with explicit `exit 0` so the helper is never fatal even if a sibling script is missing.
- **Commit the file with the executable bit (mode `0755`)** — converted SKILL.md call sites run it
  directly (`"${CLAUDE_PLUGIN_ROOT}/scripts/step-telemetry-mark.sh" ...`); a non-executable `0644` file
  returns 126 and `|| true` would silently swallow the dropped marks.

### NEW: `scripts/step-telemetry-mark.md`
Sibling contract per `.claude/rules/script-md-siblings.md`: purpose, the `--implement-tmpdir`/`--label`

### NEW: `scripts/test-step-telemetry-mark.sh`
Focused offline unit harness (`set -euo pipefail`). Use a real temp `session-env.sh` and a fake
`IMPLEMENT_TMPDIR`. Assertions:
- **Executable-bit + direct invocation**: assert `[ -x "$HELPER" ]`, and run the happy path by invoking
  `"$HELPER"` **directly by path** (not `bash "$HELPER"`) so a lost executable bit fails CI.
- Happy path: with a temp `session-env.sh` carrying the three keys and a temp ledger dir, the helper
  exits 0 and both ledger files receive a mark row for the supplied label.
- Missing `session-env.sh` (bad `--implement-tmpdir`): exits 0, never fatal.
- **Omitted `--implement-tmpdir`**: invoke with no `--implement-tmpdir` flag and assert exit 0 (guards
  the `set -u` regression in FINDING_3).
- Missing/empty `--label`: exits 0, never fatal.
- Optionally PATH-shim a failing `token-ledger.sh` to prove `|| true` keeps exit 0.

## Approach

1. Write `scripts/step-telemetry-mark.sh` (executable, vars initialized before the arg loop) + its
   `.md`, self-contained via `SCRIPT_DIR` (reuses `read-session-env-key.sh`, `token-ledger.sh`,
   `timing-ledger.sh` siblings).
2. Write the new unit harness (asserts `[ -x ]`, direct-path invoke, omitted-flag exit 0) + `.md`;
   register it in the `Makefile`; add `agent-lint.toml` exclusions for the harness `.sh`/`.md`.
3. Audit all 8 token-mark / 6 timing-mark sites; convert only the 4 clean adjacent step-ENTRY pairs.
4. Update `test-implement-timing-rehydration.sh` + `.md` for the helper-aware counts.
5. Run `make test-step-telemetry-mark`, `make test-implement-timing-rehydration`,
   `make test-implement-structure`, `make agent-lint`, and `bash scripts/relevant-checks.sh`.

## Edge cases
- Omitted/empty `--implement-tmpdir` → vars pre-initialized → no `set -u` abort → `session-env.sh`
  unreadable → reads return `""` → marks still run with empty env → `exit 0`.
- Missing label → `exit 0`, no fatal.
- Helper committed non-executable → 126 at call sites; the unit harness's `[ -x ]` + direct-path invoke
  catches it in CI; `|| true` keeps the live step non-fatal as a backstop.
- `LARCH_TIMING_LEDGER` empty → `timing-ledger.sh` uses its `IMPLEMENT_TMPDIR` fallback (exported by the
  helper), identical to the old inline fence.

## Failure modes
- **Silent telemetry loss**: a converted site stops emitting marks (dropped helper call or lost exec
  bit). Earliest signal: missing Step-N rows in the larch-token / larch-timing ledgers; the
  `step_telemetry_mark_count` arithmetic fails if a helper call is dropped, and the harness `[ -x ]` +
  direct-path invoke fails if the exec bit is lost.
- **Test-count drift**: the equality assertions silently mis-tuned. Mitigation: derive
  `step_telemetry_mark_count` from the file, never hardcode; keep `plugin_root_source_count` pinned.
- **CI false-flag**: agent-lint G004 marks the new harness dead. Mitigation: the `agent-lint.toml`
  exclude entries above.
- **Behavior change on Step 2 / Step 18-done**: avoided by explicitly excluding both from conversion.

## Testing strategy
- New `scripts/test-step-telemetry-mark.sh`: `[ -x ]` + direct-path happy path + 3 never-fatal paths
  (bad tmpdir, omitted flag, missing label), wired into the Makefile.
- Updated `scripts/test-implement-timing-rehydration.sh` stays green with helper-aware counts.
- `test-implement-structure.sh` is unaffected (it pins marks in child scripts, not SKILL.md preambles).
- Run `make agent-lint` and `bash scripts/relevant-checks.sh` (shellcheck, markdownlint, agent-lint,
  bash32, siblings).
