## Plan

Implement a static lint that catches monkeypatches aimed at facade-only imported bindings. Mirror the `lint_tempfile_dir` ratchet shape, keep the scan static, and do not import scanned modules.

### Approach

- Add `python/larch/lint/lint_monkeypatch_facade_binding.py`.
- Scan only:
  - `python/tests/**/test_*.py`
  - `python/test_*.py`
- Parse test files with `ast`.
- Detect:
  - `monkeypatch.setattr(M, "name", ...)`
  - `monkeypatch.setattr("pkg.mod.name", ...)`
- Resolve the first argument:
  - Bare imported repo module names (`run_logs`).
  - Attribute chains rooted in imported repo modules (`ship.run_logs`, `run_logs.larch_io`), walking `ast.Attribute` nodes until the leaf module object is a repo module whose source file lives under `python/`.
  - Dotted-string form: final component is the attribute name; all prior dotted components are the module path.
- Skip silently when the chain cannot be resolved to a repo module, the attribute name is not a string literal, module source is missing, or parsing fails.
- Parse resolved module source without runtime import and classify **only the patched attribute's own module-level binding** in that facade module.
- Flag only when that specific name is bound solely by import (`from x import name`, `from x import y as name`, `import x as name`) and has no module-level `def name`, `class name`, `Assign` to `name`, or `AnnAssign` to `name`.
- Do not use a module-wide shortcut: unrelated top-level defs, classes, or assignments must not exempt an import-only patched attribute.
- Support relative imports in analyzed repo modules enough for accurate `defining_module` report text.
- Assign `occurrence` before baseline and suppression filtering. Count resolved repo-module `monkeypatch.setattr` candidates with literal attributes within the nearest lexical scope.

- For `monkeypatch.setattr(<expr>, "attr", ...)`:
  - If `<expr>` is a `Name`, resolve when it maps to a repo module.
  - If `<expr>` is an `Attribute` chain (`a.b.c`), walk from the root `Name` through each attribute, resolving each step to a repo submodule when the parent module's source binds that attribute as an import or submodule reference; stop at the module object being patched.

- For dotted-string targets, split on `.`; last segment is `attribute`; preceding segments form `facade_module`.

**Attribute-specific classifier.**

- In the resolved facade module AST, inspect bindings for the patched `attribute` name only.
- Treat as import-only when the binding for that name comes from `from x import name`, `from x import y as name`, or `import x as name`, and there is no module-level `def`, `class`, `Assign`, or `AnnAssign` for that same name.
- If the module both imports and later defines the same name at module scope, do not flag.

### Edge cases

- `from x import name` should report defining module `x`.
- `from x import y as name` should treat `name` as import-only and report the imported source.
- `import x as name` should treat `name` as import-only.
- If a module both imports and defines the same name at module scope, do not flag.
- Attribute chains stop at the repo module whose attribute is being patched; do not follow into instance-only or third-party objects.
- Do not attempt V1 late-attribute-access detection.
- Do not import repo modules while linting.

### Failure modes

- Baseline widening without reasons can re-admit the bug. Keep write mode fail-closed when a new live identity lacks a preserved or initial reason.
- Reusing the tempfile lint's `larch/` baseline path guard would reject valid test baselines; use the test-path validator instead.
- A module-wide structural shortcut would miss import-only facade bindings when unrelated top-level code exists; keep classification attribute-specific.
- Dotted-string parsing can overreach. Use the final component as the attribute and all prior components as the module; skip if that module source is missing.
- Attribute-chain resolution can overreach on dynamic intermediates; skip silently when any chain step is not statically resolvable to a repo module.
- Existing tests may intentionally patch facade attributes for late access. Grandfather or suppress with a reason rather than expanding V1 scope.
