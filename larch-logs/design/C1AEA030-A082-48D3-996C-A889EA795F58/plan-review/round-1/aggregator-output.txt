  - From Cursor-Pragmatic: Gate the healthy completion path on the skip reasons `flush_logs_post` actually returns after a terminal merge (mirror `git/merge.py` `_post_flush`: warn-and-continue for non-fatal skips; keep stalled only for `redaction-failed` and `manifest-recovery-failed), or document and implement a post-merge path that can emit `preterminal-outcome` before adding that gate
  - From Cursor-Requirements: Either wire post-merge flush to propagate preterminal-outcome when appropriate, or state explicitly that the classifier evidence gate is the production fix and keep the ship change defensive; add an integration test through flush_logs_post if ship-layer behavior is required.
  - From Cursor-dyn-Postmerge Route Auditor: Either extend flush_logs_post to return REFRESH_SKIP_PRETERMINAL_OUTCOME when post-merge tmpdir finalization hits the same NEVER-16 preterminal policy, or narrow the ship change to classifier-only and drop the Outcome.OK acceptance for a skip reason the post-merge path does not produce.

- **Severity**: major
- **Concern**: `classify()` recomputes the resume hint through `_resume_hint_for()`. Because `postmerge-flush` sanitizes to `unknown` and `operator-action` is not currently in the non-resumable set, the result can still be `RESUME_HINT=step8-shippr`, recreating the spurious reship.
- **Suggested revisions (informational for voters; coder decides)**:
  - From Cursor-Arch: `classify()` discards the hint from the classification tuple and always recomputes via `_resume_hint_for()` (line 284). `operator-action` is not in the early non-resumable class set (line 99). Without the planned `_resume_hint_for()` change, even a short-circuit returning `operator-action` can still yield `RESUME_HINT=step8-shippr` when `step` sanitizes to `unknown` and `phase` is `postmerge`. [ALREADY_ADDRESSED] Plan already requires adding `operator-action` to the non-resumable branch in `_resume_hint_for()`; keep that step explicit in `_classify.py` and assert `RESUME_HINT=none` in the new classifier regression test.
  - From Cursor-Innovation: Add operator-action to the klass set that returns none before the phase fallback at line 119. Assert RESUME_HINT none in the new classifier regression test.
  - From Cursor-Pragmatic: Add `operator-action` (and optionally `environment`) to the early non-resumable set in `_resume_hint_for()`, returning `none`; keep this even if classify short-circuits, because short-circuit tuples discard their embedded hint and always recompute via `_resume_hint_for()`
  - From Cursor-Requirements: Add an early return none when klass is operator-action, and cover STALL_STEP=postmerge-flush in the planned classifier regression test.
  - From Cursor-dyn-Postmerge Route Auditor: Add operator-action to the early non-resumable return at _resume_hint_for (line 99) as the plan states; add a regression assertion that RESUME_HINT=none when FAILURE_CLASS=operator-action and PHASE=postmerge.
