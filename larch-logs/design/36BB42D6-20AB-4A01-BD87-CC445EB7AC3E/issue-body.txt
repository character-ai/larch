## Edge cases

- Existing terminal state with a different outcome/site/trigger must still preserve the old file and emit `STAGED=false`.
- Existing terminal state that is a symlink or non-regular file must fail.
- `--failure-detail-log` must stay under `DESIGN_TMPDIR`, must be regular, readable, and not a symlink.
- `EVIDENCE_REF` must reject unsafe tokens, absolute paths, URLs, spaces, backticks, and traversal.
- Missing terminal state for terminal failure outcomes must still produce fallback chat, not a hard crash.
- Cancellation outcomes must still produce operator-action skip artifacts.
- Final-summary output must add a newline before `LARCH_FINAL_SUMMARY_END` when the file lacks a trailing newline.
- The final-summary completion sentinel must be written only after marked output and sidecar handoff are ready.
- The hook-bg-poll-guard marker name `design-step-final-summary` must remain unchanged.

## Failure modes

- A partial port could silently change stdout contracts. Prevent this with exact stdout tests for KV rows, final-summary markers, and sidecar handoff.
- In-process ports can leak stdout from imported helper mains. Capture helper stdout where the shell version wrote env files.
- Calling `cli.py` from Python callers would violate the no-shell-out rule. Use imports and direct function calls.
- Removing shell files before updating `session_env.py` can break prompt-side launcher fences.
- Changing historical tool labels can break run-log assertions and audits. Keep labels stable unless tests require a private-only rename.
