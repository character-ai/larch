## Findings

### 1. [correctness] `python/larch/review/snapshot.py:472-494` — missing `snapshot_head` contract in unified tracked-delta helper

The plan routes both families through one shared tracked-delta implementation and converges on `_tracked_paths_vs_ref()`, but it never preserves the pre-coder-only `snapshot_head` override in `_round_coder_delta_paths`:

```472:494:python/larch/review/snapshot.py
def _round_coder_delta_paths(
    *, round_dir: Path, diff_base: str, snapshot_head: str | None = None
) -> list[str]:
    ...
    compare_head = snapshot_head if snapshot_head is not None else diff_base
    ...
        if path in pre_tracked_set and _path_matches_pre_coder_snapshot(
            round_dir=round_dir, pre_head=compare_head, path=path
        ):
            continue
```

`_collect_round_stage_paths` supplies that override when `since_committed=True` and the post-coder head differs from the stored pre-coder head (`python/larch/review/snapshot.py:817-820`). `coder_runner._collect_review_fix_stage_paths` depends on this path (`python/larch/review/coder_runner.py:350`). Collapsing to a single ref would break pre-existing dirty exclusion after MAV/coder commits.

**Suggested revision:** Document and implement `patch_compare_ref` / `snapshot_head` on the shared helper; pre-coder facade wires it from `_collect_round_stage_paths`; self-review leaves it unset.

### 2. [correctness] `python/larch/review/snapshot.py:226-236` vs `930-933` — validation completeness must stay facade-specific

Pre-coder full validation requires an exact patch set (`python/larch/review/snapshot.py:226-236`). Self-review validation explicitly does not (`python/larch/review/snapshot.py:930-933`); missing patch files are handled per-path during matching. If shared validation imports the pre-coder completeness rule, self-review collection degrades from “include paths with missing patches as deltas” to “return no stage paths,” which can stall commit-route.

The plan’s failure-modes section warns about over-generalizing validation but does not name this split. **Suggested revision:** Add an explicit `require_complete_patches` (or profile enum) to the shared validation helper; only pre-coder full mode enables it.
