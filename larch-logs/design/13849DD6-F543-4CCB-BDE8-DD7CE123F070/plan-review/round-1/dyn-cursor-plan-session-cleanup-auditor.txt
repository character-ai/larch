### 1. (correctness) Wrong path helper for `step0-parsed` residual

The plan tells `reap_pid_residuals` to unlink `cleanup_cache_sessions_root() / f"step0-parsed-{claude_pid}.env"`, but the writer uses a different root:

```365:366:python/larch/design/design_step0_env.py
def _parsed_cache_path(claude_pid: str) -> Path:
    return Path.home() / ".cache" / "larch" / "sessions" / f"step0-parsed-{claude_pid}.env"
```

Symlink and launcher helpers also hardcode `Path.home()/.cache`, not `cleanup_cache_sessions_root()`:

```816:822:python/larch/state/session_env.py

    home = Path.home()
    return home / ".cache" / "larch" / "sessions" / (f"current-design-env-{pid}.sh" if pid else "current-design-env.sh")


def _design_run_path(pid: str) -> Path:
    return Path.home() / ".cache" / "larch" / "sessions" / f"design-run-{pid}.sh"
```

`cleanup_cache_sessions_root()` follows `XDG_CACHE_HOME` when set:

```312:320:python/larch/state/session_env.py
def cleanup_cache_sessions_root(*, env: Mapping[str, str] | None = None) -> Path:
    environ = os.environ if env is None else env
    xdg = environ.get("XDG_CACHE_HOME")
    if xdg:
        base = xdg
    else:
        home = environ.get("HOME", "")
        base = f"{home}/.cache" if home else f"{TMP_FALLBACK}/.cache"
    return Path(base) / "larch" / "sessions"
```

Tests already document that design session artifacts stay under `$HOME/.cache` even when `XDG_CACHE_HOME` is set (`python/tests/state/test_session_env.py:992-996`). With XDG set, the planned reap would remove symlink and launcher but leave `step0-parsed-{pid}.env` behind.

**Suggested revision:** Build the third path with the same rule as `_parsed_cache_path`, or extract one shared helper used by both writer and reaper.
