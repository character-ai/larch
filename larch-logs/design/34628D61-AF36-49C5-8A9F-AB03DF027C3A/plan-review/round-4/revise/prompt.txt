Key decisions and tradeoffs:

- **Launcher wraps `run-external-agent.sh`** so the markdown-fence consumers keep their existing background-launch + `collect-agent-results.sh` collection contract (`.meta`, `.diag`, `.done` sidecars keyed to `--output`).

## Edge cases

- **`OPENAI_API_KEY` unset/empty/whitespace**: `external_prepare_codex_auth` symlinks `~/.codex/auth.json` into the ephemeral home and `external_codex_auth_config_args` appends nothing — login behavior preserved at every swept site.
- **No `~/.codex/auth.json` and no env key**: prepare succeeds (symlink branch is conditional); Codex itself fails auth downstream — same as covered sites.
- **Unsafe `--output` path**: `validate_meta_scalar_path` rejects before sidecar writes; launcher exits **2** with no `.done` (argv error class, not collect-managed).
- **Auth-prep / model-args failure under background fences**: full `launch-review.sh:444-463` bundle + wrapper exit 0 — collectors observe immediate FAILED diag.
- **Auth-retry publishes `.done` only after final attempt**: inner sentinel prevents collectors from racing on a failed retry's `.done`.
- **`lint-fix-loop` launcher exit vs RC**: wrapper always exits 0; `run_codex` parses stdout `LAUNCHER_EXIT`.
- **Missing `codex` binary**: no launcher pre-check; `run-external-agent.sh` writes `.meta`/`.done` as today.
- **Collector retry loses `CODEX_HOME` env**: `-c` provider args persist in argv — documented in `launch-codex-exec.md`, not fixed here.
- **Collector retry rejects missing `--add-dir`**: launcher defaults `--add-dir "$workdir"`; fences also pass explicit `--add-dir "$PWD"`.
- **Negotiation trust/config under ephemeral home**: `config.toml` copied before prepare strips credentials; trust `-c` applied before auth `-c` overrides — matches `check-reviewers.sh`.
- **ARG_MAX**: negotiation keeps stdin pipe; other sites use argv as today.
- **Lint false positives**: comment lines stripped; env-assignment prefix skipped; basename allowlist for canonical dispatchers; per-line pragma for inline exceptions (negotiation).

## Failure modes

1. **Fence swap breaks `/research` collection** (wrong output path or missing `.meta`/`.done`). Earliest signal: `collect-agent-results.sh` timeout/empty-output failures. Mitigation: harness asserts `.meta` after stubbed run; inner-sentinel promotion tested.
1b. **Pre-dispatch omits `.done`/`.meta`**. Earliest signal: background lanes stall until collector timeout. Mitigation: harness asserts full bundle on auth-prep **and model-args** failures.
1c. **Early `.done` on auth retry**. Earliest signal: collector classifies lane failed while retry still running. Mitigation: `.inner.done` + single promotion; harness asserts no early `.done`.
2. **`lint-fix-loop.sh` sidecar rename breaks stderr-tail consumers**. Mitigation: update call sites and harness in same PR.
2b. **`lint-fix-loop` treats launcher failure as success**. Mitigation: `LAUNCHER_EXIT` parse; harness stubs `LAUNCHER_EXIT=1` with wrapper exit 0.
3. **Negotiation exit-grammar / protocol drift**. Mitigation: auth-prep → exit 2; update `external-reviewers.md` and `run-negotiation-round.md`; harness pins trust `-c` and config copy.
4. **`test-implement-structure.sh` pin breaks CI**. Mitigation: repoint lint-fix-loop assertion to `launch-codex-exec.sh` in same PR.
5. **Linter allowlist too broad or file-scope helper exemption hides raw exec**. Mitigation: explicit six-path basename allowlist only (not helper-presence); harness proves allowlisted launchers pass, helper-plus-raw-exec still fails, negotiation uses per-line pragma.
6. **Negotiation exit-code doc updated in wrong file**. Mitigation: `skills/shared/external-reviewers.md:114` for orchestrator prose; `docs/external-reviewers.md` auth-scope only.
