1. [risk-integration] `.pre-commit-config.yaml:145-169`

The plan adds `lint-awk-multibyte-regex` to `make lint`, but CI’s lint job runs `make lint-only`, which delegates to pre-commit. The new harness will run in the test matrix, but that only tests fixtures; it does not scan the real repo for newly introduced awk multibyte regex hazards.

Suggested revision: add a local pre-commit hook next to `lint-bare-grep-probe`:

`entry: bash scripts/lint-awk-multibyte-regex.sh`, `language: system`, `pass_filenames: false`, `always_run: true`.

That keeps the change minimal and puts the new lint on the same enforced path as the sibling static lints.
