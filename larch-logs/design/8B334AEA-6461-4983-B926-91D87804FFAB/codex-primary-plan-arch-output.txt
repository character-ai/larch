1. [risk-integration] `.pre-commit-config.yaml:1-6`

Concern: The plan wires `lint-awk-multibyte-regex` into `Makefile`, but not into `.pre-commit-config.yaml`, which this repo declares as the linter source of truth. CI’s lint job runs `make lint-only`, and `scripts/relevant-checks.sh` delegates to `pre-commit run --files`, so the new lint will not run in those paths.

Suggested revision: Add a local `always_run: true`, `pass_filenames: false` pre-commit hook for `bash scripts/lint-awk-multibyte-regex.sh` alongside `lint-bare-grep-probe`.
