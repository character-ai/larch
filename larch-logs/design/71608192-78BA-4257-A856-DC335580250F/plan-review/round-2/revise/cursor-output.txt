## Failure modes

- A missing `gpt-5.6-sol` rate row makes every default Codex cost report raise `KeyError`.
- If role-path `default_model` is not threaded through `dispatch-waterfall`, manifests may claim one model while launches use role defaults.
- If TRIVIAL forwards a blank `--default-model`, blank-value rejection or wrong fallback can break Cursor-down Codex singles.
- If TRIVIAL row selection is only changed for static rows, dynamic archetypes can still spawn the wrong vendor shape.
- If targeted revotes omit `--tier`, TRIVIAL/MODERATE rounds can revote at the flat vote-role default instead of the tier-specific model.
