- If CI recovery order changes without launcher role changes, Codex may run the default role instead of the fix role.
- If docs change but plugin text does not, users may pin the wrong model or expect stale panel shapes.
- If topology projection is generated from role defaults, stale generated docs may fail checks or mislead operators.
