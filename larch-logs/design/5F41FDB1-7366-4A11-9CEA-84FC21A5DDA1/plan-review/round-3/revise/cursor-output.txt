**Critical constraint (FINDING_1 — publish-tail stubs):** Postplan's `_write_recording_cli` only special-cases `plan validate` and otherwise exits 0 with empty stdout. A recording CLI that omits those handlers causes `publish_core` to fail at redact (~294-295, rc 5) before `PLAN_WRITE_OK=true` or the planned validate assertions run. The regression test must exercise the full publish path through validate.

Add a module-local `_write_recording_cli(path: Path) -> None` that:

## Edge cases

- Cwd is not inside a git worktree: `_consumer_repo_root()` returns `None`; fallback to `plugin_root` preserves current plugin-only behavior (including existing harness tests without `git init`).
- Consumer repo and plugin root are the same path: dual-root collapse in `plan_quality.py` is unchanged.
- Plugin-cache install: `--repo-root` points at the consumer repo; `CLAUDE_PLUGIN_ROOT` points at the cache.
- Missing `git` binary or git failure: return `None` and use existing fallback.
- Truly absent script files: validation should still fail with `missing-script`.
- Unsafe tokens: no behavior change in this PR.
- Recording fake CLI without publish-tail stubs: publish aborts at redact with rc 5 before validate assertions; mitigated by copying `_write_fake_cli` tail handlers into `_write_recording_cli`.

## Failure modes

- If `_consumer_repo_root()` is wrong but the regression omits `cwd=str(consumer)`, the test may pass for the wrong reason or miss the plugin-cache vs consumer-repo split.
  - Mitigation: require `cwd=str(consumer)` on the publish subprocess, matching postplan coverage.
- If `CLAUDE_PLUGIN_ROOT` is not preserved in Step 5c validate env, plugin-only scripts can become false `missing-script`.
  - Mitigation: assert `CLAUDE_PLUGIN_ROOT` in the recorder file, not only publish stdout.
- If the shared `_write_fake_cli` is changed to fail on plugin `--repo-root`, existing harness tests break even when production behavior is correct.
  - Mitigation: dedicated `_write_recording_cli` for the new test only; leave shared fake CLI unchanged.
- If `_write_recording_cli` omits redact/named-block/rename/log-publish stubs, the regression test fails at rc 5 before reaching `PLAN_WRITE_OK` or validate assertions.
  - Mitigation: base `_write_recording_cli` on `_write_fake_cli` publish-tail handlers; instrument only the `plan validate` branch.
- If Step 5c result-env keys change, callers may break.
  - Mitigation: do not rename or remove existing keys.
