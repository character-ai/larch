# Implementation Plan — `--brainstorm` flag for /design (issue #2754)

## Summary

Add a public boolean flag `--brainstorm` to `/design`. When set, a new **Step 1d.5** runs between Step 1d (Round 1 discussion) and Step 1e (Gate A): it dispatches a 3-agent ideation panel (Cursor + Codex + always-Claude), the main agent synthesizes/dedupes/orders the outputs to `$DESIGN_TMPDIR/brainstorm.md`, then enters a free-form discussion loop with the user until they signal ready. A `$DESIGN_TMPDIR/.brainstorm-done` sentinel makes the step one-shot per invocation. Downstream Step 2a (sketch prompt context), Step 2a.5 (dialectic synthesis input), Step 2b (plan), and Step 3 (plan-review reviewer context) read `brainstorm.md` additively (never required, never load-bearing). All existing tier flows are functionally unchanged when `--brainstorm` is absent.

Dialectic-resolved (DECISION_1, 3-0): Step 1d.5 placement (before Gate A) wins over Step 1f (after Gate A's first-time Ready). Reason: post-Gate-A re-entry is post-plan, writes `discussion-round2.md`, and does NOT re-run sketches — placing brainstorm before Gate A preserves the pre-plan Gate A "Discuss more" re-entry path for scope questions surfaced by brainstorm.

## Approach

The implementation is shaped exactly like the existing `--partition` plumbing for reviewer comparability — same flag-parsing pattern, same JSON-field pattern, same recovery-block pattern. The key novelties are the new Step 1d.5 step body (modeled on Step 2a sketch parallel-launch but with the Agent-return-then-parent-write convention) and the free-form discussion loop with its explicit anti-halt override.

`effective_tier` is the single mechanism that mediates `--trivial` + `--brainstorm` collision: Pre-Step-0 sets it on Upgrade-to-simple, Step 0b parser checks it before consuming raw argv tier flags, and Step 0b's tier gate also honors it when the user picks trivial on the gate while brainstorm is requested.

The Agent fallback contract (FINDING_7) is critical: existing larch convention is that Agent tools return text to the parent and do NOT write files. The brainstorm panel must follow that contract — parent captures returns, writes to deterministic output paths, then calls collect-agent-results.sh ONLY for genuinely external Cursor/Codex slots. This is the same pattern dialectic uses for inline Claude judges and matches Step 2a sketch Agent fallback when launched today.

Downstream consumers (Step 2a / 2a.5 / 2b / 3) all read brainstorm.md additively. None require it; absent/empty file is a no-op. This means when `--brainstorm` is OFF, all four downstream steps behave byte-identically to today.

## Edge cases

- **`--brainstorm --trivial`**: Pre-Step-0 interactive AskUserQuestion. Upgrade sets `effective_tier=simple` + `brainstorm_requested=true`; Step 0b parser honors the override. Cancel exits before DESIGN_TMPDIR.
- **`--brainstorm` with tier-gate trivial selection**: Step 0b tier gate fires the same collision prompt after the user picks trivial; same Upgrade/Cancel semantics (FINDING_13).
- **`--brainstorm` on already-planned ad-hoc Q&A**: Step 0b writes run-params.json with `--brainstorm-requested true` AND runs Step 1d.5 before the ad-hoc Q&A body (FINDING_2). Cancel branch still exits without brainstorm.
- **Sentinel re-entry**: `$DESIGN_TMPDIR/.brainstorm-done` short-circuits Step 1d.5 entry. Gate A "Discuss more" re-enters 1c/1d only; brainstorm sentinel guard is defense-in-depth.
- **Step 1d short-circuit + brainstorm**: when `discussion-round1.md` is absent/empty, brainstorm prompt rendering uses `feature-description.txt` alone (FINDING_12).
- **External tool fails at runtime**: collect-agent-results.sh STATUS != OK → log to execution-issues.md, proceed with available slots' content. brainstorm.md still written. No automatic runtime fallback to Claude (intentional — Round 1 decision #11 covers LAUNCH-time fallback only).
- **Agent fallback failure**: Agent return text empty or error → parent logs failure to execution-issues.md (External Reviewer Issues), does NOT Write to the slot's output file. Synthesis proceeds with available slots.
- **All 3 brainstorm slots fail**: brainstorm.md missing/empty. Print warning, skip discussion loop, write sentinel anyway, proceed to Gate A. Downstream readers' `if exists and non-empty` guards prevent breakage.
- **User signals termination on first synthesis (no discussion)**: classify intent → terminal → write sentinel → continue to Step 1e in same turn (FINDING_17).
- **Ambiguous user message** (e.g., "ready if you also add cancel option"): treat as continued discussion (FINDING_18); mutate brainstorm.md per the conditional, re-print synthesis, await user. May fire two-option AskUserQuestion (Continue / Proceed) when intent is genuinely unparseable.
- **Run-params recovery with both flags**: outer predicate is `partition_requested OR brainstorm_requested`; jq merge sets both fields when applicable; no-file recovery writer passes both flag values (FINDING_15).

## Failure modes

1. **`--brainstorm` not propagated to `run-params.json` from a fast-path argv edit** (e.g., orchestrator misses the new flag in Step 0b): Step 1d.5 entry guard sees `brainstorm_requested=false` and silently skips. Warning signal: argv had `--brainstorm` but no brainstorm step ran. Mitigation: test-design-structure.sh assertions (FINDING_16) pin the writer callsite literals; test-write-run-params.sh round-trip catches writer-level regressions.

2. **Free-form discussion loop never terminates** (user keeps refining, or main agent misreads termination cue): bounded by user attention, not by a hard cap. Mitigation: the ambiguity confirmation prompt (FINDING_18) gives the user an explicit escape; recognized-vocabulary guidance in brainstorm.md documents known-good cues. A future iteration could add a soft turn-count cap with continue-or-proceed prompt.

3. **brainstorm.md schema drift**: downstream readers expect `## Brainstorm Synthesis` H2 + per-idea H3 blocks. Mitigation: schema documented in `references/brainstorm.md`; downstream reads are prose-consumption (not mechanical parsing). Drift degrades gracefully — Step 2b's incorporation becomes "best effort" but does not break.
