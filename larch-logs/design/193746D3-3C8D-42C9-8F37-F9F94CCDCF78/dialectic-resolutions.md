Gate A is not itself a clarifying-question step (it is the readiness chooser whose first-time prompt exists before sketches), so adding brainstorm output to its decision context does not turn it into a "brainstorm-aware state machine" — Gate A's prompt and option set are unchanged; it simply has richer pre-approval context.
