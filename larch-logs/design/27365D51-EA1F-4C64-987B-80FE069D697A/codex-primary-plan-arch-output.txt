1. [risk-integration] `scripts/design-log-publish.sh:14-15` and `scripts/design-pause-save.sh:29-35`

Both scripts have machine-readable stdout contracts. The plan uses `larch_design_tmpdir_validate ... || exit $?`, which bypasses those contracts on invalid-but-expected input.

Suggested revision: keep the validator, but route failure through each script’s existing structured failure mechanism.

2. [correctness] `scripts/write-design-current-env.sh:113-116`

The proposed placement runs the allowlist validator before the script’s existing absolute-path validation. That changes diagnostics and exit code for relative paths.

Suggested revision: validate after the current absolute-path check, and use `|| exit 1` to preserve the invalid-args exit contract.

3. [correctness] `skills/design/scripts/emit-design-plan-preview.sh:91-107`

This script intentionally treats empty or missing design tmpdirs as a user-facing warning path for `step3` and exits 0. The proposed top-level validator would turn that into exit 2.

Suggested revision: validate only after the existing variant-specific invalid-dir branch, before reading `$design_tmpdir/plan.txt` or touching sentinel files.
