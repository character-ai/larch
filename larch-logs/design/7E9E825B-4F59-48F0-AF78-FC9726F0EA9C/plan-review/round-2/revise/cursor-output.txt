## Edge cases

- **Missing snapshot**: never stage the whole tree.
- **Empty `pre-coder-head.txt`**: return no stage paths.
- **Empty or missing `post-coder-head.txt` with `since_committed=True`**: `_round_diff_base` returns `""` without pre-coder-head fallback; return no stage paths.
- **Head-only legacy snapshots**: preserve scoped attempt behavior. Do not upgrade them to full snapshots.
- **Pre-lint baseline dirt**: do not commit unless lint-fix reports the path.
- **Unreported lint edits**: leave them dirty rather than sweeping them into the lint commit.
- **Reported then reverted lint paths**: exclude from the lint commit even if still present in `unioned_delta_paths`.
- **Path order**: keep deterministic sorted output where helpers already promise it.

## Failure modes

- A lint-fix tool may omit `LINT_FIX_DELTA_PATHS`; `_lint_fix_delta_paths` should return no paths.
- A degraded coder snapshot may produce no stage paths; the round may return `no-changes`.
- A `since_committed=True` call with empty post-coder-head must not stage stale deltas since pre-coder baseline.
- A partial cleanup verification failure should stop coder fallback and log the path-specific detail.
- If new tests reveal existing cleanup flow already handles partial verification, do not add cleanup code.
