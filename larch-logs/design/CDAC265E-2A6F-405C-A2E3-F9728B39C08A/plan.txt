## Edge cases

- **Row ordering**: the existing rows on lines around test-parse-plan-commands and test-validate-plan-commands are adjacent; place the new row between them to match Makefile recipe order. Markdown tables are unordered structurally, so this is purely for human readability.
- **Backtick code spans**: the row contains tokens beginning/ending with non-whitespace (no `MD038` violation). Use backticks around all code identifiers; the `→` glyph is plain text (renders cleanly in `markdownlint`).
- **Stale prose warning**: per `.claude/rules/drift-prone-prose-in-docs.md`, do NOT reference Makefile line numbers in the docs prose — the description names scripts by path only.
