## Failure modes when non-trivial

- **Secret count/content mismatch** if design copy counts one scrub pass but writes another. Always write the exact `scrub_log_secrets()` output that was counted.
- **Secret count double-count** if design pre-scrub totals are added again when `_copy_tree_to_repo()` re-scrubs the same worktree files. Skip duplicate scrub/count when source and dest resolve to the same path.
- **Warning carry over-report** if all state is carried. Restrict carry to the two warning keys.
- **Reviewer tokenization regression** if spaced dynamic labels are split. Keep longest-known-label matching and the existing spaced-label test green before adding the whitespace-separated two-label case.
