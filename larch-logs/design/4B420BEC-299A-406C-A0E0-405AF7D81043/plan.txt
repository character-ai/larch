- Make the minimal default bump for both selected knobs.
- Preserve existing semantics:

## Edge cases

- Empty string for `LARCH_EXTERNAL_HEALTH_CHECK_TIMEOUT` is non-digit, so it should fall back to `"60"`.
- `"0"` for `LARCH_EXTERNAL_HEALTH_CHECK_TIMEOUT` must remain an opt-out.
- `probe_timeout_seconds` passed directly to `check_reviewers` should still override env fallback.
- `LARCH_PROBE_TIMEOUT_SECONDS=0` must still fall back because `zero_allowed=False`.

## Failure modes

- Accidentally sharing semantics between the two knobs can break the `0` opt-out for launch-time health gates.
- Updating docs but not `_external_timeout` can leave `/design` and `/implement` session writers persisting the old value.
- Adding retry-budget behavior here would overlap with #4756 and is out of scope.
