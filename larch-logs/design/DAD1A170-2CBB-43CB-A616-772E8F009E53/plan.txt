## Edge cases

- **No completed rounds**: keep renderer output. It may say `No review rounds completed.`.
- **Missing timing ledger**: table may render. Gantt charts do not.
- **Missing token ledger**: cost renders as unavailable or zero per renderer behavior.
- **Missing findings file**: top-reviewers may be absent. Table and Gantt still render.
- **Missing `jq`**: renderer returns empty. Final report still succeeds.
- **Renderer timeout**: omit detail. Final report still succeeds.
- **Post-redact truncation marker**: if `redact_outbound` introduces `[content truncated ...]`, omit detail to avoid publishing a body that would fail summary upsert redaction.
- **Implement run-log root exists but has no completed rounds**: use that root, not live `IMPLEMENT_TMPDIR/round-N`, to preserve committed-log final report semantics. Stale live `round-meta.json` must not produce a completed-round table row (#3794).

## Failure modes

- If helper import fails, both final report paths fail. Keep the new module stdlib-only plus existing local `redact` import.
- If helper appends before fallback creation, degraded fallback reports can lose detail. Append after fallback body exists.
- If helper strips markdown for terminal use, public comments lose tables and code fences. Preserve markdown.
- If detail is appended before the run-summary marker, downstream parsers may misread the compact block. Append after the marker.
- If truncation is checked on raw renderer stdout before `redact_outbound`, PEM redaction can introduce a truncation marker that leaks into chat and upsert paths. Check only post-redact.
- If tests only monkeypatch `render_*_review_detail` at call sites, a helper that raises on subprocess failure or selects the wrong rounds root would ship untested. Cover subprocess swallow paths in `test_review_phase_detail.py` and the #3794 rounds-root case in both `test_review_phase_detail.py` and a subprocess-layer `test_pr_body.py` test.
- If CI runs only targeted pytest (`make py-test` / `python3 -m pytest ...`) without `make test-write-final-report` or `make test-harnesses-19`, real `write_final_report` → `render-review-phase-detail.sh` wiring (including `--findings-file` and rounds-root selection) can regress until the bash harness fails.
