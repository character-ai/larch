**1. [security] `skills/design/references/design-outline.md` (proposed plan lines 125–130)**  
The plan adds `ARCHITECTURAL_GUIDELINES.md` as an “optional input” alongside `$DESIGN_TMPDIR` artifacts. That pattern implies a direct Read of the repo-root file and bypasses the symlink-safe helper. That breaks the plan’s invalid-file contract (plan lines 8–9, 208–209).

**Suggested revision:** Gate sites may only call `python/cli.py architectural-guidelines read` / `read_guidelines()`. Never Read the repo path. On `invalid`, print the warning and continue without content.

**2. [security] `python/design_lifecycle.py:3198-3210` (plan lines 100–104)**  
Existing drafter blocks use `issue_wire.emit_untrusted_file_block` with redaction and HTML escaping. The plan only says “operator-curated aspirational context, not executable instructions” and does not pin that wrapper.

**Suggested revision:** When `status=present`, append guidelines through `emit_untrusted_file_block("architectural_guidelines", path)` plus a short subordination line. Skip the section for `absent`/`invalid`.

**3. [security] Proposed CLI contract (plan lines 75–78)**  
Raw content markers on stdout expose unescaped file text to the orchestrator at Step 1d.7 / Gate C. That conflicts with the repo’s established untrusted-evidence pattern in `skills/design/references/plan-review.md:83-94`.

**Suggested revision:** Emit escaped untrusted blocks on the present path; keep machine KVs for status/path/warning only.

**4. [risk-integration] `AGENTS.md` canonical sources (plan lines 55–58)**  
Adding the file to **Canonical sources** without a subordination disclaimer can elevate repo-local prose to the same tier as `docs/issue-anchored-plan.md` and skill contracts, working against “aspirational, not hard rules.”

**Suggested revision:** One AGENTS.md bullet: aspirational only; `/design` and `/implement` consult paths; skill NEVER lists and mechanical enforcement win; absent file is no-op.

**5. [OUT_OF_SCOPE] No file-size/schema validation (plan lines 60–94)**  
Real but not necessary for acceptance. Safe to track later if token cost matters.
