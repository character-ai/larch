## Approach

- Add a small renderer in `python/plan_review_round.py`.
  - Input: `reviewer-status.tsv` rows.
  - Output: one chat-ready line:
    - `📊 Reviewers: | Cursor-Arch: ✅ 4m12s | ... |`
  - Map statuses:
    - `done` → `✅`
    - `pending` / `in-progress` → `⏳`
    - `failed` / `timeout` → `❌`
    - `skipped` → `⊘`
  - Append elapsed only when the TSV elapsed field is non-empty.
- Add table write/clear helpers with symlink-safe destinations.
  - Write per-round `plan-review/round-N/reviewer-status-table.txt`.
  - Write stable `$DESIGN_TMPDIR/reviewer-status-table.txt`.
  - Before every stable-table refresh, clear any prior stable table without following symlinks.
  - When render returns `None` or table write fails, leave both table paths absent (unlink if present).
- In `write_reviewer_status_tsv()`, after a successful per-round TSV write, render and write both table artifacts **before** calling `sync_latest_reviewer_status()`.
  - Keep `sync_latest_reviewer_status()` responsible for TSV copy only.
  - Stable table must not depend on latest-TSV copy succeeding.
- Move round-binding fallback into Python for callers that lack an in-scope round id.
  - `_bind_step3_review_round()` reads `.step3-review-result.env` with key order `FINAL_ROUND_NUM` → `STEP3_REVIEW_ROUND_NUM` → `ROUNDS_COMPLETED` (numeric only).
  - `materialize_stable_reviewer_status_table(design, *, round_num: int | None = None)` uses explicit `round_num` when supplied; env binding is **secondary** for post-envelope callers only.
  - **Never** rely on env binding inside `_run_round_body`: `.step3-review-result.env` is not updated until after `_run_round_body` returns, so round 2+ can still carry the prior round's keys.
- Centralize stable-table recovery in `_run_round_body()` for **both** subprocess and in-process tails.
  - Subprocess path where per-round TSV already exists: after `sync_latest_reviewer_status()`, unconditionally refresh table artifacts from that TSV with explicit `round_num`.
  - Before return (both branches converged): when `reviewer-status-table.txt` is still absent, call `materialize_stable_reviewer_status_table(tmpdir, round_num=round_num)`.
- Harden `try_write_reviewer_status_tsv()` terminal cleanup.
  - When `wrote is None` and `header_fallback` is false, clear stale stable table.
  - When header fallback was attempted but `wrote` is still `None` (fallback `OSError`, symlinked candidate, or symlinked per-round TSV), also clear stale stable table.
- Keep the prompt-side Step 3 output path thin:
  - After the completion gate, use the Read tool on `$DESIGN_TMPDIR/reviewer-status-table.txt`.
  - Write the Read result as plain orchestrator chat text.
  - Do not use Bash, Python, or other tool calls to print the table body.
  - If the file is missing, print exactly:
    - `**⚠ Reviewer status table omitted: pre-rendered table not found.**`
  - Do not keep the TSV rendering prose.
  - Do not keep the multi-key round-binding fallback prose in SKILL.md.
  - Do not keep the example table fence or icon/elapsed legend in SKILL.md; Python owns all icon and elapsed formatting.
  - Parse `.step3-review-result.env` only after that emit or warning.
- Treat the existing `NO_SKETCHES` synthesis as binding.
  - Draft from direct repository inspection only.

## Edge cases

- **Upgrade or race:** if `$DESIGN_TMPDIR/reviewer-status-table.txt` is missing at Step 3, warn and continue; `_run_round_body()` unified tail with explicit `round_num` should have materialized it from the current per-round TSV before the orchestrator reads the stable file.
- **Stale env during round body:** `.step3-review-result.env` may still name round N-1 while round N runs; `_run_round_body()` must never call env-only materialization on the hot path.
- **Subprocess TSV pre-exists:** parent must refresh stable table from current per-round TSV after `sync_latest_reviewer_status()`, not only when stable file is absent.
- **Header-only TSV:** render returns no table; shared clear path removes stale stable and per-round table artifacts.
- **Header fallback failure:** when fallback does not produce a writable TSV (`wrote is None`), clear stale stable table even though `header_fallback=True`.
- **Symlinked latest TSV:** stable table still refreshes from the per-round TSV written in `write_reviewer_status_tsv()` or `_run_round_body()` recovery; latest copy may no-op.
- **Symlinked table destinations:** skip writes and clears without following symlinks.
- **Unknown status:** render as failed or skipped only if existing status vocabulary supports that safely; otherwise omit the row or use `❌` with a unit test documenting the choice.
- **Blank elapsed:** do not add trailing duration text after the icon.
- **SKILL.md checklist drift:** implementers must not paraphrase the missing-table warning or resurrect the retired round-unbound message; all three compact-table copies must quote the same literal.
- **Progress Reporting legend drift:** implementers must not leave the example fence or **Icons:** legend in place; those lines reintroduce orchestrator-side rendering even when post-notification bullets are updated.

## Failure modes

- **Table write failure:** keep the current reviewer-status failure logging pattern.
  - On `OSError`, unlink `$DESIGN_TMPDIR/reviewer-status-table.txt` and the per-round table artifact if created.
  - Do not fail the review round solely because the chat table could not be written.
- **Render returns None:** unlink both table destinations so Step 3 hits the missing-file warning instead of prior-round icons.
- **sync_latest early return or copy failure:** stable table must already reflect the current round from per-round TSV write or `_run_round_body()` unconditional refresh; do not leave a prior stable artifact in place.
- **try_write terminal path with wrote=None:** clear stale stable table for both `header_fallback=false` and failed `header_fallback=true` paths.
- **Malformed TSV:** skip table writes via render `None` and clear stale artifacts.
- **In-process gap:** unified `_run_round_body()` tail closes the case where TSV exists but table artifact write failed during `execute_round`.
- **Prompt-side stale instructions:** update all three SKILL.md compact-table copies so there is no remaining instruction to render TSV in prose, bind round numbers in the orchestrator, omit the quoted missing-table warning, or keep the example/icon legend that conflicts with the read-only emit contract.
