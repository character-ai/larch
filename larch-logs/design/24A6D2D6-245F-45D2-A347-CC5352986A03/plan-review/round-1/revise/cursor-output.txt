## Edge cases

- **Upgrade or race:** if `$DESIGN_TMPDIR/reviewer-status-table.txt` is missing, Step 3 warns and continues; Python round-binding materialization should have run during the round body before the orchestrator reads the stable file.
- **Header-only TSV:** render returns no table; shared clear path removes stale stable and per-round table artifacts.
- **Symlinked latest TSV:** stable table still refreshes from the per-round TSV written in `write_reviewer_status_tsv()`; latest copy may no-op.
- **Symlinked table destinations:** skip writes and clears without following symlinks.
- **Unknown status:** render as failed or skipped only if existing status vocabulary supports that safely; otherwise omit the row or use `❌` with a unit test documenting the choice.
- **Blank elapsed:** do not add trailing duration text after the icon.

## Failure modes

- **Table write failure:** keep the current reviewer-status failure logging pattern.
  - On `OSError`, unlink `$DESIGN_TMPDIR/reviewer-status-table.txt` and the per-round table artifact if created.
  - Do not fail the review round solely because the chat table could not be written.
- **Render returns None:** unlink both table destinations so Step 3 hits the missing-file warning instead of prior-round icons.
- **sync_latest early return or copy failure:** stable table must already reflect the current round from the per-round TSV write; do not leave a prior stable artifact in place.
- **try_write terminal path with wrote=None:** clear stale stable table when header fallback is not used.
- **Malformed TSV:** skip table writes via render `None` and clear stale artifacts.
- **Prompt-side stale instructions:** update all three SKILL.md compact-table copies so there is no remaining instruction to render TSV in prose or bind round numbers in the orchestrator.
