> **Update 2026-06-17 (survey reconciliation).** The original "final sweep" framing was premature. A repo survey found **~30.6k lines of live bash still in the runtime** — dominated by un-ported /design + /implement step orchestration (skill `.md` fences still run `bash …/step*.sh`) and the review-pipeline `run_legacy` façade bodies — **not** the "hooks + deliberately-kept guards only" residual this issue assumed. E3 is now **re-blocked on the G-track body ports G1–G13 (#4630–#4642)** and runs **last**.

> Stale specifics corrected: `sleep-seconds.sh` is still consumed by `python/stall_recovery.py` (not an orphan); `repro-claude-p-edit-permissions.sh` is already deleted; `lib-quiet.sh` has ~73 live `.sh` consumers, so it retires only after G1–G13 land.

**Goal**: Close out the migration: retire the terminal shared bash libs, scope down (never port) the bash-targeting linters, shrink authoring docs, regenerate topology, rebalance CI.

- Shrink `BASH_AUTHORING.md`; rewrite the `AGENTS.md` Python section and `python/README.md`.
- Regenerate topology docs (`skills/shared/topology.tsv` projection).
- Rebalance CI test-harness shards after the mass bash-harness deletion from G1–G13.
- `SECURITY.md` update for the changed security surface.
