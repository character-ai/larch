## Edge cases

- **Checks failure with no redacted log**: composite emits `NEXT_ACTION=checks-failed`; §1 structural gate still routes to stall when `FAILURE_REASON` is structural and no `REDACTED_LOG_FILE`.
- **Checks-leg timeout**: child killed; composite emits `NEXT_ACTION=checks-failed` with `FAILURE_REASON=checks-leg-timeout` when relayed; commit/resume leg not started.
- **Checks pass plus commit failure with successful stall seed**: composite emits exactly one `NEXT_ACTION=stall` after full chain.
- **Checks pass plus commit failure with stall seed failure**: composite emits **no** `NEXT_ACTION`; non-zero exit; orchestrator invalid-envelope fail-closed (preserves standalone no-token path).
- **Commit-leg timeout after checks pass**: durable stall seeding attempted per commit-route site; composite emits `NEXT_ACTION=stall` only on `seeded-stall`.
- **Step 5 resume commit succeeds but review loop fails preflight**: `STEP5_REVIEW_STATUS` gate on relayed resume stdout unchanged; composite does not add `NEXT_ACTION=continue` after checks alone.
- **Resume-leg timeout**: resume child killed; relay partial stdout if any; no composite `NEXT_ACTION=continue`; resume stall tokens in relayed stdout when present.
- **Duplicate `NEXT_ACTION` from child routes**: prevented by `emit_next_action=False` on commit child; `checks-step5-resume` emits composite `NEXT_ACTION` only for `checks-failed`.
- **Step 6 `FILES_CHANGED=false`**: do not run composite verb; skip to Step 7a.
- **Repair re-entry at folded sites**: full composite re-run on every repair-loop `NEXT_ACTION=continue` per §4 site-split rule.

## Failure modes

- Checks child raises unexpectedly: emit `NEXT_ACTION=checks-failed`; return non-zero; do not run commit or resume.
