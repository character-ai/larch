# Implementation Plan — Preserve vendor-agent error diagnostics in committed run logs (#3713)

SIMPLE tier. **Centralize**: `run-external-agent.sh` is the single composed-carrier producer so every vendor launch inherits the fix; launchers archive per-attempt history and do site-aware logging. Fix the incident's 4 stacked layers; classify every site in an audit table; add regression coverage. Sites not directly fixed are `inherits-via-run-external-agent.sh` or residual-OOS.

## Root cause (code-confirmed)

1. `scripts/append-tool-failure.sh:152` `cat`s `--output-file` verbatim; line 100 only checks existence → empty fenced block when the source is empty/zero-byte at give-up.
2. `scripts/launch-review.sh:644/1102` pass the live `$SIDECAR` as `--output-file`; retries truncate it first with no archive → empty at give-up. **`launch-review.sh` does NOT `source lib-failed-agent-stderr-tail.sh`** today.
3. `scripts/run-external-agent.sh:207-224` health-gate fast-fail writes only `${OUTPUT}.diag` and `: > "$OUTPUT_FILE"`; never touches the sidecar.
4. `scripts/design-log-publish.sh:304` excludes `*.sidecar`/`*.diag`/`*.events.jsonl`; `scripts/larch-log-batches.sh` has no failure slug.

## Central carrier — composed, final-failure-only

`${OUTPUT}.failure-diag` is the single committed failure carrier: a bounded **composed** artifact with labeled sections for every non-empty diagnostic stream needed for the failure.

**Producer + retry-then-success guard**: `run-external-agent.sh` clears `${OUTPUT}.failure-diag` at ENTRY, and composes it inside the existing `_write_sentinel_on_exit` EXIT trap when `EXIT_CODE != 0`, **before** writing `${OUTPUT}.done`, so a visible `.done` always implies the carrier exists for failures. A retry that later SUCCEEDS clears the prior carrier at the success-attempt entry → retry-then-success commits nothing. Direct/site launchers that own `${OUTPUT}` (`launch-claude-subprocess.sh`) clear it at launch start and remove it on success too (F7). Launcher give-up backstops cover early exits that never reach a final wrapper attempt.

**Carrier source list (composed sections)**: `.sidecar.history`, bounded filtered events history (archived before every events `rm`/reset), final sink/sidecar, `.diag`, filtered `.events.jsonl` tail, `${OUTPUT}.stderr`, `${OUTPUT}.launch-stderr`, `${OUTPUT}.launcher-stderr`, the base output file for `--capture-stdout`, and — pre-output failures — a persisted wrapper-stderr (`SUBPROCESS_STDERR` → `${OUTPUT}.launcher-stderr`, F10). `--sink`/`--history`/`--events` cover caller paths.

**Redaction boundary**: `write_failure_diag` folds only error/quota/`turn.failed` event lines; strips success transcripts and non-error bulk. **Cursor `.result`**: strip on success, but preserve a bounded redacted failure-only excerpt when exit is nonzero or `is_error` is true (F12). Keep byte caps. Apply the same filter before `append_vendor_failure_diagnostics` / `append-tool-failure.sh --redact`.

**Publish**: only `*.failure-diag` is committed (design staging redacts at `design_publish_stage_file:420`; implement via the batch). Keep `*.sidecar`, `*.diag`, `*.events.jsonl`, `*.sidecar.history`, AND scout tier raw stems (`*.raw.cursor`/`*.raw.claude` + sidecars, `scout-plan-manifest.json.raw.*`) excluded with explicit deny arms (F1).

## Approach

1. **Compose helper** `write_failure_diag OUTPUT [--sink] [--history] [--events]`: bounded labeled carrier with the redaction-boundary filter; append-with-header when the carrier exists. Bash 3.2-safe.
2. **Resolver** `resolve_failure_diagnostic_source OUTPUT [--sink] [--history] [--events]`: carrier-preferred, else first non-empty across the source list (incl. retry / ns-retry candidates — F9). Returns 1 when all empty.
3. **Never-empty log**: site-aware callers pass the resolved carrier to `append-tool-failure.sh`, which gains a fail-closed backstop — missing/zero-byte `--output-file` → synthesize `no diagnostics captured (exit N)`.
4. **Archive per-attempt** `external_stream_reset TARGET HISTORY LABEL`: archive then truncate at every sidecar, `.diag`, and codex events truncation/removal site, including `run-external-agent.sh` entry cleanup.
5. **Verdict ordering**: compute `external_failure_verdict` (codex `.diag`+events parity) BEFORE any reset.
6. **Give-up ordering**: (A) preflight/no-wrapper/direct branches (auth-setup, model-args, binary-missing, direct Claude) → `write_failure_diag` from the branch sink/stderr/`.diag`, resolve, `append_launch_failure` + `append_vendor_failure_diagnostics` before exit/KV return (F15, mirrors launch-review F8); (B) post-wrapper give-up → carrier exists, resolve + log only.
7. **Health-gate fast-fail** echoes its diagnosis to stderr in addition to `.diag`.
8. **Implement durable path**: one canonical `$IMPLEMENT_TMPDIR/vendor-failure-diagnostics.txt` batch is the **sole** durable implement flush path; all implement review producers append it via `append_vendor_failure_diagnostics` (redacts + atomic temp+`flock`/per-slot staging — F6). A flush helper (sentinel / clear-after-success) runs from `step-7a.sh`, `larch-log-flush.sh`, `refresh-run-logs.sh`, AND `implement-finalize.sh` teardown (F13) before commit. Keep `*.failure-diag` DENIED in `larch-log.sh` `round_artifact_included` (no per-output write-round commit — avoids double-commit; F14).
9. **Log-location resolution**: shared resolver precedence `LARCH_EXECUTION_ISSUES_LOG` → `dirname(SESSION_ENV_PATH)` → IMPLEMENT_TMPDIR → DESIGN_TMPDIR → REVIEW_TMPDIR.
10. **Site-aware logging only in site-aware callers**: generic `launch-claude-subprocess.sh` calls `write_failure_diag` only; execution-issues + batch live in the wrappers that know the tmpdir + site.
11. **Audit + tests**; classify every site directly-fixed | inherits-via-`run-external-agent.sh` | residual-OOS, naming residual {saved, logged, flushed} gaps.

## Edge cases
- Retry-then-success (wrapper and subprocess same-output): entry/start-clear → no carrier (F2/F7).
- `.done` visible ⇒ carrier present for failures.
- Preflight/no-wrapper/binary-missing/direct-Claude branches: ordering A composes the carrier before exit (F8/F15).
- Pre-output Claude failure (no `OUTPUT_CANON`): persist wrapper stderr to `.launcher-stderr` (F10).
- Codex events removed between attempts: filtered events history archived first.
- `--capture-stdout`: base output file is a bounded source.
- Cursor failure whose only evidence is `.result`: bounded failure-only excerpt kept (F12).
- Scout tier reuse: tier-specific stems; raw stems publish-denied (F1/F15).
- Collector retry failure: retry/ns-retry carrier candidates resolved (F9).
- Implement double-commit avoided: batch is the sole durable path; `*.failure-diag` denied in write-round (F14).
- `/dev/null` sidecar no-op; redaction on every committed copy; Bash 3.2 (temp files + `while read`).

## Failure modes
- **Classification corruption.** Reset before verdict could misclassify auth/quota. Signal: `test-launch-review.sh`. Mitigation: verdict before reset (codex+cursor parity); history/carrier never read by classifiers.
- **Publish leak / balloon.** Stale carrier on retry-success, raw JSON/`.result`, scout raw stems, double-commit, or secrets could leak/bloat. Signal: `test-design-log-publish.sh` retry-then-success + redaction-boundary + raw-stem exclusion; `test-larch-log.sh` deny. Mitigation: entry/start-clear, final-failure carrier, error-line filter + failure-only `.result` excerpt, raw-stem deny arms, batch-as-sole-durable-path, line-420 / `larch_log_redact_file` redaction, byte caps.
- **Site-coverage drift.** A site marked "inherits" without a real carrier path stays broken. Signal: audit table + per-site harnesses. Mitigation: central carrier in `run-external-agent.sh`; audit names residual {saved,logged,flushed} gaps.

## Testing strategy
- Unit: composed carrier (Cursor `.result` failure-only, retry candidates, capture-stdout, events history) + resolver + log-resolver precedence + `external_stream_reset` + atomic `append_vendor_failure_diagnostics`.
- Wrapper: `test-run-external-agent.sh` entry-clear + sentinel-trap-ordering + retry-then-success + events archive + capture-stdout + health-gate.
- Launchers/dispatch/coder/scout/collector/code-flow/lint-fix: per-path give-up carrier + non-empty execution-issues + batch (multi-retry, single-attempt, preflight ordering A, no-wrapper, tier reuse, dropped slot, retry, pre-output, failure-then-success, concurrent append).
- Publish/flush: `test-design-log-publish.sh`, `test-larch-log.sh`, `test-step-7a.sh` + implement-finalize.
- Repo: `bash scripts/relevant-checks.sh` / `make lint` (bash32, script-md-siblings, launcher parity, launcher-argv-test-coverage, renderer-substitution-safety).
