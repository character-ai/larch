## Edge cases

- **No session env path:** `_copy_gate_audit_to_parent` should still no-op.
- **Zero drops:** the parent audit should be overwritten with the empty current audit.
- **All security-only drops:** existing behavior should remain. The public audit stays empty and may overwrite the parent public audit.
- **Copy failure:** a failed parent overwrite now raises `PreVoteGateError` even for zero drops. This is correct because stale audit cleanup is part of the invariant.

## Failure modes

- If `gate.dropped_file` is missing, the copy raises through the existing `PreVoteGateError` path.
- If parent audit overwrite fails, downstream readers may see stale content. The existing fail-closed error path should stop that.
