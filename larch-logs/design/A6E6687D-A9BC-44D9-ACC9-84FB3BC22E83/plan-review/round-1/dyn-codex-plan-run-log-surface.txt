1. **[correctness] `<TMPDIR>/plan.txt:71-103`**

   **Concern:** The plan lists `/voter-calibration [--log-root DIR]` as optional, but then says the analyzer exits non-zero when `--log-root` is missing.

   **Why it matters:** A no-arg `/voter-calibration` run should scan the current repo's committed `larch-logs`. The analogous `/fluff-analysis` analyzer defaults to `<git toplevel>/larch-logs` and only errors when that directory is absent.

   **Suggested revision:** Keep `--log-root` optional. Resolve it to `<git toplevel>/larch-logs` by default. Exit non-zero only when the resolved log root does not exist.
