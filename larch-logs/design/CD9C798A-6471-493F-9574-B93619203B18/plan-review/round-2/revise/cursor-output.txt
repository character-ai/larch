### Edge cases
- Trailing slash on macOS `$TMPDIR` (`/var/folders/.../T/`): strip it before composing the path to avoid `//` (production helper and relocation test both use `${var%/}`).
- Round parent does not resolve (round_dir not yet created): `pwd -P` fallback returns the literal parent; real call sites always pass an existing absolute `IMPLEMENT_TMPDIR`, so the result stays stable within a round.
- Pathological `$TMPDIR` under `$PWD`: the relocation target would still sit inside `--add-dir "$PWD"`. Out of scope to fully defend; documented as a precondition. The in-repo test asserts the standard case (snap_dir outside `$PWD`).
- Stale `0444` on deterministic relocated `snap_dir`: a later same-repo/same-round run reuses the path; targeted `rm -f` before redirects prevents silent carryover skew (head redirect fails → `|| rm -f` drops head while tracked-path/patch `0444` files remain).
- `chmod 0444` then re-write within a round: never happens (each artifact written once per round after clear); cross-run reuse is handled by `clear_stale_pre_coder_snapshot_artifacts` / `rm -f` on `post-coder-head.txt` before write.
- MAV subshell without `clear_stale` eval: fails at first production call; mitigated by line-2664 eval (FINDING_1).
- Post-coder mode test on MAV no-changes: vacuous or false failure; mitigated by scoping to orchestrator integration paths (FINDING_2).

### Failure modes
1. Test function extraction breaks: a multi-line helper with a column-0 `}` mid-body truncates the `sed`-range `eval` in `test-review-and-fix.sh`, silently testing a partial function. Earliest signal: the new in-repo assertion or existing carryover-guard cases fail. Mitigation: keep one closing `}` at column 0; keep signature on one line.
2. Relocated-snapshot leak: in-`$PWD` layouts leave read-only snapshots under `${TMPDIR}/larch-pre-coder-snapshots/` that `cleanup-tmpdir.sh` does not remove. Earliest signal: `$TMPDIR` litter across non-standard runs. Mitigation (chosen): per-round targeted clear before write + OS `$TMPDIR` reaping; no broad `${TMPDIR}/larch-pre-coder-snapshots` tree wipe (scope creep).
3. `chmod 0444` blocks cleanup: if a directory were chmod'd `0444`, `rm -rf` could not descend. Earliest signal: round/session cleanup errors. Mitigation: harden files only; `rm -rf` removes read-only files when the parent dir is writable (cleanup-tmpdir.sh:70).
4. Stale `0444` blocks snapshot rewrite: without clear-before-write, relocated reuse leaves hardened files; head redirect fails and carryover state diverges. Earliest signal: stale-0444 regression or carryover-guard false results. Mitigation: `clear_stale_pre_coder_snapshot_artifacts` + `rm -f` before `post-coder-head.txt`.
5. Step5 `clear_stale` undefined in subshell: `mav-apply-relocated-pre-head` exits non-zero under `set -e`. Earliest signal: `step5-starting-round` shard failure immediately after implementation. Mitigation: eval `clear_stale_pre_coder_snapshot_artifacts` at line 2664 (FINDING_1).
6. Vacuous post-coder acceptance: asserting mode `444` on a file MAV never writes. Earliest signal: missing-file failure or false confidence in acceptance criterion 2. Mitigation: assert only on `run_orchestrator_case` / `carryover-orchestrator` (FINDING_2).
