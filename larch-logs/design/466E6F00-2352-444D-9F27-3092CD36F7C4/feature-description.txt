# /implement: collapse Bash-fence rehydration preludes via a session launcher script

**Problem.** Every post-Step-0 Bash fence in `skills/implement/SKILL.md` repeats the multi-line `CLAUDE_PLUGIN_ROOT` rehydration prelude (source guard plus, at some sites, the `LARCH_CLAUDE_PLUGIN_ROOT` awk fallback). The repetition bloats the always-loaded skill body and invites copy drift between fences.

**Proposal.**

- Step 0 (`scripts/implement-bootstrap.sh`) writes an executable `$IMPLEMENT_TMPDIR/larch-run.sh` next to `plugin-root.env`. The launcher sources `plugin-root.env`, falls back to the `LARCH_CLAUDE_PLUGIN_ROOT` awk extract from `session-env.sh` when the sibling is absent, exports `IMPLEMENT_TMPDIR` and `CLAUDE_PLUGIN_ROOT`, then execs `"$CLAUDE_PLUGIN_ROOT/$1"` with the remaining argv.
- Every post-Step-0 fence in SKILL.md becomes one line, for example: `bash "$IMPLEMENT_TMPDIR/larch-run.sh" skills/implement/scripts/step-16.sh`.
- Pre-bootstrap sites (Preflight, Step 0 initial invocation, legacy resume) keep the existing source-guard shape.
- `implement-bootstrap.sh --resume-plan-tail` emits the launcher on legacy tmpdirs the same way it emits `plugin-root.env`.

**Acceptance.**

- Post-Step-0 fences collapse to one line each; `scripts/test-implement-fence-shape.sh` pins the new shape.
- Bash 3.2 portable; no behavior change to any wrapped script.
