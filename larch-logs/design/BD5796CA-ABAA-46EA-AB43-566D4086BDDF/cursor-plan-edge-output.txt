**Findings (numbered)**

1. **[correctness]** `plan.txt` (marker write gating) — Step 5c item 11 reuses the item-10 gate (`PUBLISH_OK=true` + rename), so the marker is not written when the plan is on the issue but publish failed or rename was skipped. A same-session spurious re-fire still has no `[DESIGNED]` title and no marker. **Suggested revision:** Write the marker on `PLAN_WRITE_OK=true` (step 4 success) only; decouple from publish/rename.

2. **[correctness]** `skills/design/SKILL.md:975` / `plan.txt` — Item 10 has no “on non-zero, log Warnings and continue” (unlike Step 0b 5.5). A `tracking-issue-write.sh` failure can prevent item 11 from running, leaving no marker after an otherwise successful publish. **Suggested revision:** Best-effort continue after rename failure, or write the marker before item 10.

3. **[correctness]** `plan.txt` / `scripts/session-setup.sh:234-236` — Marker paths use `$HOME/.cache` while sessions use `XDG_CACHE_HOME`. **Suggested revision:** Reuse `session_cache_root()` for marker paths.

4. **[correctness]** `plan.txt:51` / `scripts/lib-external-launcher-common.sh:103-106` — Proposed `stat -f` before `stat -c` is unsafe on Linux. **Suggested revision:** GNU `-c` first, then BSD `-f`, with numeric validation.

5. **[architecture]** `skills/design/SKILL.md:189-190` / `plan.txt:80` — Sub-step 2.6 `exit 1` omits `SUMMARY_OUTCOME` and the Final summary block used by 2.5 rejects. **Suggested revision:** Add a cancelled/spurious-reentry outcome and run the Final summary block before exit.

6. **[correctness]** `scripts/test-design-structure.sh:761-767` / `plan.txt:86-93` — Check (20) still enforces `2 → 2.5 → 3` only; checks 21–22 are grep-only. **Suggested revision:** Extend (20) for `2.6` ordering.

7. **[correctness]** `plan.txt:50-51` — `touch` without `mkdir -p` can fail on a missing sessions directory. **Suggested revision:** `mkdir -p` parent before `touch`.
