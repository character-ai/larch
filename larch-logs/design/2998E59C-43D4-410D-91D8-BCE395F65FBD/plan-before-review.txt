## Edge cases

- A recipe-less aggregate can hide both pytest and Bash prerequisites. The guard must not accept it as a Bash shard member.
- A multi-command target containing any pytest invocation must not enter the Bash inventory.
- Multi-invocation Bash harness targets must count once while preserving every timing row.
- Historical timing rows may use retired aggregate labels. Treat missing timing for new leaf targets as incomplete evidence, not as zero duration.
- Dependency branches may already have removed paths. Manifest and reference cleanup must use the final merged tree, not the issue’s original inventory.
- The partition guard remains valid if a later measured change adds or removes a numeric shard.

## Failure modes

- Indirect pytest scheduling keeps pytest as an undeclared CI dependency and duplicates `python-tests`.
- Removing a smoke from the manifest can exclude it from shell lint coverage.
- Retaining stale `agent-lint.toml` exemptions can hide dead files.
- Rebalancing from partial or retried timing logs can create a slower shard.
- Updating the workflow without matching Makefile definitions can leave CI invoking missing targets.
