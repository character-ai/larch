## Plan

## Approach

- **Use the Round 1 decisions.**
  - Keep reviewer attribution lines in voter-facing and MAV-facing ballots.
  - Replace only the reviewer value with `anonymous`.
  - Do not scrub body text.
  - Keep `voting.reviewer_for_block` unchanged for legacy callers.

- **Add a proposer sidecar.**
  - Build `proposer-map.tsv` from the attributed ballot immediately before neutralization.
  - Store `item_id`, normalized reviewer label, and the original reviewer line.
  - Use the sidecar for classification, scoreboards, and post-vote artifacts.

- **Rebuild the attributed ballot every round before sidecar write.**
  - `/design`: after aggregation succeeds, always compose voter ballot text from the current round's post-aggregate `findings-in-scope.md` plus OOS content (`oos_md`, or `findings-oos.md` when written).
  - Include both `FINDING_N` and `OOS_N` blocks in the attributed ballot.
  - Do not branch on existing `ballot.txt` or reuse the pre-aggregate `in_scope` variable.
  - Round 2+ must not read a prior neutralized `ballot.txt` as source input.

- **Validate sidecar coverage before dispatch.**
  - Pin map extraction to the same heading regex and block boundaries as `voting.split_ballot`.
  - Fail closed before voter dispatch when any split item ID is missing from the map.
  - Treat sidecar write or coverage validation failure as a hard error.

- **Neutralize before any voter or MAV path can read the ballot.**
  - `/design`: write `proposer-map.tsv`, validate coverage, then rewrite `$DESIGN_TMPDIR/ballot.txt` with `voting.neutralize_reviewer_attribution(...)` before `plan-review voter-dispatch`.
  - `/review` and `/implement` Step 5: after aggregation and prune, write the round sidecar, validate coverage, then neutralize the round `findings.md` before `agent dispatch-voters`.
  - Tally commands default to the tmpdir sidecar only when explicitly intended; stale sidecars from prior rounds must not be reused implicitly.

- **Restore attribution only after voting.**
  - Accepted, rejected, and OOS artifacts should include the original reviewer line.
  - Voter-facing files should keep `anonymous`.
  - When a sidecar is present or explicitly passed, missing map entries for neutralized blocks must fail tally instead of silently scoring `anonymous`.

Add shared helpers beside `reviewer_for_block`:

- `BALLOT_HEADING_RE`.
  - Single source of truth for ballot block headings.
  - Must match `split_ballot` exactly: `^### (FINDING_[0-9]+|OOS_[0-9]+):`.

  - Match only whole structured reviewer lines:

    - `- **Reviewers**: ...`
    - legacy plain `Reviewer:` / `Reviewers:` forms already accepted by `reviewer_for_block`.
- `neutralize_reviewer_attribution(text: str, token: str = "anonymous") -> str`.
  - Preserve the original label form and prefix.
  - Replace only the value after `:`.
  - Leave body text unchanged.
- `proposer_map_from_ballot(text: str)`.
  - Walk blocks using `BALLOT_HEADING_RE` and the same heading-to-heading boundaries as `split_ballot`.
  - Key by `FINDING_N` / `OOS_N`.
  - Value includes normalized reviewer text and the original reviewer line.
- `validate_proposer_map_coverage(ballot_text: str, proposer_map: dict[str, tuple[str, str]]) -> None`.
  - Split the ballot with `BALLOT_HEADING_RE`.
  - Raise a hard error when any split item ID is absent from the map.
  - Call this before voter dispatch in production paths.
- `write_proposer_map(ballot_file: Path, map_file: Path)`.
  - Build the map from attributed ballot text.
  - Run `validate_proposer_map_coverage`.
  - Write TSV header: `item_id\treviewer\treviewer_line`.
  - Sanitize tabs, carriage returns, and newlines.
  - Fail hard on read, validation, or write errors.
- `read_proposer_map(map_file: Path)`.
  - Return an empty map when the file is absent.
  - Ignore malformed rows.
- `proposer_for_item(item_id, block_file, map_file="", sidecar_required=False)`.
  - Prefer the sidecar when present or explicitly required.
  - When the sidecar is present or explicitly passed and the block reviewer line is neutralized (`anonymous`), missing or malformed map entries must raise a tally error instead of falling back to `anonymous`.
  - Fall back to `reviewer_for_block(block_file)` only for legacy attributed ballots with no sidecar, or when the block still carries a non-anonymous reviewer line.
- `reviewer_line_for_item(item_id, map_file="")`.
- `restore_reviewer_attribution(block_text, reviewer_line)`.
  - Replace a neutral reviewer line with the original line.
  - If no reviewer line exists, insert the original line after the heading.
  - Use only for post-vote artifacts.

Do not add vendor substring scrubbing.

## Edge cases

- **Merged findings with multiple proposers**:
  - Preserve the full comma-separated reviewer value in the sidecar.
  - Split only where existing scoreboard logic already splits multi-reviewer labels.

- **Legacy attributed ballots with no sidecar**:
  - Tallies must still read reviewer labels from the ballot.

- **Neutralized ballots with no sidecar**:
  - Production paths must prevent this by treating sidecar write or coverage validation failure as a hard error before dispatch.

- **Sidecar missing one item on a neutralized ballot**:
  - Fail tally when the sidecar is present or explicitly passed.
  - Allow per-item fallback only for legacy attributed ballots with a non-anonymous reviewer line.

- **Body text contains vendor names**:
  - Do not change it.

- **OOS rows**:
  - Include OOS blocks in the attributed ballot before sidecar extraction and neutralization.
  - Restore labels for OOS artifacts and issue-filing audit trails.

- **Multi-round `/design` plan review**:
  - Rebuild attributed ballot text from the current round's aggregated findings every time.
  - Never derive `proposer-map.tsv` from an already-neutralized prior `ballot.txt`.

## Failure modes

- **Sidecar write or coverage validation fails**:
  - Abort before voter dispatch.
  - Do not launch voters with an attributed ballot.

- **Ballot rebuilt from stale source**:
  - Prevent by always reading post-aggregate `findings-in-scope.md` plus current OOS content, never `ballot.is_file()` or pre-aggregate `in_scope`.

- **Neutralization removes too much**:
  - Tests must cover body lines that contain “Reviewer” but are not structured attribution lines.

- **Aggregator still needs reviewer labels**:
  - Neutralize only after aggregation and prune.

- **MAV bypasses normal voter dispatch**:
  - Keep the canonical on-disk ballot neutralized before any MAV branch can read it.
  - Tally uses the current-round sidecar explicitly when defaulting.

- **Stale sidecar reused across rounds**:
  - Validation-exhausted and later-round tallies must build or pass the current map, not inherit an older `proposer-map.tsv` by presence alone.

- **Map parser diverges from `split_ballot`**:
  - Prevent by sharing `BALLOT_HEADING_RE` and validating full coverage before dispatch.
