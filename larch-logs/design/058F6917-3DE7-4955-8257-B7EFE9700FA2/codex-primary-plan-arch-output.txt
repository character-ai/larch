1. **[correctness] `python/review_and_fix.py:2182-2205`; `skills/review-and-fix/SKILL.md:12-24`**

   **Concern:** The cleanup plan can erase pre-existing tracked work.

   **Scenario:** `/review` uses `apply-findings` to apply fixes directly to the current working tree. That tree may already contain the diff under review. If a coder returns `False`, the proposed `git reset --hard HEAD` cleanup drops those pre-existing tracked changes.

   **Suggested revision:** Restore the **pre-coder tracked snapshot** after reset, or only use hard-reset cleanup when the caller has verified a clean tracked baseline.

2. **[correctness] `python/test_review_and_fix.py:354-369`**

   **Concern:** The plan changes MAV from a head-only snapshot to a full snapshot but does not update the existing test.

   **Scenario:** `test_mav_apply_writes_relocated_pre_coder_head_only` currently asserts that tracked and untracked snapshot files do not exist. The proposed MAV change makes them exist, so `make py-test` will fail.

   **Suggested revision:** Update that test to assert the new full snapshot contract.
