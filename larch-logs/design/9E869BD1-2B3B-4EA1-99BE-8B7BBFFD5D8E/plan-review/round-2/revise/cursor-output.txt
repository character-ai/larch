## Plan

This is a packaging change. Gate behavior, prompts, routing, and Python runtime stay unchanged.

Approved scope:

- Split `approval-gates.md` into shared core plus Gate A / B / C slices loaded only at their gates.
- Move Step 3 runtime guidance into `plan-review-runtime.md`, including the Step 3 entry preview contract; keep `plan-review.md` as editing-only authority.
- Split Step 5 green path from failure reporting, with failure-slice wiring on every pre-Step-5 terminal exit.
- Do not slim `discussion-rounds.md` or `design-outline.md`.

## Approach

Split three large reference files so each gate/step loads only the slice it executes. The main wins are unconditional Gate B/C slice reads (no skip-if-loaded on gate slices), Step 3 runtime ownership of preview/large-plan-summary before the entry wrapper emits preview, promoted validation so CI proves closure and pytest regressions, and failure-slice reads on every `failed-*` / Final-summary terminal path.

Key decisions:

1. **Gate slices are always read at their step.** Shared core may use skip-if-loaded when already loaded at Step 1e; Gate B and Gate C slices are unconditional MANDATORY READ at Steps 3.5 and 4b. Gate A slice loads only at Step 1e re-entry.
2. **Step 3 runtime loads before entry.** `plan-review-runtime.md` is MANDATORY READ immediately after the Step 3 breadcrumb and **before** `design-step3-entry.sh`, because `design-step3-entry.sh` invokes `design-step3-entry-preview.sh` internally. Gate C **See full plan** / render-gate re-fire stays in `approval-gates-gate-c.md` only.
3. **Failure slice loads before every terminal failure path.** Retarget the Final-summary-block auto-error anchor (current SKILL.md line ~189) to `finalize-step5-failures.md`. MANDATORY READ that slice immediately before any `failed-*` `SUMMARY_OUTCOME` export/staging and immediately before the Final summary block fence. Green `finalize-step5.md` stays Step 5 happy-path only.
4. **Validation is firm, not optional.** Promote split-sensitive pytest files to `### UPDATED:` and require heatmap evidence or a recorded fallback reason.

## Edge cases

- Gate A re-entry from Gate B(c) or Gate C(b) loads Gate A slice and routes **Ready for review** through single `design-step3-entry.sh --reentry` (runtime slice still loads before entry on that path).
- Default run must not load Gate A slice or `finalize-step5-failures.md`.
- Gate B zero-findings must not load `approval-gates-explicit.md`.
- Gate B post-apply resume must not re-apply findings.
- Gate B/C slice reads are unconditional at Steps 3.5/4b; skip-if-loaded applies only to shared core.
- Gate C `--skip-approve` still runs accepted-findings audit and forces prompt on strong dissent.
- Gate C **See full plan** / Other full-plan paths must not mutate state.
- Step 3 preview must load runtime slice before `design-step3-entry.sh`; must not require Gate C slice or `plan-review.md`.
- Pre-Step-5 terminal exits (clarify, Split-path, Step 3 `final-summary:*`, Step 5c abort) must load failure slice before staging/Final summary; green finalize must not be cited as their authority.
- Step 5 failure reporting stages terminal state only after loading the failure slice.

## Failure modes

- Stale MANDATORY READ on monolith keeps old file eager in closure.
- Step 3 runtime read ordered after `design-step3-entry.sh` leaves preview without normative contract (entry wrapper already emitted preview).
- Step 3 preview left in Gate C/shared core forces wrong eager load or undefined preview after split.
- Skip-if-loaded on gate slices suppresses Gate B/C rules.
- Failure slice not wired to Final summary / `failed-*` paths leaves auto-error reporting on green finalize or unstaged terminal failures.
- Moved sections leave harness pins on monolith variables; missing Gate A default-path negative allows re-entry slice on common path.
- Cross-reference pulls Gate A or failure slice onto common path.
- Slice omits shared invariant from core.
- Closure linter classifies new read as eager without clear conditional wording.
- Promoted pytest fixtures not updated → green CI with broken split.
