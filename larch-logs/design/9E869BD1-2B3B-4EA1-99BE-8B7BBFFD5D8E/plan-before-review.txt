## Edge cases

- Gate A re-entry from Gate B(c) or Gate C(b) must load the Gate A slice and still route Ready for review through the single Step 3 entry fence.
- A default run must not load the Gate A slice.
- Gate B zero-findings must not load explicit-mode content.
- Gate B post-apply resume must not re-apply findings.
- Gate C `--skip-approve` must still run accepted-findings audit and force the prompt on strong dissent.
- Gate C See full plan and Other full-plan paths must not mutate state.
- Step 5 failure reporting must still stage terminal state and run failure-report logic, but only after loading the failure slice.

## Failure modes

- A stale `MANDATORY READ` line can keep the old large file eager in closure.
- A moved section can leave grep-pinned harnesses checking the wrong file.
- A cross-reference can make an agent load Gate A or failure-reporting content on the common path.
- A slice can omit a shared invariant, causing a gate to run with incomplete instructions.
- The closure linter can classify a new read as eager if the SKILL wording lacks a clear conditional prefix.
