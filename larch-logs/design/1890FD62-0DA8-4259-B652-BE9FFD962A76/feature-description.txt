# [OOS] Token recording, NDJSON gaps & research sidecar ingestion — 7 items

## Out-of-Scope Observations — Token recording, NDJSON gaps & research sidecar ingestion

Combined from issues #4092 and #4083.

### Item 1 — Codex drafter sidecar copy failure hidden after billable usage

- **Location**: scripts/launch-codex-drafter.sh
- **Description**: `launch-codex-drafter.sh` copies the raw Codex sidecar to a stable path with `cp || true`, silently swallowing copy failures. If the copy fails after billable usage is written to the raw sidecar, the token record is lost with no operator-visible error. Suggested fix: remove `|| true`, or log and surface the failure explicitly.

### Item 2 — Golden fixtures duplicate the shipped default rate table

- **Location**: python/fixtures/report_tokens_design_golden.md, python/fixtures/report_tokens_implement_golden.md, python/report_tokens_cost.py, python/test_report_tokens_cost.py
- **Description**: `report_tokens_design_golden.md` and `report_tokens_implement_golden.md` embed copies of the shipped default rate table, creating a second authority outside `python/report_tokens_cost.py`. Edits to the canonical table won't update the fixtures automatically, causing silent test drift.

### Item 3 — Unknown TOOL sidecars split NDJSON and active-ledger behavior silently

- **Description**: When `TOOL=` is unknown or malformed, `append_token_record_from_sidecar()` appends a row to `token-report.ndjson` while `record_vendor_from_sidecar` silently skips the active-ledger recording. Live cost displays will be inconsistent with the NDJSON record.

### Item 4 — Python lint-fix Codex usage missing from NDJSON and active ledger

- **Location**: python/checks.py, scripts/lint-fix-loop.sh
- **Description**: The Python ship lint-fix path in `python/checks.py` calls `record-vendor` directly into the active ledger but does not append the Codex launcher `.token-record` to `token-report.ndjson`. The path also lacks `append_token_record_from_sidecar` coverage, so lint-fix Codex usage is absent from the NDJSON stream.

### Item 5 — relevant-checks.sh missing lint-fix-loop harness mapping

- **Location**: scripts/relevant-checks.sh
- **Description**: `scripts/relevant-checks.sh` does not map edits to `scripts/lint-fix-loop.sh` to `test-lint-fix-loop.sh`. Changes to the lint-fix-loop can land without the corresponding harness running. Fix: add a `scripts/lint-fix-loop.sh → test-lint-fix-loop.sh` mapping entry.

### Item 6 — Research/Codex lanes write token-record without ledger ingestion

- **Location**: skills/research/references/research-phase.md:135-150
- **Description**: Research lanes (and other Codex execution lanes beyond the drafter) write `${OUTPUT}.token-record` sidecars, but sidecar ingestion in research phase is prompt-only prose. Research/validation/voter/judge lanes can finish without ledger rows even when sidecars exist.

### Item 7 — Bash-only ship-pr.sh recovery inapplicable to default Python ship driver

- **Location**: python/ship.py
- **Description**: Bash-only `ship-pr.sh` recovery ingestion does not help operators on the default Python ship driver. When `LARCH_SHIP_PR_IMPL` is unset, `python/ship.py` owns CI fix/recovery, so the recovery ingestion logic in the Bash path is a dead code path for most users.
