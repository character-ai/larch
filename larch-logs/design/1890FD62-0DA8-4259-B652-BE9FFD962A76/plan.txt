## Edge cases

- **Copy failure after billable usage**: the drafter continues, but stderr exposes the loss.
- **Unknown `TOOL` with positive totals**: NDJSON append still records the raw sidecar payload, while active-ledger skip becomes visible.
- **Lint-fix launcher failure after billable usage**: NDJSON append and active-ledger ingestion still run before returning the launcher failure.
- **Lint-fix token sidecar exists but append fails**: active-ledger ingestion still runs, and the append failure is visible.
- **Lint-fix active-ledger ingestion fails**: NDJSON append remains preserved, and the active-ledger failure is visible.
- **No `allowed_tmpdir` in `run_lint_fix`**: derive the effective implementation root from `Path(run_parent).resolve().parent`, not `run_parent`.
- **Python runner without shell env prefix support**: active-ledger ingestion receives `IMPLEMENT_TMPDIR` through `runner.run(..., env=...)`.
- **Stale lint-fix explicit ledger**: `LARCH_TOKEN_LEDGER` is removed before active-ledger ingestion so `implement_tmpdir` binds the ledger path.
- **Stale lint-fix session ID**: `LARCH_TOKEN_SESSION_ID` is removed before active-ledger ingestion so `implement_tmpdir/session-id` can bind the ledger slug.
- **Stale lint-fix design or research context**: `DESIGN_TMPDIR`, `RESEARCH_TMPDIR`, and `SESSION_ENV_PATH` are removed before active-ledger ingestion.
- **Consumer repo cwd**: token subprocesses use the plugin-absolute CLI path, not `python/cli.py` relative to the consumer repo.
- **Research standalone session**: `RESEARCH_TMPDIR` can resolve the active ledger.
- **Research inherited implementation env**: the documented ingestion command unsets inherited ledger env so the research ledger is used.
- **Research inherited session ID**: the documented ingestion command unsets `LARCH_TOKEN_SESSION_ID` so the research tmpdir session ID is used.
- **Research retry output reported by collector**: ingest the sidecar next to `REVIEWER_FILE` and also consider the fixed slot path.
- **Research retry sidecar beside derived fixed path**: ingest sidecars next to `${fixed%.txt}-retry.txt` and `${fixed%.txt}-ns-retry.txt`.
- **Research first-pass output after retry**: ingest the original fixed-output sidecar when it exists, even if `REVIEWER_FILE` points at a retry output or the fixed output.
- **Research failed, timed-out, or non-substantive Codex lane**: ingest the sidecar if it exists, because billable usage may already have been written.
- **Research runtime fallback**: Claude fallback lanes keep Claude lane telemetry; Codex sidecars remain best-effort sidecar ingestion.
- **Rate table edits**: snapshot test now follows the canonical table instead of freezing duplicate literals.

- Research docs still rely on prompt-side orchestration to run ingestion commands.
- If `RESEARCH_TMPDIR` lacks a usable `session-id` and no explicit ledger is available, active-ledger ingestion can still no-op as today.
