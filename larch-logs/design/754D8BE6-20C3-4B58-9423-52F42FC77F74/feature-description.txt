# [DESIGNING] Refactor AGENTS.md to be shorter — it currently sits at the Windsurf 12000-cha…

## Problem

`AGENTS.md` is at 11997 bytes after the PR #2653 foreground-markers implementation, which is just 3 chars under the 12000-char Windsurf compatibility limit enforced by `agent-lint`. Adding any further conventions prose (new rules, cross-references, etc.) immediately risks a lint failure.

This came up during the /implement run for issue #2641 — the foreground-markers conventions cross-reference pushed AGENTS.md 1 char over the limit, requiring a trim before checks could pass.

## Goal

Bring AGENTS.md well under 12000 chars so there is room to add future conventions entries without hitting the limit.

## Approaches (pick one or combine)

1. **Move Conventions block to a separate importable file** — Extract `## Conventions` into `.claude/rules/conventions.md` (or `CONVENTIONS.md`) and import it with an `@` line from `CLAUDE.md`. AGENTS.md retains a one-line pointer ("see `CONVENTIONS.md`"). This is the most structural approach and scales as conventions grow.

2. **Trim prose that duplicates SKILL.md / CLAUDE.md** — Several convention bullets in AGENTS.md repeat guidance from `KARPATHY_CLAUDE.md`, `BASH_AUTHORING.md`, or individual SKILL.md files. Identify and remove duplicated content, replacing with a single cross-reference.

3. **Split Honesty and Editing rules into separate files** — These sections (Honesty, Editing rules, Common editing tasks) are stable boilerplate that don't need to be in AGENTS.md proper. Move to a dedicated file imported from CLAUDE.md.

## Acceptance

- `make lint` passes (agent-lint char-limit check green).
- AGENTS.md ≤ 11000 chars (leaves room for ~1000 chars of future growth).
- Existing tests and structure checks (test-design-structure, test-implement-structure, etc.) still pass — no anchors break.
