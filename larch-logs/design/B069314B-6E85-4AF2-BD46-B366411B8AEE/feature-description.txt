That message is the `python/larch/design/design_publish.py:396` branch: `token claude-source` exits non-zero or returns no `TRANSCRIPT_PATH=`. Design publish passes its `--session-id` (a larch run-id, not a Claude session UUID) as `LARCH_TOKEN_SESSION_ID` (`design_publish.py:394`), so the lookup hard-fails every run. Only 1 of 655 design run dirs ever captured a transcript. Implement capture also cliffed: 20 transcripts/day (06-30), 5 (07-01), 0 since, while run volume held. The Step 7a and Step 18 guards skip silently when `LARCH_CLAUDE_SOURCE_FILE` is empty. The reference heatmap (#5871, #5976) stays at zero coverage until this is fixed.
