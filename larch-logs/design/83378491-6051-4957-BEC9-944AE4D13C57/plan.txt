## Files to modify/create

### NEW: `scripts/lib-phantom-probe.sh`

Sourced-only library exposing the `phantom_probe_with_warn` shell function. **Binding to dialectic resolution DECISION_1**: this library is the shared source for the phantom probe + warn + append-failure logic across both wrappers; both wrappers `source` it and call the function. The function emits its phantom KVs through the caller's already-initialized FD-3 quiet stream (`lib-quiet.sh`'s `emit_kv`) — no nested `larch_quiet_init`, no extra `emit_breadcrumb`. Idempotency guard: `LARCH_LIB_PHANTOM_PROBE_LOADED=1` (matches `scripts/lib-dirty-tree-sidecar.sh` lines 3-5 / `scripts/lib-codex-launcher-common.sh` pattern).

Signature: `phantom_probe_with_warn <step-token> <baseline-path> <phantom-paths-dir> <execution-issues-log>`.

Function body invokes `check-phantom-dirty.sh --baseline … --step … --phantom-paths-dir …`, parses `STATUS`/`REASON`/`PHANTOM_COUNT`/`PHANTOM_PATHS_FILE` without `eval`/`source`, branches:
- `STATUS=clean` or `STATUS=tracked-only`: emit `PHANTOM_STATUS=<status>`, return 0 silently.
- `STATUS=phantom`: emit `PHANTOM_STATUS=phantom`, `PHANTOM_COUNT=<n>`, `PHANTOM_PATHS_FILE=<path>`. Invoke `append-execution-issue.sh --log <log> --category Warnings --entry "- **Step <step-token> — phantom untracked files:** <n> file(s) appeared since session baseline (inspect <phantom-paths-file> locally)"`.

  **FINDING_1 binding** — append-execution-issue.sh error parsing: capture both stdout AND stderr (`2>&1` merge or two temp files). Parse `ERROR=<message>` and `FAILED=true` from the combined capture as `emit_kv` lines (`append-execution-issue.sh` initializes lib-quiet at line 11-14 and emits FAILED/ERROR via `emit_kv` to the contract stream at lines 58-79). When the helper exits non-zero AND no `ERROR=` line was found, fall back to the stderr text (if any). Emit `PHANTOM_APPEND_WARN_FAILED=true` plus `PHANTOM_APPEND_WARN_ERROR=<sanitized-message>` (KV-only surface so the wrapper's terminal block carries the secondary warning without a second user-visible line).
- `STATUS=unknown`: emit `PHANTOM_STATUS=unknown`, `PHANTOM_REASON=<reason>`. Invoke `append-execution-issue.sh` with the existing `Step <step-token> — phantom detection inconclusive: STATUS=unknown REASON=<reason>` warning string. Same combined-capture + `ERROR=`-first parsing rule and `PHANTOM_APPEND_WARN_*` surface on append failure.

Function never calls `exit`; only `return` codes (0 = function completed; the wrapper decides the overall exit code from rebase + phantom KVs). The function does NOT call `set -e` or mutate caller traps.

**FINDING_13-style hardening (already accepted as a defensive practice for FINDING_1, kept here even though FINDING_13 was exonerated):** the `<sanitized-message>` token folds newlines via `tr '\n' ' '` before the `emit_kv` call so multi-line stderr/stdout cannot break the contract stream's token parser. This matches `rebase-push.sh`'s existing `REBASE_OUTPUT="${REBASE_OUTPUT//$'\n'/ }"` pattern.

### NEW: `scripts/rebase-checkpoint-probe.sh`

Combined wrapper replacing the four-call-site Rebase Checkpoint Macro. Top-of-file: `set -euo pipefail`, **`SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"`** (FINDING_8 — helpers resolved via `$SCRIPT_DIR/...`, never bare command name), `source "$SCRIPT_DIR/lib-quiet.sh"` + `larch_quiet_init`, `source "$SCRIPT_DIR/lib-phantom-probe.sh"`. Argv:

```
rebase-checkpoint-probe.sh <step-prefix> <short-name> [--base-remote <name>] [--base-ref <branch>]
```

`<step-prefix>` must match `^[A-Za-z0-9_.-]+$` (mirrors `check-phantom-dirty.sh:55`). `<short-name>` is free-text and is single-quoted into the breadcrumb. `--base-remote` / `--base-ref` are optional; when present they pass through verbatim to `rebase-push.sh` (FINDING_4 — caller passes them conditionally on `forked_target=true` at **all 4** sites, not just 1.r). Wrapper does NOT detect forked state itself.

Body in order:
1. `emit_breadcrumb '→ rebase-probe: <step-prefix> <short-name>'` (exactly one).
2. Invoke `"$SCRIPT_DIR/rebase-push.sh" --no-push --skip-if-pushed --keep-on-conflict [--base-remote …] [--base-ref …]`. Capture stdout to a temp file (this is the lib-quiet contract stream — same file used to scan for `SKIPPED_ALREADY_PUSHED`, `SKIPPED_ALREADY_FRESH`, `CONFLICT_FILES`, and per FINDING_1 also `REBASE_ERROR`); capture stderr to a separate temp file (kept only as a defensive fallback when the contract stream is empty); capture exit code to `rc`.
3. Branch on `rc`:
   - **`rc=0`**: parse captured stdout (contract stream) for `SKIPPED_ALREADY_PUSHED=true` BEFORE `SKIPPED_ALREADY_FRESH=true` (precedence preserved — `rebase-push.sh` exits early on already-pushed before fetch).
     - If `SKIPPED_ALREADY_PUSHED=true`: emit `REBASE_OUTCOME=skipped`, `SKIPPED_ALREADY_PUSHED=true`.
     - Else if `SKIPPED_ALREADY_FRESH=true`: emit `REBASE_OUTCOME=skipped`, `SKIPPED_ALREADY_FRESH=true`.
     - Else: emit `REBASE_OUTCOME=ok`.
     Then call `phantom_probe_with_warn "<step-prefix>-post-rebase" "$IMPLEMENT_TMPDIR/untracked-baseline.z" "$IMPLEMENT_TMPDIR" "$IMPLEMENT_TMPDIR/execution-issues.md"` to emit the phantom KV block (including the new `1.r-post-rebase` token uniformly per discussion-round1 Decision 1). Exit 0.
   - **`rc=1`** (rebase conflict): parse captured stdout (contract stream) for `CONFLICT_FILES=<comma-list>` (FINDING_1 — `rebase-push.sh` emits CONFLICT_FILES via `emit_kv` to the contract stream when `--keep-on-conflict` leaves the rebase in progress). Defensive fallback: if no `CONFLICT_FILES` line and there are unmerged paths, set `CONFLICT_FILES=$(git diff --name-only --diff-filter=U | paste -sd ',' -)`. Emit `REBASE_OUTCOME=conflict`, `CONFLICT_FILES=<list>`. Do NOT invoke phantom probe. Exit 1 (orchestrator's existing M2 parse routes to Conflict Resolution Procedure with `caller_kind=early_rebase` unchanged).
   - **`rc=3`** (non-conflict rebase failure): **FINDING_1 binding** — parse REBASE_ERROR from the captured stdout/contract stream first (since `rebase-push.sh` lines 103-228 emit `REBASE_ERROR` via `emit_kv` to the contract stream after `larch_quiet_init`). If no `REBASE_ERROR=` line is in the contract stream, fall back to stderr text (defensive). Emit `REBASE_OUTCOME=failed`, `REBASE_ERROR=<sanitized-message-or-unknown>` (newline-folded). Do NOT invoke phantom probe. Exit 3.
   - **Other rc**: emit `REBASE_OUTCOME=failed`, `REBASE_ERROR=unexpected-rc-<rc>`. Do NOT invoke phantom probe. Exit `$rc`. **FINDING_9 binding**: the orchestrator-side M2 routing branches on whether `REBASE_ERROR` starts with the literal `unexpected-rc-` prefix to select between the two distinct user-visible bail strings (see Region 1 below).

Wrapper does NOT set `STALL_TRACKING` — orchestrator parses `REBASE_OUTCOME` from wrapper stdout and sets `STALL_TRACKING=true` itself on `REBASE_OUTCOME=failed` (preserves Step-18 bail wiring exactly).

KV grammar at terminal block (canonical order; all are `emit_kv` calls — emitted via `lib-quiet.sh` FD-3):

```
REBASE_OUTCOME=ok|skipped|conflict|failed
SKIPPED_ALREADY_PUSHED=true        (only on rc=0 already-pushed)
SKIPPED_ALREADY_FRESH=true         (only on rc=0 already-fresh, after PUSHED check)
REBASE_ERROR=<msg>                 (only on rc=3 / other-rc; `unexpected-rc-<n>` prefix on other-rc)
CONFLICT_FILES=<comma-list>        (only on rc=1)
PHANTOM_STATUS=<status>            (only on rc=0; emitted by lib-phantom-probe)
PHANTOM_COUNT=<n>                  (only on PHANTOM_STATUS=phantom)
PHANTOM_PATHS_FILE=<path>          (only on PHANTOM_STATUS=phantom)
PHANTOM_REASON=<reason>            (only on PHANTOM_STATUS=unknown)
PHANTOM_APPEND_WARN_FAILED=true    (only on append-execution-issue.sh failure)
PHANTOM_APPEND_WARN_ERROR=<msg>    (only on append-execution-issue.sh failure; newline-folded)
```

Cleanup: temp files removed via `EXIT` trap. **chmod +x** required (FINDING_10).

## Approach

The shared library at `scripts/lib-phantom-probe.sh` is the binding consequence of dialectic DECISION_1 (THESIS won 2-1). Both wrappers `source` the library and call the single `phantom_probe_with_warn` function — single source of phantom-probe + append-warn + append-failure logic, no subprocess overhead, no nested `larch_quiet_init`, no extra `emit_breadcrumb`. Idempotency uses the established `LARCH_LIB_PHANTOM_PROBE_LOADED=1` guard.

The combined wrapper preserves orchestrator-side M2 routing by:
1. Exiting with the same exit codes as the original macro (0 success, 1 conflict, 3 non-conflict failure, other = unexpected).
2. Emitting `CONFLICT_FILES=<list>` on `rc=1` from the lib-quiet contract stream (FINDING_1; defensive `git diff` fallback).
3. Emitting `REBASE_ERROR=<msg>` from the lib-quiet contract stream on rc=3, falling back to stderr (FINDING_1).
4. Using `unexpected-rc-<n>` prefix on other-rc so orchestrator can branch the two distinct user-visible bail strings (FINDING_9).
5. Not mutating `STALL_TRACKING` — the orchestrator parses `REBASE_OUTCOME` and sets it.

The `1.r-post-rebase` phantom probe is added per discussion-round1 Decision 1 (uniform invocation; sub-second cost). The standalone wrapper at `phantom-probe-with-warn.sh` is genuinely thin (~40 LOC) but exists for symmetry: the two standalone sites become single foreground-marked invocations. Per-run mid-run Bash call savings: ~6 calls.

Both wrappers and the library use `SCRIPT_DIR`-relative helper resolution (FINDING_8); production code never depends on PATH lookup. Test harnesses use per-test-case temp-dir copies with stub sibling helpers, not PATH injection.

The 6 SKILL.md call-site fences all set `export LARCH_QUIET_BREADCRUMBS=1` (FINDING_12) and use real conditional `BASE_ARGS` shell (FINDING_5) with forked-target argv at all 4 rebase sites (FINDING_4).

## Edge cases

- **`SKIPPED_ALREADY_PUSHED` vs `SKIPPED_ALREADY_FRESH` precedence**: wrapper checks `SKIPPED_ALREADY_PUSHED` first. Test case 2 pins this.
- **`CONFLICT_FILES` missing on `rc=1`**: defensive fallback to `git diff --name-only --diff-filter=U`. Test case 5.
- **`REBASE_ERROR` channel** (FINDING_1): wrapper reads from lib-quiet contract stream first, stderr fallback. Test cases 6 + 6b.
- **`append-execution-issue.sh` ERROR channel** (FINDING_1): library reads from combined capture (stdout + stderr), `ERROR=` line first, stderr fallback. Test cases 11 + 11b.
- **`<step-prefix>` regex**: wrapper accepts `^[A-Za-z0-9_.-]+$`. Free-text `<short-name>` is single-quoted into breadcrumb only.
- **`--base-remote` / `--base-ref` argv pass-through** (FINDING_4): caller (SKILL.md) passes them conditionally on `forked_target=true` at ALL 4 rebase sites via `BASE_ARGS=()` shell idiom (FINDING_5). When absent, do NOT pass empty strings.
- **`append-execution-issue.sh` failure**: surfaces as KVs `PHANTOM_APPEND_WARN_FAILED=true` + sanitized `PHANTOM_APPEND_WARN_ERROR=<msg>`. Wrapper still exits 0.
- **Sourcing `lib-phantom-probe.sh` twice**: `LARCH_LIB_PHANTOM_PROBE_LOADED` guard. Test case 15.
- **`IMPLEMENT_TMPDIR` unset or baseline missing**: `check-phantom-dirty.sh` already returns `STATUS=unknown REASON=baseline-missing-or-empty`. Wrapper surfaces it normally.
- **6 standalone vs combined sites total** (FINDING_16): SKILL.md pointer explicitly states "6 sites total" — 4 combined + 2 standalone.
- **chmod +x** (FINDING_10): new runtime wrappers (`rebase-checkpoint-probe.sh`, `phantom-probe-with-warn.sh`) MUST be 0755. Lib/test files stay 0644.
- **Newline sanitization**: `PHANTOM_APPEND_WARN_ERROR` and `REBASE_ERROR` are folded with `tr '\n' ' '` before `emit_kv` (matches `rebase-push.sh`'s pattern).

## Failure modes

1. **KV-ordering regression** — wrong precedence on `SKIPPED_ALREADY_PUSHED` / `SKIPPED_ALREADY_FRESH` would misreport `REBASE_OUTCOME=skipped`. **Signal**: test case 2 fails. **Mitigation**: case 2 required for `make lint` to pass.
2. **Conflict-path regression** — wrapper accidentally invoking `phantom_probe_with_warn` on `rc=1` would corrupt orchestrator's conflict view during a half-finished rebase. **Signal**: test case 4 fails (asserts no `PHANTOM_*` keys on rc=1).
3. **Wrong-channel parsing regression (FINDING_1)** — wrapper reverts to stderr-only parsing for REBASE_ERROR / ERROR; real failures degrade to `REBASE_ERROR=unknown` / empty `PHANTOM_APPEND_WARN_ERROR`. **Signal**: test cases 6 + 11 fail (stubs emit on the contract stream, not stderr).
