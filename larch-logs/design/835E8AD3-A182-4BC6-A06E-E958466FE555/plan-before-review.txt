## Edge cases

- Match either vendor signal in stderr, sidecar, or relayed launcher text.
- Prefer the model named by the diagnostic. Fall back to the resolved role model when the server message omits it.
- Do not classify generic metadata, authentication, quota, or HTTP 400 errors as an upgrade gate.
- Do not reuse a cached gate reason after a healthy or unrelated failed probe.
- Preserve operator model overrides for the review role while keeping luna as the default probe model.
- Never grant fallback edit authority after a partially mutating failed launch.

## Failure modes

- If gate-detail persistence cannot be read, retain the generic probe-failed explanation rather than inventing a model.
- If launch diagnostics are missing, retain `codex-runtime-failure`.
- If the diagnostic model is malformed, use the already resolved model or `unknown`; never emit control characters into a KV value.
- If Step 2 safety checks fail, bail instead of silently continuing with Claude.
