2. **Stale artifact removal** — on `absent` or `invalid`, unlink any existing regular non-symlink `architectural-guideline-assessment.md` before returning success; **unlink failure exits non-zero** so Gate C cannot approve with a stale artifact.

6. **tmpdir validation** — call `session_env.validate_design_tmpdir` on `--design-tmpdir` (and `$DESIGN_TMPDIR` env fallback) before mkdir, read, write, or unlink.
7. **Sidecar TOCTOU** — re-validate `--assessment-file` as a regular non-symlink file immediately before read; load content into memory once; do not follow symlinks at read time.
8. **Shared clean classification** — fluff-analysis and audit-runs both classify `assessment_kind=clean` when `body.rstrip("\n") == CLEAN_PRESENTATION_NOTE` (imported constant), matching the persist writer's committed clean-note shape.

### Edge cases

- Guidelines absent: persist unlinks stale artifact when possible; no committed assessment; CLI rejects assessment flags; **unlink failure exits non-zero**.
- Guidelines invalid: same unlink behavior; existing chat warning remains sufficient; CLI rejects assessment flags; **unlink failure exits non-zero**.
- Guidelines present, no assessment flag: CLI exits non-zero; Gate C cannot proceed (fail-closed).
- Guidelines present, both flags: CLI exits non-zero.
- Gate C re-entry: present-status calls overwrite `architectural-guideline-assessment.md`; absent/invalid re-entry unlinks stale file when unlink succeeds.
- `--skip-approve`: persists with the same fail-closed contract before auto-approval.
- Deviation draft input: use a `.sidecar` basename so the temporary input file is excluded by `design_log_publish_flow._publish_excluded`; persist immediately after write.
- Sidecar TOCTOU: CLI re-stat's and reads in one shot; orchestrator does not defer persist across turns.
- Symlink target or tmpdir: fail closed before writing the final artifact.
- Missing `$DESIGN_TMPDIR`: CLI exits non-zero instead of writing relative to the repo.
- Persist failure on present guidelines: Gate C halts; operator must repair before approval or publish.
- Persist unlink failure on absent/invalid: Gate C halts; stale assessment must not reach Step 5c publish.
- fluff-analysis zero-finding corpus: coverage section still renders from manifest-enumerated design runs.
- fluff-analysis clean runs with trailing newline: classified as `clean`, not `deviation`.
- audit-runs missing artifact: informational, not fail (many runs legitimately lack the file).

### Failure modes

- If persistence fails when guidelines are present, Gate C stops for repair rather than approve a run that lacks the required audit artifact.
- If persistence fails on absent/invalid sync because unlink of a stale assessment file raises `OSError`, Gate C stops for repair rather than publish a stale assessment from an earlier present-guidelines visit.
- If present guidelines are persisted without an assessment source flag, CLI fails closed before Gate C can approve.
- If the assessment input file cannot be read, return non-zero and surface the error.
- If design-log publish later fails redaction or secret scrubbing, keep existing publish failure behavior.
- If fluff-analysis coverage enumeration hits malformed `manifest.json`, skip that run defensively; do not crash the report.
- If audit-runs finds an empty assessment file, emit `fail` so malformed committed artifacts are visible.
