## Edge cases

- Re-entry after a prior one-down Continue should not re-prompt.
- Re-entry after both-down must still stop, even if `.degraded-tools-gate-prompted` exists.
- Non-interactive one-down without a sentinel must not auto-proceed.
- `/review --subagent` one-down without a sentinel must stop with a prompt-required envelope because it cannot ask the operator.
- Empty `CODEX_PRESENT` or `CURSOR_PRESENT` from Step 0 remains a caller bug signal and should fail safe as down for the Step 0 gate only.
- Legacy callers may still pass `--codex-available`, `--cursor-available`, `--codex-present`, or `--cursor-present`; accept but ignore those values for routing where needed.
- Binary presence is not health. A found binary can still fail and should use existing launcher retry/failure paths.
- Missing or non-executable binaries should fast-fail before probe retries and before outer launch retries.
- `command -v` can find shell functions in some contexts. Prefer executable path checks where practical.
- Embedded plan-review assets and compatibility tests must be updated together.
- Expected reviewer and voter counts must not shrink silently because Step 0 probe health was false.
- Stale source env files from older sessions may contain health globals; do not let them override binary-derived routing.

## Failure modes

- If `session write-design-env` removes too much, later design fences may lose `CLAUDE_PLUGIN_ROOT`, `DESIGN_TMPDIR`, or binary-found state.
- If Step 0 exits non-zero without a clear terminal envelope, the user may see a misleading generic session setup failure.
- If one-down non-interactive runs still auto-proceed, CI can mask degraded reviewer coverage.
- If both-down re-entry honors a stale sentinel, `/design` or `/implement` can continue when the new contract requires refusal.
- If dispatch-code-voters keeps expected judges at 2 or 1, failed external launches may not be reported as degradation.
- If auto-fix or revise-waterfall treats missing binaries as retryable failures, it can waste attempts and time.
- If outer launch retry treats health-probe fast-fail as transient, missing binaries can still burn multiple launch attempts.
- If `CheckReviewersResult.kv_lines()` order changes unexpectedly, shell parsers and tests may fail.
- If embedded plan-review assets are not regenerated or updated, compatibility tests may pass old routing into runtime.
- If review-and-fix exports stale `CODEX_PRESENT=false` / `CURSOR_PRESENT=false`, downstream legacy shell can still skip external fix tiers.
- If docs and shared skill prose diverge, `/review` or `/research` can preserve the old degraded UX.
