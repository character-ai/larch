## Approach

The issue's goal is "no dedicated turn" for two trivial file-setup operations. Each
operation is folded into a fence that already runs on the same path:

- FINALIZE → the Step 3b boundary write. The boundary already runs a bash write on
  every Step 3b path and sits strictly before Step 4. This is the issue's "Step 3b
  tail" suggestion. The Gate C preview alternative was rejected: it runs after Step 4,
  so it would also force Step 4's `rejected-findings.md` read to become
  absence-tolerant — more change, not less.
- SIMPLE sentinels → the Step 2a entry fence, guarded by `design_classification ==
  SIMPLE`. HARD is unaffected; the HARD zero-sketches degraded path keeps its own
  sentinel writes.

`finalize-plan.sh` and `design-driver.sh` are not edited. FINALIZE keeps its own
`.completed/finalize` idempotency sentinel, so a resumed run never double-runs it.

## Edge cases

- HARD run: entry fence reads `HARD`, writes nothing; existing HARD flow intact.
- HARD both-tools-down (zero-sketches degraded): still writes the sentinels on its own
  path (unchanged) — the entry-fence write is SIMPLE-guarded and does not fire.
- Non-architectural plan at Step 3b: after the `architecture-diagram.skipped` write,
  the boundary fence still runs FINALIZE + sentinel.
- Voting skipped (all reviewers clean, no tally): `rejected-findings.md` etc. do not
  exist; FINALIZE touches them at Step 3b so Step 4's read succeeds.
- Gate-B-bypass short-circuits (cap-reached, tally-error, panel-failed, …) that jump to
  Step 3b: Step 3b still runs its boundary fence, so FINALIZE still fires before Step 4.

## Failure modes

1. Ordering regression — FINALIZE folded after Step 4's `rejected-findings.md` read,
   so the read fails when voting was skipped. Signal: Step 4 read error / empty-file
   handling. Mitigation: fold at the Step 3b boundary (before Step 4) and pin
   `ACTION=FINALIZE` to the Step 3b region in the harness.
2. Missing pause-check on the new fence — `assert_bash_fences_have_pause_check` fails
   in CI. Signal: structure test failure "(21) current-design-env source lines missing
   pause-check". Mitigation: copy the canonical two-line prelude verbatim into the new
   Step 3b fence.
3. Resume skips FINALIZE after a failure — step-3b sentinel written even though
   FINALIZE failed, so a resumed run skips re-ensuring artifacts. Signal: missing
   finalize artifact on a resumed run. Mitigation: write `.completed/step-3b` only after
   FINALIZE exits 0; rely on FINALIZE's own `.completed/finalize` sentinel for idempotency.

## Testing strategy

- `bash scripts/test-design-structure.sh` — updated/added assertions green; pause-check

- `bash skills/design/scripts/test-design-pause-resume.sh` — resume at step-2a / step-3b
