### 1. [correctness] `operator_override` preservation vs regeneration wording (`python/larch/lint/lint_complexity_baseline.py:652-653`)

The plan’s writer bullets say to never copy or create `operator_override` during regeneration, and the test plan says regeneration must never emit `operator_override` even when the input row contains one. `migrate_baseline` already preserves operator overrides at lines 652–653. A literal reading of the plan would strip manual overrides on the next `--write`, which breaks acceptance criterion “override silences gate” and I-Gate-1’s intent (writer must not fabricate overrides, not erase operator edits).

**Suggested revision:** Require pass-through of stored `operator_override` on identity match; forbid creation from `--reason` or live rows only; update the test bullet to prove no fabrication while overrides survive merge.

### 2. [correctness] `--write` must validate merged snapshot before disk replace (`python/larch/lint/lint_complexity_baseline.py:707-721`)

Current `_run_write` writes live four-field rows directly at line 721. Piece 2’s merge/repeat-bump work must not replace the committed file until the merged snapshot passes validation and the repeat gate. Failure modes mention this, but the UPDATED writer section should make the ordering explicit and tests should assert byte-stable baseline on rejected writes.

### 3. [correctness] Pin calendar-date validation before window policy (`python/larch/lint/lint_complexity_baseline.py:248-318`)

History and `added_at` validators today accept any non-empty string. The plan adds ISO validation but should pin `YYYY-MM-DD` UTC calendar dates (with `legacy` only on `added_at`) so 14/30-day boundaries and malformed history fail closed before gate or debt calculations.

### 4. [risk-integration] Makefile regen needs `REASON` wiring (`Makefile:89-92`)

`regen-complexity-baseline` still invokes `--write` without `--reason`. After Piece 2, any regen that adds rows or increases metrics needs a nonblank reason; the Makefile target should forward `REASON=` like other ratchet regen targets do for bootstrap reasons.

### [OUT_OF_SCOPE] Shared window helper between gate and debt report

Extracting shared date-window logic is reasonable hygiene but not required for the stated acceptance criteria; defer unless implementation duplicates the math.
