# review dynamic archetype scout was supposed to be replaced by coder making same decisions but it has come back apparently

Apparently, though, either for --emergency mode (with main agent doing the coding) or in general, this optimization was not implemented or does not work.  I do want it though since it will save time AND have the agent with better model AND more familiar with the code change pick optimal dynamic reviewers archetypes, so I expect higher quality AND shorter run time.
