## Edge cases

- **Deleted-only branches:** still run agent-lint and direct checks where applicable.
- **No regular files for pre-commit:** do not silently pass; fail with no-phase semantics unless agent-lint runs.
- **Missing tools:** preserve current warnings for optional Python lint/test direct targets. Keep hard failure for missing `pre-commit` if pre-commit would run.
- **Dangling symlinks:** keep fail-closed tmpdir and log handling.
- **Large logs:** keep streaming marker scan and bounded redaction behavior.
- **Prompt text drift:** update external-fixer prompts so they do not ask agents to run deleted scripts.
- **Sandbox grants:** removing `--codex-add-dir` must not remove the required output-parent `--add-dir` for Codex review output.
- **Case-map parity:** changing a file that mapped to a make target in bash must schedule the same target in Python (minus retired-path rows only).
- **Plugin-session env leakage:** nested harnesses must not inherit plugin `CLAUDE_PLUGIN_ROOT` or quiet-suppression vars.
- **Step 18 finalize restore:** runs without bash selector; stale ship-pr vs finalize-state reconciliation unchanged on Python path.

## Failure modes

- **Stale caller remains:** deleted helper causes runtime failure. Mitigate with `git grep` for every retired path before deletion.
- **Coverage drop:** deleting bash harnesses can hide behavior regressions. Mitigate by moving behavioral cases into pytest before deleting harness targets (especially case-map routing and env scrub).
- **Envelope mismatch:** skills expect old KEY output. Mitigate with CLI tests for exact stdout grammar and `review_and_fix` adapter tests.
- **Gate mis-route after adapter gap:** `_step5_post_round_gates` may skip fixes or stall. Mitigate with capture-dict adapter coverage for all `ChecksResult` / `FixOutcome` branches.
- **Migration lint noise:** retired manifest catches historical docs. Mitigate by removing stale live refs and keeping excluded-path rules intact.
- **Security doc drift:** log redaction or Codex auth claims may become inaccurate. Mitigate by updating `SECURITY.md` in the same change.
- **Live `LARCH_SHIP_PR_IMPL` in step-18-finalize:** DoD grep / structural harness failure. Mitigate by updating finalize script, md sibling, and `test-implement-structure.sh` in the same change.
