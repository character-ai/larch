## Edge cases

- **No plan context:** preserve current guidance. Missing plan context is not an automatic NO for `/review --diff`.
- **Plan does not mandate the deliverable:** keep default-deny. A test or doc that could merely exist remains OOS or NO.
- **Rubric vs lens ordering:** because the rubric is embedded before the archetype lens, both must carry the carve-out; lens-only fixes are insufficient.
- **Voter vs proposer citation:** voters map plan lines silently; reviewer proposers may cite plan lines in finding text. Do not tell voters to quote plan lines in vote output.
- **Generated output omitted:** treat as in-scope only when the plan or generator contract made it required.
- **Pre-rendered drift:** editing agent markdown without refreshing `agents/pre-rendered/*` leaves `/review` and `/implement` serving stale specialist prompts.
- **Calibration false pass:** `render voter` substring tests alone do not satisfy acceptance criteria; executable `dispatch-voters` replay is required.
- **Committed logs omit findings.md:** `python/run_logs.py` `_ROUND_ARTIFACT_DENY_GLOBS` excludes `findings.md`; most implement runs ship `findings-classification.tsv` and run-root `review-findings-full.jsonl` only. Use the reconstruction helper; never assume `round-<N>/findings.md` or `ballot.txt` exists in committed logs.
- **Committed logs omit plan.txt:** implement run logs commit `plan-goals-test.md`, not `plan.txt`. Replay must use committed `fixture_plan` under `plans/`; empty `fixture_plan` or run-log plan discovery produces invalid before/after comparison.
- **Plan-goals-test shape:** frozen plan fixtures must contain the extracted `## Implementation Plan` body only (production-shaped plan text for `agent_voters` bounding), not the Goal preamble or Test plan tail.
- **Jsonl prose truncation:** `compose_review.py` caps `prose_body` at 2000 characters; jsonl-only reconstruction is not production-parity for truncated rows. Commit a frozen ballot fixture for those manifest rows or hard-fail the row.
- **Jsonl heading shape:** jsonl `prose_body` uses a `## title` lead line; production ballots use `### FINDING_N:` headings. The helper must normalize shape before neutralization; prefer committed fixtures when normalization is ambiguous.
- **`v2_tool` / availability mismatch:** replay with both externals true when production used `cursor-plan-fidelity` exercises Codex slot-2 and invalidates before/after comparison; always derive flags from the row's `v2_tool` (and `v1_tool` when needed).
- **Partial dispatch success:** exit code 0 with `VOTER_2_STATUS=skipped|failed`, empty/malformed `*-plan-fidelity-vote-output.txt`, or `VOTER_2_PARSE_RATE_STATUS=NOT_SUBSTANTIVE` must not count as YES or NO; fail the criterion for that row.
- **Diff-required rows:** when the historical cohort vote used diff context, `diff_required=true` and a committed `fixture_diff` are mandatory; replay without the frozen diff is a hard failure for that row.

## Failure modes

- **Prompt contradiction remains:** mini may still follow gate 4's default-test-to-OOS rule if `review-acceptance-rubric.md` is not updated. Fix the canonical rubric first, then mirror in templates and the plan-fidelity lens.
- **Citation/output conflict:** telling voters to cite plan lines in gate 4 or the lens can produce ignored prose, skipped votes, or parser pollution. Use internal mapping only for voters.
- **Generated agents drift:** hand-edited agents may fail sync. Regenerate through `python3 python/cli.py generate <verb>`.
- **Pre-rendered prompts stay stale:** `generate check` passes on agent markdown but live `render specialist` still serves old bodies. Always run `python3 python/cli.py generate pre-rendered-reviewer-prompts` after agent regeneration.
- **Over-broad carve-out:** reviewers may promote optional tests. Limit wording to explicitly plan-mandated deliverables.
- **Calibration replay not executable:** using `render voter` for pass/fail leaves the ~36% → ~20% regression unverified. Use `agent dispatch-voters` with frozen fixtures and parse vote output files.
- **Ballot reconstruction assumes findings.md:** replay hard-fails or diverges when committed round directories lack `findings.md` (the common case). Use manifest-bound fixtures plus jsonl fallback through `calibration_replay.py`.
- **Empty fixture_plan / run-log plan fallback:** allowing empty `fixture_plan` with discovery from `larch-logs/implement/<RUN_ID>/` fails because committed logs have no `plan.txt`. Require non-empty committed plan fixtures for every manifest row and validate before replay.
- **Non-parity replay stack:** ignoring per-row `v2_tool` or setting both availability flags true for all rows can dispatch a different prompt/model path than the baseline cohort and produce bogus pass/fail evidence.
- **Ballot reconstruction drift:** replaying attributed jsonl text without neutralization, or using truncated jsonl bodies for long findings, diverges from production voter ballots and can change votes independent of prompt fixes.
- **Silent partial failure:** counting after-rate when any row has `VOTER_2_STATUS!=launched`, unparseable slot-v2 output, ballot reconstruction failure, or missing plan/diff fixtures masks replay breakage as a calibration win.
