### FINDING_2: Invalid `mechanical_churn` values silently bypass validation
- **Reviewer(s)**: Cursor-Innovation, Cursor-Pragmatic, Cursor-Requirements
- **Severity**: important
- **Concern**: In `lib-plan-optional-trailers.awk`, the upward block scan only accepts `^mechanical_churn: (true|false)$`. For values like `mechanical_churn: 35`, the scan `break`s before `has_mech` is set, so the line is excluded from the optional-trailer block. Parse mode then emits `mechanical_churn=false` (line 4), `has_key` mode reports absent (`exit 1`), and `check-plan-size.sh` validation that only inspects the fourth parse line cannot distinguish invalid-present from absent. Bug 1 can still silently downgrade the diff gate without `PLAN_SIZE_STATUS=invalid-mechanical-churn`.
- **Suggested revisions (informational for voters; coder decides)**:
  - From Cursor-Innovation: For mechanical_churn: 35 the upward block scan breaks on the non-strict line so has_mech stays 0 and parse mode line 4 is false. check-plan-size validation accept only true or false on that line cannot tell invalid-present from absent so Bug 1 can still silently downgrade. Make invalid state machine-readable: e.g. in parse mode emit a sentinel fourth line such as invalid or add a fifth MECH_STATUS line; set has_mech when any ^mechanical_churn: line exists; or have check-plan-size grep the trailer block for ^mechanical_churn: lines not matching ^mechanical_churn: (true|false)$ before size math.
  - From Cursor-Pragmatic: Update `has_key` (and `keys`/`values` if they must reflect presence) in the same awk change: any `^mechanical_churn:` line that is not exactly `true`/`false` counts as present-invalid; pair with stderr `invalid-mechanical-churn:` and a non-boolean parse token that `check-plan-size.sh` rejects.
  - From Cursor-Requirements: Bind the contract: treat ^mechanical_churn: present lines as block members set has_mech=1 and a parse-visible invalid marker (e.g. mechanical_churn=invalid) when the value is not true/false; reject in check-plan-size.sh before sizing
