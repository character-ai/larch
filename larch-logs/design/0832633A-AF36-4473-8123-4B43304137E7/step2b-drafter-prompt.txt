# [BUG] /design Step 5c: orchestrator skips composing composed-plan.md, causing design-publish.sh exit 5

## Summary

In `/design` Step 5c the orchestrator must compose `$DESIGN_TMPDIR/composed-plan.md` (SKILL.md Step 5c item 1) **before** invoking `design-step5c.sh` (item 3). When the orchestrator skips composition and calls `design-step5c.sh` directly, `design-publish.sh` detects the missing file and exits 5. Exit code 5 is outside the expected `{0,1,3,4}` contract, so `design-step5c.sh` stages `failed-publish-tail` and aborts the entire `/design` run as a terminal failure.

## Root cause

- SKILL.md Step 5c items 1–3 are a three-step sequence: (1) compose `composed-plan.md`, (2) optionally validate, (3) call `design-step5c.sh`.
- The orchestrator (main agent) mistakenly called `design-step5c.sh` without first writing `composed-plan.md`, treating the fence as self-contained.
- `design-publish.sh` emits `design-publish.sh: composed-plan.md missing or empty — orchestrator must compose the plan first` and exits 5.
- Step 5c abort-path extracts the final-summary block and stops at `failed-publish-tail` with no recovery option.

## Impact

A valid `/design` run that completed plan review and Gate C approval cannot write `larch:plan` to GitHub. The operator must restart the entire design session. On the run where this was observed, ~90 minutes of review work was completed before the publish step aborted.

## Reproduction

1. Run `/design &lt;issue&gt;` through Gate C (Approve).
2. In Step 5c, skip composing `composed-plan.md` and call `design-step5c.sh` directly.
3. Observe `design-publish.sh: composed-plan.md missing or empty` and exit code 5.

## Recommendation for fix

**Option A (preferred):** Change `design-publish.sh` to exit 4 (the existing plan-command-validator-failure gate) when `composed-plan.md` is missing or empty, rather than exit 5 (unexpected abort). Exit 4 routes through the existing **Fix-and-retry / Override / Cancel** prompt, letting the operator compose the file and retry without restarting.

**Option B:** Add an explicit pre-fence guard in `design-step5c.sh` that checks for `composed-plan.md` and prints a diagnostic before calling `design-publish.sh`, surfacing the missing-file path as a validator defect (rc=4) rather than an unexpected abort (rc=5).

Either option converts a silent session-killing abort into a recoverable validator gate, consistent with the existing plan-command-validator-failure handling at the same Step 5c call site.
