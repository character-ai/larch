# B1 — git/gh/ci primitives: Python consolidation, CLI verbs, bash retirement

## Approach

**Reuse, don't re-port.** The ship-pr port already landed typed libraries (`git.py`, `gh.py`, `pr.py`, `push.py`, `merge.py`, `ci_monitor.py`, `rebase.py`). Several backing functions are only **partial** — they do not preserve the old script's full flag/KV/exit contract. The mapping tables mark each row **have** / **partial** / **gap**. B1's work: expose ~40 CLI verbs, fill gaps/partials at **exact** contract parity, cut over consumers, port harness semantics to pytest, then delete only the bash with zero remaining live callers.

**CLI surface = thin companion modules.** One `*_cli.py` companion per domain holds `<verb>_main(argv) -> int` entrypoints (mirrors `report_tokens_cli.py`). Keep wrappers **thin** — all real logic (including every partial/gap parity function) lives in the typed library modules, never in `*_cli.py`. Register `(domain, verb): (module, func)` rows in `cli.py` `_REGISTRY`; `cli.py` top-level imports stay `argparse`/`importlib`/`sys`.

**Python internals import libraries directly** (`checks.py`, `ci_monitor.py`, `finalize.py`) — they do NOT shell out to `cli.py`. Only external/bash/doc consumers use `python3 cli.py`.

**Bash caller CLI form (FINDING_3-r3 / FINDING_2-r4).** Every bash script caller — root `scripts/*.sh` AND helpers under `skills/**` and `.claude/skills/**` — invokes the CLI through its existing local-root fallback (`$SCRIPT_DIR` / `PLUGIN_ROOT` / `LARCH_ROOT` / `REPO_ROOT`), not the env-only literal: e.g. `PLUGIN_ROOT="${CLAUDE_PLUGIN_ROOT:-$(cd "$SCRIPT_DIR/.." && pwd -P)}"; python3 "$PLUGIN_ROOT/python/cli.py" ...`. Reserve the literal `python3 "${CLAUDE_PLUGIN_ROOT}/python/cli.py"` form for markdown/orchestrator prose where rehydration guarantees the env var.

**Deletion safety — binding retention carve-out (FINDING_1/6/10/15/16/17/18).**
- **First B1 commit (FINDING_15):** upgrade `python/migration_lint.py` (+ test) BEFORE any manifest append or deletion. It matches **manifest full paths** plus `$SCRIPT_DIR/<basename>.sh` **derived from each manifest path** — NOT repo-wide bare-basename substrings (FINDING_17 guards against `run-analysis.sh`-style false positives). Update `docs/python-migration.md` in the same commit.
- **ship-pr blocker = live forms only (FINDING_18):** a match inside `scripts/ship-pr.sh` blocks deletion only for **live invocation/source forms** (`$SCRIPT_DIR/<basename>.sh`, optional `source`/`.` prefix, word-boundary `<basename>.sh` not preceded by `/`), NOT comment/prose mentions. So a non-live comment (e.g. the `scripts/git-current-branch.sh` text at ship-pr.sh) does not force E1 deferral.
- `scripts/ship-pr.sh` stays untouched until E1; its transitive closure (Deferred-to-E1 table) is retained. Those scripts get CLI verbs + non-ship-pr cutover now; deletion + manifest wait for E1.
- All OTHER non-migrating root bash callers ARE in scope.
- **Cutover prerequisite (FINDING_1):** instead of a fixed caller list, `rg` every absorbed basename under `scripts/ skills/ .claude/ docs/ Makefile .github/` (excluding `ship-pr.sh` per carve-out), cut over every live hit, then `make lint-retired-scripts`.
- **Pre/post-delete gates (FINDING_6):** pre-delete grep over repo-relative + `$SCRIPT_DIR` + live bare-invocation forms is the candidate gate; then delete, append manifest, and run `lint-retired-scripts` as the post-delete gate. Closure walks one-hop callers among retained scripts (e.g. ci-wait→ci-status/ci-decide, resolve-repo→github-remote-repo, create-pr→resolve-repo), not only ship-pr.sh.

**Hard cutover, no shims.** Same-change repoint; no `LARCH_*_IMPL` selector.

**Parity gate, then delete.** Run each retargeted `test-*.sh` once against the new CLI; then delete zero-caller scripts + `.sh`/`.md`/`test-*.sh`, append `migrated-scripts.tsv`, run `make lint-retired-scripts`.

**Sequence per `docs/python-migration.md` recipe** (migration_lint upgrade first, then git → push → pr → merge → gh → ci), each its own commit.

## Out of scope (binding)

- `scripts/ship-pr.sh` + inlined copies untouched (E1). Its transitive closure retained until E1.
- `scripts/check-mid-run-dirty-tree.sh` NOT absorbed; phantom verbs shell out to it.
- Hooks stay bash; none reference absorbed scripts.
- **Scope reduction (FINDING_16):** B1 deletes only zero-live-caller scripts; ship-pr-closure scripts get verbs + non-ship-pr cutover, deletion deferred to E1.

## Edge cases

- **Exact parity per script.** Raw-stdout verbs: git-show-stage, gh-pr-checks, resolve-repo, github-remote-repo, gh-run-logs, read-workflow-path, extract-closes, **git count-commits** (integer on stdout + status-file, F5). Always-exit-0-with-status: merge-pr, ci-status, ci-rerun-failed, check-remote-branch, check-phantom-dirty, phantom-probe-with-warn, ci-decide. **NOT always-exit-0:** check-main-sync (0/1/2). **snapshot-untracked**: file-only, no status KV.
- **Exit maps:** force-push 0/1/2; create-pr 0/1/2; rebase-push 0/1/2/3; gh-run-logs 0/1/3; ci-wait 0/1; behind-count fail-open 0 + usage 2; sync-local-main 0/1 only; check-main-sync **0/1/2 (F5)**.
- **KV keys:** branch-info `HEAD_SHA`+`CURRENT_BRANCH` (detached empty, F14); create-pr `PR_TITLE` new+existing (F6); count-commits status-file (F5).
- **phantom split (F8):** `check-phantom-dirty` → STATUS/REASON/PHANTOM_COUNT/PHANTOM_PATHS_FILE only; `phantom-probe`/checkpoint → PHANTOM_* + optional PHANTOM_APPEND_WARN_ERROR.
- **ci status text fallback (F15); ci failed-jobs sanitization (F16).**
- **Deletion safety:** never delete a script with a live reference; migration_lint catches `$SCRIPT_DIR`/manifest-derived forms (live only, F17/F18).
- **`ci wait` full wrapper (F4):** atomic output publish + `.done` sentinel on trap-deliverable exits, ordered KVs, suspend-aware iteration, progress stderr.

## Failure modes

1. **Silent contract drift on cutover.** Verb emits slightly different KV/exit; a `.md` parser, Python internal caller, or ship-pr path breaks at runtime. *Signal:* retargeted `test-*.sh` / CLI-contract pytest fails. *Mitigation:* port white-box semantics 1:1; F5-r2 rewires Python internals to typed calls.
2. **Deleting a script with a live caller.** Breaks `LARCH_SHIP_PR_IMPL=bash`. *Signal:* upgraded `migration_lint`/`lint-retired-scripts` red. *Mitigation:* migration_lint-first commit + retention closure + `$SCRIPT_DIR`-aware live-form gate + manifest before deletion.
3. **Over-matching deletion gate (F17).** Bare-basename substring matching false-positives (the `run-analysis.sh` incident class). *Mitigation:* match only manifest paths + `$SCRIPT_DIR`-derived forms; live-invocation ship-pr blocker; cross-directory false-positive test.
4. **Phantom / execution-issues regression.** Mis-handled `check-mid-run-dirty-tree.sh` subprocess or append layer corrupts `/implement` dirty-tree recovery. *Signal:* `test_phantom.py` / retargeted harness fails. *Mitigation:* highest-risk port; `check_phantom_dirty` side-effect-free; `probe_with_warn` byte-parity append; stub the bash subprocess.

## Testing strategy

- Colocated `python/test_<domain>_cli.py` (KV/raw/exit parity, `RecordingRunner`-injected `proc`); reuse existing library tests.
- `python/test_migration_lint.py` for the upgraded matcher (F1/F15/F17/F18); `python/test_checks.py` + `python/test_ci_monitor.py` for the typed-call rewire (F5); finalize parity test for `remote_branch_state`; `scripts/test-verify-skill-called.sh` Section 5 for count-commits CLI.
- Port white-box semantics from each `scripts/test-<name>.sh` into pytest before deleting (incl. `test-ci-wait.sh`, `test-check-main-sync.sh` exit-2/probe-error, `test-git-push.sh`).
- Parity gate: run each retargeted `test-*.sh` once against the new CLI before deletion.
- Gates green: `make lint`, `make py-lint`, `make py-test`, `make lint-retired-scripts`.
