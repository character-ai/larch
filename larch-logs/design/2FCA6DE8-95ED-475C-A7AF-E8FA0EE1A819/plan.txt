# B1 — git/gh/ci primitives: Python consolidation, CLI verbs, bash retirement

## Approach

**Reuse, don't re-port.** The ship-pr port already landed typed libraries (`git.py`, `gh.py`, `pr.py`, `push.py`, `merge.py`, `ci_monitor.py`, `rebase.py`). Several backing functions are only **partial** — they do not preserve the old script's full flag/KV/exit contract. The mapping tables mark each row **have** / **partial** / **gap**. B1's work: expose ~40 CLI verbs, fill gaps/partials at **exact** contract parity, cut over consumers, port harness semantics to pytest, then delete only the bash with zero remaining live callers.

**CLI surface = thin companion modules.** One `*_cli.py` companion per domain holds `<verb>_main(argv) -> int` entrypoints (mirrors `report_tokens_cli.py`). Keep wrappers **thin** — all real logic (every partial/gap parity function) lives in the typed library modules, never in `*_cli.py`. Register `(domain, verb): (module, func)` rows in `cli.py` `_REGISTRY`; `cli.py` top-level imports stay `argparse`/`importlib`/`sys`.

**Python internals import libraries directly** (`checks.py`, `ci_monitor.py`, `finalize.py`) — never shell out to `cli.py`. Only external/bash/doc consumers use `python3 cli.py`.

**Bash caller CLI form (FINDING_3-r3 / FINDING_2-r4).** Every bash script caller — root `scripts/*.sh` AND helpers under `skills/**` and `.claude/skills/**` — invokes the CLI through its existing local-root fallback (`$SCRIPT_DIR` / `PLUGIN_ROOT` / `LARCH_ROOT` / `REPO_ROOT`), not the env-only literal: e.g. `PLUGIN_ROOT="${CLAUDE_PLUGIN_ROOT:-$(cd "$SCRIPT_DIR/.." && pwd -P)}"; python3 "$PLUGIN_ROOT/python/cli.py" ...`. Reserve the literal `python3 "${CLAUDE_PLUGIN_ROOT}/python/cli.py"` form for markdown/orchestrator prose where rehydration guarantees the env var.

**Deletion safety — binding retention carve-out (FINDING_1/6/10/15/16/17/18 + r5).**
- **First B1 commit (FINDING_15):** upgrade `python/migration_lint.py` (+ test) BEFORE any manifest append or deletion. **F17 (repo-wide path precision):** match manifest full paths plus `$SCRIPT_DIR/<basename>.sh` derived from each manifest path — NOT repo-wide bare-basename substrings (guards the `run-analysis.sh` false-positive class). **F18 (ship-pr blocker, distinct):** classify a `scripts/ship-pr.sh` match as a deletion blocker only for **live invocation/source forms** (`$SCRIPT_DIR/<basename>.sh`, optional `source`/`.` prefix, word-boundary `<basename>.sh` not preceded by `/`), NOT comment/prose mentions (e.g. the `scripts/git-current-branch.sh` text at ship-pr.sh:976). Update `docs/python-migration.md` (currently full-path-only) in the same commit to document both behaviors (FINDING_24-r5).
- `scripts/ship-pr.sh` stays untouched until E1; its transitive closure (Deferred-to-E1) is retained.
- All OTHER non-migrating root bash callers ARE in scope.
- **Cutover prerequisite (FINDING_1):** `rg` every absorbed basename under `scripts/ skills/ .claude/ docs/ Makefile .github/` (excluding `ship-pr.sh`), cut over every live hit, then `make lint-retired-scripts`.
- **Pre/post-delete gates (FINDING_6):** pre-delete grep over repo-relative + `$SCRIPT_DIR` + live bare-invocation forms is the candidate gate; then delete, append manifest, run `lint-retired-scripts` as the post-delete gate. Closure walks one-hop callers among retained scripts.

**Hard cutover, no shims.** Same-change repoint; no `LARCH_*_IMPL` selector.

**Parity gate, then delete.** Run each retargeted `test-*.sh` once against the new CLI; then delete zero-caller scripts + `.sh`/`.md`/`test-*.sh`, append `migrated-scripts.tsv`, run `make lint-retired-scripts`.

**Sequence per `docs/python-migration.md` recipe** (migration_lint upgrade first, then git → push → pr → merge → gh → ci), each its own commit.

## Out of scope (binding)

- `scripts/ship-pr.sh` + inlined copies untouched (E1). Its transitive closure retained until E1.
- `scripts/check-mid-run-dirty-tree.sh` NOT absorbed; phantom verbs shell out to it.
- **`scripts/append-execution-issue.sh` NOT absorbed (FINDING_5/8/11-r5):** `phantom.probe_with_warn` calls it via `proc` only; do NOT port/duplicate it (it owns a security-sensitive locked markdown-mutation path — a separate issue).
- `scripts/implement-finalize.sh` stays bash until E1 (it lives-invokes retained helpers incl. `check-remote-branch`).
- Hooks stay bash; none reference absorbed scripts.
- **Scope reduction (FINDING_16):** B1 deletes only zero-live-caller scripts; ship-pr-closure scripts get verbs + non-ship-pr cutover, deletion deferred to E1.

- **`ci wait` full wrapper (F4):** atomic output publish + `.done` on trap-deliverable exits, ordered KVs, suspend-aware iteration, progress stderr.

## Failure modes

1. **Silent contract drift on cutover.** A verb emits a different KV/exit (incl. dropping usage exits, F13-r5) than the old script; a `.md` parser, Python internal caller, or ship-pr path breaks at runtime. *Signal:* retargeted `test-*.sh` / CLI-contract pytest fails. *Mitigation:* port white-box semantics 1:1 incl. invalid-argv cases; F5-r2 rewires Python internals to typed calls.
2. **Deleting a script with a live caller** (esp. `check-remote-branch` via implement-finalize, F23-r5). Breaks `LARCH_SHIP_PR_IMPL=bash`. *Signal:* upgraded `migration_lint`/`lint-retired-scripts` red. *Mitigation:* migration_lint-first commit + full retention closure (incl. check-remote-branch) + `$SCRIPT_DIR`-aware live-form gate.
3. **Over-matching deletion gate (F17/F24-r5).** Bare-basename substring false-positives (the `run-analysis.sh` class). *Mitigation:* match only manifest paths + `$SCRIPT_DIR`-derived forms; F18 ship-pr live-invocation filter distinct from F17; cross-directory false-positive test.
4. **Phantom / execution-issues regression.** Mis-handled `check-mid-run-dirty-tree.sh` subprocess or wrong append layer corrupts `/implement` dirty-tree recovery. *Signal:* `test_phantom.py` / retargeted harness fails. *Mitigation:* highest-risk port; `check_phantom_dirty` side-effect-free; `probe_with_warn` calls existing `append-execution-issue.sh` (not ported); stub the bash subprocess.
