## Edge cases

- **Single YES voter:** high severity returns `+2` because `1 > 0.5`.
- **Two YES voters:** one high severity returns `+1`; two high severities return `+2`.
- **Three YES voters:** two or three high severities return `+2`; zero or one returns `+1`.
- **NO high severity:** ignored for points.
- **Accepted row with no YES votes:** defensive path returns `+1`; normal tally logic should not produce this.
- **Invalid severity:** counts as non-high.
- **Missing severity with YES vote:** counts as a YES voter but not high, so it cannot inflate points.
