## Approach

Address the three hardening items from OOS issue #3074 in one coherent change:

1. **Item 1 — lib-voter-coverage plan-scope rename.** Rename the file and every public function via `git mv` so the old paths do not ship alongside the renamed ones. Plan-review-specific KV ordering becomes explicit at the symbol level; a future code-review caller hits a missing-symbol error rather than silent KV breakage.
2. **Item 2 — shared `--design-tmpdir` validator, narrowly wired.** Add a new helper `larch_design_tmpdir_validate` that canonicalizes paths via nearest-existing-ancestor resolution (no `mkdir` of untrusted parents) and enforces a documented prefix allowlist (allowlist prefixes also canonicalized; macOS `/private` mapping handled). Wire it into the two OOS-named consumers only: `dispatch-plan-voters.sh` and `tally-plan-review.sh`. The broader `--design-tmpdir` sweep is deferred (reviewers FINDING_6 explicitly recommended deferral; OOS issue body only names these two scripts).
3. **Item 3 — `emit_kv` newline reject.** Make the FD-3 contract robust by rejecting embedded `\n`/`\r` in values. Callers that legitimately need multi-line data must serialize themselves.

All three changes preserve the public contract for well-behaved callers. Grep audit during implementation confirms no current `emit_kv` site passes multi-line values.

The validator algorithm (per FINDING_3, FINDING_4, FINDING_10):

1. Reject empty input with `larch_err` + return 2.
2. Build the canonical allowlist once at first call: `${XDG_CACHE_HOME:-${HOME:-/tmp}/.cache}/larch/sessions/`, `${TMPDIR%/}` (when set), and `/tmp`. Each prefix is itself canonicalized via `cd "$prefix" 2>/dev/null && pwd -P` when it exists, falling back to the literal string otherwise. Append a trailing `/` to each canonical prefix.
3. Walk up the candidate path component-by-component until the deepest existing ancestor is found (`while [ ! -d "$ancestor" ]; do ancestor="${ancestor%/*}"; done`, with `/` as the floor).
4. Canonicalize that ancestor explicitly: `if ! resolved_ancestor=$(cd "$ancestor" 2>/dev/null && pwd -P); then larch_err "parent resolution failed: $ancestor"; return 2; fi`.
5. Concatenate the unresolved tail (the path components walked off) onto `resolved_ancestor` to form `resolved_candidate`. No `mkdir` of untrusted parents.
6. If `resolved_candidate` already exists as a directory, canonicalize the leaf too (`if ! resolved_leaf=$(cd "$resolved_candidate" 2>/dev/null && pwd -P); then larch_err "leaf resolution failed: $resolved_candidate"; return 2; fi`) and use it. If it exists as a symlink to a non-directory, reject. This catches leaf-symlink escapes (FINDING_4).
7. Compare `resolved_candidate` (or `resolved_leaf` when set) against each canonical allowlist prefix using `case "$resolved" in "$prefix"*)` — quoted prefix literal, only the trailing `*` unquoted (FINDING_9).
8. On no match, `larch_err` naming the resolved path and the allowlist; return 2.

The validator never modifies the filesystem. Callers `mkdir -p "$DESIGN_TMPDIR"` themselves only after validation succeeds.

The `voter_coverage_*` rename uses `plan_voter_coverage_*` (full prefix replacement). One production sourcer needs updating. Both REWRITTEN entries are implemented as `git mv` operations so the old paths do not ship (FINDING_8).

## Edge cases

- `--design-tmpdir` empty string. Validator returns 2 with `empty path` message; consumers' existing argv check already requires non-empty.
- `..` segments. Nearest-existing-ancestor walk + canonicalize resolves them — e.g., `/tmp/foo/../etc` becomes `/etc` after canonicalization and fails the allowlist.
- Parent symlink pointing outside the allowlist. Canonicalization via `cd && pwd -P` exposes the true location.
- **Leaf symlink** pointing outside the allowlist. When the candidate leaf exists, the validator canonicalizes it explicitly (or rejects a symlink-to-non-directory leaf). FINDING_4 regression case included in the harness.
- `$TMPDIR` unset. Allowlist skips that prefix; `$XDG_CACHE_HOME` / `$HOME/.cache/larch/sessions/` and `/tmp` still accepted.
- `$XDG_CACHE_HOME` set to a non-standard location. Validator accepts paths under it.
- macOS `/tmp` paths. `cd /tmp && pwd -P` returns `/private/tmp`; allowlist prefix is canonicalized the same way so they match.
- Fully non-existent candidate path. Walk up to deepest existing ancestor; canonicalize that; append unresolved tail; check prefix. No `mkdir` happens.
- All-existing-path. Leaf canonicalization runs and is used for the prefix check.
- `emit_kv` value with literal `\n` text (two characters: backslash + lowercase n). Allowed; the reject is for actual control bytes only.
- `emit_kv` long single-line value. Allowed; no length cap is added.
- `emit_kv` value containing `=` characters. Allowed; consumers split on first `=`.

## Failure modes

1. **Trailing-slash mismatch in canonical prefix.** Canonical `$TMPDIR` may include a trailing slash on some shells. Normalize via `${tmpdir%/}/` at allowlist construction. Earliest warning: harness covers trailing-slash variants.
2. **`emit_kv` reject breaks a hitherto-tolerant caller.** A caller might pass a value with a trailing newline. Mitigation: pre-flight `grep -rn 'emit_kv' scripts/ skills/` during implementation; fix any caller that constructs values from raw multi-line sources. Earliest warning: CI `make lint` and the extended `scripts/test-lib-quiet.sh` cases.
3. **`git mv` rename misses a call-site or doc reference.** Post-rename `grep -rn 'voter_coverage_\|lib-voter-coverage' scripts/ skills/ docs/ .github/` audit; update every match. Earliest warning: `make lint` (drift-prone-prose hook) and reviewer audit during /implement.
