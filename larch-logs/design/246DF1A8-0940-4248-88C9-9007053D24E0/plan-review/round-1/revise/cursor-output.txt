## Edge cases

- **Same-directory basename lint**: after manifest updates, `make lint-retired-scripts` will flag bare legacy basenames in sibling docs. Fix by rewriting the prose, not by adding ignores.
- **Survivor shell wrappers**: `create-pr.sh`, `merge-pr.sh`, `rebase-checkpoint-probe.sh`, and `lib-phantom-probe.sh` stay. Only repoint their internals. Survivors use `python3 "$SCRIPT_DIR/../python/cli.py" …`, not `${CLAUDE_PLUGIN_ROOT}`.
- **Phantom warning duplication**: do not keep shell append logic when delegating to `cli.py git phantom-probe`.
- **Push domain**: use `cli.py push branch` and `cli.py push force`. Do not route these through `cli.py git`.
- **Quiet / machine stdout**: register retired git/push verbs in `_MACHINE_STDOUT_KEYS` before cutover. Without that, quiet parents mis-route `PUSHED`/`STATUS`/`COMMITTED`/etc.
- **Argument-error parity**: some legacy scripts intentionally returned `0` on parse errors. Preserve those cases where callers rely on fail-open behavior.
- **Legacy stderr prefixes in Python**: strings like `git-commit.sh:` and `git-push.sh:` in `python/git.py`, `python/push.py`, and pytest assertions are intentional parity output. Do not remove them to satisfy reference checks.
- **Docs references**: update prose references before adding paths to `migrated-scripts.tsv`, or retired-script lint will fail.

## Failure modes

- **Deleted helper still referenced**: `make lint-retired-scripts` fails. Use `rg` on full retired paths (`scripts/<name>.sh`, `$SCRIPT_DIR/<name>.sh`, `${CLAUDE_PLUGIN_ROOT}/scripts/<name>.sh`) and fix live consumers. Do not grep bare basenames; that conflicts with required stderr parity strings in Python.
- **Quiet stdout regression**: if `push force`/`push branch` or other contract verbs are not in `_MACHINE_STDOUT_KEYS`, `merge-pr.sh` mis-parses force-push recovery and `create-pr.sh` can leak push keys into `PR_*` stdout.
- **Survivor `CLAUDE_PLUGIN_ROOT` regression**: `rebase-checkpoint-probe.sh` calling `${CLAUDE_PLUGIN_ROOT}` fails under `set -u` in copied-harness runs. Use `$SCRIPT_DIR/../python/cli.py`.
- **Coverage loss**: deleting bash harnesses without pytest replacements may hide parity regressions. Add pytest first.
