### 1. [correctness / blocking] Remove parallel Claude launch on the Cursor path

**Location:** `python/agent_voters.py:397-404`

**Concern:** Today `dispatch_voters` always calls `_launch_claude_voter` before the waterfall. The plan assigns slot 1 to `cursor-validity` when Cursor is available but does not explicitly drop that Claude launch.

**Scenario:** Claude plus three Cursor voters run together. Slot 1 gets Claude output while `v1_tool` is `cursor-validity`. Quorum, attribution, and cost goals all break.
