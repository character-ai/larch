## Edge cases

- Cursor available, Codex unavailable: still launch all three Cursor voters at fixed slots via `dispatch-waterfall --no-fallback`; no `_launch_claude_voter`; no Codex backfill on middle-slot failure.
- Cursor unavailable, Codex available: launch only the Claude fallback voter at slot 1; slots 2–3 skipped with empty paths.
- Middle-slot failure (for example plan-fidelity): slot 3 votes remain under `v3_*`; `v2_tool` stays `cursor-plan-fidelity` with empty rating cells; `EFFECTIVE_VOTERS` excludes the failed slot; no Codex voter file appears.
- Claude fallback with one populated file and two empty placeholder paths: `EFFECTIVE_VOTERS=1`, binding-single thresholds, not 2-of-3.
- One Cursor archetype fails or returns narrative output: reduce effective quorum and emit degraded-panel warning without column shifting or Codex backfill.
- No plan file for plan-fidelity voter: use diff and ballot scope; do not auto-reject.
- Parse-rate retry on slot 2/3 must use the archetype prompt for that slot, not legacy codex/cursor prompt files.
- `cursor-validity` (and other `cursor-*` labels) must normalize to `cursor` before `launch_voter_retry`.
- MAV re-tally after 0-judge round: one `--voter-files` (`voter-main-agent.txt`), no `--voter-tools`; must not hit three-slot validation; stays 18-column.
- Zero-findings `emit_zero_findings_branch`: one empty `--voter-files` entry, no `--voter-tools`; must not hit three-slot validation.
- Legacy callers passing two or three `--voter-files` without `--voter-tools`: keep compacted semantics unchanged.
- All three Cursor voters fail on normal dispatch: `review-core.sh` still passes three empty `--voter-files` plus three `--voter-tools` so tally reaches `main-agent-required` with fixed-slot 21-column placeholders.
- Claude fallback slot 1 failure: `DISPATCH_OK=false` is acceptable; tally proceeds to main-agent-required without misclassifying as full panel-init failure when slots 2–3 were skipped by design.
- Historical TSVs without `vN_tool` or with 18 columns: readers (`fluff-analysis`, tally legacy path) must continue to tolerate them.

## Failure modes

- If implementer keeps `_launch_claude_voter` on the Cursor-available path, four judges launch, Claude votes land in `v1` while `v1_tool` expects `cursor-validity`, and `ALL_OUTPUT_*` keyed on `tool=cursor` can overwrite slot paths. Explicit branch dispatch is the mitigation.
- If all Cursor archetype voters fail, tally reaches the existing main-agent-required path.
- If Claude fallback fails, tally also reaches the existing main-agent-required path.
- If `cursor-*` labels are not normalized before retry, parse-rate retry fails with unknown voter tool. The voting helper test should catch this.
- If `review-core.sh` compacts surviving voter paths on the normal dispatch path, `v2_*`/`v3_*` analytics corrupt silently. Fixed three-slot arrays are the mitigation.
- If `tally-code-votes.sh` derives quorum from `${#VOTER_FILES[@]}` in the preamble or 0-judge branch, empty placeholder slots inflate thresholds. Substantive-slot counting everywhere on the three-slot path is the mitigation.
- If tiered validation requires `--voter-tools` whenever multiple `--voter-files` are present, legacy two/three-file callers without tools break. Omit-tools legacy path is the mitigation.
- If bash header/row writers drift from `CODE_REVIEW_FINDINGS_CLASSIFICATION_HEADER`, new logs break readers/tests. Shared `code-review-classification-header` CLI plus 21-field row writes are the mitigation.
- If code-review rows add `body_severity` or switch to `finding_reviewers`, consumers break without voter-identity benefit. Minimal 21-column schema is the mitigation.
- If `dispatch-waterfall` loses `--no-fallback`, failed Cursor slots can spawn Codex voters. Preserving `--no-fallback` is the mitigation.
- If `parse_impl_tsv` stays index-based, new 21-column logs misread severities in `/fluff-analysis`. Header-name parsing is the mitigation.
- If `DISPATCH_OK=false` still keys off lone slot-1 failure on Claude fallback, audit surfaces misreport recoverable single-judge rounds as panel-init failures.
- If `skills/implement/SKILL.md` Step 5 IMPORTANT prose is not updated, operators still see retired Claude+Codex+Cursor voter documentation after the banner ships.
