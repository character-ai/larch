## Edge cases

- Cursor available, Codex unavailable: still launch all three Cursor voters at fixed slots.
- Cursor unavailable, Codex available: launch only the Claude fallback voter at slot 1; slots 2–3 skipped with empty paths.
- Middle-slot failure (for example plan-fidelity): slot 3 votes remain under `v3_*`; `v2_tool` stays `cursor-plan-fidelity` with empty rating cells.
- One Cursor archetype fails or returns narrative output: reduce effective quorum and emit degraded-panel warning without column shifting.
- No plan file for plan-fidelity voter: use diff and ballot scope; do not auto-reject.
- MAV re-tally after 0-judge round: one `--voter-files` (`voter-main-agent.txt`), no `--voter-tools`; must not hit length-3 validation.
- Zero-findings `emit_zero_findings_branch`: one empty `--voter-files` entry, no `--voter-tools`; must not hit length-3 validation.
- Historical TSVs without `vN_tool` or with 18 columns: readers (`fluff-analysis`, tally legacy path) must continue to tolerate them.

## Failure modes

- If all Cursor archetype voters fail, tally reaches the existing main-agent-required path.
- If Claude fallback fails, tally also reaches the existing main-agent-required path.
- If a `cursor-*` label is not normalized before retry, parse-rate retry can fail with an unknown voter tool. The voting helper test should catch this.
- If `review-core.sh` compacts surviving voter paths on the normal dispatch path, `v2_*`/`v3_*` analytics and point-competition attribution corrupt silently. Fixed three-slot arrays are the mitigation.
- If `tally-code-votes.sh` applies length-3 validation to all `--voter-files` callers, MAV re-tally and zero-findings recovery break binding-single adjudication. Tiered validation is the mitigation.
- If `parse_impl_tsv` stays index-based, new 21-column logs misread severities in `/fluff-analysis`. Header-name parsing is the mitigation.
