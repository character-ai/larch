# Implementation Plan: Stop the /design scope-creep ratchet (#3512)

Three coupled loop-level changes, plus the operator-chosen full removal of the `--manual` surface, with KV plumbing and step-boundary contracts for merged drift.

## Approach

Three threads, all in the `/design` Step 3 review path:

1. **Remove inter-round auto-apply → single review pass.** `plan-review-loop.sh`'s multi-round path revises `plan.txt` between rounds via `revise-plan-with-waterfall.sh` and re-reviews the bloated result (loop body lines ~1728-1887). Delete the revise / post-apply / loop-again machinery so each Step 3 entry runs exactly one review round and never revises the plan. Gate B (Step 3.5) becomes the sole apply point. Keep the richer single-round error handling (`panel-failed`, `tally-error`, `degraded-empty-collector`, zero-findings, `main-agent-vote-required`).

2. **Add a cumulative drift guard at Step 2b.5.** Capture a tier-agnostic baseline (plan body lines + diff estimate) once at the initial Step 2b. On later Step 2b.5 runs (after each Gate B apply, after discussion-round2), compare the current plan against that baseline. When growth exceeds a multiple (`LARCH_DESIGN_DRIFT_MULTIPLE`, default `2`), surface it to the operator with an `AskUserQuestion` (Continue / Cancel) and block silent auto-continue. The drift guard backstops the residual ratchet across Gate-C "Re-run review panel" loops.

3. **Remove `--manual` / `-m` / `manual_gate_b` entirely** (operator decision). With no auto-apply on either tier, the `manual_gate_b=false` auto-apply branch is deleted; Gate B always presents accepted findings for explicit operator choice.

4. **Wire drift through the merged post-plan fence.** Gate B apply and discussion re-emits use `design-postplan-emit.sh --with-plan-size`, not standalone Step 2b.5. Extend `_postplan_finish_merged_plan_size` (after hard/partition checks, before under-threshold rc 0) to parse `DRIFT_*` KVs and exit **14** when `DRIFT_TRIGGER_FIRED=true`; mirror the Step 2b.5 Continue/Cancel prompt in `SKILL.md`, `approval-gates.md`, and `discussion-rounds.md` case arms.

Reuse decisions (keep the change minimal):
- Drift logic lives in the existing `check-plan-size.sh` + Step 2b.5 plumbing, not a new helper.
- Baseline is written by `design-postplan-emit.sh --snapshot-original` on **both** tiers **after** `_postplan_run_plan_size` (not inside the early snapshot block) — fixing the SIMPLE gap where `plan.txt-original` is HARD-only today (`design-postplan-emit.sh:457`) and ensuring `PLAN_LINES` / `DIFF_LINES` are populated before write.
- Drift-cancel reuses `SUMMARY_OUTCOME=cancelled-sprawl` (drift is sprawl) — no new render-final-summary outcome.
- The **outer** Gate-C re-review counter (`review-round-count.txt`, tier cap SIMPLE=3 / HARD=5) is unchanged — only the **inner** auto-apply loop is retired.

Coordination: the issue-anchoring sibling also edits `plan-review-loop.sh` but in the scope-anchor materialization region (lines ~140-200); this change edits the loop body (revise/convergence, lines ~1728-1887). No logical overlap, but expect a textual merge.

## Edge cases

- **Baseline missing** (resumed pre-upgrade run, or `drift-baseline.env` unreadable): `check-plan-size.sh` emits `DRIFT_TRIGGER_FIRED=false`; Step 2b.5 skips the drift branch. No crash.
- **Initial Step 2b.5**: baseline just written, current == baseline, ratio = 1 → no drift trigger.
- **Both hard size trigger and drift fire**: hard size trigger wins (Split / Cancel, no Continue). Drift branch only fires when `HARD_TRIGGER_FIRED=false`.
- **`--manual` on argv after removal**: rejected as an unrecognized flag by `parse-design-argv.sh` (hard error before Step 0), matching the documented allowlist behavior.
- **`manual_gate_b` present in a stale `run-params.json`** (resumed run): harmless — all readers removed including `design-route.sh` resume; Gate B always prompts; resume env refresh never passes `--manual-requested`.
- **Zero baseline** (`diff_lines: 0` or empty plan body at Step 2b): later nonzero growth triggers drift via the zero-baseline rule without divide-by-zero.
- **Merged emit under hard/partition caps but over drift multiple** (main Gate B ratchet path): `_postplan_rc=14` surfaces Continue/Cancel — not silent `exit 0`.
- **Single-pass zero-findings**: empty `accepted-plan-findings.md` → Gate B zero-findings short-circuit (unchanged) → Step 3.6 (HARD) → Step 3b.
- **`LARCH_DESIGN_DRIFT_MULTIPLE` invalid** (non-numeric / ≤0 / leading zero): fall back to default `2` with no error (mirror the `LARCH_DESIGN_PLAN_SUMMARY_THRESHOLD` coercion pattern).
- **Drift Continue without step-2b.5 sentinel**: pause/resume treats plan-size check incomplete; mitigated by mandatory `.completed/step-2b.5` touch on all drift Continue arms.

## Failure modes

- **Branch-matrix drift between SKILL.md and the reduced `LOOP_STATUS` enum.** Earliest signal: `test-design-structure.sh` / `test-step3-orchestrator-fence.sh` fail on the status regex. Mitigation: update the enum regex and the branch matrix in the same commit; the harness pins both.
- **Step 0-pre KV-count desync.** Removing `MANUAL_REQUESTED` without flipping `8 → 7` aborts every `/design` run at Step 0-pre ("success output was incomplete"). Earliest signal: `test-parse-design-argv.sh` + a live argv parse. Mitigation: edit `parse-design-argv.sh`, the SKILL.md Step 0-pre block, and `test-step0b-router-flag-recovery.sh` together.
- **parse-design-argv.md eight-KV drift.** Doc still mandates eight KVs while stdout emits seven. Mitigation: update `parse-design-argv.md` (and `test-parse-design-argv.md` if pinned) in the same commit as the script.
- **Drift baseline written on the wrong call or before plan-size.** If the baseline is (re)written on a non-initial emit or before `_postplan_run_plan_size`, drift ratios stay ~1× and never fire. Mitigation: gate write on `--snapshot-original` + write-once + post-`_postplan_run_plan_size` only; harness asserts re-emit without `--snapshot-original` does not touch `drift-baseline.env` and snapshot path emits non-empty baseline KVs.
- **Merged drift exit 14 without KV plumbing.** `DRIFT_TRIGGER_FIRED` never binds if `parse_kv_from_output` / `_postplan_build_kvs` omit `DRIFT_*` / `BASELINE_*`. Mitigation: extend both helpers (mirror `HARD_TRIGGER_FIRED`) and add `test-design-postplan-emit.sh` drift-exit-14 case.
- **Merged fence omits drift exit 14.** Gate B growth past drift multiple silently continues. Mitigation: update `_postplan_finish_merged_plan_size`, `approval-gates.md`, `discussion-rounds.md`, and `SKILL.md` case arms together; add `test-design-postplan-emit.sh` drift-exit-14 case.
