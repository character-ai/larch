**What:** Port `skills/implement/scripts/slack-issue-announce.sh` (~92 lines) to Python behind `cli.py` (stdlib `json` + `urllib.request`).

**Why:** A self-contained, non-thin utility with zero `cli.py` delegation: it reads KV session files via awk, builds JSON via `jq`, and POSTs to a webhook via `curl`. Trivially expressed with stdlib. Overlooked by the migration.

**Evidence:** Step 16a optional Slack notification; reads `$IMPLEMENT_TMPDIR` state; gated on `LARCH_SLACK_WEBHOOK_URL`; has a `__LARCH_FAKE_CURL` test seam.

**Scope:**
- New `cli.py` verb.
- Preserve skip-when-webhook-unset behavior, `--best-effort` semantics, numeric `ISSUE_NUMBER` validation, and the KV / STATUS output grammar.
- Replace the fake-curl seam with an injectable transport for tests.
- Migrate `test-slack-issue-announce.sh` to pytest.
- Delete the `.sh`; record in the manifest.

**Acceptance:** posted / skipped / failed statuses match; webhook-unset and issue-not-set skips preserved; best-effort exit-0 path preserved.
