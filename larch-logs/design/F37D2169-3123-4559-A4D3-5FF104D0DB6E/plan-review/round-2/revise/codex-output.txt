### Edge cases

- Invalid, stale, malformed, unsafe, duplicate, or unknown-kind waivers fail closed.
- A waiver cannot affect violations, authored deviations, stale assessments, or requests.
- Reconciliation writes nothing before a merged PR probe succeeds.
- Reconciliation cannot return success while any state layer retains `STALL_TRACKING`, `STALL_STEP`, `BAIL_NEEDS_USER_INPUT`, `BAIL_REASON`, `IMPLEMENT_BAIL_REASON`, `BAIL_FAILURE_DETAIL_LOG`, a nonterminal `EXIT_CODE`, or `FAILED_RUN_ID`; it also fails if terminal finalize data is stale or manifest postconditions fail.
- A proven merge overrides forked-dry-run classification without removing fork metadata.
- Failed reconciliation blocks Steps 16–18, even if some artifacts were already written.
- Post-merge durable record changes remain uncommitted until the required reviewable repair PR; no post-merge commit amends the merged implementation PR.
- Lost in-context body does not authorize durable-cache reconstruction.
