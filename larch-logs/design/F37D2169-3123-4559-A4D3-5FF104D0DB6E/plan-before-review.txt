   - Write `assessment-operator-waiver.json` with contained, atomic, no-follow I/O.

   - Keep the invariant-violation branch first and unchanged.

   - Write the normal post-merge sentinel.
   - Update the existing run-log manifest to `status=done` with `pr_number`.
   - Make reruns converge and verify written postconditions.
   - Leave report rendering to Steps 16 through 18.

   - For `architectural-assessment-unavailable`, ask whether to proceed or stop.
   - On proceed, write the waiver and relaunch the existing Step 8 ship bgjob start/wait pair.
   - On stop, use the existing Step 12d bail flow.
   - For every approved recovery, block Steps 16 through 18 until recovery finishes.
   - Require manual merge recovery to end with `ship reconcile-manual-merge`.

   - Carry the cached-body obligation into the next turn.
   - Emit the in-context body before responding to the intervening user message.
   - Keep the no-Read and no disk-backed-cache rules.
   - If the in-context cache is unavailable, point to the tracking comment and stop.

## Edge cases

- A waiver with the wrong run ID, unknown kinds, malformed JSON, unsafe path, or wrong schema is ignored by the gate and cannot disarm it.
- A waiver for one unavailable kind does not waive another unavailable kind.
- A waiver cannot affect an invariant violation, authored deviation, stale assessment, or assessment request.
- Relaunch after waiver preserves ship counters and restarts at `pre-pr-compose`.
- Reconciliation rejects any PR not proven merged by GitHub.
- Reconciliation remains safe when state contains counters, branch metadata, or future unrelated keys.
- Reconciliation clears stale stall and bail rows so outcome normalization cannot retain `stalled`.
- Reconciliation is idempotent after partial completion.
- Explicit `--step17-emitted false` overrides a stale sentinel, but does not force output when snapshot comparison says the refreshed body is unchanged under the normal no-Step-17 case.
- A lost in-context body does not authorize reading a deleted or durable file to recreate terminal chat output.

## Failure modes

- Waiver write failure returns `WAIVER_STATUS=failed`, leaves no published partial JSON, and blocks reship.
- Unsafe waiver or state artifacts fail closed.
- GitHub probe failure returns `RECONCILE_STATUS=failed` without claiming merge completion.
- A state, sentinel, or manifest write failure returns failure with a stable reason. A rerun converges from any already-written valid artifact.
- Manifest reconciliation cannot report success unless `status=done` and `pr_number` re-read correctly.
- Sidecar waiver marking cannot silently corrupt the existing assessment receipt.
- Step 18 still surfaces render failures through `WFR_RC` and `ERROR`.
- If a turn boundary loses the in-context cache, the orchestrator reports the tracking-comment location and emits no reconstructed body.
