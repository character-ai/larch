## Findings

### 1. [blocking / correctness] `test-classify-bump` evades the partition guard

`Makefile:353-354` runs both `python/test_version_bump.py` and `python/test_release.py`. The guard's `extract_pytest()` only records the first `.py` path (`scripts/lint-harness-pytest-partition.py:128`), so `python/test_release.py` is invisible to `ENFORCED` checks. Adding `python/test_release.py` to `ENFORCED` can pass while shard 19 still pays the full release module on every `test-classify-bump` run. The plan mentions this (lines 22, 81, 141, 153) but treats a guard extension as an acceptable fallback; for Bucket 1's CI-time goal, the Makefile fix must be mandatory.

### 2. [important / correctness] `test_design_summary.py` duplicate targets have no semantic distinction

`Makefile:577-580` shows byte-identical recipes for `test-render-final-summary` and `test-render-final-summary-bash32`. `python/test_design_summary.py` has no bash-3.2-specific tests. Two full-file targets cannot satisfy `ENFORCED`. Retire one duplicate and slice the remainder.

### 3. [important / correctness] `test-scrub-submodule-paths` is a pure duplicate

`Makefile:901-902` runs full `python/test_redact.py`, but grep shows no submodule-related tests in that file. Retirement should be explicit, not conditional on audit.

### 4. [important / correctness] `test-run-step2-dispatch` / `test-step2-dispatch` duplicate pair omitted

Both `Makefile:652-656` run the full `python/test_implement_dispatch.py` file in shards 15 and 18. The plan should name this pair for retirement like other pure duplicates.

### 5. [important / risk-integration] Ambiguous `test-redact` catch-all guidance

Plan line 66 conflicts with the filename-collision edge case (line 145). Catch-all must be `-k 'not (...)'`, not bare full-file or `-k redact`.

### 6. [important / correctness] `test_design_lifecycle.py` slice keys do not match tests

Only five tests exist with prefixes `phase_driver`, `design_route`, `design_driver`, and `design_read_result_env`. Plan references to `step0b` and `reentry` do not map to test names.

### 7. [important / correctness] `test_plan_scout.py` collision risk

Target names invite `-k scout`, which matches the module stem `test_plan_scout`. Use specific test-name families or node IDs.

### 8. [important / risk-integration] Missing Makefile-wide invocation audit

Beyond `test-classify-bump`, the plan should require verifying every Makefile reference to each Bucket-1 file is part of the declared partition, because `extract_pytest()` only sees one file per recipe.
