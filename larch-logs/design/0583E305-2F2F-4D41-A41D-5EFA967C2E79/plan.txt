## Approach

Port the 18 absorbed scripts into `python/rendering.py` as importable functions with thin `*_main(argv)` entry points. Register 17 verbs in `python/cli.py` across 4 domains:

- `render specialist | reviewer | debate-retry | lane-status | voter | plan-review`
- `mermaid sanitize`
- `diagrams upsert`
- `generate code-reviewer-agent | reviewer-plan-fidelity-agent | reviewer-code-robustness-agent | reviewer-security-structure-tests-agent | pre-rendered-reviewer-prompts | codex-implementer | cursor-implementer | topology-docs | check`

Follow `docs/python-migration.md` steps 1–8: port, register, pytest, cut all consumers, run retargeted bash harnesses once as a parity gate, delete, append manifest rows, run `make lint-retired-scripts`.

Reuse existing Python runtime instead of re-implementing:

- `python/logging_util.py` — `quiet_init`, `emit`, `emit_kv`, contract stream. Preserve per-verb routing: `render voter`, `render plan-review`, and `render debate-retry` write payload/KV to plain stdout and never init quiet (bash parity — quiet redirection would swallow the prompt). All other verbs init quiet and route payload/KV through the contract stream.
- `python/redact.py` — secret + tmpdir redaction (already pinned to `scripts/redact-*.sh` parity). Replaces the subprocess calls to `redact-secrets.sh` / `redact-tmpdir-paths.sh` in the specialist renderer and the upserter.
- `python/pr_body.py` — mermaid validation core. Make `_flowchart_rejects_pipe` and `_body_start_line` public; `mermaid sanitize` reuses them and adds what `pr_body.sanitize_fragment` lacks: `REASON_TOKEN=<tok> fence=N line=M` attribution, `FENCE_N_HEADING` (last-5-nonblank-line heading history: `## Architecture Diagram` / `## Code Flow Diagram`), `FENCE_COUNT`, `STATUS`, and `--warnings-log`/`--warnings-step` append via `append-execution-issue.sh`.
- `python/tracking_issue.py` — marker-comment upsert engine. Add a small public wrapper accepting an explicit marker + optional comment id; `diagrams upsert` calls it in-process. `scripts/tracking-issue-summary.sh` stays for its remaining bash callers.
- `python/retry.py` `with_transient_retry` — the comment DELETE path in `diagrams upsert`.
- `python/proc.py` + `python/gh.py` — `gh api` calls and repo resolution.
- `python/session_env.py` — import the run-params classification reader for `render plan-review` (replaces its `session read-classification` subprocess).

Port into `rendering.py` as Python-internal helpers (the sourced bash libs stay; they keep other bash consumers — `plan-review-loop.sh`, `run-step3-review.sh`, `persist-retally-step3-env.sh`, `aggregate-findings.sh`, `revise-plan-with-waterfall.sh`, design SKILL inline blocks):

- untrusted block emission (`<tag encoding="literal-redacted">` wrap: redact, then `&`/`<`/`>` entity escape) — parity with `scripts/lib-untrusted-block.sh`;
- scope-anchor validators (voter + design variants and the common shape check) — parity with `scripts/lib-scope-anchor-handoff.sh`;
- the design-tmpdir validation `render plan-review` needs — parity with `scripts/lib-design-tmpdir.sh`.

Generators: keep the hard-coded YAML frontmatter headers as module string constants; one shared GENERATED_BODY-marker extractor (heading-scoped, drops the outer fence pair by position); substitutions via `str.replace`. `generate check` ports the `check-generators.sh` walker: parse `scripts/generators.tsv` with the same row-hygiene rules (CRLF, two non-empty columns, duplicate detection, tracked output), run each registered verb's check in-process, and keep the before/after `git diff` no-delta guard. `scripts/generators.tsv` column 1 changes from a script path to `generate <verb>`; column-2 output-path semantics unchanged.

Generated-artifact headers must change: each artifact carries `AUTO-GENERATED ... Regenerate via: bash scripts/<generator>.sh`, and `agents/pre-rendered/.manifest` names the bash generator. Left as-is, `lint-retired-scripts` would flag every artifact and operator guidance would point at deleted scripts. Update the header constants to the `python3 python/cli.py generate <verb>` invocation and regenerate all artifacts in the same commit. This is the only artifact content change; pytest then pins generator output byte-identical to the committed artifacts.

Kept subprocess boundaries (scripts not absorbed by B6): `classify-diff-mode.sh` (default diff-mode), `append-execution-issue.sh` (warnings append).

Caller cutover form: bash callers derive the plugin root from their own script directory first, falling back to `${CLAUDE_PLUGIN_ROOT}` (playbook step 4). SKILL prose uses `python3 "${CLAUDE_PLUGIN_ROOT}/python/cli.py" <domain> <verb> ...`.

Behavior contracts preserved per verb: flags, exit codes (usage 2; drift/rejected 1; upsert failure envelope KVs), KV key names, sentinel-override loud failure in `render reviewer`, `{CONTEXT_BLOCK}` validate-before-substitute ordering, calibration-examples strip, pre-rendered body preference, `LARCH_RENDER_CACHE_DIR` cache keying (same key fields incl. file SHA-256s), reviewer-testing plan/feature exception, tmp-scoped input gate + `--allow-external-paths` in the upserter, and the debate-retry failure-token allowlist with 8192-byte excerpt cap.

## Edge cases

- `&` in substitution values (`--target "R&D"`, readability/feature text with `&`): `str.replace` keeps it literal. Pin with a `Strunk & White` pytest case — the hazard class this migration deletes.
- `render reviewer` sentinel-override target missing from the archetype: fail loudly (exit 1) with the same drift message; `{REVIEW_TARGET}`/`{OUTPUT_INSTRUCTION}` unresolved-placeholder gate and the exactly-one-`{CONTEXT_BLOCK}` check run before user content is substituted (security ordering preserved).
- `render specialist`: pre-rendered body preferred over frontmatter extraction; calibration-examples strip; reviewer-testing receives plan/feature blocks in all modes while other agents only in generic diff mode; `--commit-count` 1–5 omits the git-log instruction; missing `LARCH_RENDER_CACHE_DIR` silently disables caching; cache key fields unchanged.
- `mermaid sanitize`: fail closed on unclosed frontmatter; auto-detect `--from-md` when the first non-blank line is a mermaid fence; heading attribution from the last 5 non-blank pre-fence lines; KV shape (`STATUS`, `REASON_TOKEN ... fence= line=`, `FENCE_COUNT`, `FENCE_N_HEADING`) byte-stable for the SKILL parsers.
- `diagrams upsert`: marker grammar gate, multiple-marker-comment failure, empty-sections delete path, no-op path, `--dry-run` preview on the contract stream, tmp-scoped input validation with `--allow-external-paths` escape, redaction before publish, failure KV envelope on every exit.
- `render lane-status`: unknown non-empty token → `(unknown)` + stderr warning; reason sanitize order (strip `=`/`|`, collapse whitespace, trim, truncate 80).
- `render debate-retry`: comma splitting only before known token heads; semicolon list form; unknown head → exit 2; bounded 8192-byte excerpt with truncation note; atomic `.tmp` → `mv` output write.
- `generate check`: rejects unknown/duplicate verbs in column 1 (registry-backed instead of file-exists), keeps all column-2 path hygiene and the post-run working-tree no-delta guard.
- Stdout routing: voter/plan-review/debate-retry payloads must survive quiet-aware parents (no `quiet_init`); the rest emit via the contract stream. Regression-tested under a `LARCH_QUIET`-active parent.

## Failure modes

- Forgotten artifact regeneration → `generate check` (CI `agent-sync`) fails. Self-enforcing.
- Missed caller or doc reference → `make lint-retired-scripts` fails via the 56 manifest rows. Self-enforcing.
- Quiet regression swallowing a rendered prompt → empty external-reviewer prompts; covered by explicit non-empty-stdout pytest cases.
- `gh` transient failures in `diagrams upsert` → `with_transient_retry` parity on DELETE; upsert engine failures surface as `UPSERT_STATUS=failed` with redacted `ERROR`.
- Harness stub drift (callers now invoke the CLI) → update the stub plugin roots in the surviving caller harnesses listed above; they fail loudly if missed.

## Testing strategy

- `python/test_rendering.py` ports the assertion coverage of the ten deleted harnesses: per-verb happy paths, flag/usage errors (exit 2), drift/rejection paths (exit 1), KV contracts, quiet/stdout routing, redaction + entity escape, scope-anchor and tmpdir validation accept/reject, mermaid fixtures (incl. the three former bash-parity fragments), debate-retry token matrix, lane-status token table, and the `Strunk & White` substitution case. Subprocess cases derive the CLI path from `Path(__file__).with_name("cli.py")`; no retired-path literals in fixtures.
- Generator byte-identity: for each `generate` verb, compare write-mode output byte-for-byte against the committed artifact (and assert `--check` exit 0); a second run proves determinism. Topology fixtures reuse the `LARCH_TOPOLOGY_TSV`/`LARCH_TOPOLOGY_DOC` override seam.
- Parity gate before deletion (playbook step 5): retarget the ten bash harnesses' invocations to the CLI locally and run once; delete them only after they pass.
- Green gates: `make lint` (includes `lint-retired-scripts`, shard harnesses, `agent-sync`), `make py-lint`, `make py-test`, plus the updated caller harnesses.
