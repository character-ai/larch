### In-Scope Findings

- **correctness** `skills/review/scripts/aggregate-findings.sh:393-406` — The post-validation rewrite uses `python3 - "$cand" <<'PY' >"$merged_tmp" || true`, so a non-zero Python exit (missing `python3`, runtime error, or I/O failure) is treated as success. When `count_finding_blocks "$cand"` is `0` (the new empty-merge path), the next branch does `[[ -s "$merged_tmp" ]] || printf '\n' >"$merged_tmp"`, which can turn an empty/partial `merged_tmp` into a single-newline file that still satisfies `[[ -s "$merged_tmp" ]]`, allowing `mv` to replace `findings.md` even though the strip step never ran successfully—ballot loss or silent corruption relative to the validated `cand`. **Suggested fix:** Drop `|| true`, propagate Python failures as `REASON=validation-failed` (or a dedicated failure log), and only apply the “force a non-empty staged file for zero-block merges” path after a confirmed successful strip (e.g., gate on `python3` exit status and optionally compare a checksum/size sanity against `cand` minus attestation lines).

- **correctness** `skills/review/scripts/aggregate-findings.sh:260-308` — Symmetric `normalize_slot` on input means `oos_only_slots = oos_slots - non_oos_input_slots` is computed in **normalized** identity space: two syntactically different comma-separated tokens whose only difference is a trailing `(...)` suffix collapse to the same key, so a reviewer that appeared **only** on an OOS-tagged input finding under a suffixed label can become indistinguishable from another reviewer’s base label that only appeared in-scope, shrinking `oos_only_slots` and allowing that normalized name in a non-`[OUT_OF_SCOPE]` merged block where the old unsuffixed comparison would have failed closed (this is the converse of the intended “`(via …)` on output matches base input” fix). `skills/review/scripts/aggregate-findings.md:201-204` documents the collapse as contract, but it is still a real semantic broadening vs output-only normalization. **Suggested fix:** If you must preserve strict OOS-only separation across distinct reviewer strings, avoid normalizing input-derived sets (normalize only merge-output tokens when testing membership against raw `input_slot_set`), or require canonical slot strings from `collect-findings.sh` and strip suffixes only on the aggregator-output side.
