Only the `LARCH_CODEX_MODEL` "When not set" section partially corrects this for Codex — Cursor has no such correction. Operators setting `LARCH_CURSOR_MODEL` for probe robustness will be surprised when the probe uses Cursor's default model. **Suggested fix:** Remove "Step 0 `check-reviewers.sh` probes" from the "When set" bullets for both `LARCH_CURSOR_MODEL` and `LARCH_CODEX_MODEL`; the probe intentionally omits model argv as documented in `check-reviewers.md`.
