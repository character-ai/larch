### In-Scope Findings

1. **risk-integration** `skills/implement/scripts/test-step2-dispatch.sh:225-238` — Test 3e wraps the dispatcher invocation in a bare subshell `(...)` on its own line inside a `set -euo pipefail` script (line 225: `(`). Every other test block in this file uses `OUT=$(cd "$REPO_ROOT" && "$DISPATCHER" ... 2>&1)` — command substitution, which captures the exit code without triggering the outer `-e`. If `step2-implement.sh` exits non-zero for any unexpected reason (e.g., the cursor launch-infrastructure returns an unexpected exit code before writing the manifest, or a missing timing-ledger setup step fails), the outer `set -e` fires at line 238 without reaching the `fail 3e "..."` message, making the failure completely opaque: no test name, no output context, just a bare script exit. **Suggested fix:** Add `set +e` / `_3e_rc=$?` / `set -e` guards around the subshell, matching the `|| true` resilience pattern the file already uses for internal check commands, or redirect both streams into a single capture with `2>&1` and drop the subshell.

2. **risk-integration** `scripts/session-setup.sh:349-490` — The `CODEX_BINARY_FOUND` / `CURSOR_BINARY_FOUND` propagation through `session-setup.sh → write-session-env.sh` has no corresponding test. These keys are now the load-bearing split for `SKILL.md`'s two-tier Option A bail (`CODEX_BINARY_FOUND=false` → binary-missing message vs `CODEX_PRESENT=false` → probe-failed message) and the `--design-only` both-externals-down diagnostics. The propagation path is: `check-reviewers.sh` emits the keys → `session-setup.sh` parses them into `PROBED_CODEX_BINARY_FOUND` / `FINAL_CODEX_BINARY_FOUND` → forwarded as `--codex-binary-found` to `write-session-env.sh` → written to `$IMPLEMENT_TMPDIR/session-env.sh`. A silent regression anywhere in this chain (e.g., the `[[ -n "$PROBED_CODEX_BINARY_FOUND" ]]` guard returning false because `check-reviewers.sh`'s output parsing missed the key) would leave `CODEX_BINARY_FOUND` absent from session-env, causing `SKILL.md` Step 0's `read-session-env-key.sh --key CODEX_BINARY_FOUND` to return empty, and the orchestrator to silently skip both warning branches. **Suggested fix:** Add a test in `test-check-reviewers.sh` (or a minimal `test-session-setup.sh`) that invokes `session-setup.sh --check-reviewers --write-session-env <path>` with a PATH-stubbed binary and asserts the resulting session-env file contains both `CODEX_BINARY_FOUND=...` and `CURSOR_BINARY_FOUND=...`.

3. **risk-integration** `scripts/check-reviewers.sh:127-145` — `larch_poll_probe_pid` is never exercised on the timeout branch (`probe_rc=124`). The function uses `sleep 1` granularity and the `SECONDS` builtin: if `SECONDS >= LARCH_PROBE_TIMEOUT_SECONDS`, it kills the PID and sets `_poll_rc=124`. On a slow machine or under heavy load, the `SECONDS` builtin advances correctly, but the signal + `wait` interplay under `set -euo pipefail` is not covered. A subtle race (e.g., the process exits between `kill -0` and `kill`, leaving `_poll_rc=""` and falling through to `wait`) could silently produce an incorrect `probe_rc`. The plan documents this as an edge case but the test matrix omits it. **Suggested fix:** Add a test with a cursor/codex stub that sleeps for a long time (e.g., `sleep 300`) and set `LARCH_PROBE_TIMEOUT_SECONDS=2`; assert the probe completes within a few seconds and `*_PRESENT=false` is emitted.

4. **risk-integration** `scripts/test-check-reviewers.sh:188-230` — The codex matrix tests t6–t11 and t14 don't assert `CODEX_BINARY_FOUND`. The only codex test that checks the key is t12 (the skip-probe path). If `emit_kv CODEX_BINARY_FOUND "$CODEX_BINARY_FOUND"` were accidentally dropped or made conditional in `check-reviewers.sh`, t6–t11 would still pass silently. The happy-path t0 does assert both binary-found keys for a combined cursor+codex stub, but per-tool binary-found assertions in the individual codex matrix tests (t6 success, t9 auth-exhausted, t10 stamp-hit, t11 stamp-expired) would provide stronger regression pins. **Suggested fix:** Add `assert_line "codex ok binary" "CODEX_BINARY_FOUND=true" "$out"` (and the corresponding false assertion for the t7 non-auth-fail path) to the codex matrix tests.
