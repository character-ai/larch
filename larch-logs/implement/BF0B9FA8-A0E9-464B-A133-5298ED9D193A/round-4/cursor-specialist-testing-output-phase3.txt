### In-Scope Findings

- **risk-integration** `scripts/test-check-reviewers.sh` (Codex matrix tests t6–t12, new-file lines ~200–310) — Codex matrix tests (`SB6`/`t6` through `SB12`/`t12`) are missing `LARCH_LIB_CURSOR_AUTH_TEST_MODE=1 LIB_CURSOR_AUTH_TEST_UNAME=Linux` in their `run_cr` invocations. Each of these tests places a `cursor` stub on PATH that exits 127; because `cursor_auth_preflight` is called unconditionally before the probe loop (and before the stub can short-circuit it), the Darwin keychain path can execute on macOS CI runners, potentially attempting real keychain operations, hanging, or producing non-deterministic results. The plan explicitly required these flags for every test involving a Cursor stub on PATH to guarantee cross-platform isolation. The same t13 and t14 tests correctly set both flags, confirming the pattern was known. **Suggested fix:** Add `LARCH_LIB_CURSOR_AUTH_TEST_MODE=1 LIB_CURSOR_AUTH_TEST_UNAME=Linux` to the `env …` call in each of t6, t7, t8, t9, t10, t11, and t12.

- **correctness** `scripts/session-setup.sh` (passthrough branch, diff context lines ~748–781) — When `CHECK_REVIEWERS=false` (no probe invoked, i.e., `--check-reviewers` was not passed) and `CALLER_CODEX_BINARY_FOUND` is absent from `--caller-env`, the inference logic falls back to `_passthrough_codex_bin="$CALLER_CODEX_PRESENT"`. If an old session-env has `CODEX_PRESENT=false` due to a probe failure (binary was on PATH but probe timed out or auth-exhausted), the inferred `CODEX_BINARY_FOUND=false` is factually wrong — the binary exists. SKILL.md's Option A then prints "binary not found" rather than "runtime probe failed / auth error", which could send the user down the wrong remediation path (reinstalling Codex vs. fixing auth). There is no test covering the `--caller-env`-only passthrough path for the `BINARY_FOUND` inference. **Suggested fix:** When `CALLER_CODEX_BINARY_FOUND` is absent and `CALLER_CODEX_PRESENT=false`, omit the inferred `CODEX_BINARY_FOUND` entirely (do not emit it) rather than silently infer `false`. Let SKILL.md's "absent → treat as not found" default apply. This is semantically correct (no inference is better than wrong inference) and matches SKILL.md's explicit handling of the absent case.

- **risk-integration** `scripts/test-check-reviewers.sh` (t0c ~line 85, t0d ~line 94) — The `--skip-codex-probe` test (t0c) asserts `CODEX_BINARY_FOUND=true` but omits `CURSOR_BINARY_FOUND=true`; the `--skip-cursor-probe` test (t0d) asserts nothing about `BINARY_FOUND` for either tool. These gaps leave the "skip flag does not suppress the other tool's `BINARY_FOUND`" invariant unchecked. **Suggested fix:** Add `assert_line "skip codex cursor binary" "CURSOR_BINARY_FOUND=true" "$out"` to t0c, and `assert_line "skip cursor codex binary" "CODEX_BINARY_FOUND=true" "$out"` plus `assert_line "skip cursor cursor binary" "CURSOR_BINARY_FOUND=true" "$out"` to t0d.
