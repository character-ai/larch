**F-5** | **Severity: Latent** | **Focus: Coverage gap — fd3 contract path** | **File: `python/logging_util.py` — `contract_stream()`**

**Issue:** The fd3 branch of `contract_stream()` is never exercised in any test. Because `conftest.py` always runs `monkeypatch.setattr(logging_util, "_self_initialized_quiet", False)`, `contract_stream()` always returns `sys.stdout`. The `os.fdopen(os.dup(3), "w", closefd=True)` branch (activated when `_self_initialized_quiet=True`) is dead code in tests. A regression in the fd-dup path — including the dup-on-every-call semantics, which could leak fds — would not be caught. The risk is latent rather than immediate because the `sys.stdout` fallback is what non-quiet callers use, but the feature's primary correctness guarantee (JSON staying on fd3, not fd1) is unverified.

**Fix:** Add test that: (1) uses `monkeypatch.setattr(logging_util, "_self_initialized_quiet", True)`, (2) pre-opens a writable fd at position 3 via `os.pipe()` or a tmpfile, (3) calls `contract_stream()`, writes to it, closes it, (4) reads back the fd3 pipe and asserts the data arrived.

**F-6** | **Severity: Latent** | **Focus: Coverage gap — XDG integration** | **File: `python/finalize.py` — `_cleanup_target_ok()`**

**Issue:** `_cleanup_target_ok()` is not exercised with an XDG-rooted path. `test_finalize.py` tests `cache_sessions_root()` in isolation (absolute XDG honored, relative/empty falls back to `~/.cache`), but no test calls `_cleanup_target_ok()` with a path that would only be approved because `XDG_CACHE_HOME` was set. **F-7** | **Severity: Nit** | **Focus: Coverage gap — parser edge cases** | **File: `python/test_finalize.py` — `read_finalize_state`**

**Issue:** `read_finalize_state` uses `shlex.split()` per line but only the newline-rejection path is tested for non-standard input. Edge cases not covered: (a) `KEY=` (empty value — `shlex.split("KEY=")` returns `["KEY="]`, split on first `=` gives `("KEY","")`, correct); (b) `KEY="quoted value"` (shlex would return `["KEY=quoted value"]` if unquoted at word level, or `["KEY=", "quoted", "value"]` — behavior is ambiguous and worth a test); (c) comment lines (`#...`); (d) `export KEY=value` lines from real bash files. If `finalize-state.sh` was written by bash and contains `export` declarations, the current parser would silently misparse them.

**Fix:** Add parametrized test for `KEY=`, `KEY=v`, and a line starting with `export KEY=v` (assert raises or strips prefix), plus a line starting with `#` (assert skipped or included — document the contract).
