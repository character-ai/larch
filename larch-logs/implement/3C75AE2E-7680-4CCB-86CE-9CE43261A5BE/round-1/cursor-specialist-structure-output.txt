Scenario: a script adds `coproc { … }` on macOS system Bash → runtime parse/runtime failure while `make lint-bash32` stays green. Suggested fix: add a second pattern for `coproc[[:space:]]*\{` or document the intentional gap in `BASH_AUTHORING.md` / `scripts/lint-bash32.md` if anonymous form is considered out of scope.
