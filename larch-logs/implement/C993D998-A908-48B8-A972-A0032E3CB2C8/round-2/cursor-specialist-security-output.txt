### In-Scope Findings

1. **security — Latent —** [`scripts/hook-anti-read-poll.sh`](scripts/hook-anti-read-poll.sh) **28–61**  
   The hook stores mutable state under `${TMPDIR:-/tmp}/larch-read-poll` and opens `state-*.tsv` with a normal `>` redirect. On a shared machine, a classic `/tmp` symlink race (another uid placing a symlink where `state_file` will be written) can theoretically cause truncation or overwrite of an attacker-chosen file **if** the hook process follows the symlink and the victim path is writable by the hook user. `chmod 700` on the directory uses `|| true`, so a pre-existing attacker-owned directory with the same name is not forcibly secured.  
   **Scenario:** Multi-user host, malicious local user races the state path before the operator runs Claude.  
   **Fix:** Use `mkdir` with safe permissions then `O_EXCL`/`mktemp` for the state file, or write state only under the user’s home (e.g. `~/.cache/larch/…`), or use `shred`+exclusive create patterns; avoid blind `>` into a predictable path in world-writable roots.

2. **risk-integration — Latent —** [`skills/implement/scripts/write-rejected-findings.sh`](skills/implement/scripts/write-rejected-findings.sh) **62–71**  
   This change **introduces** a redaction pipeline but ends it with `… 2>/dev/null || true`, so any failure in `redact-tmpdir-paths.sh` / `redact-secrets.sh` after the output file is truncated by `>` still exits 0 and can leave an empty or **partial** `rejected-findings.md` in the run log (silent integrity failure). When both scripts are non-executable, the `else` branch **`cp`s `detail_file`**, which is now often the **full** `rejected-findings-full.md` instead of the old short ledger—so the “no redaction available” path carries **more** raw review prose to durable logs than before.  
   **Scenario:** Broken permissions on redactors in a forked/custom layout, or redactor crash mid-stream during a large full file.  
   **Fix:** Drop `|| true` for the redacted path (fail the copy or skip the log artifact with a loud `emit`/stderr), or write to a temp file and `mv` only on pipeline success; if redactors are missing, either refuse to copy the full artifact or run a minimal safe subset.

3. **security — Nit —** [`scripts/hook-anti-read-poll.sh`](scripts/hook-anti-read-poll.sh) **10**  
   Slurping the entire hook stdin with `INPUT=$(cat …)` allows a pathologically large `PostToolUse` payload to consume memory in the hook process before the 5s timeout. Host DoS only in a hostile or buggy caller scenario.  
   **Fix:** Bound reads (e.g. `head -c …`) or stream-parse with `jq` from a fifo with limits if the platform allows.
