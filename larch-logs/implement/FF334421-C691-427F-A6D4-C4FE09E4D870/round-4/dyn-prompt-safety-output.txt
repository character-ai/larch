### In-Scope Findings

- **security** `skills/shared/scripts/render-voter-prompt.sh:92-100` — The new `--scope-anchor-file` path is accepted with only a readability check (`-r "$SCOPE_ANCHOR_FILE"`) before the anchor body is redacted, HTML-escaped, and inlined into the voter prompt. Unlike `render-main-agent-scope-anchor.sh` (non-symlink + `DESIGN_TMPDIR` containment) and `dispatch-plan-voters.sh` (same checks before calling this helper), the renderer itself does not reject symlinks or enforce that the anchor resolves under the design session tmpdir. A miswired or TOCTOU-swapped path could therefore pull content from an unintended readable file into an external voter prompt (information disclosure; redaction reduces secret leakage but does not remove the boundary violation). **Suggested fix:** Mirror the containment contract from `render-main-agent-scope-anchor.sh` inside `render-voter-prompt.sh` (reject CR/LF paths, require regular non-symlink file, canonicalize under `DESIGN_TMPDIR` when set, or under the ballot/session root otherwise) before calling `emit_untrusted_file_block`.

- **security** `python/finalize.py:664-680` and `python/finalize.py:743-780` — This branch makes `python/ship.py` the default Step 8+ driver and adds `_write_terminal_finalize_if_terminal`, which writes `finalize-state.sh` on every terminal Python outcome via `write_finalize_state` / `write_finalize_state_merged`. Those writers use plain `Path.write_text` + `replace` with no symlink/`O_NOFOLLOW` guard, while `_write_ship_state` in `python/ship.py:720-725` explicitly refuses symlinked targets and opens temps with `O_EXCL|O_NOFOLLOW`. `SECURITY.md` now documents symlink hardening for Python ship state files, but the same protection is not applied to `finalize-state.sh`. A same-UID attacker (or a tmpdir TOCTOU) who replaces `$IMPLEMENT_TMPDIR/finalize-state.sh` with a symlink could cause terminal finalize writes to land outside the session tmpdir. **Suggested fix:** Extract the `_write_ship_state` symlink-safe temp+replace pattern (or shared helper) and use it for both `write_finalize_state` and `write_finalize_state_merged`; reject symlinked destination paths before write, matching the documented contract for Python driver state files.
