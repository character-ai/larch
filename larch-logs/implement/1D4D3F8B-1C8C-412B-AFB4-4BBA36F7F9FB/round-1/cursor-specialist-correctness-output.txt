### In-Scope Findings

1. **Latent** `correctness` ([`scripts/launch-claude-review.sh:73-83`](scripts/launch-claude-review.sh)) — The new `--role` gate applies only to subprocess `--context-files` (`append_context_file`). The `--agent-file` branch still always passes `--description-text`, `--scope-files`, `--diff-file`, `--commit-count`, `--plan-file`, and `--feature-file` into `render-specialist-prompt.sh` regardless of `ROLE`. **Concrete scenario:** `launch-claude-review.sh --agent-file agents/code-reviewer.md --mode diff --role voter --diff-file /tmp/large.patch` still runs the renderer with `--diff-file`; `render-specialist-prompt.sh` injects the diff path and related instructions into the rendered prompt (see `render-specialist-prompt.sh` around the “diff has been pre-computed…” text), so a large or sensitive diff can still bloat the prompt and undermine the “voter skips bundling / 1 MB cap” intent for any future `--agent-file` voter use. **Suggested fix:** apply the same `ROLE` guard to `render_args` construction, or reject `--agent-file` combined with `--role voter`. **Source:** `plan` (voter skips context) plus code behavior.

2. **Nit** `architecture` ([implementation plan](file:///Users/zhupanov/.cache/larch/sessions/claude-implement-larch7-lxTHEt/round-1/diff.txt) vs [`scripts/test-launch-claude-review.sh`](scripts/test-launch-claude-review.sh)) — The plan said to verify `test-launch-review.sh` coverage; the harness that exists and was updated is `test-launch-claude-review.sh`. **Suggested fix:** align planning templates or add a one-line cross-reference so future runs do not search for the wrong filename.

3. **Nit** `architecture` ([`scripts/launch-claude-review.md:13`](scripts/launch-claude-review.md)) — The contract says the reviewer “sees the full diff **inline**”; for typical `--prompt-file` reviewer launches, the diff is supplied as attached `--context-files` to `launch-claude-subprocess.sh`, not necessarily as inline prose in the primary prompt. **Suggested fix:** rephrase to “attached as context files” (or similar) so operators do not misread the mechanism.
