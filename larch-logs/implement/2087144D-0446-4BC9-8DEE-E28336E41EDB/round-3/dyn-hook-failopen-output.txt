Reviewing the branch diff and SessionStart sparse-cone probe implementation for fail-open and integration risks.
### In-Scope Findings

- **risk-integration** `scripts/sessionstart-health.sh:45-80` — `probe_sparse_cone_drift()` only disables `errexit` (`set +e`) while the hook runs under `set -euo pipefail` and the plan/contract call for isolation from the full `-euo` stack. The probe dynamically sources `scripts/lib-sparse-dirs.sh` and invokes `normalize_sparse_dirs`; any future or malformed library that touches an unset variable under `-u` can abort SessionStart before the unconditional `exit 0`, breaking the non-blocking hook invariant. **Suggested fix:** In `probe_sparse_cone_drift()`, save and disable both `errexit` and `nounset` (e.g. `set +e` / `set +u` with corresponding restore before every return), matching the documented “cannot abort SessionStart” requirement; add a harness case that sources a stub lib referencing an unset variable and asserts exit 0 with no advisory.

- **risk-integration** `scripts/sessionstart-health.sh:73-74` — The drift compare pipes through external `sed` and `sort` without checking availability, yet SessionStart is explicitly designed for stripped PATHs (see header comment at `scripts/sessionstart-health.sh:22-24`). If `git`/`jq` are on PATH but `sort` or `sed` is missing, the pipelines can still yield non-empty, differently ordered `configured`/`expected` strings and fire the fixed drift advisory on every session even when the cone matches—fail-open on exit code, but not on advisory correctness. **Suggested fix:** Before comparing, require `command -v sed` and `command -v sort`; if either is missing, skip silently (same as empty compare inputs). Optionally add a `test-sessionstart-health.sh` case with a minimal PATH containing only `git`/`jq`/`bash`/`dirname`/`mkdir` to pin the skip behavior.

### Out-of-Scope Observations

- Pre-existing git-state probes in the same `JQ_AVAILABLE && GIT_AVAILABLE` block (`scripts/sessionstart-health.sh:95-133`) also rely on external `sed`/`sort`/`awk`/`grep` without PATH guards; the new probe follows that pattern but is the first to source a plugin library mid-hook, which is why the missing `set +u` isolation is in-scope here.

- `scripts/test-sessionstart-health.sh:101-115` links `sed`/`sort`/`tr` into the test `PATH` via `build_bin`, so the harness does not exercise the stripped-PATH false-positive/skip path described above.

- `.claude/skills/release/SKILL.md:178-187` parses only `LARCH_CONE_RECONCILED=true` for Step 8 restart coupling and does not implement the plan’s substring fallback on the “Already at latest stable … sparse checkout is out of date … Reconciling” fragment; that is a release/restart integration gap, not part of the SessionStart fail-open surface.
