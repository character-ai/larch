Reviewing the branch diff and SessionStart sparse-cone probe implementation for security issues.
Checking whether sourcing the library can mutate parent-shell state (e.g. `MSG`) despite the fixed-string `append_msg` call:
### In-Scope Findings

- **security** `scripts/sessionstart-health.sh:73-85` — The sparse-cone probe sources `lib-sparse-dirs.sh` in the **parent** shell and then calls `append_msg` with a fixed literal. That matches the maintainer-trust model for the library, but it does **not** mechanically enforce the “fixed-string advisory only” property: a tampered or buggy `scripts/lib-sparse-dirs.sh` (or any accidental function/variable in a future edit) can redefine `append_msg`, assign `MSG` at top level, or run code inside `normalize_sparse_dirs` before the fixed string is appended, so SessionStart context could carry attacker-controlled text even though the call site looks safe. **Suggested fix:** Isolate allowlist loading (subshell or helper that prints the normalized list on stdout only), or snapshot/restore `append_msg`/`MSG` around a minimal source block; add a harness fixture lib that defines a hostile `append_msg` and assert the emitted `additionalContext` stays exactly the fixed sparse-drift string.

### Out-of-Scope Observations

- Pre-existing SessionStart advisories (e.g. `larch-stalled-run.txt` at `scripts/sessionstart-health.sh:147-160`) still interpolate local file contents into `MSG` and then into `jq --arg`; that is outside this branch’s sparse probe but remains the larger prompt-injection surface for the hook.
- The sparse probe is gated on both `jq` and `git` (`scripts/sessionstart-health.sh:101-102`); environments missing `jq` never get the drift warning (availability, not a fail-open violation).
- Branch commits (since merge-base with `main`): `884b10d7f` (core fix) plus four review-feedback commits; implementation otherwise aligns with the plan on fail-open (`set +e`/`set +u` with restore on all paths), HOOK_CWD independence, read-only `git sparse-checkout list`, non-mutating behavior, empty-input silence, and regression cases 4b–4l/4f2 in `scripts/test-sessionstart-health.sh`.
