Reviewing the branch diff and `recover_prior_env_value` for eval-safety.
Checking path validation, whether recovered values are re-validated, and how `%q` interacts with `eval` for this pattern.
### In-Scope Findings

- **security** `scripts/write-design-current-env.sh:153-166` — `recover_prior_env_value` runs `eval "$line"` on whatever `grep -E "^export ${key}="` returns from the prior `--output` file, without checking that the line is exactly `export <KEY>=true|false` in the shape `build_export` emits. For the intended `/design` path that is not a practical issue: `build_export` uses `printf 'export %s=%q\n'` (lines 148–151), argv paths only ever supply `true`/`false` via `validate_bool` (lines 84–94), and `%q` round-trips those literals as single physical lines, so `grep`/`tail -1` cannot stitch a multi-line statement and dollar signs/newlines in legitimate values are not in play for these four keys. If `source-env.sh` is hand-edited or otherwise writable by an attacker (same trust boundary as downstream `source "$out12"` in the harness), a line like `export CODEX_PRESENT=true; …` still matches `^export CODEX_PRESENT=` and `eval` executes the suffix — the branch adds code execution in the writer on refresh, not only when consumers source the file. **Suggested fix:** Drop `eval`; accept only `^export (CODEX_PRESENT|CURSOR_PRESENT|CODEX_AVAILABLE|CURSOR_AVAILABLE)=(true|false)$` (or parse the `%q` RHS with a dedicated decoder) and pipe the captured value through `validate_bool` before `printf -v`.

### Out-of-Scope Observations

- **`--output` vs allowlist:** Only `--design-tmpdir` is checked with `larch_design_tmpdir_validate` (lines 124, 107–175 in `scripts/lib-design-tmpdir.sh`); `--output` is only required to be absolute (lines 126–129). A malicious caller could already overwrite an arbitrary absolute path; the new read path does not tighten that pre-existing contract.
- **Diff noise:** Commit `f8684b9e1` adds `larch-logs/implement/4529BA14-…/` artifacts unrelated to the env-refresh fix; no eval-safety bearing.
- **Canonical round-trip:** For writer-only `source-env.sh` content, `printf '%q'` + single-line `grep` + `tail -1` + `eval` on `export KEY=true|false` is sound; the residual risk is untrusted file content, aligned with existing full-file `source` usage in `skills/design/scripts/test-write-design-current-env.sh` and `skills/design/SKILL.md`.
