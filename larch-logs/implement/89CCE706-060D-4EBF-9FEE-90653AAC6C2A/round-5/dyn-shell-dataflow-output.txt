### In-Scope Findings

- **correctness** `skills/review/scripts/review-core.sh:430-476` — The new `static_archetype_coverage_ok` gate can fail a round even when `check-reviewer-failure-threshold.sh` has already upgraded the same static slot to success from its on-disk output. Collector parsing writes failed bases into `rejected_file`, and the fallback loop refuses to credit any output whose normalized basename appears there (`grep -Fxq … "$rejected_file"`), but the threshold script explicitly allows a substantive `--reviewer-output-files` entry to override a collector failure via `count_static_status_once` (see `skills/review/scripts/test-check-reviewer-failure-threshold.sh:154-162`). After a Claude phase-2/3 recovery or any path where collector status is stale relative to the final output file, threshold math can pass while coverage fails with `no successful static reviewer for archetype(s): …`, producing a false `panel-failed` stall. **Suggested fix:** Reuse the same per-base reconciliation as `count_static_status_once` (or call into a shared helper): when an output path in `"$@"` passes the same substantive check used by the threshold script, record the archetype slug as covered regardless of the earlier collector failure entry in `rejected_file`.

- **correctness** `skills/review/scripts/review-core.sh:441-449` — The coverage gate treats collector `OK`/`cap_hit` as sufficient for archetype coverage without applying the substantive output check that the threshold path applies in `check-reviewer-failure-threshold.sh:198-209`. If collector results and file contents diverge the other way (collector `OK`, but the corresponding output file is empty or contains `NOT_SUBSTANTIVE`), threshold downgrades the slot to failure while coverage still marks the archetype covered. That lets aggregate ≤50% failure math pass with zero substantive peer coverage for a slug. **Suggested fix:** When evaluating coverage, require `output_file_is_success` (or equivalent) for any matching path present in the `"$@"` output list before accepting collector `OK`/`cap_hit`; alternatively derive coverage from the same reconciled per-base status map the threshold script emits.
