### In-Scope Findings
- **risk-integration** `scripts/launch-claude-subprocess.sh:249-276` — The new JSON-envelope path only extracts `.result` when it is non-empty; if Claude exits 0 with a valid envelope whose `.result` is empty/missing, the raw JSON remains non-empty, so the existing empty-output fail-loud guard is bypassed and `${OUTPUT}.done` records success. The same pattern exists in `scripts/launch-claude-ci.sh:198-215`, leaving CI collectors with raw envelope bytes instead of stable prose/failure behavior. **Suggested fix:** After validating a JSON envelope, explicitly treat empty/missing `.result` (and ideally `is_error=true`) as a launcher failure or a clear sentinel before writing `.done` / `LAUNCHER_EXIT=0`; add regression tests for `{"result":"","usage":...}` and missing `result`.

- **risk-integration** `scripts/token-report.sh:482-486` — The `--summary` Claude subprocess lane drops cache-creation tokens: launcher capture records `cache_creation_input_tokens` as `cache_create`, but the summary JSON only exposes `input`, `cache_read`, and `output`, and `scripts/token-report.sh:731` sums only those fields. This makes `Tokens: ... | Claude (subprocess): ...` underreport the new lane even though `token_total` includes the full vendor total. **Suggested fix:** Include a `cache_write_5m`/`cache_create` field for `claude_sub` in summary mode and include it in `cs_raw`; add a summary test with non-zero `cache_create`.

- **risk-integration** `scripts/launch-claude-subprocess.sh:116-120` — Unknown Claude subprocess timing kinds are now silently recorded as `raw=claude_review`, but an existing caller, `skills/implement/scripts/generate-code-flow-diagram.sh:68-74`, invokes the same launcher with `--timing-task-kind implement-code-flow`. That spawned Claude token spend will be reported as reviewer provenance, which pollutes the new lane’s role breakdown. **Suggested fix:** Add an explicit provenance mapping for `implement-code-flow` (or fail/record `claude_unknown` for unmapped kinds) and document/test the additional raw label.
