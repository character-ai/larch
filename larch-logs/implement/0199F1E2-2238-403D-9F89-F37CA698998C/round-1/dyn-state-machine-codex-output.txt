### In-Scope Findings
- **architecture** `skills/design/scripts/review-design-step3-loop.sh:53-55` — Loop-mode terminal paths only write `.completed/step-3`, but `scripts/design-pause-save.sh:171-176` still interprets `step-3` without `step-3.5` as resume-at-Step-3.5. A crash/pause after `STEP3_REVIEW_LOOP_STATUS=complete`, `cap-hit`, `panel-failed`, `tally-error`, or `degraded-empty-collector` returns but before Step 3b writes `.completed/step-3.5` will re-enter Gate B instead of Step 3b, risking duplicate Gate B handling or misrouting. **Suggested fix:** For loop terminal statuses that transition to Step 3b, atomically write both `.completed/step-3` and `.completed/step-3.5` before returning, or update pause/resume routing to distinguish loop-terminal Step 3 from legacy pre-Gate-B Step 3.

- **architecture** `skills/design/SKILL.md:1212-1233` — The parse fence validates only legacy `LOOP_STATUS`, not the new `STEP3_REVIEW_LOOP_STATUS` envelope that the branch matrix claims is authoritative. If the loop exits without a valid envelope while a stale `.step3-review-result.env` still contains `LOOP_STATUS=complete`, the guard can pass and the orchestrator may continue down the wrong path. **Suggested fix:** Add a closed-enum validation for `STEP3_REVIEW_LOOP_STATUS` in loop mode, fail closed when it is missing/invalid, and keep legacy `LOOP_STATUS` validation separate for `--mode single`.

- **architecture** `skills/design/scripts/run-step3-review.sh:466-475` — Default loop re-entry ignores existing intra-round phase markers: when `--starting-round` is omitted it always starts at `review-round-count + 1`. After an in-loop pause or crash with `.step3-round-N.phase` still present and `review-round-count.txt=N`, the normal Step 3 invocation in `skills/design/SKILL.md:1189-1195` resumes at round `N+1`, skipping the required `awaiting-apply` / `awaiting-post-apply` / `awaiting-continuation` work for round `N`. **Suggested fix:** On loop entry without `--starting-round`, detect an unsettled phase marker for the last consumed round and default to that round, or have the resume/pause path pass `--starting-round N` based on the durable phase marker.
