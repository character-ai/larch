### In-Scope Findings
- **architecture** `skills/design/SKILL.md:1267-1279` — The new continuation check depends on in-memory `IMPORTANT_ACCEPTED_COUNT` / `REVIEW_ROUND_COUNT`, but Gate B can resume from `.gate-b-postapply-ready-N` after a pause with `.completed/step-3` present and `.completed/step-3.5` absent; `scripts/design-pause-save.sh:173-176` resumes that state at Step 3.5, whose prelude at `skills/design/SKILL.md:1243-1256` does not reload `.step3-review-result.env`. A resumed substantial round can therefore see empty/stale counts and proceed to Step 3b/Gate C instead of launching the required next review. **Suggested fix:** Before the Gate B resume path and heuristic check, reload allowlisted Step 3 result values from `$DESIGN_TMPDIR/.step3-review-result.env` or the current round summary, validate numeric counts, and base continuation on that persisted state; add a pause/resume regression where a round with `IMPORTANT_ACCEPTED_COUNT=2` pauses after Gate B apply and still launches the next round.

- **architecture** `skills/design/SKILL.md:1274-1279` — The automatic “loop back to Step 3” path bypasses the normal re-entry hygiene used by Gate C re-runs: Gate C writes `.step3-reentry` (`skills/design/SKILL.md:1422`), and `design-step3-state.sh` clears downstream/completed sentinels (`skills/design/scripts/design-step3-state.sh:59-72`). Because Step 3.5 has already written `.completed/step-3` at `skills/design/SKILL.md:1243-1246`, an automatic next-round entry leaves stale Step 3 completion state behind; if a pause is requested before or during that next review, `scripts/design-pause-save.sh:173-176` saves the resume point as Step 3.5, skipping the fresh review and risking stale findings. **Suggested fix:** Route automatic continuation through the same Step 3 re-entry hygiene as Gate C re-runs, or add a dedicated auto-review re-entry helper that clears `.completed/step-3`, `.completed/step-3.5`, downstream sentinels, and Gate B ready markers before invoking `run-step3-review.sh`; cover pausing during automatic round N+1.
