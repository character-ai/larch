### In-Scope Findings
- **correctness** `scripts/ship-pr.sh:1026-1030` — The new computed title is not applied when `create-pr.sh` finds an existing open PR: `create-pr.sh` returns `PR_STATUS=existing` without using the passed `--title`, and this branch only updates the PR body afterward. Concrete scenario: an open PR created before this fix still has title `Bump version to 1.0.1`; rerunning `pr-create` with `ISSUE_NUMBER=7` computes `Fixes #7: initial` and stores it in state, but GitHub keeps the old title. **Suggested fix:** On `PR_STATUS=existing`, update the title too, for example via `gh pr edit "$pr_number" --title "$title"` with the same repo args, and add a regression test for the existing-PR path.
