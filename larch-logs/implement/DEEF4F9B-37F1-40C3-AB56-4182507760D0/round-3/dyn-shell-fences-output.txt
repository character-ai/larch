### In-Scope Findings

- **correctness** `skills/design/SKILL.md:697-717` — Step 2a.2’s skip predicate treats any `approach-synthesis.txt` containing `NO_SKETCHES_CLASSIFIED_SIMPLE` as proof the **entry fence** finished, but the HARD zero-sketches degraded path (line 717) writes the same sentinel later in 2a.3. A tmpdir with markers but missing/corrupt `approach-synthesis.txt` / `contested-decisions.md` / `dialectic-resolutions.md` still skips sketch launch and routes to 2b, bypassing the 2a.5 repair fence (which only runs when Step 2a.5 is entered). **Suggested fix:** Require all three sentinel artifacts (same checks as the 2a.5 repair block) in addition to both markers, or route marker-only gaps through the repair fence before allowing the 2a.2 skip.

- **correctness** `skills/design/SKILL.md:811-813` — The Step 2a.5 resume “marker-only” `elif` branch writes `.completed/step-2a.5` without `set -e` or exit-status checking on `mkdir` / `: >`. A disk/permission failure leaves the run thinking 2a.5 is complete when the marker is still absent, so later skips assume a repaired state. **Suggested fix:** Mirror the entry-fence pattern: wrap the `elif` body in `set -e` (or test each command and `exit 1` on failure) so a failed marker write aborts the Bash fence non-zero.

- **correctness** `skills/design/SKILL.md:650-657` — The SIMPLE guard uses `[ "$_design_classification" = SIMPLE ]` (unquoted `SIMPLE`). In Bash, `SIMPLE` is expanded as a variable; when unset this becomes `[ "$_design_classification" = ]`, which is true for an empty classification string. The harness pins this pattern, but it is fragile if `SIMPLE` is set in the environment or classification is ever empty despite the `|| printf HARD` fallback. **Suggested fix:** Compare against the literal `"SIMPLE"` (`[ "$_design_classification" = "SIMPLE" ]`) in both the Step 2a entry and 2a.5 repair fences, and update `assert_step2a_entry_simple_guard` to match.
