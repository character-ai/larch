Reviewing the branch diff with a security focus on the pause/resume restore path.
### In-Scope Findings

- **risk-integration** `scripts/design-pause-load.sh:217-248` — The new `git ls-tree` + per-file `git show` restore uses mutable symbolic refs (`FETCH_HEAD`, `origin/<default>`, local branch names) for every blob without first pinning a single commit OID. Unlike the old one-shot `git archive | tar` path, a concurrent `git fetch` (or any ref movement between enumeration and extraction) can mix files from different commits into one restore while `manifest.json` / `pause-state.txt` cross-checks still pass on matching `issue_number` and `run_id`. That can install an internally inconsistent design tmpdir (for example, `plan.txt` from one commit and reviewer artifacts from another), which downstream `/design` steps treat as trusted session state. **Suggested fix:** Immediately after fetch/ref resolution, resolve once with `snapshot_sha=$(git -C "$REPO_TOP" rev-parse --verify "${snapshot_ref}^{commit}")` and use only that SHA for both `ls-tree` and every `git show "$snapshot_sha:$path"` call so the restored tree is a single immutable snapshot.

- **security** `scripts/design-pause-load.sh:243-247` — Relative paths are filtered with prefix stripping and a `case` arm for `..` segments, but the loader never verifies canonical containment (for example, `$(cd "$(dirname "$dest")" && pwd -P)` under `$(cd "$restore_tmp" && pwd -P)`), unlike `design-log-publish.sh`'s `design_publish_ancestor_within_root` checks before staging. Git tree paths make practical traversal unlikely, but the manual `dest="$restore_tmp/$rel"` assembly is new surface introduced by this branch; a future odd `ls-tree` path shape or parser gap would write outside the staging tmpdir before `cp -R` installs into the allowlisted design tmpdir. **Suggested fix:** After building `dest`, reject unless `realpath`/`pwd -P` containment proves the resolved parent directory stays under `$restore_tmp`, mirroring the publish-side ancestor guard.

### Out-of-Scope Observations

- `scripts/design-pause-load.sh:203-204` binds snapshot git reads to `REPO_TOP` from the caller cwd while `--repo` only threads `gh`; a cwd/repo mismatch can restore the wrong worktree. That predates this branch (the export-ignore harness documents it) and is operational rather than introduced here.

- The large `python/ship.py` / `python/run_logs.py` diff on this branch comes from the separate `#3448` commit (`21d62ab59`) and was not part of the pause/resume fix commits (`5ccd6e3e8`, `55c4d6a9f`, `e82a291f9`); it was outside the pause-restore security scope for this review.

- WI1 (`scripts/design-log-publish.sh:589-598`) and WI3 marker lifecycle changes look sound: driver phase sentinels are empty allowlisted markers, marker retention on retryable failures is restored, post-success delete failures surface `MARKER_CLEARED=false` + `WARN=marker-delete-failed` without failing load, and `enum_tmp` is cleaned in the EXIT trap.
