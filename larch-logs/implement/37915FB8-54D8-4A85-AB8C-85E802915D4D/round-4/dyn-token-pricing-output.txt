### In-Scope Findings

- **correctness** `python/report_tokens_cost.py:45-65` — `_aggregate_tokens()` for Claude sums `cache_create`, `cache_create_5m`, and `cache_create_1h` together, but `scripts/token-report.sh` defines `cache_create` as `cache_create_5m + cache_create_1h` (see `usage_row` around lines 194–210). On any blended-Claude path (`--claude-tokens` when `BUCKETS_claude` is missing/empty, or `_fallback_cost()` after `token-cost.sh` fails), cache-write tokens are counted twice, inflating Claude costs by up to ~2× on the cache-write portion. The per-bucket happy path is unaffected because `BUCKETS_claude` omits legacy `cache_create`, but the fallback contract is wrong for real run-log JSON. **Suggested fix:** Match the old bash aggregate: sum `input + cache_read + cache_create + output` only, or if split fields are present use `cache_create_5m + cache_create_1h` and do not also add `cache_create`; add a fixture mirroring production totals where `cache_create == cache_create_1h`.

- **correctness** `python/report_tokens_cost.py:45-65,135-148` — For Codex/Cursor blended aggregation and `_fallback_cost()`, `_aggregate_tokens()` prefers `input + cached_input/output + output` from `VendorTotals`, but vendor-level `codex.totals` / `cursor.totals` in committed reports only carry `input`, `output`, and `total` — cached volume lives in `BUCKETS_codex.cached_input` and `BUCKETS_cursor.cache_read` (e.g. `larch-logs/implement/B8EEF7CC-715C-4285-A6DC-D35B78177AD2/token-report.json`: Codex `total` 53,816,797 vs component sum ~2,437,981). Whenever blended flags are used (missing/empty buckets, legacy reports without `BUCKETS_*`, or Python fallback after `token-cost.sh` failure), Codex/Cursor headline costs are computed on a tiny fraction of actual tokens. Old bash used `cod.get("total")` / `cur.get("total")` for blended mode. **Suggested fix:** For blended/fallback, derive token counts from `raw_report["BUCKETS_*"]` when present and numeric; otherwise fall back to `VendorTotals.total` (not partial component sums). Extend `test_report_tokens_cost.py` with a fixture whose vendor totals omit cache fields but buckets include them, asserting blended argv/fallback uses full bucket totals.
