Reviewing plot-isolation architecture: reading the diff and key plot-related files.
### In-Scope Findings

- **architecture** `skills/report-tokens/scripts/plot-cost-over-time.py:27-67` — The normative contract in `plot-cost-over-time.md` requires `implement` to receive exactly one `All runs` series and `design` to receive `SIMPLE` and `HARD`, but the child only checks that `series` is a list. It never reads `version`, never validates `skill`, and never checks label cardinality. A drifted or hand-edited `plot-input.json` can exit 0 with the wrong number of PNGs (or misleading titles) while `report_tokens_plot.py` still treats the run as successful. **Suggested fix:** Add a small `validate_plot_input(skill, data) -> None` in the child (or in `report_tokens_plot._series` before write) that enforces `version == 1`, allowed `skill` values, required labels, and series count; return non-zero with stderr when validation fails so the parent’s existing “plot child failed” path surfaces it.

- **architecture** `skills/report-tokens/scripts/plot-cost-over-time.py:40-53` — Malformed `series` entries and `points` entries are skipped with `continue` instead of failing the subprocess. A partially invalid payload can therefore exit 0 and print `[]` or a shortened path list with no indication that part of the contract was ignored, which is indistinguishable from “no dated runs” at the `report_tokens_plot.plot` / CLI layer. **Suggested fix:** Treat structural defects (non-dict series item, non-dict point, missing `date`/`cost` when a point dict is present) as fatal with exit 2 and a clear stderr line; reserve exit 0 with an empty `written` list only for structurally valid input that legitimately has zero plottable points.

- **architecture** `python/report_tokens_plot.py:70-83` — After the child succeeds, the parent trusts stdout JSON and returns `Path` objects without checking that each PNG exists under `plot_dir`. A buggy or interrupted child could advertise paths that were never written, and `report_tokens_cli.py` would still print “Plots written to:” for them (and macOS `open` would fail opaquely via the runner). **Suggested fix:** After parsing stdout, filter to `path.is_file()` paths; if the child returned a non-empty list but none exist, emit the same stderr skip line used for child failure and return `[]` (or fail loud if any advertised path is missing).

### Out-of-Scope Observations

- The plan explicitly preserves the pre-existing date-axis mismatch: plots bucket on `closed_at` (`python/report_tokens_plot.py:32-35`) while per-day tables use `started_at` in render — not introduced by plot isolation and already flagged as OOS.
- `python/test_plot_cost_over_time.py:14-21` smoke-tests only an `implement` payload and does not set `MPLCONFIGDIR`; production always sets it (`python/report_tokens_plot.py:62-64`). This is harness hygiene, not a runtime isolation break.
- Stdlib-only invariant for `python/` is satisfied: matplotlib appears only in `skills/report-tokens/scripts/plot-cost-over-time.py`; `report_tokens_plot.py` invokes it via `proc.Runner` + `sys.executable` with a full `os.environ` copy and `MPLCONFIGDIR` under a persistent `mkdtemp` tree — the core D1 design is implemented as intended.
