Reviewing the plot-boundary architecture: reading the diff and key plot-related files.
### In-Scope Findings

- **architecture** `python/report_tokens_cli.py:89-96` — The CLI always prints `No plots generated.` whenever `plot()` returns an empty list, but `plot()` returns `[]` for three different reasons: `--no-plot` / `LARCH_REPORT_TOKENS_NO_PLOT`, a failed or skipped matplotlib subprocess, and an empty series after validation. That collapses intentional opt-out and real plot failure into the same stdout line, so operators and harnesses cannot tell whether plotting was disabled or attempted and failed (stderr has detail only on the failure path). **Suggested fix:** Have `plot()` return a small result type (for example `PlotOutcome` with `attempted: bool` and `paths: list[Path]`), or branch in `main()` on the already-resolved `no_plot` flag so stdout omits the line when plotting was not requested and only prints `No plots generated.` when `not no_plot` and no paths were produced.

- **architecture** `python/report_tokens_plot.py:100-102` — macOS auto-open is gated with `not os.environ.get(config.ENV_LARCH_REPORT_TOKENS_NO_OPEN)`, while plot enablement uses `_env_flag_enabled()` for `LARCH_REPORT_TOKENS_NO_PLOT` (treating `0` / `false` as off). Setting `LARCH_REPORT_TOKENS_NO_OPEN=0` is therefore interpreted as “suppress open” because any non-empty string is truthy, which breaks the symmetric env contract documented beside `NO_PLOT` in `skills/report-tokens/scripts/run-analysis.md`. **Suggested fix:** Gate `open` with `not _env_flag_enabled(config.ENV_LARCH_REPORT_TOKENS_NO_OPEN)` (or a shared helper) so only `1` / `true` / `yes` disable opening and `0` / empty leaves the default behavior.

### Out-of-Scope Observations

The matplotlib boundary itself matches the plan: `python/report_tokens_plot.py` stays stdlib-only, invokes `skills/report-tokens/scripts/plot-cost-over-time.py` via `proc.Runner` and `sys.executable`, sets `MPLCONFIGDIR` under a persistent `larch-report-tokens-plot.*` directory, validates child-returned PNG paths stay inside that directory, and degrades subprocess failures to stderr plus an empty path list without aborting the run. `python/test_stdlib_only.py` does not scan the matplotlib helper, and `python/test_report_tokens_plot.py` plus `python/test_plot_cost_over_time.py` cover the JSON contract and optional smoke path. The plot axis still uses `closed_at` while per-day tables use `started_at`; the plan records that as an intentional, pre-existing quirk rather than a regression from this branch.
