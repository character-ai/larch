Reviewing the awk-based TOML strip helper: reading the diff and implementation.
Checking one more edge case: whether table-header detection runs on comment lines and how inline comments interact.
### In-Scope Findings

- **correctness** `scripts/lib-external-launcher-common.sh:550-556,578-580` — `update_multiline_state` only treats whole-line comments (`^[[:space:]]*#`) as non-string content. Trailing `# ... """` / `# ... '''` on a normal assignment is still scanned by `count_occurrences`, so a single odd count can flip `in_dq_multiline` / `in_sq_multiline` while the line is otherwise treated as a key/value. That disables table-header handling (`!was_in_multiline && is_table_header`) for following lines, so a real `[model_providers.openai-larch-env]` header can be printed instead of skipped, leaving larch env-key artifacts on the login path. **Suggested fix:** In `update_multiline_state`, ignore `#` and everything after it on non-comment lines (or only scan the value portion before `#`), and on the top-level strip rules at 578–579 use bare `next` without calling `update_multiline_state` on lines that are deleted anyway.

- **correctness** `scripts/lib-external-launcher-common.sh:578-579` — Top-level `model_provider` / `env_key` stripping is gated on `current_table == ""`, and `current_table` is set to `"other"` on the first non-larch table header and never cleared. Any `model_provider = "openai-larch-env"` or `env_key = "OPENAI_API_KEY"` that appears after the first `[...]` header is kept, including as sibling keys under another table (see `scripts/test-lib-external-launcher-common.sh:140-142`, which expects `name = "keep nested selector text"` but does not require removal of the following larch selector/env_key lines). If a copied `~/.codex/config.toml` places legacy larch keys under `[profile.*]` or similar instead of at file prefix, login fallback can still leave env-key forcing in the temp home. **Suggested fix:** Either document that only pre-first-table keys are stripped, or extend stripping to matching `model_provider` / `env_key` lines whenever `!was_in_multiline && !skip_larch_provider` (still honoring multiline and skip state), with harness fixtures for post-header legacy keys.
