Reviewing the branch diff and tracing `SCOPE_ANCHOR_FILE` through result-env plumbing.
### In-Scope Findings

- **risk-integration** `skills/design/scripts/run-step3-review.sh:176-195` — `recover_main_agent_scope_anchor` returns exit **1** when it cannot recover a staged anchor (or when it downgrades `main-agent-vote-required` to `panel-failed`), but the driver runs under `set -euo pipefail` and calls it bare at line 394. That aborts the driver before the terminal `emit_kv` breadcrumbs and before `phase_driver_write_result_env` writes `.step3-review-result.env`. In practice the stubbed harness case `=== main-agent-vote-required preserved on non-zero rc ===` now captures only `WARN=Step 3: main-agent-vote-required without valid SCOPE_ANCHOR_FILE` and the script exits **1** with no normalized `LOOP_STATUS` handoff. Any real path where inner env lacks `SCOPE_ANCHOR_FILE` and the staged file is absent (failed materialization, partial write, symlink-inner stdout-only fallback) will hit the same premature exit instead of emitting `panel-failed` durably. **Suggested fix:** Make recovery non-fatal for `set -e` (`recover_main_agent_scope_anchor || true`, or `return 0` after setting `LOOP_STATUS=panel-failed`), then always run the terminal emit/write block. Add a harness asserting downgrade emits `LOOP_STATUS=panel-failed` in stdout **and** `.step3-review-result.env` with exit **0**.

- **risk-integration** `skills/design/scripts/plan-review-loop.sh:177` — `_materialize_scope_anchor` is invoked with no return-code check. On strip failure (`MALFORMED=…`), empty post-strip body, or path sanity failure, the function returns **2** but the loop continues into scout/panel/voter dispatch with `SCOPE_ANCHOR_FILE` still bound to `$DESIGN_TMPDIR/plan-review-scope-anchor.txt`. That file may be missing or stale from a prior round/session. Reviewer rendering degrades silently when the file is unreadable (`render-plan-review-prompt.sh` only inlines when `-r`), while `dispatch-plan-voters.sh` hard-fails on unreadable `--scope-anchor-file`, producing inconsistent failure modes and defeating the scope-anchor contract on malformed `larch:plan` bodies (explicitly required to “fail loud” in the plan). **Suggested fix:** Check `_materialize_scope_anchor`’s exit status and `exit 2` (or `panel-failed` with loud error) before any dispatch; delete or truncate any pre-existing `plan-review-scope-anchor.txt` before materialization so a failed run cannot reuse stale scope. Add the plan-listed malformed-`larch:plan` regression in `test-plan-review-loop.sh`.

- **risk-integration** `skills/design/scripts/render-main-agent-scope-anchor.sh:22-33` — The new MainAgent renderer accepts any readable `--scope-anchor-file` path with no `DESIGN_TMPDIR` containment or symlink rejection, unlike `run-step3-review.sh:148-173` which canonicalizes and clears paths outside the design tmpdir. SKILL.md Step 3 instructs the orchestrator to call this helper whenever `$SCOPE_ANCHOR_FILE` is readable, without re-running the driver-side sanitizer. If durable result state is ever poisoned (stdout-only fallback, manual env edit, pause/resume drift), MainAgent voting can read arbitrary host files while voters/reviewers were anchored to the staged tmpdir copy. **Suggested fix:** Mirror `validate_scope_anchor_handoff` inside `render-main-agent-scope-anchor.sh` (reject symlinks, require path under caller-supplied `--design-tmpdir`, reject CR/LF), and pass `--design-tmpdir "$DESIGN_TMPDIR"` from SKILL.md. Add a focused harness for rejection of `/tmp/outside` and symlink paths.

- **risk-integration** `skills/design/scripts/test-run-step3-review.sh:564-571` — The plan called for CR/LF rejection, outside-`DESIGN_TMPDIR` clearing, `IMPLEMENT_TMPDIR` precedence, and `SCOPE_ANCHOR_FILE` parse/emit coverage; none of those cases are present (only a key-presence check at line 748). The main-agent stub omits `SCOPE_ANCHOR_FILE` and no longer matches production behavior after `recover_main_agent_scope_anchor` was added, so the harness currently fails silently mid-run rather than guarding the handoff contract. **Suggested fix:** Extend the harness with fixtures for CR/LF clearing, outside-path clearing, canonical recovery from `plan-review-scope-anchor.txt`, design-wins feature-file launch when `IMPLEMENT_TMPDIR` is set, and a fixed main-agent case that seeds the staged anchor file before asserting preservation.
