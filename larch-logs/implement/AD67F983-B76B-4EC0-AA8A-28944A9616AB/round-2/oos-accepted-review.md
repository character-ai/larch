### OOS_2: **risk-integration** `python/test_review_and_fix.py:583-595` — The new mid-round Step 5 harness starts a **non-daemon** worker and only calls `worker.join(5)`. If `step5` never reaches the monkeypatched `_run_round` (preflight hang, unexpected exception before the fake runs, or join timeout under load), `release_round` in `finally` does not unblock the worker, `join(5)` can return while the thread is still alive, and the follow-on `assert not worker.is_alive()` fails without terminating the thread. Python then blocks interpreter shutdown on the orphan thread, which can stall the whole `make py-test` shard with no outer timeout configured. **Suggested fix:** Mark the worker `daemon=True`, or use a bounded join helper that fails the test explicitly and documents the stall (e.g. `threading.Thread.join` return value / `is_alive()` check with a hard pytest failure message), and add a `@pytest.mark.timeout` (or equivalent) on this test so CI cannot hang indefinitely.
