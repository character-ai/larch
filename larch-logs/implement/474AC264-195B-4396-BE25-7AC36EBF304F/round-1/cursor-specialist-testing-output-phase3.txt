- **Latent** **risk-integration** `skills/design/scripts/design-postplan-emit.sh:195-198` — `parse_kv_from_output "$_snap_out"` is called on the `2>&1`-merged output of `snapshot-plan-round.sh`. The function matches `EMIT_PLAN_STATUS`, `DIFF_LINES`, `VALIDATE_STATUS`, and other already-set KV keys. If `snapshot-plan-round.sh` emits any stdout/stderr line whose prefix matches those key names (e.g. a breadcrumb or error containing `=`), it would silently overwrite variables already populated by the EMIT step. The helper is unlikely to emit such lines in practice, but this call is also unnecessary since only `_snap_rc` is used from the snapshot step. **Suggested fix:** remove `parse_kv_from_output "$_snap_out"` after the snapshot call; the snapshot helper does not emit KV output consumed by this driver.

- **Nit** **risk-integration** `skills/design/scripts/test-design-postplan-emit.sh` — Case 8 exercises the `_val_rc != 0` validator-infra-failure branch.
