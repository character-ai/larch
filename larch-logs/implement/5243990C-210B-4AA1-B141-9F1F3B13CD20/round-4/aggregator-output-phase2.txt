### FINDING_1: EMIT_BODY gated on snapshot_ok suppresses re-emit when prebody absent or snapshot fails
- **Reviewer(s)**: cursor-specialist-structure-output.txt, cursor-specialist-testing-output.txt, cursor-specialist-edge-cases-output.txt, cursor-specialist-plan-fidelity-output.txt, dyn-emit-body-snapshot-semantics-output.txt
- **Severity**: important
- **Concern**: Post-write `EMIT_BODY` promotion requires `snapshot_ok=true` before `cmp` runs when `.step17-emitted` is already present. Legacy inline Step 18 treated a missing `.step18-prebody` as a body change (`! cmp` succeeds). When the sentinel exists but pre-write `summary-final.md` is missing, pre-write `cp` to `.step18-prebody` fails, or only a failed snapshot is taken, a successful `write-final-report.sh` that produces a new non-empty body leaves `EMIT_BODY=false` and the orchestrator skips the verbatim Step 18 re-emit despite material body refresh (including cost-line updates).
- **Suggested revisions (informational for voters; coder decides)**:
  - From cursor-specialist-structure-output.txt: Restore legacy cmp semantics (treat missing prebody as changed): drop snapshot_ok from the cmp branch or use [ ! -f prebody ] || ! cmp -s ...; add harness case for sentinel present + no pre-write summary.
  - From cursor-specialist-testing-output.txt: Confirm intent; either remove snapshot_ok guard to match plan/prior behavior, or document the guard and add harness cases for cp-fail/body-changed and cp-fail/body-unchanged.
  - From cursor-specialist-edge-cases-output.txt: Treat failed snapshot like missing prebody or cmp when post-write body is non-empty; add harness with forced cp failure
  - From cursor-specialist-edge-cases-output.txt: Document invariant or widen gate when sentinel present but pre-body absent and WFR_RC=0
  - From cursor-specialist-plan-fidelity-output.txt: Match legacy cmp semantics: treat missing prebody as diff, or drop snapshot_ok requirement when prebody is absent; add harness for sentinel-present + no successful snapshot + successful write.
  - From dyn-emit-body-snapshot-semantics-output.txt: In the `emit_body=false` branch after a successful write, treat “no pre-write snapshot” as eligible for cmp (e.g. drop the `snapshot_ok` guard and use `cmp` only when `.step18-prebody` exists, or set `emit_body=true` when `snapshot_ok=false`, `wfr_rc=0`, and the new body is non-empty). Add a harness case in `skills/implement/scripts/test-step-18b-final-report.sh` (sentinel present, no pre-write `summary-final.md`, write succeeds) and align `skills/implement/scripts/step-18b-final-report.md` step 4 if the contract changes.
