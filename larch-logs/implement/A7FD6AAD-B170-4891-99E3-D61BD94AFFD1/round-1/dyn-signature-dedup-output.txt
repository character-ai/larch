Reviewing signature dedup correctness: reading the diff and the relevant implementation files.
### In-Scope Findings

- **correctness** `scripts/lib-failed-agent-stderr-tail.sh:119-120` — The session-path normalization builds a `sed -E` regex from `home_cache="${HOME:-}/.cache/larch/sessions"` with only `/` escaped (`${home_cache//\//\\/}`). Other `sed` metacharacters in `HOME` (notably `#`, which is also the pattern delimiter, plus `.`, `*`, `[`, `\`, `&`, etc.) are injected verbatim into the pattern. A `#` in `HOME` can break the `s#…#<path>#g` command outright; with `set -o pipefail` in `scripts/collect-agent-results.sh:92`, a failing `norm=$(… | sed …)` pipeline makes `failed_agent_stderr_signature` exit non-zero before `cksum`, and `scripts/collect-agent-results.sh:1481-1482` treats that as “no signature” and `continue`s—so the first (and only) full stderr tail for that slot is never emitted on the collector path. Even when `sed` does not fail, unescaped `.` in typical usernames (e.g. `john.doe`) matches any character in ERE, widening path normalization and increasing false “identical failure” dedup (`scripts/collect-agent-results.sh:1485-1488`) for distinct root causes. **Suggested fix:** Do not embed `HOME` in a dynamic `sed` regex. Prefer a fixed, delimiter-safe substitution (e.g. `printf '%s\n' "$norm" | sed "s|$(printf '%s' "$home_cache" | sed 's/[[\.*^$[]/\\&/g')|[^[:space:]]*|<path>|g"` with a tested escaper, or a non-regex path strip such as a small `awk`/bash loop using literal prefix match). Add harness cases with `HOME` containing `.` and `#` (and assert dedup still emits the first tail).

- **correctness** `scripts/lib-failed-agent-stderr-tail.sh:105-124` — `failed_agent_stderr_signature` has no guard around the `home_cache` `sed` pipeline; callers with `pipefail` (`scripts/collect-agent-results.sh:92`) inherit failure from line 120 as function failure, which is indistinguishable from “no tail” at `scripts/collect-agent-results.sh:1481-1482` and drops emission entirely rather than falling back to a checksum of partially normalized text. **Suggested fix:** Wrap the `home_cache` normalization in `set +o pipefail` / `|| true` (mirroring `render_failed_agent_stderr_tail:75-77`) or check `sed`’s exit status and continue to `cksum` on the pre-home `norm` so a bad `HOME` only weakens dedup, never suppresses the first tail.

No defect found for the empty-map first iteration.

- **Harness gap** (`scripts/test-lib-failed-agent-stderr-tail.sh:92-102`): Signature tests cover `/tmp/foo123` vs `/tmp/foo456` stability but not `HOME`-derived session paths or metacharacter `HOME` values; that gap is pre-existing relative to the scout focus once the `sed` embedding is fixed.
