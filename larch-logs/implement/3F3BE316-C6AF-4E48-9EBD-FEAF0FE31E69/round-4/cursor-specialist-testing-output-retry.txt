A regression that clears in-memory first or promotes a bad temp file would not be caught. **Suggested fix:** Add a negative fixture: temp file still `STALL_TRACKING=true` after write, or `read-session-env-key.sh` forced to return `true` on temp read-back; assert the reference path keeps both layers true and does not take `[DONE]`.
