### In-Scope Findings

1. **Important** `scripts/design-log-publish.sh:518-522` — On `--reason pause`, empty porcelain short-circuits to `PUBLISH_OK=true` when `origin/<default>` already has `larch-logs/design/<RUN_ID>/manifest.json`, **before** considering whether `origin/larch-log-design-<RUN_ID>` is ahead. After a successful main merge (older snapshot) and a later pause that only lands on the recovery branch (merge blocked), a no-op republish can return success without `LOG_RECOVERY_BRANCH`, while `design-pause-save.sh` still writes a fresh marker. Resume then `git archive`s from default and restores stale artifacts while the marker claims a newer `STEP`. **Suggested fix:** When `REMOTE_BRANCH_EXISTS` and porcelain is empty, compare trees (or at least `.completed/` / manifest `updated_at`) between `origin/<default>` and `origin/$WT_BRANCH`; prefer recovery / emit `RECOVERY_BRANCH` when they differ. Only treat main-only manifest as success when recovery is absent or identical.

2. **Important** `skills/design/SKILL.md:72-73` + `scripts/design-pause-save.sh:33-36` — The defensive prelude uses `exec design-pause-save.sh`, and save emits `PAUSE_OK=false` with **exit 0**. If save fails (e.g. `marker-write-failed`, `publish-and-recovery-failed`) while `.pause-requested` remains, the Bash block ends with exit 0 and the rest of that step’s commands never run, but nothing in SKILL.md requires parsing `PAUSE_OK` or stopping `/design`. The operator can believe pause failed while the run advances with a truncated step. `/larch:pause` checks `PAUSE_OK` and exits 1; the prelude path does not. **Suggested fix:** Have `design-pause-save.sh` exit non-zero on `PAUSE_OK=false` when `LARCH_DESIGN_PAUSE_PRELUDE=1`, or replace `exec` with a call that parses stdout and `exit 1` on failure.

3. **Important** `scripts/design-pause-load.sh:197-209` — After validation, the loader deletes the issue marker, then `cp -R` into `$DESIGN_TMPDIR`. If `cp` fails (`restore-install-failed`), the marker is already gone and the next `/design` starts fresh with no resume pointer—worse than delete failure (which the harness covers). **Suggested fix:** Copy into `$DESIGN_TMPDIR` first (or only delete after a successful install), or restore the marker on `restore-install-failed`.

4. **Latent** `scripts/design-pause-load.sh:208-209` — Restore uses `cp -R "$restore_tmp"/. "$DESIGN_TMPDIR"/` without clearing pre-existing files from Step 0a `session-setup.sh`. Stray files not in the tarball can survive resume. **Suggested fix:** Extract into an empty staging dir and replace tmpdir contents (e.g. `rsync --delete` or `rm` + copy), or document that resume requires a pristine allocation.

5. **Latent** `scripts/design-pause-save.md:33-35` vs `scripts/design-log-publish.sh:518-522` — The save contract says a no-op pause publish “fails closed” so markers do not point at non-materialized snapshots, but publish returns `PUBLISH_OK=true` when default already has a manifest (and tests assert that). That is intentional idempotency on a single branch, but it conflicts with the save doc and enables finding #1 when main and recovery diverge. **Suggested fix:** Align the contract with behavior (document main-manifest no-op success) and narrow “fail closed” to the recovery-vs-main divergence case.

6. **Nit** `skills/design/SKILL.md:73` — Prelude pause-check passes only `--design-tmpdir` and `--issue`, not `${REPO:+--repo "$REPO"}`, while Step 0b load/save use explicit `REPO`. In multi-remote or fork layouts, save may resolve a different repo than load expects, causing `repo-mismatch` or silent wrong-repo `gh` calls. **Suggested fix:** Thread `REPO` through the prelude the same way as sub-step 2.5-bis (from `resolve-repo.sh` or `source-env.sh`).

### Out-of-Scope Observations

1. **architecture** `skills/pause/SKILL.md:45-46` — `/larch:pause` still creates `.pause-requested` before synchronous save even though FINDING_17 removed flag-only pause as the primary path. Harmless when save succeeds (flag removed), but redundant and can trigger a second save at the next `/design` boundary if the first save failed. Out of scope: not introduced by this branch’s core design (pattern predates round-2 diff focus).
