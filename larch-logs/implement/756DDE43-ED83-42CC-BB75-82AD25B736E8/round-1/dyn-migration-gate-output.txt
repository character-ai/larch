Reviewing `migration_lint.py` and the branch diff for migration-gate correctness.
### In-Scope Findings

- **correctness** `python/migration_lint.py:37-48` — `_ship_pr_live_ref` treats bare `basename.sh` tokens as live invocations, but `scripts/ship-pr.sh` uses those names only in `record_failure` diagnostic labels (e.g. `record_failure checks "git-commit.sh (post-checks-waterfall)"` at `scripts/ship-pr.sh:789`, `record_failure pr-create "create-pr.sh"` at `scripts/ship-pr.sh:1187`, `record_failure rebase "rebase-push.sh --no-push"` at `scripts/ship-pr.sh:2502`, `record_failure "$phase" "ci-wait.sh"` at `scripts/ship-pr.sh:2816`). Those are prose labels, not executable calls. The F18 carve-out is meant to ignore comment/prose mentions while still catching `$SCRIPT_DIR/<basename>` invocations; bare-basename matching breaks that and will keep flagging Deferred-to-E1 scripts even after live `$SCRIPT_DIR/...` calls are removed in E1. **Suggested fix:** Drop the bare `(?<!/)\b{basename}\b` arm from `_ship_pr_live_ref` and match only `$SCRIPT_DIR/${basename}` / `${SCRIPT_DIR}/${basename}` plus optional `source`/`.` prefixes (and quoted forms). Add pytest cases for a live `"$SCRIPT_DIR/git-commit.sh"` line (expect flagged) and a `record_failure ... "git-commit.sh (...)"` line (expect not flagged).

- **correctness** `python/migration_lint.py:51-58` — For non-`ship-pr.sh` files under `scripts/`, only full manifest paths and `$SCRIPT_DIR/<basename>` substrings are detected; bare `basename.sh` tokens in the same directory are not (e.g. `scripts/test-implement-rebase-macro.sh:164` `grep -cF 'rebase-push.sh'`). That matches `docs/python-migration.md:66-71`, but it is a real false-negative hole: a `scripts/test-*.sh` harness can keep a bare retired basename in a grep/assert string after cutover and still pass `lint-retired-scripts`. **Suggested fix:** Either extend `_line_references_retired` with a same-parent bare-basename live-invocation pattern (word-boundary `basename.sh` with invocation-like delimiters, excluding quoted diagnostic contexts), or require retargeted structural tests to assert full `scripts/<name>.sh` paths / CLI forms and add a regression test that bare-only grep pins are flagged.
