That combination both violates the “prose mentions do not block” rule and leaves a live invocation shape unguarded. **Suggested fix:** Require full-path/basename matches to occur only in shell command positions or after explicit `source`/`.` prefixes, and add tests for quoted full-path prose remaining clean and direct bare command invocations being flagged.
