### In-Scope Findings

- **correctness** `python/changelog.py:137-154` — `_rst_merge_first_index` only skips a leading `=`-underlined title when `lines[fh1] == "Changelog"` **or** that title is not in `_rst_release_section_indices`. `auto-resolve-changelog.sh` `rst_merge_fh` skips **any** first section whose underline is all `=` (`ul ~ /^=+$/`), with no title check. A semver release block at the top with an `=` underline (non-standard but valid-looking RST) is treated as the merge/insert anchor in Python while bash skips it—`auto_resolve`, `write_changelog_entry`, `drop_version_section`, and `extract_version_body` can diverge from the shell on the same file. **Suggested fix:** Drop the `(lines[fh1] == "Changelog" or fh1 not in release_indices)` guard and mirror bash: skip whenever `is_rst_adornment(ul, title)` and the underline is all `=`; keep the “need a second section” guard. Add a unit/parity fixture with a top-level `Version X.Y.Z` + `===` underline.

- **correctness** `python/version_bump.py:131-140` — `_extract_frontmatter` treats the opening delimiter as `lines[0].strip() == "---"`, and closes on any line with `line.strip() == "---"`. Bash `classify-bump.sh` requires `^---$` at column 0 (no surrounding whitespace). A skill/agent file whose first line is ` --- ` or `--- ` can be classified differently (flag/`name:` evidence) between Python and bash. **Suggested fix:** Match bash literally: only enter frontmatter when `lines[0] == "---"` (no strip), and only close on a line exactly equal to `---`.

- **correctness** `python/changelog.py:514-524` — `_insert_rst_after` always appends `"\n"` (`return result + "\n"`), while `_write_md_entry`, `_drop_md_section`, and `_drop_rst_section` preserve whether the input ended with a newline. Markdown writes via awk/`print` always end with a newline; RST insert can add a newline to a previously newline-free file and change byte-level diffs on round-trip edit/drop. **Suggested fix:** Use the same rule as `_write_md_entry`: `return result + ("\n" if original_text.endswith("\n") else "")`, passing the source `text` through `_write_rst_entry` / `_insert_rst_after`.
