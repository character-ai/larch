### In-Scope Findings

- **[correctness]** [`skills/review/scripts/collect-findings.sh:281-284`](skills/review/scripts/collect-findings.sh) — The new `/^##/` rule matches any line whose first two characters are `##`. In awk, that includes every `### ...` line that does **not** match the two earlier exact headers (`### Out-of-Scope Observations`, `### In-Scope Findings`). A non-canonical third-level heading (e.g. `### Notes` between sections) therefore runs `flush(); skip=1; next` and subsequent list bullets are dropped until another canonical header clears `skip`, whereas before they would have been folded into the prose `NF` path. That is a real narrowing of accepted reviewer grammar introduced by this branch. **Suggested fix:** Restrict the skipper to level-2 headings only (for example require the third character not to be `#`, or match `^## ` / `^##[^#]` with an explicit `^##$` edge case), or add explicit allow patterns for benign `###` subheads if you want to keep `^##` as written.
