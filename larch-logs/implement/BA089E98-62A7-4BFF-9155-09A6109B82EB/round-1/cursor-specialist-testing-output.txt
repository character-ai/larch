1. **`**Important**` (`risk-integration`, `plan`) — [scripts/collect-agent-results.sh](scripts/collect-agent-results.sh) (NOT_SUBSTANTIVE retry block ~892–1035)**  
   The implementation plan required a fallback when only `CMD_JSON` is present (re-launch via `run-external-agent.sh` like the empty-output retry path). The diff only retries when `.meta` has `OUTER_LAUNCHER*` fields; reviewers that only have `CMD_JSON` metadata never get a NOT_SUBSTANTIVE retry. **Scenario:** a slot that still uses the inner `CMD_JSON` launch path can remain `NOT_SUBSTANTIVE` with no retry even though the plan promised one. **Fix:** implement the `CMD_JSON` branch (mirroring section 3 empty-output retry) and add a harness case that proves it runs.

2. **`**Important**` (`risk-integration`, `plan`) — [scripts/test-collect-agent-results.sh](scripts/test-collect-agent-results.sh):266-290**  
   `C_NSR` only asserts the initial `STATUS=NOT_SUBSTANTIVE` and then treats either presence or absence of `-ns-retry.txt.done` as success, so the test cannot fail on a broken retry pipeline. The plan called for verifying the retry path including validation and outcome. **Scenario:** regressions in `wait-for-reviewers`, launcher wiring, or `validate-research-output` on retry output could ship unnoticed. **Fix:** stub a minimal launcher that writes non-empty `*-ns-retry.txt` + `.done` with `0` and structured-valid content, then assert `STATUS=OK` and `REVIEWER_FILE=…-ns-retry.txt`; add a negative case where retry output still fails validation.

3. **`**Latent**` (`correctness`) — [skills/review/scripts/tally-code-votes.sh](skills/review/scripts/tally-code-votes.sh):434-437**  
   Dead-slot rows use `collector_status[normed]` when present, otherwise hard-code `NOT_SUBSTANTIVE`. **Scenario:** a manifest slot missing from `collector-results.env` (dispatch skip, parsing gap, or partial file) is labeled `NOT_SUBSTANTIVE` even when the real reason is not narrative-only output. **Fix:** use a distinct default such as `UNKNOWN` / `NO_COLLECTOR_STATUS` or omit the row until a status is known.

4. **`**Latent**` (`risk-integration`) — [skills/review/scripts/tally-code-votes.sh](skills/review/scripts/tally-code-votes.sh):351-377 vs 382-437**
