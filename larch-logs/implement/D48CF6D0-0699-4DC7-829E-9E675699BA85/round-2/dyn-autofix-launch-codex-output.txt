### In-Scope Findings
- **risk-integration** `skills/design/scripts/auto-fix-plan-commands.sh:234-249` — The write-enabled Codex/Cursor fixer is treated as successful solely when `validate-plan.sh` returns `VALIDATE_STATUS=ok`; there is no post-dispatch guard that the target is still a regular file under `$DESIGN_TMPDIR`, that only the flagged fenced commands changed, or that other session files were untouched. This is especially risky for Step 5c, where `skills/design/SKILL.md:1775` resumes publish without prompting and `skills/design/scripts/design-publish.sh:360-382` writes the fixed `composed-plan.md` to GitHub after validation. A buggy or untrusted fixer can rewrite approved plan prose or session artifacts and still pass the command validator. **Suggested fix:** Run the fixer against an isolated copy or snapshot/digest `$DESIGN_TMPDIR` before dispatch; after dispatch, reject symlink/out-of-scope target replacements, diff pre/post content, allow only expected command-block edits, and restore/abort on any other session-file changes. For Step 5c, either apply a constrained patch back to the approved composed plan or return the changed plan through Gate C before publish.

- **risk-integration** `skills/design/SKILL.md:1740-1747` — The durable auto-fix cap is keyed only by `<SITE>` and is created before the helper runs, so one Gate B or discussion validator failure consumes auto-fix for every later failure at that same site in the session. Subsequent review rounds can produce independent command defects in new plan content, but they will hit `AUTOFIX_STATUS=skipped-cycle-cap` and go straight to the operator prompt even though auto-fix was not exhausted for that defect. A transient helper/config failure before any vendor dispatch also permanently burns the site. **Suggested fix:** Key the sentinel by site plus target file and failure generation, such as review round/cursor and a hash of the failing plan or validator log, or clear/rotate it after a clean success; only suppress repeated auto-fix for the same unchanged failing artifact.
