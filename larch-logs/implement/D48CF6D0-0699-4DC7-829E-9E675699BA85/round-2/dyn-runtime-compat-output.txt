### In-Scope Findings

- **risk-integration** `skills/design/scripts/auto-fix-plan-commands.sh:150-223` — Component D grants Codex/Cursor workspace write access under `$DESIGN_TMPDIR`, but the helper never runs a post-dispatch integrity check (unlike sketch/plan-review collection, which call `check-mid-run-dirty-tree.sh --mode checkpoint`). A vendor can mutate or create other tmpdir artifacts besides `--plan-file`, and the orchestrator will still treat `AUTOFIX_STATUS=ok` as success and continue the Gate B / Step 5c pipeline on potentially corrupted session state. **Suggested fix:** Snapshot a bounded set of `$DESIGN_TMPDIR` paths before dispatch and fail closed (or log and escalate) when unexpected files change after each attempt; alternatively invoke the existing mid-run dirty-tree checkpoint with a design-tmpdir-scoped mode.

- **risk-integration** `skills/design/SKILL.md:1247` — The Step 3.5 tail still says Round 2 discussion is reached via “Gate B's **Switch to discussion mode**”, but default auto-apply (`approve_requested=false`) skips the Gate B prompt entirely; `approval-gates.md` documents that `Switch to discussion mode` is reachable only under `--approve`, with default-path discussion via Gate C “Discuss further”. Stale orchestrator guidance is a control-flow integration bug waiting to happen on resume/pause or long sessions. **Suggested fix:** Reword that paragraph to match `approval-gates.md`: default path → Gate C “Discuss further”; Gate B switch → `--approve` only.

- **risk-integration** `Makefile:32-38` — The bundled #3629 Python 3.11 alignment adds an explicit `>=3.11` guard on `py-test` but not on `py-lint`, while `docs/linting.md` and CI now describe both as Python 3.11 jobs and `scripts/relevant-checks.sh` gates `py-test` at 3.11+ but only checks tool presence for `py-lint`. On Python 3.10 hosts, `make py-lint` fails opaquely instead of emitting the clear floor error `py-test` already does. **Suggested fix:** Add the same version probe to the `py-lint` recipe (and optionally mirror it in `maybe_append_py_lint_target`).

- **risk-integration** `scripts/test-design-structure.sh:781-1976` — Acceptance criteria call for regression coverage of default Gate B auto-apply (no prompt) and `--approve` restore, but the branch only adds prose/structure pins (`contains`/`grep -Fq` on `SKILL.md` / `approval-gates.md`).
