This means an exhausted/failed auto-fix can still silently alter the plan that the operator is asked to Fix/Override/Cancel. **Suggested fix:** Snapshot the target file before each vendor attempt and restore it on every non-success path; only keep the target edit after revalidation returns `VALIDATE_STATUS=ok`, and add harness assertions that exhausted/guard-failed attempts leave the target unchanged.
