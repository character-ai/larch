### In-Scope Findings
- **risk-integration** `skills/design/scripts/auto-fix-plan-commands.sh:345-382` — Repository dirty-tree deltas detected after a vendor attempt are not sticky and are not restored. The helper sets `dispatch_rc=90` for that attempt, then continues to the next vendor; the next attempt snapshots the already-dirty repo as its new baseline, so a later successful validation can return `AUTOFIX_STATUS=ok` while the repo remains mutated by the earlier failed vendor attempt. **Suggested fix:** Treat any repo dirty-tree delta as terminal for the auto-fix cycle: compare every attempt against the original pre-autofix repo baseline, emit a failed/exhausted status, and prevent `AUTOFIX_STATUS=ok` until the dirty state is cleaned or mechanically restored.

- **risk-integration** `skills/design/scripts/auto-fix-plan-commands.sh:127-161` — The target-file-only guard snapshots only regular files via `find . -type f`, so off-target directories, symlinks, fifos, or other non-regular paths created under `$DESIGN_TMPDIR` are invisible to both the manifest comparison and restore path. A vendor can leave a new symlink or directory outside `plan-autofix/**` and still pass the guard if no regular-file manifest changes occur. **Suggested fix:** Snapshot all filesystem entries except the target and `plan-autofix/**` using NUL-delimited paths with type metadata, reject symlinks/special files, and remove added directories/files in depth order before allowing success.

- **risk-integration** `skills/design/scripts/auto-fix-plan-commands.sh:362-375` — Successful auto-fix is gated only on `validate-plan.sh` returning `VALIDATE_STATUS=ok`, but that validator only checks parsed plan commands; it does not prove the vendor preserved non-command prose, headings, scope, or intent despite the prompt’s byte-for-byte preservation instruction at `skills/design/scripts/auto-fix-plan-commands.sh:208-213`. This can silently accept broad target-file rewrites as long as command validation passes. **Suggested fix:** Before dispatch, snapshot the target file and after dispatch mechanically diff it, allowing only the minimal command-fence regions implicated by the validator defects plus permitted metadata normalization; otherwise restore the target and exhaust/escalate to the operator prompt.
