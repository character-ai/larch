Peer dispatch scripts in this repo (`skills/design/scripts/revise-plan-with-waterfall.sh:68`, `skills/design/scripts/dispatch-plan-review-panel.sh:53`, `skills/design/scripts/decompose-panel-dispatch.sh:56`) all fail closed on non-numeric/zero timeouts; a malformed `--timeout` here can produce undefined launcher behavior instead of a clean exit 2. **Suggested fix:** Add the same `case "$TIMEOUT" in ''|*[!0-9]*|0)` guard used elsewhere (after argv parsing, before the attempt loop), normalize with `$((10#$TIMEOUT))`, and extend `test-auto-fix-plan-commands.sh` with a fail-closed case for an invalid `--timeout`.
