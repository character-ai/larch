Reviewing waterfall semantics in `python/agents.py` against the bash reference and the branch diff.
### In-Scope Findings
- **correctness** `python/agents.py:84-95,227-233` — `run_waterfall` gates the first-fixer short-circuit on `effective_failure_class(attempt)`, but that helper does not mirror bash `ship_pr_read_launcher_failure_class` when `failure_log` is present. If the capture file exists but has no valid `LAUNCHER_FAILURE_CLASS=` line (or only an unknown value), bash treats the class as `health` and keeps cascading (`scripts/ship-pr.sh:2076-2084` with `ship_pr_read_launcher_failure_class` at `1696-1706`), while Python falls back to `attempt.failure.failure_class`, which `classify_launch_failure` can still set to `other`. A first-tier attempt with `wrapper_rc == 0`, `launcher_exit != 0`, and a log file missing the KV would short-circuit in Python but not in bash—opposite of the “log without KV defaults to health” behavior already tested for `parse_launcher_failure_class` in `python/test_agents.py:42-49`. **Suggested fix:** When `attempt.failure_log` is set and the path is a file, delegate to `parse_launcher_failure_class(attempt.failure_log)` (same none/health/other + default-health rules as bash); only use `attempt.failure.failure_class` when no log path was supplied. Add a waterfall test with a nonempty capture file lacking `LAUNCHER_FAILURE_CLASS=` and `failure_class="other"` to assert no short-circuit, plus the mirror case with `LAUNCHER_FAILURE_CLASS=other` in the log.

### Out-of-Scope Observations
- **correctness** `python/agents.py:213-218,228-233` / `python/test_agents.py:233-249` — When `first_tier` is not in `tiers`, rotation is skipped and short-circuit uses `tier_list[0]` (`idx == 0` + `tier == first`). Bash always derives `first_tier` from the same fixed array it iterates (`scripts/ship-pr.sh:2032-2035`), so it never hits this case; the Python behavior is intentional per test but is a footgun for Phase 7 if a caller passes a mismatched `first_tier` without rotating. Prefer requiring `first_tier in tiers` or documenting that absent `first_tier` means “first list element is the policy tier.”
