# scripts/test-implement-finalize.sh — contract

`scripts/test-implement-finalize.sh` is the offline regression harness for `scripts/implement-finalize.sh`. The primary behavioral contract lives in `scripts/implement-finalize.md`; this sibling exists for script discoverability and documents only the harness role. The harness copies `implement-finalize.sh` into a `/tmp` sandbox, supplies stub sibling helpers plus git/gh shims for postbump larch-log writes, CHANGELOG detection/commit, rebase, remote-branch detection, force-push, local cleanup, verify-main, issue lookup, title rename, tmpdir cleanup, stalled-run auto-stash, and sentinel writing, then exercises the subcommands plus state-file parsing without touching real git, GitHub, or the caller's real `$IMPLEMENT_TMPDIR`. It covers postbump happy path, categorized and fallback CHANGELOG bullets, compact Step 8/8a/8b/14/15/18 breadcrumbs, skip paths, conflict checkpoint resume, corrupt checkpoint rejection, remote-check and force-push failures, changelog-failed routing, and validation failures. It also asserts `.run-cleaned-up` is written before tmpdir cleanup, is still written when cleanup target validation refuses removal, and is best-effort when the touch operation fails. It includes a regression case for teardown's session-scoped background process termination: a real background process whose argv contains the session tmpdir path is launched, teardown is invoked, and the test asserts the process was killed and a warning breadcrumb was emitted.
