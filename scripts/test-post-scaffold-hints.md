# scripts/test-post-scaffold-hints.sh — contract

Black-box regression harness for `skills/create-skill/scripts/post-scaffold-hints.sh`. Each case invokes the hints script with controlled `--target-dir` and `--plugin` flags and asserts on exit code plus the presence (or absence) of specific literal tokens in stdout — the scaffolded-path line, the plugin-dev block, the dual `Skill` permission lines, the `Bash` permission line, and the README-subsection cross-reference. Asserts on contract-critical tokens (not full-text equality) so additive churn in the common reminder block does not force test changes. Wired into `make lint` via the `test-post-scaffold-hints` target. The full contract for the primary script is owned by `skills/create-skill/scripts/post-scaffold-hints.md`. Per `.claude/rules/script-md-siblings.md`, the harness lives under `scripts/` (cross-tree) but its sibling `.md` here serves as the discoverability stub; the canonical contract remains with the primary.
