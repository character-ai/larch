# scripts/test-lint-literal-counts.sh - contract

Black-box regression harness for `scripts/lint-literal-counts.py`, invoked as `python3 scripts/lint-literal-counts.py --root "$TMPROOT"` against a `mktemp -d` fixture root with `trap 'rm -rf "$TMPROOT"' EXIT` cleanup. Cases a-s cover: clean prose; single `5 reviewers` violation with message text; fenced-code exemption; same-line allow pragma with reason; empty allow reason rejected; every plural noun in the lint regex; mid-line count exemption; multi-file aggregation; BOM/CRLF normalization; non-UTF-8 internal error; exit-code 2 priority when errors and violations coexist; off-by-one fence close behavior; empty root; lowercase-only `allow`; nested 4-tick/3-tick fence length awareness; git worktree enumeration plus `.gitignore`/`.agents/` exclusion, paired with non-git fallback exclusion and a non-excluded control file; symlink non-following; positional-argument rejection; and untracked-non-ignored markdown coverage (case `s`) — the regression guard for `git ls-files --cached --others --exclude-standard` so a fresh untracked `.md` cannot bypass the lint under `pass_filenames: false`. The harness uses `assert_case`, `write_md`, `reset_tree`, and `run_lint` helpers, prints `Summary: $PASS passed, $FAIL failed`, exits 0 when all assertions pass, and exits 1 on any assertion failure. It exercises every primary code path: length-aware fence state, BOM/CRLF read posture, allow-pragma parser, exit-code precedence, git-worktree-aware file enumeration, gitignored-dir exclusion, symlink non-following, and argparse's `--root`-only CLI. Wiring expectations are Makefile target `test-lint-literal-counts`, one `test-harnesses-N` shard entry (currently shard 2), and an `agent-lint.toml` exclude for the `.sh` only, mirroring the `test-lint-skill-invocations.sh` precedent.
