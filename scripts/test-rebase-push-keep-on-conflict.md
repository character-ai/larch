# scripts/test-rebase-push-keep-on-conflict.sh — contract

`scripts/test-rebase-push-keep-on-conflict.sh` is the offline regression harness for `scripts/rebase-push.sh --keep-on-conflict`. It creates isolated temporary git repositories with a bare `origin`, pins the legacy `--no-push` conflict behavior (abort rebase, exit 1, no stdout), pins the new `--no-push --keep-on-conflict` behavior (leave rebase in progress and emit `CONFLICT_FILES=...`), verifies `--continue --no-push --keep-on-conflict` completes a resolved local-only rebase without pushing a feature branch, and verifies `--keep-on-conflict` without `--no-push` fails with exit 3. Wired into `make lint` via the `test-rebase-push-keep-on-conflict` target. Edits to `scripts/rebase-push.sh` conflict handling, `--continue --no-push`, or flag validation must keep this harness and `scripts/rebase-push.md` in sync.
