# scripts/post-slack-message.sh — contract

`scripts/post-slack-message.sh` is the low-level Slack `chat.postMessage` poster. All higher-level Slack composers (`scripts/post-issue-slack.sh`, `scripts/post-research-slack.sh`, `scripts/post-design-slack.sh`, etc.) call this script after composing the message text. Inputs: `--channel-id`, `--text` (Slack mrkdwn), `--token` (Slack bot token), optional `--username`, optional `--slack_timestamp` (for in-thread replies). Stdout: the message timestamp on success. Exit 0 on success, 1 on missing arguments or API failure. Tokens are passed by flag (not env var) so the composing scripts retain control over where the token is sourced from (`LARCH_SLACK_BOT_TOKEN` first, then `CLAUDE_PLUGIN_OPTION_SLACK_BOT_TOKEN`). This script does NOT itself read environment variables — that policy lives one layer up.
