# lib-resolve-active-larch-session.sh

Purpose: resolve whether a Claude Code hook event belongs to an active larch `/implement` or `/review` session. It is an executable helper, not a sourced library, so hooks can call it without sharing shell state.

Primary caller: `scripts/hook-block-skill-relevant-checks.sh`.

Input: hook JSON on stdin. The helper reads `.cwd` with `jq`. The hook payload's `.session_id` (Claude transcript namespace) is intentionally NOT consulted — see "Resolution contract" below. Missing `jq`, malformed JSON, or missing `cwd` all fail open with empty stdout and exit 0.

Resolution contract: scan accepted larch session roots for `claude-implement-*` and `claude-review-*` directories containing `.larch-keepalive`. The accepted roots are `${XDG_CACHE_HOME:-$HOME/.cache}/larch/sessions/` (canonical) AND `/tmp` and `/private/tmp` (the fallback `session-setup.sh` uses when the cache root is unwritable; macOS resolves `/tmp` to `/private/tmp`). A candidate matches when `CLONE_PATH=<cwd>` is present and exact and the keepalive is fresh per the TTL below.

The keepalive's `SESSION_ID` value (uuidgen, generated by `session-setup.sh`) is in a different namespace from the Claude hook payload's `.session_id` (Claude transcript / session id) and they never match in production. Binding on cwd + TTL only is the production-correct contract; the helper does NOT compare hook `session_id` against keepalive `SESSION_ID`.

The helper does not depend on `manifest.env`, so quick-mode `/implement` and standalone `/review` sessions are covered.

Staleness: `.larch-keepalive` mtime must be younger than `LARCH_ACTIVE_SESSION_TTL_SECONDS` (default 21600). Set the variable to `0` in tests to disable TTL. When `date +%s` or `stat` cannot produce numeric values, the candidate is skipped.

Output: empty stdout on no match. On match, one line:

```text
PREFIX=claude-implement TMPDIR=/path/to/session
```

or `PREFIX=claude-review ...`.

Harness: `scripts/test-hook-block-skill-relevant-checks.sh` covers resolver-positive, resolver-negative, stale, cwd mismatch, hook-session-id-mismatch (must still deny — confirms cwd-only binding), and jq-missing behavior through the hook.

Edit in sync: update this file, `scripts/hook-block-skill-relevant-checks.sh`, and `scripts/test-hook-block-skill-relevant-checks.sh` when changing keepalive keys, root enumeration, TTL behavior, or stdout grammar.
