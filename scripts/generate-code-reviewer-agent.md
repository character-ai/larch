# scripts/generate-code-reviewer-agent.sh — contract

`scripts/generate-code-reviewer-agent.sh` regenerates `agents/code-reviewer.md` from the canonical archetype in `skills/shared/reviewer-templates.md` (template-substitution, no hand-edits to the agent file). Two modes: default `write` mode rewrites `agents/code-reviewer.md` in place; `--check` mode exits non-zero if the committed agent file would drift from generator output. Determinism is load-bearing: `LC_ALL=C`, no timestamps, no git state in output, hard-coded substitution map (`{REVIEW_TARGET}`, `{CONTEXT_BLOCK}`, `{OUTPUT_INSTRUCTION}`). Enforcement: in CI the `agent-sync` job runs `scripts/check-generators.sh` (the registry walker), which dispatches every generator listed in `scripts/generators.tsv` — including this one — in `--check` mode and fails on drift. Locally, `make test-check-generators` (or the broader `make lint`, which transitively reaches the walker via `make test-harnesses` → `test-harnesses-5` → `test-check-generators`) exercises the same check; there is no pre-commit hook today. Editing the archetype in `skills/shared/reviewer-templates.md` requires re-running the script in the same PR. See `AGENTS.md` "Adding/modifying the Code Reviewer archetype" for the canonical workflow.
