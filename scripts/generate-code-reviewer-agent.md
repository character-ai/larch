# scripts/generate-code-reviewer-agent.sh — contract

`scripts/generate-code-reviewer-agent.sh` regenerates `agents/code-reviewer.md` from the canonical archetype in `skills/shared/reviewer-templates.md` (template-substitution, no hand-edits to the agent file). Two modes: default `write` mode rewrites `agents/code-reviewer.md` in place; `--check` mode (used in CI) exits non-zero if the committed agent file would drift from generator output. Determinism is load-bearing: `LC_ALL=C`, no timestamps, no git state in output, hard-coded substitution map (`{REVIEW_TARGET}`, `{CONTEXT_BLOCK}`, `{OUTPUT_INSTRUCTION}`). Editing the archetype in `skills/shared/reviewer-templates.md` requires re-running the script (or the corresponding pre-commit / `make lint` invocation that wraps `--check`) in the same PR. See `AGENTS.md` "Adding/modifying the Code Reviewer archetype" for the canonical workflow.
