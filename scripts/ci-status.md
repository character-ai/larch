# scripts/ci-status.sh — contract

`scripts/ci-status.sh` is the snapshot probe invoked by `scripts/ci-wait.sh`. It fetches `origin/main`, queries `gh pr checks --json` for the named PR, and counts commits behind `origin/main`. Always exits 0 — status is communicated via three stdout lines in fixed order: `CI_STATUS=pass|fail|pending|merged`, `BEHIND_COUNT=<N>`, `FAILED_RUN_ID=<id>` (empty when no failure). `ci-decide.sh` consumes this output verbatim. Edits must keep the four `CI_STATUS` tokens stable — `ci-decide.sh`'s decision matrix and `/implement`'s Step 10 / 12 control flow both branch on these literals.
