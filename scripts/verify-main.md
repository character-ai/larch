# scripts/verify-main.sh — contract

`scripts/verify-main.sh` is the post-merge verification probe invoked by `/implement` Step 15. It confirms that `main`'s HEAD is the squash-merge commit produced by the just-merged PR, distinguishing real merges from concurrent main advancement. The match is dual-mode: prefix-match (commit message starts with the expected `<PR title> (#<PR number>)` — the normal squash-merge case) OR suffix-match on `(#N)` (the `--admin` merge case, where GitHub uses the first commit message as the merge subject but still appends `(#N)`). Outputs `VERIFIED=true|false`, `COMMIT_HASH=<short>`, `COMMIT_MESSAGE=<msg>`. The caller must have already checked out and pulled `main` (typically via `local-cleanup.sh`) — this script does not refresh `main` itself.
