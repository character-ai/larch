# scripts/lib-count-commits.sh — contract

`scripts/lib-count-commits.sh` is a sourced-only shell library (no shebang, not invokable directly) that defines `count_commits` for both `scripts/check-bump-version.sh` and `scripts/verify-skill-called.sh`. It distinguishes `ok` / `missing_main_ref` / `git_error` outcomes via a file-based side channel (`COUNT_COMMITS_STATUS_FILE`) so callers can fail-closed on degraded git state instead of silently mis-counting. The fail-closed status plumbing is the load-bearing invariant — callers MUST consult `STATUS` before trusting any returned commit count. This contract is also documented as a sub-bullet inside `scripts/verify-skill-called.md`; this file is the shared canonical anchor for both consumers, kept alongside the library per the AGENTS.md per-script-contract convention. Do NOT invoke `lib-count-commits.sh` directly. Edits must update both consumers and the regression harness `scripts/test-verify-skill-called.sh` in the same PR.
