# scripts/lib-validate-meta-path.sh - contract

`scripts/lib-validate-meta-path.sh` is a sourced-only shell library (no shebang, not invokable directly) that defines `validate_meta_scalar_path` for first-party writers of `OUTPUT_FILE=` records consumed by `scripts/collect-agent-results.sh`. Rejection messages use `larch_err` when that helper is defined (callers that sourced `scripts/lib-quiet.sh` first); otherwise they print to stderr. The full contract is owned by `scripts/run-external-agent.md`; this sibling exists for discoverability per `.claude/rules/script-md-siblings.md`. Update this file with `scripts/run-external-agent.md`, `scripts/run-external-agent.sh`, `scripts/launch-review.sh --tool gemini`, `scripts/test-run-external-agent.sh`, and `scripts/test-collect-agent-retry.sh` when the accepted `.meta` path alphabet or retry-substitution invariant changes.
