# scripts/gather-branch-context.sh — contract

`scripts/gather-branch-context.sh` collects the git diff (with 20 lines of context per hunk via `-U20`), changed-file list, and commit log for the current branch versus `main`, writing each to a separate file in the caller-supplied `--output-dir` and emitting `DIFF_FILE` / `FILE_LIST_FILE` / `COMMIT_LOG_FILE` / `COMMIT_COUNT` on stdout. Used by legacy callers and review helpers to feed external Codex / Cursor reviewers a stable, file-backed context bundle. The `DIFF_FILE` path is forwarded to reviewer launchers via `--diff-file` so each reviewer reads the pre-computed diff instead of independently running `git diff`. `COMMIT_COUNT` is forwarded to `launch-review.sh` via `--commit-count` so `render-specialist-prompt.sh` can omit the `git log` instruction when the branch has ≤5 commits (single-commit diffs get no benefit from the log since the commit is visible in the diff header). The script computes the merge-base once (`git merge-base HEAD main`) and uses it for all three commands: three-dot diff for `diff.txt` / `file-list.txt` (equivalent to GitHub's PR diff view), and two-dot log for `commit-log.txt` (shows only PR commits, not the symmetric difference). All three commands apply pathspec `:(exclude)larch-logs/**` so committed run-log artifacts are omitted from review/scout context inputs.

Harness: `scripts/test-gather-branch-context.sh` (Makefile `test-gather-branch-context`, shard `test-harnesses-8`). Splitting the three artifacts across files (rather than concatenating) keeps each surface independently parseable and avoids prompt-token bloat when only one is needed.
