# scripts/lint-bash32.sh - contract

`scripts/lint-bash32.sh` is a repo-wide static lint that rejects Bash 4+ constructs and known Bash 3.2 condition-probe hazards in tracked and untracked non-ignored `*.sh` and `*.inc.bash` files so the plugin remains usable on macOS system Bash 3.2. It detects associative-array declarations (`declare`/`typeset` options containing `A`), `mapfile`/`readarray`, parameter case conversion (`${var^^}` / `${var^}` / `${var,,}` / `${var,}`), namerefs (`declare`/`local` options containing `n`), `&>>`, coprocs (`coproc {` and `coproc NAME {`), and direct `command <grep-family>` probes in `if`/`elif` conditions. The grep-family rule covers `grep`, `egrep`, `fgrep`, `rg`, and `ripgrep` only when `command` appears directly after `if` or `elif` plus optional `!`; sanctioned subshell conditions such as `if ( command grep ... )` and piped probes such as `cat file | command grep ...` are not violations. Full-line comments are ignored. Same-line `# lint-bash32: ok <reason>` suppresses intentional fixture or reviewed exception lines only; use it narrowly.

The default root is the repository root. `--root PATH` exists for the regression harness and alternate-root scans. When `PATH` is a git worktree and `scripts/residual-bash-paths.txt` exists, file enumeration intersects manifest rows with `git ls-files --cached --others --exclude-standard -z -- '*.sh' '*.inc.bash'` so newly added, untracked, non-ignored residual shell scripts are scanned before staging while manifest rows missing from git are skipped. Without a manifest, enumeration uses the git listing alone. Non-git fixture roots fall back to a deterministic `find` walk over `*.sh` and `*.inc.bash`, excluding `.git/`, `node_modules/`, `.venv/`, and `.agents/`. Symlinks are not scanned. Exit codes are `0` clean, `1` violations, and `2` CLI/root errors. Violation output is written to stderr as `lint-bash32: <path>:<line>: Bash 3.2 incompatible: <rule>`.

The script also accepts positional `*.sh` and `*.inc.bash` paths. Positional paths are interpreted relative to `ROOT` and resolved through canonical parent directories before scanning so symlinked temp roots and embedded `..` segments cannot escape the lint root. Absolute paths inside `ROOT` are converted to relative paths before scanning; absolute paths outside `ROOT` are skipped with a warning. Non-shell positional paths are skipped with a warning. This mode is for pre-commit's incremental filename passing and scans only the listed paths.

Primary callers are the `lint-bash32` pre-commit hook, `make lint-bash32`, and the local `make lint` dependency chain. The pre-commit hook passes staged filenames positionally; `make lint-bash32` and local `make lint` keep the whole-repo untracked-aware scan. `scripts/test-lint-bash32.sh` is the black-box regression harness, wired through Makefile target `test-lint-bash32` and one `test-harnesses-N` shard. Because agent-lint does not follow Makefile-only script references, `agent-lint.toml` excludes both this linter and its harness.

Edit in sync with `BASH_AUTHORING.md` section "Bash 3.2 Portability", `.pre-commit-config.yaml`, `docs/linting.md`, `Makefile`, `scripts/test-lint-bash32.sh`, and any intentional fixture suppressions in existing portability guards.

## E3 residual scope

This check reads the residual Bash manifest through `python3 python/cli.py residual-bash paths --root "$ROOT"` or the equivalent root-local manifest read. The manifest covers kept hooks, linters, thin wrappers, `scripts/sleep-seconds.sh`, the combine-issues helper, manifest-listed includes when present, and residual harnesses. Terminal shared libraries and retired non-thin helpers are out of scope.
