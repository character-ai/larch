# scripts/test-anti-halt-banners.sh — contract

`scripts/test-anti-halt-banners.sh` is a freestanding regression harness (no primary `.sh` script) that asserts three contracts defined in `skills/shared/subskill-invocation.md` "Anti-halt continuation reminder": (A) the banner substring `**Anti-halt continuation reminder.**` appears in each orchestrator SKILL.md; (B) the same banner does NOT appear in any pure-delegator SKILL.md (the rule explicitly exempts them); (C) the micro-reminder substring `Continue after child returns` appears at least once in each orchestrator SKILL.md. Wired into `make lint` via the `test-anti-halt` Makefile target. The banner and micro-reminder substrings are fixed contract tokens — when editing the canonical wording in `skills/shared/subskill-invocation.md`, keep this harness in sync in the same PR.
