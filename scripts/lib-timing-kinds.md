# lib-timing-kinds.sh

`scripts/lib-timing-kinds.sh` exposes the canonical `TIMING_TASK_KINDS_ALLOWED` Bash array consumed by `scripts/timing-ledger.sh`.

The timing ledger accepts any kebab-case task kind matching its grammar, but emits a warning when the value is not listed here. That warning catches typo-class drift without dropping timing data. When adding a new `--timing-task-kind <kind>` call site under `skills/` or `scripts/launch-*`, update this allow-list in the same change; structural tests (including `scripts/test-design-structure.sh` Check 16 for dialectic retry kinds) pin parts of the pairing. The CI-fix launchers reserve `cursor-ci-fix`, `codex-ci-fix`, and `claude-ci-fix`. Claude review, voter, plan, decomp, phase-3, and dynamic-archetype scout roles have stable entries here so normal subprocess timing does not warn. `/design` Step **1d.5** brainstorm externals use `cursor-brainstorm` and `codex-brainstorm`. Generic Codex prompt dispatch through `scripts/launch-codex-exec.sh` records `codex-exec` unless the caller deliberately supplies a narrower task kind such as `codex-judge`. `skills/implement/scripts/generate-code-flow-diagram.sh` records `implement-code-flow`.

The waterfall dispatch (`dispatch-with-waterfall.sh`) constructs timing kinds as `${tool}-${phase}-${slot_name}` where `tool` is `codex`, `cursor`, or `claude`, `phase` is `phase1`, `phase2`, or `phase3`, and `slot_name` is the slot name from the panel manifest (e.g., `correctness`, `edge-cases`, `testing`). Phase-1 and phase-2 slots for the static specialist set are listed explicitly (`{cursor,codex}-phase{1,2}-{correctness,edge-cases,testing}`). Claude phase-3 fallback records `claude-phase3-<slot_name>` for static specialist slots and `claude-phase3-aggregator`. Dynamic archetype fallback slots (`dyn-*` prefix) produce `claude-phase3-dyn-*` kinds that intentionally remain warning-only, since their names are runtime-constructed. Timing kinds are clamped to the 64-char ledger grammar limit at the dispatch site.

`claude-plan-draft` is used by `scripts/launch-claude-drafter.sh` for `/design` Step 2b drafter subprocess timing rows.
