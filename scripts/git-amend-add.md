# scripts/git-amend-add.sh — contract

`scripts/git-amend-add.sh` wraps `git add <files>` followed by `git commit --amend --no-edit`. Folds the staged delta into the preceding commit without prompting for a message edit. It does not flush `/implement` larch logs; log commits are owned by the explicit pre-bump, external-implementer, and pre-push refresh points. Used by `/implement` Step 8a (folding `CHANGELOG.md` into the bump commit) and by the Rebase + Re-bump Sub-procedure step 4a. Per-script contract is short because the script has no business logic beyond invocation; the WHY (preserving the single-bump-on-HEAD invariant) lives in `skills/implement/SKILL.md` Step 8 and `skills/implement/references/rebase-rebump-subprocedure.md`.
