# scripts/test-collect-agent-retry.sh - contract

`scripts/test-collect-agent-retry.sh` is the regression harness for `scripts/collect-agent-results.sh` retry metadata deserialization (issue #1154). It creates synthetic empty reviewer outputs plus `.meta` sidecars and drives the real collector, which in turn launches the real `scripts/run-external-agent.sh` wrapper for retry. Case K is an exception: it sources the collector to invoke `build_missing_retry_sentinel_result` directly without launching a retry, because the production retry-phase wait (`max(30, max(ORIG_TIMEOUT+60))` per `scripts/collect-agent-results.md`) would otherwise add wall time to the harness scaling with the queued reviewer timeouts.

Cases: (A) valid `CMD_JSON` retries an empty output and returns `STATUS=OK` with `REVIEWER_FILE=*-retry.txt`; (B) malformed JSON fails closed; (B2) alphabetic `TIMEOUT=` fails closed; (B3) padded-zero `TIMEOUT=00` fails closed; (B4) missing `TIMEOUT=` fails closed; (C) stale legacy `CMD=`-only metadata fails closed with the narrow `missing CMD_JSON` reason (TOOL is present); (C2) both `CMD_JSON` and `TOOL` missing fails closed with the combined `missing CMD_JSON and TOOL` reason; (D) non-string array elements fail the `array of string` validator; (E) an argv element ending in `\n` survives the base64+sentinel decode path; (F) output retargeting swaps only the standalone output-path argv element and leaves prompt substrings unchanged; (G) when `/bin/bash` is older than 4.4, the happy retry path is re-run under that runtime as the macOS bash-3.2 portability guard; (H) mixed-batch — one candidate with malformed `CMD_JSON` plus one candidate with valid `CMD_JSON`, asserts the malformed entry retains its specific `FAILURE_REASON` and is not overwritten by the post-wait result-update loop's generic "sentinel file missing" message (regression guard for the `RETRY_LAUNCHED` per-`j` tracker); (I) retry helper exits with a non-zero code, asserts the result row carries `EXIT_CODE=<RETRY_EXIT>`, `STATUS=EMPTY_OUTPUT`, `HEALTHY=false`, and a `FAILURE_REASON` containing the wrapper's `Failed with exit code <N>` text — the regression guard for #1290 retry-failure exit-code propagation; (J) retry helper exits 0 but writes empty output, asserts the result row carries `EXIT_CODE=0`, `STATUS=EMPTY_OUTPUT`, `HEALTHY=false` — pins the documented sub-case from `scripts/collect-agent-results.md` that `EXIT_CODE=0` alone is not a success signal; (K) missing retry sentinel result construction via helper extraction; (L) malformed initial `.done` content `0|EXTRA` is coerced to `EXIT_CODE=99` without output-field injection; (M) oversized digit content is rejected before Bash arithmetic overflow; (N) empty-but-readable initial sentinel content is coerced to `99`; (O) numeric content above 255 is coerced to `99`; (P) coerced-99 with empty output plus a valid `.meta` retries via the empty-output recovery path instead of routing to `STATUS=FAILED`, because a corrupt or partially-written initial `.done` should not deny the one-shot retry the path was designed for; (P2) Cursor `CMD_JSON` with an injected `--add-dir /etc` fails the per-tool argv-shape allowlist; (P3) Codex's registered `codex exec ... -C ... --output-last-message ...` shape is accepted; (P3b) Gemini's `launch-review.sh --tool gemini ...` launcher-shaped `CMD_JSON` is accepted; (P4) unknown `TOOL=` values fail closed; (Q) valid `OUTER_LAUNCHER*` metadata retries through `launch-review.sh --tool cursor` and returns post-processed prose; (R) missing outer prompt/workdir keys fail closed; (S) `OUTER_LAUNCHER` containing `..` or canonicalizing away from the real launcher fails closed; (U) prompt-file path mismatch and symlink prompt sidecars fail closed; (V) valid outer metadata with deliberately broken `CMD_JSON` succeeds, pinning the branch-before-CMD_JSON ordering; (W) outer retry runs from `OUTER_LAUNCHER_WORKDIR`; (X) `..` in `OUTER_LAUNCHER` is rejected before retry output creation. Cases B/B2/B3/B4/C/C2/D/H/P2/P4 and the outer fail-closed cases also assert `EXIT_CODE=99` on fail-closed rows.

Retry-site malformed-`.done` coverage is intentionally deferred. The current Case K helper extraction covers the missing-sentinel row builder without launching a retry, but malformed retry sentinel content still requires either a future extraction around retry-failure row construction or a retry-wait refactor that makes the corrupted-`.done` branch cheap to exercise end-to-end.

Wired into `make lint` via the `test-collect-agent-retry` target and one `test-harnesses-N` shard. The harness is added to `agent-lint.toml`'s exclude array because it is a Makefile-only harness. Update this file with `scripts/collect-agent-results.sh`, `scripts/launch-review.sh --tool cursor`, `scripts/run-external-agent.sh`, `scripts/run-external-agent.md`, and `scripts/collect-agent-results.md` when changing the retry metadata format, fail-closed health behavior, outer-launcher retry path, or Bash 3.2 deserialization strategy.
