# normalize-oos-block-header.sh Contract

Shared helper that rewrites an accepted-OOS block's **first line only** to the canonical `### OOS_<seq>:` header (#3550). Args: `--seq N` (required non-negative integer) and optional `--block-file PATH` (reads stdin when omitted). The full block is emitted on stdout with line 1's leading `### <WORD>_<n>:` id token — legacy `### FINDING_N:` (tagged `[OUT_OF_SCOPE]` or scope-drift bare) or an existing `### OOS_N:` being renumbered — replaced by `### OOS_<seq>:`; the title text after the colon is preserved verbatim. The rewrite is a portable awk `sub()` under an `NR==1` guard — body lines are never matched, so cited `### FINDING_N:` headings inside Concern / Suggested-revision prose and unsplit aggregate tails pass through unchanged. A line 1 that carries no `### <WORD>_<n>:` token passes through unmodified. No GNU-only sed; Bash 3.2 / BSD safe.

Callers: `skills/review/scripts/tally-code-votes.sh` (accepted non-security OOS writes) and `skills/review-and-fix/scripts/review-and-fix.sh` (coder-`SKIPPED` OOS appends). Harness: `skills/shared/scripts/test-normalize-oos-block-header.sh` (`make test-normalize-oos-block-header`, `test-harnesses-9` shard).
