# test-plan-review-prompt.sh

Stub regression harness for `skills/design/scripts/render-plan-review-prompt.sh`. It renders all 4 archetypes across the 2 supported external vendors, checks the focus-area enum, `NO_ISSUES_FOUND` instruction, plan-file reference, vendor-style invariants, and invalid-argument exit-2 behavior.

Run with `make test-plan-review-prompt` or `bash skills/design/scripts/test-plan-review-prompt.sh`.
