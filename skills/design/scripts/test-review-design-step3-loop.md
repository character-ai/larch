# test-review-design-step3-loop.sh

Regression harness for `review-design-step3-loop.sh`, the script-internal `/design` Step 3 round loop. Coverage includes terminal envelopes, bail-outs, phase resume, postplan routing, dedup restore, CR/LF sanitization before envelope emission, omission of invalid multiline scope anchors, merge-fallback sanitization, omission of sanitized-empty merged continue reasons, and result-env write failures. The write-failure regression verifies a symlinked `.step3-review-result.env` preserves the already emitted operational status and records `phase_driver_write_result_env` in `execution-issues.md`. The primary contract lives in `review-design-step3-loop.md`; this file exists to satisfy the script sibling rule.
