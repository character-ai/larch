# skills/implement/scripts/test-post-design-boundary.sh — contract

`test-post-design-boundary.sh` is the skill-local integration harness for `skills/implement/scripts/post-design-boundary.sh`. It owns wrapper-only behavior; `scripts/test-implement-post-design-boundary.sh` owns the repo-root SKILL.md and reader-pin assertions.

Covered cases:
- Successful synthesized manifest: wrapper exits 0, re-emits `MANIFEST_OK=true`, captures `BRANCH=boundary-test` from a temporary git repo, emits `POST_DESIGN_BOUNDARY_OK=true`, writes `.boundary-gate-passed`, and ends with the default `➡️` imperative breadcrumb. Re-running the wrapper is idempotent.
- Missing manifest and invalid tmpdir: wrapper exits 0 with `MANIFEST_FAILED=true`, suppresses `POST_DESIGN_BOUNDARY_OK=true`, suppresses the imperative breadcrumb, and does not write `.boundary-gate-passed`.
- Boundary sentinel write failure: read-only tmpdir permissions force `ERROR=boundary-gate-sentinel-write-failed` with no success markers.
- Anchored reader-output parsing: an `IMPLEMENT_TMPDIR` path component containing `MANIFEST_FAILED=true` does not affect success classification when the reader emits anchored `MANIFEST_OK=true`.
- Health sidecar behavior: monotonic degradation rewrites session-env while preserving `REPO` and `REPO_UNAVAILABLE`; absent sidecar is a no-op with no warnings; malformed booleans warn and preserve prior values; `write-session-env.sh` failure warns and remains non-fatal.
- Branch capture: named branch emits `BRANCH=boundary-test`; persistent detached HEAD failure emits `MANIFEST_FAILED=true ERROR=branch-capture-failed` after retry and suppresses success output.
- Design-only mode emits the design-only `➡️` variant.
- Control-character path injection is rejected with `ERROR=invalid-tmpdir`.
- `--hook-mode true`: sentinel NOT written (`.boundary-gate-passed` absent), `POST_DESIGN_BOUNDARY_HOOK_INJECTED=true` emitted instead of `POST_DESIGN_BOUNDARY_OK=true`, `➡️` line begins with `hook injected boundary context`. Covers default variant and design-only variant. Stop hook still blocks (manifest present, sentinel absent) after hook-mode; once the orchestrator's wrapper call writes the sentinel (non-hook-mode), Stop hook allows.
- PostToolUse hook integration: synthetic `Skill` stdin for `design` resolves the cwd-bound tmpdir, reads `.design-only`, passes `--hook-mode true` to the wrapper, emits `hookSpecificOutput.additionalContext` with `POST_DESIGN_BOUNDARY_HOOK_INJECTED=true` (not the orchestrator success token), and does NOT write `.boundary-gate-passed`. Non-design Skill calls and no matching tmpdir emit empty stdout.
- Stop hook integration — design boundary: synthetic Stop stdin blocks only when `manifest.env` exists and neither `.boundary-gate-passed` nor `.run-cleaned-up` exists; `.boundary-gate-passed`, `.run-cleaned-up`, absent manifest, and `stop_hook_active=true` all allow stop with empty stdout. Concurrent-session fixtures prove `cwd` binds to the matching `.larch-keepalive` `CLONE_PATH` and fails open when no candidate matches. TTL/session fixtures prove stale tmpdirs are ignored when no session id is available, fresh tmpdirs still block, `LARCH_TOKEN_SESSION_ID` mismatches and missing keepalive `SESSION_ID=` lines disqualify candidates, exact session-id matches block and bypass TTL, and a missing `date +%s` rejects TTL-only candidates.
- Stop hook integration — review boundary (issue #1862): Stop stdin blocks on a tmpdir that has `review-round-summary.md` but no `design-export/manifest.env` and no `.review-boundary-passed` (covers both-externals-down path where `/design` is skipped); allows after `.review-boundary-passed` is written; allows after `.run-cleaned-up`; block reason text contains "post-/review boundary" and the tmpdir basename (not full path).
- Executable-bit assertions cover the wrapper and both hook entry points.

The harness synthesizes design manifests using the real `skills/design/scripts/read-design-manifest.sh` contract and uses real temporary git repositories for branch behavior. The `write-session-env.sh` auxiliary-failure case uses a temporary plugin-root shim for only that helper while symlinking the real manifest reader and branch helper.
