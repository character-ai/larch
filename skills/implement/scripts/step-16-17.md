# step-16-17.sh

Composed Step 16 through Step 17 wrapper. It runs rejected-findings replay, the best-effort Slack announce, the final report render, and the marker body handoff for `skills/implement/SKILL.md`.

## Caller

`skills/implement/SKILL.md` invokes this wrapper once for `/implement` Step 16, Step 16a, and Step 17.

## Sequence

1. Run `step-16.sh` for rejected findings.
2. Run `python/cli.py slack issue-announce --best-effort` and capture stdout/stderr.
3. Append Slack `STATUS=failed` output to `Warnings` with `run-log append-failure --redact`.
4. Run `step-17.sh --no-print-stdout`.
5. Print the final summary body between marker lines when the marker gate passes.

## Exit semantics

The wrapper exits `0` for all best-effort Step 16, Slack, Warnings append, and Step 17 failure paths. Only unrecoverable setup faults, such as missing `IMPLEMENT_TMPDIR` or an unreadable plugin root, may exit non-zero.

## Errexit policy

Setup uses `set -euo pipefail`. The best-effort chain switches to `set +e` before Step 16 so rejected-findings, Slack, Warnings append, and Step 17 failures cannot abort the chain before marker emission is attempted.

## Marker gate

Markers print only when the captured `STEP17_RC=0` and `$IMPLEMENT_TMPDIR/summary-final.md` is non-empty. A non-zero Step 17 rc suppresses markers even when a stale non-empty summary remains from an earlier render.

Marker grammar uses whole-line markers:

- `---LARCH-SUMMARY-FINAL-BEGIN---`
- `---LARCH-SUMMARY-FINAL-END---`

The body between the markers may contain arbitrary markdown.

## Sentinel ownership

The wrapper writes `$IMPLEMENT_TMPDIR/.step17-printed` only after it prints a non-empty marker body. The orchestrator writes `$IMPLEMENT_TMPDIR/.step17-emitted` only after emitting that body as top-level chat markdown.

## Failure behavior

Step 16 remains best-effort. Slack skipped output continues silently. Slack failed output is appended to `Warnings` with `--redact`. Step 17 non-zero `final-report write` output is appended to `Tool Failures` inside `step-17.sh` before any `--no-print-stdout` handoff exit `0`.
