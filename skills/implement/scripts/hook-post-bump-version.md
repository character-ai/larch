# skills/implement/scripts/hook-post-bump-version.sh — contract

`hook-post-bump-version.sh` is the plugin-shipped `PostToolUse` hook registered for the `Skill` tool alongside `hook-post-design.sh`. It reads Claude Code hook JSON on stdin, fires only when `tool_name` is `Skill` and `tool_input.skill` or `tool_input.skill_name` is `bump-version` or `larch:bump-version`, and resolves the active `/implement` tmpdir through `lib-resolve-implement-tmpdir.sh` using the stdin `cwd` field.

When `$IMPLEMENT_TMPDIR/.bump-version-armed` exists (written by `check-bump-version.sh --mode pre` inside the Rebase + Re-bump Sub-procedure step 4) AND `$IMPLEMENT_TMPDIR/postbump-state.sh` does NOT yet exist (i.e., the orchestrator has not finished the post-bump continuation), the hook emits a continuation `➡️` directive into `hookSpecificOutput.additionalContext`. The directive tells the orchestrator that `APPLIED=true COMMIT_SHA=<sha>` is NOT a run-completion signal and that `check-bump-version.sh --mode post --before-count $COMMITS_BEFORE` is the FIRST permitted next Bash tool call. The hook is a mechanical backstop for issue #2338, parallel to the directive-injection role of `hook-post-design.sh` for the post-`/design` boundary; the Stop-hook block in `hook-stop-fail-close.sh` remains the session-stop safety net.

Stdout is either empty or a JSON object with `hookSpecificOutput.hookEventName="PostToolUse"` and `hookSpecificOutput.additionalContext` carrying the directive. Exit code is always 0; non-`bump-version` Skill calls, missing `jq`, malformed stdin, no qualifying tmpdir, missing `.bump-version-armed` sentinel, or already-written `postbump-state.sh` are fail-open no-ops. The hook does NOT write or clear any sentinel file — its only side effect is the directive emission.

Edit in sync with `lib-resolve-implement-tmpdir.sh`, `hook-stop-fail-close.sh` (the paired session-stop block keyed on the same `.bump-version-armed` / `postbump-state.sh` sentinels), `hooks/hooks.json` (registration entry), `skills/implement/SKILL.md` (NEVER #15), `skills/implement/references/rebase-rebump-subprocedure.md` (step 4 "Continue after child returns" anti-halt reminder), and `scripts/test-implement-anti-halt.sh` (regression coverage).
