# test-call-fixer.sh Contract

Regression harness skeleton for `skills/review-and-fix/scripts/call-fixer.sh`.

It verifies structured extraction for a safe repo-relative path, rejection of `..` paths, and applied/skipped status marking.

Run with `bash skills/review-and-fix/scripts/test-call-fixer.sh` or `make test-call-fixer`.
