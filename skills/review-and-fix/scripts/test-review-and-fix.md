# test-review-and-fix.sh Contract

Regression harness skeleton for `skills/review-and-fix/scripts/review-and-fix.sh`.

It verifies the no-findings status, accepted finding ID enumeration, `FIX_COUNT`, and per-finding structured fixer env files.

Run with `bash skills/review-and-fix/scripts/test-review-and-fix.sh` or `make test-review-and-fix`.
